# 民用机场飞行区技术标准 MH5001-2021（含修订案）

一个 Agent Skills / WorkBuddy 技能，把《民用机场飞行区技术标准 MH 5001-2021》主文 + 第一~第四修订案整理为可检索的知识库。所有内容以修订案为准，被修正的原文标记为失效。

## 内容

- 12 章摘要：`chapters/ch01-总则.md` … `ch12-标示障碍物的目视助航设施.md`
- `glossary.md` 术语表（含 PCR/ACR）
- `patterns.md` 评价流程（ACR-PCR 道面强度等）
- `cheatsheet.md` 决策规则速查
- `amendments.md` 四份修订案 clause-level 覆盖登记（权威依据）

## 安装（WorkBuddy）

把本仓库克隆/解压后，将 `mh5001-2021-flight-area-standard/` 文件夹放入技能目录：

- Windows：`C:\Users\<用户名>\.workbuddy\skills\`
- macOS / Linux：`~/.workbuddy/skills/`

重启 WorkBuddy 会话即可在技能列表中看到「民用机场飞行区技术标准 MH5001-2021」，然后用中文提问，例如：

- `SMGCS 是什么`
- `道基强度的高强度 E 值是多少`
- `4.12.2 跑道等待位置怎么设`
- `修订案覆盖哪些条款`

## 修订案要点

| 修订案 | 覆盖要点 |
|---|---|
| 第一 | PCN/ACN → PCR/ACR；§3.6 整节重写（表 3.6.3、超载规则） |
| 第二 | 新增 1.0.4 SMGCS、2.1.83 术语、2.3 缩略语 |
| 第三 | 表 3.6.3 道基强度 E 值改 ≥/< 区间；轻型航空器 ≤5700kg |
| 第四 | 4.12.2 跑道等待位置；6.2.8 增强型滑行道中线；6.2.12 NO ENTRY；8.4.7 跑道脱离标记牌 |

> 具体量值（跑道宽度、限制面坡度、灯光光强等）以正本条款/附录为准，本技能负责条款定位与修订案追踪。
