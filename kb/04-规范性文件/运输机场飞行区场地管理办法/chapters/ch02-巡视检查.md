# 第二章 巡视检查

## Core Idea
本模块的**运行核心章**：规定巡视检查的分类、频次、内容、平整度标准，以及**发现损坏后的分级处置与通报**。

## Key Clauses（第十二~三十二条）

**方案与分类**
- **第十三条** 巡视检查方案至少含：类型/频次/时间/标准/方式/方法/流程；跑道滑行道通报程序；与管制员的标准用语与对讲机波道；紧急情况应急处置程序。
- **第十四条** 铺筑面巡视检查 = **每日全面巡视检查（首次 + 中间动态）+ 定期全面步行检查**。

**每日全面巡视检查（第十五~十七条）**
- **第十五条**
  - 跑道**首次**：全宽度详细检查；全天开放机场**早高峰前**完成；按航班/申请开放的机场**首个航班计划时刻前 30 分钟**完成。
  - 跑道**中间动态**：至少含跑道边灯以内区域；**每条跑道日架次（不含通航训练）≥15（含）→ 不少于 3 次；<15 → 不少于 1 次**；安排在高峰/高温时段；配备探测设备且合格运行满 1 年的区域可适当减少。
  - **滑行道**（含机坪滑行道、机位滑行通道）：首次同跑道要求；中间动态 ≥1 次；大型繁忙机场位于跑道地面保护区范围内的滑行道可用视频/瞭望方式。
  - **机坪其他区域**：一般 ≥2 次。
  - 道面损坏加剧或雨后连续高温 → 适当增加中间动态次数。
- **第十六条** 每日全面内容：道面清洁（外来物、油污）、道面损坏（板块破损/拱起/错台）、井盖完好与密合。
- **第十七条** 发现灯具损坏/道面标志不清 → 立即通报**目视助航设施维护部门**；影响飞行安全 → 立即通报管制员，必要时向情报机构提供原始资料。

**定期全面步行检查（第十八~十九条）**
- **第十八条** **每季度 ≥1 次，最大间隔 ≤4 个月**；破损较多/加剧 → 增加次数。
- **第十九条** 内容：嵌缝料失效、道面损坏位置/数量/类型统计、道面与相邻土面区高差、接地带橡胶沉积、道面清洁。

**土面区与其他区域（第二十~二十六条）**
- **第二十条** 升降带、跑道端安全区、滑行带内土面区（含防吹坪）**每日 1 次**；内容：草高、危及安全的物体、平整度（含灯/井基座高差）、气流侵蚀、跑道端外接地过早痕迹、**EMAS 拦阻系统**完好情况。
- **第二十一条** 会同驻场单位确保升降带平整区、RESA、滑行带、净空道内设施设备的**易折性及高度符合 MH5001**；保存易折性证明（厂家或专业机构检测报告）。
- **第二十二条** 雨季前 ≥1 次排水设施全面检查（积水/淤塞/漏水/破损）；暴雨随时巡查；雨后检查高差、升降带与 RESA，标记并处理积水冲沟。
- **第二十三条** 大风等不利天气增加检查；影响运行 → 通报管制员，必要时提供原始资料。
- **第二十四条** 不停航施工/维护作业等结束后检查相关区域。
- **第二十五条** **应急巡视检查** 3 情形：① 机组/管制员通报事件或异常后；② 应急救援响应结束或残损航空器搬移结束后；③ 地震等地质灾害后。
- **第二十六条** 场地与目视助航设施的巡视检查应**尽可能联合开展**。

**作业要求与平整度标准（第二十七~二十八条）**
- **第二十七条** 每次跑道/滑行道巡视 **≥2 人**（含至少 1 名场务员），**车速 ≤45 km/h**；穿反光背心/外套；通信设备按跑道侵入防范规定。
- **第二十八条（平整度）**
  | 部位 | 标准 |
  |---|---|
  | 水泥混凝土道面 | 3 m 内高差 ≤10 mm；板块接缝错台 ≤5 mm |
  | 沥青混凝土道面 | 3 m 内高差 ≤15 mm |
  | 水泥-沥青道面接缝 | 错台 ≤3 mm；3 m 内高差 ≤5 mm |
  | 升降带平整区 / RESA | 三米直尺高差 ≤5 cm，无积水、无反坡 |
  | 与道面边缘相接的土面 | 不得高于道面边缘，且不得低于道面边缘 3 cm |

**损坏分级处置（第二十九~三十二条）**
- **第二十九条 立即通报塔台暂停起降**（并报原始资料）：① 水泥混凝土道面断裂（错台或局部松动）；② 未断裂但**错台 ≥5 mm**；③ 掉块**长边 ≥12 cm**；④ 掉块 <12 cm 但**深 ≥7 cm** 或**坡 ≥45°**；⑤ 沉陷或导致平整度不符的沉降。跑道两端出现上述破损但其余部分可用 → 应会同空管、航司制定**非全跑道起飞运行工作程序**。
- **第三十条** 需处理但暂不影响安全（不松动断裂 / 错台 <5 mm / 掉块 <12 cm 且深 <7 cm 坡 <45°）→ 报告并**增加检查频次**。
- **第三十一条** 巡视后向管制员通报跑道/滑行道适用性，并将起止时间、检查人、场地及处置情况记入**检查日志**。
- **第三十二条** 实施**低能见度程序运行时，不得对跑道、滑行道进行常规巡视检查**。

## Thresholds
| 项 | 值 |
|---|---|
| 跑道首次巡视 | 首个航班计划时刻前 30 分钟 |
| 跑道中间动态 | 日架次 ≥15 → ≥3 次；<15 → ≥1 次 |
| 定期步行检查 | 每季度 ≥1 次，间隔 ≤4 个月 |
| 升降带/RESA/滑行带土面区 | 每日 1 次 |
| 巡视人数 / 车速 | ≥2 人（含 1 场务员）/ ≤45 km/h |
| 暂停起降（错台） | ≥5 mm |
| 暂停起降（掉块） | 长边 ≥12 cm；或 <12 cm 但深 ≥7 cm / 坡 ≥45° |
| 水泥道面 3 m 高差 | ≤10 mm |
| 沥青道面 3 m 高差 | ≤15 mm |
