# 运输机场飞行区场地管理办法

- **文号**：民航规〔2024〕3号
- **类别**：04-规范性文件
- **发布/实施**：2024-02-01 施行
- **状态**：现行（废止原 民航规〔2022〕9号）
- **入库日期**：2026-09-21
- **源文件**：运输机场飞行区场地管理办法（民航规〔2024〕3 号）.pdf

## 覆盖范围
聚焦**飞行区场地（道面 / 土面区 / 排水）的管理、巡视检查与维护**，共 5 章 45 条 + 2 个附件：

1. **基本要求**：适用范围、责任、场务员配置与培训、制度、道面编号、定期评估
2. **巡视检查**：每日全面（首次+中间动态）与定期步行检查的频次/内容/平整度标准，损坏分级处置与通报
3. **场地维护**：维护方案、差异化维护、抢修/维护时限、除胶、嵌缝、土面区压实、植草、排水
4. **监督检查**：局方年度行政检查与被检查方整改义务
5. **附则**：解释权、施行日期与旧规废止
- **附件 1**：运输机场场务员单班在岗人员最低配置标准
- **附件 2**：飞行区场地管理业务培训大纲

## 交叉引用
- **本库内**：
  - 第四条、第二十一条 → 引用 **MH5001-2021**（道面物理特性、升降带/RESA/滑行带/净空道设施易折性与高度）
  - 与 **CCAR-139B《运输机场运行安全管理规定》** 高度重叠并互为细化：CCAR-139B 第四十~五十九条为总纲式规定，本办法为其**操作性细化**（巡视频次、平整度、损坏阈值、除胶、压实、培训、人员配置）
- **外部**：依据《运输机场使用许可规定》《运输机场运行安全管理规定》；参照 ICAO《空中航行服务程序—机场》（PANS-Aerodromes）

## 关键条款索引
| 条款 | 要点 |
|---|---|
| 第四条 | 物理特性/有限超载须符合 MH5001；超载须运营人同意 |
| 第五条 / 附件1 | 场务员三工种 + 单班在岗最低配置 |
| 第六条 / 附件2 | 培训须符合大纲（初始 16+/24+/24+ 学时；复训 ≤1 年、≥8 学时） |
| 第九条 | 每 5 年至少 1 次道面综合评价 |
| 第十五条 | 每日巡视频次（跑道中间动态：日架次 ≥15→≥3 次） |
| 第十八条 | 定期步行检查每季度 ≥1 次、间隔 ≤4 个月 |
| 第二十七条 | 巡视 ≥2 人（含 1 场务员）、车速 ≤45 km/h |
| 第二十八条 | 平整度/错台限值（水泥 3m≤10mm、错台≤5mm；沥青 3m≤15mm） |
| 第二十九条 | 立即暂停起降的损坏情形（错台≥5mm、掉块长边≥12cm 等） |
| 第三十五条 | 严重损坏立即抢修、轻微 24h 内维护 |
| 第三十九条 | 土面区密实度 ≥87%（重型击实法），每年 ≥2 次 |
| 第四十五条 | 2024-02-01 施行；废止 民航规〔2022〕9号 |
