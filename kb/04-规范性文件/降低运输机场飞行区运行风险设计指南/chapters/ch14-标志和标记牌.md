# 第14章 标志和标记牌

## Core Idea
本章是**全书的收口章节**：当平面构型无法优化时，用**地面信息标志**强化主运行方向的目视引导。四条禁令式要求：**避免遮挡、避免过于密集、避免单块信息过于复杂、避免标志不易判断**。技术要点：标记牌可**旋转 15°**（双面牌可拆为两个单面牌）、跑道侧方**喷涂内过渡面范围**、仅靠信息标志引导的区域**宜用反光涂料**、**"APRON"目的地标记牌通常无须设置**。

## Key Clauses
- **14.1 合理设置原则**：标志及标记牌位置，在满足 **MH5001** 要求的同时，应结合实际运行需求合理设置：
  - 尽可能避免**标记牌之间存在遮挡**；
  - 避免一定区域内**标记牌过于密集**；
  - 避免单块标记牌**信息过于复杂**；
  - 避免**标志不易判断**。
- **14.2 无法安装/不易判读时补充地面信息标志**：对于现有机场**平面构型比较复杂**，确实无法安装标记牌，或即便安装了标记牌也不易于飞行员判读、容易造成混淆的，**应当补充地面信息标志**。
  - 补充的地面信息标志，应当以**强化主运行方向的目视引导**为主要考量。
- **14.3 标记牌旋转 15°**：当标记牌位置导致牌面信息**对其它滑行道上的飞机造成混淆**时，可将标记牌**旋转 15°**；如为**双面标记牌**，可将其**拆分为两个单面牌**并旋转角度。
- **14.4 明确内过渡面范围**：在**跑道侧方**应通过**喷涂标志**等方式，明确**内过渡面**的范围：
  - 方便**土面区施工作业**；
  - 防止土面区作业**车辆和人员侵入跑道**。
- **14.5 反光涂料**：在**未设置滑行道中线灯和标记牌、仅靠信息标志引导**的滑行道区域，标志划设材料**宜考虑反光涂料**，以提高标志可辨识度。
- **14.6 "APRON"目的地标记牌通常无须设置**：通常**无须设置 "APRON" 目的地标记牌**——增加建设和维护成本，但对运行并没有意义。
- **14.7 例外情形**：**有多块不同用途机坪的小型民用机场**，或需要**区分军航、民航停机坪或货机坪**的军民合用机场，**不设置此标记牌容易引起混淆、不易判断机坪位置时**，方可考虑设置。
- **14.8 防止杂草遮挡**：应采取适当措施，**避免杂草遮挡标记牌**。

## Reference — 关键数值与规则（本章）
| 项 | 值 |
|---|---|
| 标记牌旋转角度（避免混淆） | **15°** |
| 双面标记牌 | 可拆分为**两个单面牌**并旋转 |
| 仅靠信息标志引导区域 | 宜用**反光涂料** |
| "APRON" 目的地标记牌 | **通常无须设置**（例外见 14.7） |
| 跑道侧方 | 喷涂**内过渡面范围**标志 |
