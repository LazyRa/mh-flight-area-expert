# 第15章 山区或水域进近灯光系统建设

## Core Idea
非精密进近或 **Ⅰ类精密进近**跑道的进近灯光若位于**山区或邻近水域**，须对**填方方案、单灯单塔方案、桥梁方案**充分比选。采用桥梁时，比选重点不是"最大跨径"，而是**全寿命经济性 + 维护便捷性**：避免桥面以上过高支柱（风摆大、高空作业风险高）、避免墩顶桁架用钢量过大导致重心偏高、避免桥跨过小导致下部结构过多。

## Key Clauses
- **15.1 方案比选**：**非精密进近跑道或Ⅰ类精密进近跑道**，进近灯光位于**山区或邻近水域**时，应当对**填方方案、单灯单塔方案以及桥梁方案**进行充分比选。
  - 采用**桥梁形式**建设时，应对**桥型选择、桥型布置、上部结构、下部结构**等进行深入比选论证，以最大程度**减小对生态环境和既有设施的影响**、降低实施难度、减少工程造价、提高维护便捷性、降低养护成本。
- **15.2 桥梁设计原则与荷载**：进近灯光桥梁方案应本着**安全、合理、经济、适用、耐久、美观**的原则，进行桥梁总体布置和结构设计。
  - **山区桥梁**：应考虑所处外部环境，参考现行国标及《**公路桥梁抗风设计规范**》《**公路桥梁抗震设计规范**》等，合理设置**设计基准期、人群荷载标准值、风荷载标准值、雪荷载及裹冰荷载、抗震类别**等。
  - **滨水滨海桥梁**：还应考虑**波浪力、浮托力、腐蚀防护**等设计要求。
  - **荷载组合**：应充分考虑结构的**永久作用、可变作用、偶然作用和地震作用**，按**极限状态法**进行荷载组合并分析验算。
- **15.3 支柱高度与维护便捷性**：根据 **MH5001 7.1.4** 条款，进近灯的**支柱高度**应当充分考虑**维修、养护的便捷性**；避免**桥面以上过高支柱**，带来**灯光风摆较大、高空作业风险较高**等问题。
- **15.4 经济性比选而非追求最大跨径**：在满足结构安全前提下，应加强**不同桥型布置的经济性比选**，而非追求**最大跨径**。
  - **咨询评审单位应当组织**对推荐方案进行**复核验算**，并进行**专题评审**；
  - 避免出现不合理结构或未充分发挥梁桥跨越能力的结构，如：**墩顶桁架用钢量过大导致重心偏高**，或**桥跨过小导致下部结构过多**。
- **15.5 边跨悬臂**：桥梁总体设计时，结合地形特点，可考虑通过设置**边跨悬臂**，减少**高桥墩**设置，以减少用钢量或避免拆迁、改线。
  - 但**悬臂长度及悬臂根部杆件的稳定及疲劳效应**，应当予以**特别关注并加强分析**。

## Reference — 方案与要点速查（本章）
| 项 | 要点 |
|---|---|
| 适用跑道 | 非精密进近 / **Ⅰ类精密进近**跑道 |
| 适用场景 | 进近灯光位于**山区或邻近水域** |
| 必比选方案 | 填方 / 单灯单塔 / 桥梁 |
