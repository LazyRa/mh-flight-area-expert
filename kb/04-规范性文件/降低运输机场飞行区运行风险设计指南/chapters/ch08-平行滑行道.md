# 第8章 平行滑行道

## Core Idea
平行滑行道**在跑道端以外继续延伸**会让飞行员把延伸段误当成平滑的一部分，产生误滑。设计原则：**跑道端以外不宜设计与平滑直通的滑行道**；确有需要时，采用"确保平滑不再继续延伸"的构型。现状已存在的，须在**航行资料中公布说明**并采取补救措施。

## Key Clauses
- **8.1 不宜直通延伸**：跑道端以外，**不宜设计与平行滑行道直通的滑行道**。
  - **风险机理**：平行滑行道到达跑道端外后继续延伸，容易使飞行员将延伸部分当成平滑的一部分，而产生误滑。
- **8.2 确需设置时的构型**：确有需要在跑道端外设计与平滑相连的滑行道时，应采用**确保平滑不再继续延伸**的设计（即在连接处形成明确终止，而非平滑直接贯通）。
- **8.3 现状机场的处置**：跑道端以外有与平滑直通的滑行道时：
  - **应当在公布的航行资料中公布并予以适当说明**；
  - 结合运行需求研究分析，可采取以下优化措施：
    1. **补充地面信息标志**，也可考虑补充设置**跑道目的地标记牌**，以强化主运行方向上的目视引导；
    2. **设置停止排灯**；
    3. 如果相连部分滑行道**仅供内部使用、使用频次特别低**，可考虑设置**禁止进入标记牌、禁止进入排灯、强制性指令标志**等。

## Reference — 处置措施速查（本章）
| 情形 | 措施 |
|---|---|
| 新建 | 跑道端外**不宜**与平滑直通；确需时确保平滑**不再延伸** |
| 现状已存在 | 航行资料**公布说明** + 以下措施之一/组合 |
| 措施 1 | 补充地面信息标志 / 跑道目的地标记牌 |
| 措施 2 | 设置停止排灯 |
| 措施 3 | 内部低频使用时：禁止进入标记牌 + 禁止进入排灯 + 强制性指令标志 |
