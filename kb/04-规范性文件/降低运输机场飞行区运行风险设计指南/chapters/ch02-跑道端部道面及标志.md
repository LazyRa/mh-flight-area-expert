# 第2章 跑道端部道面及标志

## Core Idea
跑道端部最常见的风险是**新建端联络道后原掉头坪增补面残留**，导致道面过宽、标志施划不全、旧灯旧标志与新设施混杂，飞行员可能**把跑道边线（灯）误当跑道中线（灯）**。处置要点：补齐跑滑边线 + 道肩标志，**移除原掉头坪灯和标志**，多余道面可涂绿。

## Key Clauses
- **2.1 掉头坪增补面残留处置**：原跑道端设有掉头坪、新建端联络道后原掉头坪增补面仍存在，使跑道端部道面过宽时：
  - 应**合理调整跑道边线标志**；
  - **补齐增补面区域内的滑行道边线标志和道肩标志**；
  - **移除原掉头坪灯和掉头坪标志**；
  - 道肩宽度以外的道面**可涂刷成绿色**。
  - **风险机理**：① 未将跑滑边线施划齐全 → 飞行员由端联络道进入跑道起飞时，可能误将**跑道边线（灯）当作跑道中线（灯）**；② 原掉头坪灯光、标志未去除 → 与新建端联络道灯光标志混在一起，跑道端灯光标志过于复杂，容易混淆。
- **2.2 不供运输航班使用的端联络道**：按 MH5001 相关规定设计，**可将掉头坪标志与滑行道中线标志合并设置**，使跑道端部道面标志更简洁。
- **2.3 交叉处须为连续实线**：掉头坪标志、滑行道中线标志与**跑道号码、跑道入口、跑道边线标志**相交时，其标志线**应当为连续的实线**。
  - **注（宽度对比）**：跑道入口标志宽约 **1.8 m**，跑道中线标志宽约 **0.9 m**，掉头坪标志宽仅 **0.15 m**。宽度相差悬殊 → 掉头坪标志对飞行员空中识别跑道入口、对正跑道中线**没有影响**，但对**掉头滑行引导尤为重要**，因此必须连续。
- **2.4 接地带标志块对数**：可用着陆距离或两端入口间距离 **≥2400 m** 时，接地带标志块对数应为 **6**（**含瞄准点标志**）。
  - 若瞄准点标志与前后两对接地带标志的距离**均小于 50 m**，可省略**与瞄准点标志较近**的接地带标志，**保留较远（但仍 <50 m）** 的那一对，保证接地带标志与瞄准点标志的**对数总和为 6**。
- **2.5 冬季除冰雪机场的灯具选型**：冬季除冰雪需求较大的机场，**跑道入口和末端灯应采用嵌入式灯具**，便于除冰雪作业。
