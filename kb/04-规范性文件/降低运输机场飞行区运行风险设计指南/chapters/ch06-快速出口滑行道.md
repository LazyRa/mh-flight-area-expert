# 第6章 快速出口滑行道

## Core Idea
快滑的三条设计红线：**① 脱离后方向选择不宜超过 3 个**（否则标记牌信息复杂、大雾雨雪下误滑风险大增）；**② 数量须经需求论证**（不是越多越好，过多反而增加误滑与跑道侵入风险、抬高造价）；**③ 不得与入口/垂直出口/穿越滑行道交叉重叠**（否则强制性指令标记牌、位置标记牌、跑道警戒灯无法两侧按标准安装）。

## 6.1 简化脱离区域的滑行道布局
- **6.1.1 方向选择不超过 3 个**：快滑出口的设置，**不宜使飞行员在脱离跑道后面临 3 个以上的方向选择**。
  - **风险机理**：方向多达 5 个时，标记牌信息复杂，有的只能设在右侧，有的应设却难以设置 → 飞行员短时间内难以准确识别路由，**大雾、雨雪等视线不佳时误滑风险大大增加**。
- **6.1.2 减少滑行道口**：脱离区域设计应加强研究，结合滑行路线规划，在满足主要运行需求前提下**尽量减少滑行道口**；**优先考虑设置单向滑行路线**，简化地面滑行。
- **6.1.3 道口较多时的补救措施**：
  - 根据运行需求**补充优化地面信息标志**，强化**主运行方向**的目视引导；
  - **移除不必要的滑行道中线标志**；
  - **拆除或关闭不必要的滑行道中线灯具**。
  - 案例效果：取消机坪滑行道与快滑之间的直接联通、取消右转联通后，快滑出来的**方向选择由 5 个降为 3 个**。
- **6.1.4 两条快滑距离较近时**：应适当**缩小跑道出口标记牌与所指向滑行道与跑道相交切点的距离**，以避免指向混淆（即标记牌位置向后调整）。

## 6.2 优化快速出口滑行道数量
- **6.2.1 需求论证**：设计时应加强需求分析论证，综合考虑**起降架次、机型组合、着陆性能**等因素；在保障**跑道占用时间、跑道容量**满足需求的前提下，合理设置位置和数量，减少运行维护复杂度、降低投资成本、降低误滑及跑道侵入风险。
- **6.2.2 两侧均有航站区/货运区时**：应当针对**两侧不同需求**设计相应的出口滑行道。
  - 反例：跑道两侧设置快滑过多（如两条跑道各 12 条快滑），不仅**利用率低、建设成本高、铺筑面积大**，还**增加误滑及跑道侵入风险**。
- **6.2.3 尺寸一致性**：同一跑道所有快速出口滑行道的**尺寸、增补面、道面强度**，原则上应**一致**，便于飞行员自主选择脱离。

## 6.3 避免与入口、垂直出口或穿越滑行道交叉
- **6.3.1 间距要求**：应当避免快滑与**入口滑行道、垂直出口滑行道或穿越滑行道**交叉重叠；两者之间应提供**足够的道面间距**，确保不影响目视助航设施的设置。
- **6.3.2 交叉重叠的后果**：造成铺筑面过大 → 入口或穿越滑行道**跑道等待位置处的强制性指令标记牌、位置标记牌、跑道警戒灯等，无法按有关技术在滑行道两侧都安装** → 给飞行员判读带来困难，增加误滑和跑道侵入风险。
  - **高频场景**：中小型机场或**军民合用机场改扩建**中，现有（或军用）**垂直联络道**与规划快滑位置重叠或距离较近。
- **6.3.3 改扩建处置**：若新增快滑与原**垂直出口滑行道**存在交叉、脱离跑道标记牌难以设置、飞行员不易识别，**应当拆除原垂直出口滑行道**。

## Reference — 关键数值（本章）
| 项 | 值 |
|---|---|
| 脱离后方向选择 | 不宜 **>3 个** |
| 同一跑道各快滑的尺寸/增补面/道面强度 | 原则上**一致** |
| 快滑与入口/垂直出口/穿越滑行道 | **不得交叉重叠**，须留足够道面间距 |
| 改扩建遇原垂直出口滑行道交叉 | **拆除**原垂直出口滑行道 |
