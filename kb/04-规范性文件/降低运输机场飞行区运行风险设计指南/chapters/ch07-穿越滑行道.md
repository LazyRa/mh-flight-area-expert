# 第7章 穿越滑行道

## Core Idea
跑道中部的穿越滑行道位于**"高能量区"**——起飞航空器此时能量大，既难以中断起飞停住，也尚未达到起飞速度避让，一旦侵入后果极严重。因此**尽可能避免在跑道中部设穿越道**；无法避免时必须配**停止排灯/跑道状态灯**并明确**使用时段与规则**。构型上：**必须直线**，**禁止"Y"形**，穿越两条近距跑道**不宜"Z"形**。

## Key Clauses
- **7.1 避免设在跑道中部**：尽可能避免在跑道中部设置穿越滑行道。
  - **"高能量区"定义**：起飞航空器在跑道中部能量较大，**既难以中断起飞停住，也尚未达到起飞速度**以避免与侵入跑道的航空器或车辆相撞。一旦发生穿越飞机侵入跑道事件，可能导致极其严重的后果。
- **7.2 中部穿越道的强制措施**：位于跑道中部位置的穿越滑行道，应当考虑设置**停止排灯、跑道状态灯**等防止跑道侵入措施，并**特别明确穿越滑行道可使用的时段与使用规则**，避免穿越飞机与起降飞机产生冲突。
- **7.3 构型要求**：
  - 穿越滑行道应当设计为**直线**，**避免在穿越跑道后分成两条滑行道**；
  - **禁止在穿越跑道后形成"Y"形**，否则将增大跑道侵入风险；
  - 有穿越**两条近距跑道**的运行需求时，穿越道**不宜设计为"Z"形**。
- **7.4 避免密集交叉**：应当尽量避免多条滑行道密集交叉而出现**过多的道口**。
  - 风险：飞行员在此区域滑行时**方向选择过多、标记牌信息复杂**，容易造成混淆、不易决断，进而引发误滑。
- **7.5 现状补救**：现状机场由于各种原因难以避免多条滑行道密集交叉时，**可补充完善地面信息标志**。

## Reference — 构型禁令速查（本章）
| 情形 | 要求 |
|---|---|
| 跑道中部设穿越滑行道 | 尽可能**避免**；无法避免须配停止排灯/跑道状态灯 + 明确使用时段与规则 |
| 穿越后分成两条 | **避免** |
| 穿越后形成"Y"形 | **禁止** |
| 穿越两条近距跑道形成"Z"形 | **不宜** |
| 多条滑行道密集交叉 | 避免；现状可补充地面信息标志 |
