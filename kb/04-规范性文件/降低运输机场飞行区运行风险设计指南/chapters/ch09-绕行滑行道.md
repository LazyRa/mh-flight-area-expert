# 第9章 绕行滑行道

## Core Idea
绕行滑行道**不是有平行跑道就得建的标配**，而是**个别超级繁忙机场**才需要考虑的设施。它带来四类代价：**误滑风险、占地与造价、滑行时间与旅客体验、跑道入口内移缩短可用着陆距离**。决策须**深入论证**，并充分考虑**跑道状态灯等新技术**的替代作用；建成后也应**与穿越道灵活配合使用**，不宜无论繁忙与否都绕行。

## Key Clauses
- **9.1 避免千篇一律**：绕行滑行道是个别超级繁忙机场才需要考虑建设的设施，而不是设有平行跑道的机场都需要建设，应当**避免千篇一律地设计绕行滑行道**。
  - **四类问题**：
    1. 绕行滑行道与平滑相连，有**误滑风险**；
    2. **占地面积大**，个别还需设置**目视遮蔽物**，建设成本高；
    3. 使用绕滑的航班**滑行时间长，旅客体验差**；
    4. 为尽量缩短滑行距离，导致**部分跑道入口内移**，**缩短了可用着陆距离**。
- **9.2 论证要求**：是否设计绕行滑行道，要结合**机场功能区布局和航空业务量预测**，统筹**安全与效率、容量**的关系，并**充分考虑跑道状态灯等新设备、新技术的应用**，深入论证。
- **9.3 确需建设时**：应统筹考虑**机场机型组合、场地条件、工程投资**等因素，合理确定**适用机型**，力求**构型简洁、运行简化**。
- **9.4 灵活使用**：绕行滑行道与穿越滑行道应**视机场运行情况灵活使用**，避免无论繁忙与否都使用绕行滑行道，造成航班滑行距离大、滑行时间长、旅客体验差。

## Reference — 绕滑利弊速查（本章）
| 维度 | 要点 |
|---|---|
| 适用对象 | **个别超级繁忙机场**（非标配） |
| 风险 | 与平滑相连 → 误滑风险 |
| 成本 | 占地大；个别需目视遮蔽物；造价高 |
| 运行代价 | 滑行时间长、旅客体验差；可能导致跑道入口内移、缩短可用着陆距离 |
| 替代/配套技术 | 跑道状态灯等新设备新技术（9.2） |
| 使用策略 | 与穿越道**灵活配合**，不搞"一律绕行" |

## Amendment Notes（本章）
- 2025 年第一次修订（R1）。9.2 明确把**跑道状态灯**作为绕滑论证的考量因素，反映新技术对传统土建方案的替代。
