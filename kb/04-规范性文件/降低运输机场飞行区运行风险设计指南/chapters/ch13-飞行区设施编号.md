# 第13章 飞行区设施编号

## Core Idea
编号的目标是**统一认知、防止运行差错**。四条原则：**军民合用机场军民航使用同一编号**；机位编号**与航站楼/登机口联动**；方向改变**不超过 45°** 且翼展/PCR/使用规则相同时**不宜改编号**；编号**一经确定宜保持不变**（减少目视助航设施更改）。

## Key Clauses
- **13.1 军民合用统一编号**：为便于统一认知、防止运行差错，军民合用机场的**跑道、滑行道、机坪、机位及道路系统**，军民航应**使用同一编号**。
- **13.2 机位与登机口联动**：机坪机位编号**宜与航站楼及登机口编号联动**，易于识别和理解。
- **13.3 特殊字母编号增设方向引导标志**：滑行道编号为 **H、Z、S、N** 时，可在**滑行道转弯段增设方向引导标志**，以便于飞行员准确识别滑行道。
  - **风险机理**：仅有图上所示信息标志时，航空器由右向左滑行处于 H 滑以右时，飞行员**可能误把 J 滑当做 H 滑**（字母顺序相邻且方向近似）。
- **13.4 方向改变 ≤45° 不宜改编号**：当滑行道与其他滑行道相交但**方向改变不超过 45°**，且**滑行道最大翼展、PCR 值、使用规则相同**时，**不宜改变其编号**。
  - 案例：Z9 滑行道方向改变不超过 45°，且与 Z0 滑行道最大翼展相同、均为机坪滑行道 → 机位上方的滑行道编号**不宜由 Z9 改变为 Z0**。
- **13.5 编号稳定性**：为了减少目视助航设施更改，**飞行区设施编号一经确定，宜保持不变**。

## Reference — 编号规则速查（本章）
| 情形 | 规则 |
|---|---|
| 军民合用机场 | 军民航**同一编号** |
| 机位编号 | 宜与**航站楼/登机口**联动 |
| 编号为 H/Z/S/N | 转弯段宜增设**方向引导标志** |
| 方向改变 ≤45° 且翼展/PCR/使用规则相同 | **不宜改编号** |
| 编号确定后 | 宜**保持不变** |
