# 第12章 飞行区道路

## Core Idea
飞行区道路的风险点是**与跑道的连通**：连通跑道的道路必须采取降低跑道侵入的措施，进入跑道或导航设施敏感区的道路**除道路等待位置标志外，还须设道路等待位置标记牌**。其余要点：单车道错车道间距 ≤400 m、消防车道可豁免条件、冬季消防通道设道路边缘标志物、总体规划阶段完成道路编码。

## Key Clauses
- **12.1 错车道**：飞行区内**单车道宜设置错车道**，相邻错车道之间的**距离不大于 400 m**。
- **12.2 服务车道增补面**：服务车道**转弯处**，宜根据**拟使用车型**设置增补面。
- **12.3 连通跑道的道路**：
  - 设置连通跑道的道路时，应采取**降低跑道侵入风险**的相应措施；
  - **进入跑道、导航设施敏感区的道路**，除设置**道路等待位置标志**外，**还应设置相应的道路等待位置标记牌**。
  - **注**：还可考虑增加**禁止进入标志、地面信息标志和物理隔离设施**等措施。
- **12.4 军航道路**：通往跑道或民航滑行道的**军航道路**，应协调军方**按民航标准**设置道路等待位置及其配套目视助航设施。
- **12.5 巡逻道桥涵**：巡逻道与跑道之间的**排水明沟**，应当科学设置**桥涵**，方便**土面区维护车辆（如压路机、割草机等）** 进入作业。
- **12.6 消防车道豁免**：如消防站**距离机坪较近**，或经测算**消防站通过站坪到达跑道上任意一点能够满足响应时间要求**，则**不需要单独设置直通跑道的消防车道**。
- **12.7 冬季积雪机场**：**消防通道两侧应设置道路边缘标志物**。
- **12.8 道路编码**：在**机场总体规划阶段**，要**专题研究飞行区道路编码规则**，统筹规划近远期飞行区道路，并对飞行区道路进行编码。

## Reference — 关键数值（本章）
| 项 | 值 |
|---|---|
| 单车道错车道间距 | **≤400 m** |
| 连通跑道的道路 | 须设道路等待位置**标志 + 标记牌** |
| 消防车道豁免条件 | 消防站近机坪，或经测算满足响应时间 |
| 冬季消防通道 | 两侧设**道路边缘标志物** |
