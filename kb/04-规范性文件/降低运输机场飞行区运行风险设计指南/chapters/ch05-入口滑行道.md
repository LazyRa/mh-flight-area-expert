# 第5章 入口滑行道

## Core Idea
入口滑行道设计的核心目标是**降低跑道侵入风险**：宽度不宜过宽（便于设置等待位置及配套设施）、多条入口之间须有土面区分隔、等待位置处飞机应**垂直于跑道**以便无遮挡观察两个方向。**过宽未设停止排灯**时，用 **B 型跑道警戒灯**（横贯滑行道宽度的埋地式灯）补强。

## Key Clauses
- **5.1 避免过宽**：与跑道相交的滑行道应避免设计得过宽，以便于**跑道等待位置及其相应的标记牌、标志和助航灯光**的设置。
- **5.2 现有滑行道过宽时的处置**：
  - 按 MH5001 建议宽度**施划滑行边线标志**，并**调整相应的边灯、标记牌**等目视助航设施；
  - **跑道等待位置所在滑行道过宽且未设置停止排灯时，宜设置 B 型跑道警戒灯**。
- **5.3 多条入口须有土面区分隔**：多条入口滑行道应当**相互平行**，并由**土面区明确分开**。
  - 若入口滑行道间无土面区分隔 → **跑道警戒灯、标记牌等目视助航设施不易设置**。
- **5.4 军民合用机场超宽端联络道**：端联络道宽度远大于正常滑行道宽度时（如某机场端联络道 **45 m**、旁通联络道 **38 m**），为防止跑道侵入：
  - 如未设置**嵌入式停止排灯**，应在跑道等待位置处设置 **B 型警戒灯（横贯滑行道宽度的埋地式灯）**；
  - 并**增设跑道号码强制性地面标志**。
- **5.5 入口数量**：设有**与跑道等长的平行滑行道**的机场，**跑道每端应设置不少于 2 条入口滑行道**；交通密度高的跑道宜增加更多入口滑行道，并为**非跑道端入口滑行道设交叉点起飞标记牌**，以标示其剩余可用起飞滑跑距离。
  - **第 2 条入口的作用**：① 用于**非全跑道起飞**，缩短部分飞机滑行距离；② 调整**起飞次序**、增加跑道等待位置以提高运行效率；③ 飞机在起飞端因故放弃起飞时，兼顾**回转并尽快脱离跑道**的需要。
- **5.6 垂直于跑道**：入口滑行道、穿越滑行道的设置，应当使在跑道等待位置处等待的飞机**垂直于跑道**，确保驾驶员能对跑道**两个方向进行无遮挡观察**，从而降低跑道侵入风险。
- **5.7 锐角布置提升效率**：跑道端部或邻近端部的入口滑行道，与**起飞方向**的跑道夹角**呈锐角**，有利于缩短飞机从等待位置开始滑行至对正跑道的时间，提高起飞效率。
- **5.8 纵坡**：跑道等待位置区域的**道面纵坡应当尽可能小**，以便于等待的飞机比较容易地重新启动滑行。
- **5.9 跑道入口内移时的等待位置**：应综合考虑**跑道着陆运行标准（主要是能见度的影响）**，以及**是否穿透障碍物超障面**，并结合运行要求研究划设。
- **5.10 千万级机场**：入口滑行道的 **A 型跑道等待位置**，如未设停止排灯，**宜设 B 型跑道警戒灯**。

## Reference — 关键数值与设施（本章）
| 项 | 值 |
|---|---|
| 与跑道等长的平行滑行道 | 跑道每端 **≥2 条**入口滑行道 |
| 超宽端联络道实例 | 端联络道 45 m / 旁通联络道 38 m |
| 过宽且无停止排灯 | 设 **B 型跑道警戒灯**（埋地式，横贯滑行道宽度） |
| 千万级机场 A 型等待位置无停止排灯 | 宜设 B 型跑道警戒灯 |
| 等待位置处机头朝向 | 垂直跑道（两方向无遮挡观察） |
| 跑道端入口滑行道与起飞方向夹角 | 宜呈**锐角** |
