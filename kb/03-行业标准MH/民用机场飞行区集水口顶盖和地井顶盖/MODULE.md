## 覆盖范围

飞行区内**净孔径 ≤1000 mm** 的集水口顶盖与地井顶盖（含人孔井、非人孔井、航油井、阀门井等）的：

1. **等级**（A15 / B125 / C250 / D400 / E600 / F900，按承载能力与安装区域选型）
2. **材料**（铸铁 / 球墨铸铁 / 铸钢 / 轧制钢 / 铝合金 / 钢筋混凝土，及轧制钢 ≥2.75 mm + 热镀锌）
3. **设计要求**（净孔径、嵌入深度、总间隙、底座、边缘保护、稳固与锁定、槽孔与透水面积、表面平整度、座圈支承面与深度、铰接开启角）
4. **试验**（永久变形测定、荷载试验、各项量测方法）
5. **标志**（标准编号 + EN124、等级、制造商与产地）

**不覆盖**：净孔径 >1000 mm 的顶盖；**升降式、翻盖式机坪地井盖**不适用 6.3 净孔径要求。
