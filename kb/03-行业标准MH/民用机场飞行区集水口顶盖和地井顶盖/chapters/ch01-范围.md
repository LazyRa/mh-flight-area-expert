# 1 范围

## Core Idea

本标准规定飞行区**集水口顶盖**（gully top）和**地井顶盖**（manhole top）的定义、等级、材料、设计要求、试验要求和标志；适用于设置在民用机场飞行区内、**净孔径（CO）≤1000 mm** 的集水口顶盖和地井顶盖。

## Key Clauses

- **1 范围**：规定「定义、等级、材料、设计要求、试验要求、标志」六项内容
- **适用边界**：净孔径 **1000 mm（含）以下**；超过 1000 mm 的顶盖不在本标准覆盖范围

## 术语边界提示

- 「集水口顶盖」用于**排水沟/雨水口**，顶盖由**座圈 + 箅子或盖板**组成
- 「地井顶盖」用于**通向地下设施的腔室或竖井**（人孔井、非人孔井、航油井、阀门井等），由**座圈 + 盖板或箅子**组成
- 二者结构与受力逻辑相同，等级、材料、试验要求全部通用，**只有"人员进入的净孔径"（6.3）单独针对地井**

## 交叉引用

- 与 **MH 5001** 排水设施、飞行区构筑物与道面齐平要求配套
- 与 **MH/T 5086-2025** 第 7 章「排水设施维护」配套（本标准管产品，5086 管维护）
- 与 **AC-158-CA-2025-03R1** 第 11 章机坪（井盖锁定、井盖与道面齐平）配套
