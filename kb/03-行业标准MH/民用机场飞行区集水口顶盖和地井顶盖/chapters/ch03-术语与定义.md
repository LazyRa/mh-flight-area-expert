# 3 术语与定义

## Core Idea

19 条术语，围绕「组件—部位—尺寸—间隙—试验载荷」四类。答问时最容易混的是**嵌入深度 / 总间隙 / 净孔径 / 净面积**四个几何量。

## Key Clauses

### 3.1–3.11 组件与部位

| 条 | 术语 | 定义要点 |
|---|---|---|
| 3.1 | 集水口 gully | 一套接收地表水进入排水系统的**组件** |
| 3.2 | 地井 manhole | 通向地下设施的**腔室或竖井** |
| 3.3 | 集水口顶盖 gully top | 位于集水口箱体顶部，由**座圈 + 箅子或盖板**组成 |
| 3.4 | 地井顶盖 manhole top | 位于地井顶部，由**座圈 + 盖板或箅子**组成 |
| 3.5 | 座圈 frame | 顶盖的**固定部分**，用于放置并支承箅子及盖板 |
| 3.6 | 箅子 grating | 顶盖的**可移动部分**，允许水流通过到达集水沟 |
| 3.7 | 盖板 cover | 顶盖的**可移动部分**，用以盖住井口 |
| 3.8 | 通风孔 vent | 地井顶盖盖板上的开孔，用以通风 |
| 3.9 | 污物斗 dirt bucket | 集水口或集水口顶盖的可移动部分，收集垃圾 |
| 3.10 | 污物盘 dirt pan | 地井或地井顶盖的可移动部分，收集垃圾 |
| 3.11 | 底座 seating | 座圈上放置箅子或盖板的**表面** |

### 3.12–3.17 几何量（关键）

- **3.12 嵌入深度**：顶盖侧面与座圈配合、起定位与约束作用部分的**垂直高度**（图 1）；图中 `b ≤ al`
- **3.13 总间隙**：座圈与箅子/盖板相邻元件间**各最大间隙之和**（图 2）
  - 2a 两块：`a = al + ar`
  - 2b 三块带间隔：`a = al + ac1 + ac2 + ar`
  - 2c 三块带中缝：`a = al + ac + ar`
- **3.14 净孔径 CO**：座圈**净面积内切圆的直径**（图 3、图 4），单位 mm —— 全标准的基准尺寸，等级判定、试验载荷折减、槽孔限值都用它
- **3.15 净面积**：底座间**不被遮挡部分**的面积，单位 m²
- **3.16 单位面积质量**：盖板或箅子的**总质量 ÷ 净面积**，单位 kg/m²（用于"靠自重稳固"的判定，6.8 b）
- **3.17 减震衬垫**：座圈、箅子或盖板上的一种材料，使安放时不产生相对摆动

### 3.18–3.19 试验与使用场景

- **3.18 试验载荷**：试验时施加在顶盖上的载荷
- **3.19 行人区 pedestrian**：专供旅客及机坪作业人员使用，**只在递送货物、清洁维护或紧急状况下临时让机动车辆通行**的区域
  - ⚠️ 这个定义决定了 B125 能不能用：一旦日常有车辆通行，就不再是行人区

## 易错点

- **净孔径 ≠ 净面积**：前者是长度（mm），后者是面积（m²）
- **嵌入深度**只在 D400/E600/F900 有 ≥50 mm 的硬要求（6.4），A15～C250 无
- **总间隙**是"各间隙之和"，不是单个间隙
