# 7 试验

## Core Idea

三类试验：**永久变形测定**（2/3 试验载荷，重复 5 次）、**荷载试验**（满载保持 300 s）、以及各条设计要求的**量测方法**。型式试验取 3 个样品。

## Key Clauses

### 7.1 基本要求
- **7.1.1** 顶盖应按其**使用环境要求进行整体试验**；凹陷形盖板如以**未填充状态**交货，应做**无填充状态**的荷载试验
- **7.1.2** 第 4 章各等级产品**均应进行荷载试验**
- **7.1.3** 本标准未给出具体验证方法的，制造商应在产品文件中给出试验方法

### 7.2 试验载荷
- **净孔径 ≥250 mm**：按表 6
- **净孔径 <250 mm**：表 6 数值 **×(CO/250)**，但**最低不小于 0.6 倍**

**表 6 试验载荷**

| 等级 | 试验载荷 kN |
|---|---|
| A15 | 15 |
| B125 | 125 |
| C250 | 250 |
| D400 | 400 |
| E600 | 600 |
| F900 | 900 |

### 7.3 试验装置
- **7.3.1.1 试验机（最好液压）加载能力**：A15/B125/C250/D400 应 **>试验载荷 125%**；E600/F900 应 **>110%**
- **7.3.1.2** 试验载荷最大允许误差 **±3%**
- **7.3.1.3** 测试台面尺寸应**大于单体试件的支撑面积**（多联体试件不考虑）
- **7.3.1.4 刚性垫块（表 7）**
  - 300 < CO ≤ 1000：垫块尺寸 = **CO × CO**（边长等于净孔径）
  - 200 ≤ CO ≤ 300：**250 mm**（圆角 R25，边缘 R3）
  - CO < 200：**75 mm**（边缘 R3）
- **7.3.2 试验准备**：垫块置于试件上，**纵轴垂直于试件表面并过几何中心**；双三角状盖板/箅子垫块置于几何中心（图 8）；载荷应**均匀分布**；表面不平整时加软木/纤维板/毛毡中间垫层（**垫层尺寸不得大于垫块**）；非平面顶盖垫块接触面应做成匹配形状（按 6.12 制作的表面及与平面差别不大的表面除外）
- **7.3.3 型式试验**：取 **3 个样品**，每个均须满足第 5、6 章要求；产品**结构改动**时须重做型式试验，所有设计改动（结构性/非结构性）均须**认证机构批准**

### 7.4 试验程序
**7.4.1** 所有盖板或箅子均应做**永久变形测定试验 + 荷载试验**

**7.4.2 永久变形测定**
- 加载前记录几何中心初始读数
- 以 **1～5 kN/s** 加载至 **2/3 试验载荷**，然后卸载，**重复 5 次**，记最终读数
- **永久变形量 = 初始读数 − 5 次加载后最终读数**，测量精确到 **0.1 mm**
- 双三角盖板/箅子**两个部件均须测**，位置尽量靠近几何中心
- 钢筋混凝土试件试验后测裂缝，**裂缝宽度 ≤0.2 mm**

**表 8 允许的永久变形**

| 等级 | 允许永久变形 |
|---|---|
| A15、B125 | 1/100 CO（CO<450 mm 时 1/50 CO） |
| C250、D400、E600、F900 | 1/300 CO（CO<300 mm 时最大 1 mm） |
| 采用 6.8 a)、c) 稳固方案 | 1/500 CO（CO<500 mm 时最大 1 mm） |
| 采用 6.8 b) 稳固方案 | 见上一行限值口径（原文表注按 7.8 引用） |

> ⚠️ 表 8 原文写的是「7.8(a)和 7.8(c)」「7.8(b)」，**本标准无 7.8 条**，按上下文应为 **6.8**（盖板和箅子在座圈中的稳固）。已按 6.8 理解，原文错误保留记录。

**7.4.3 荷载试验**
- 永久变形试验**做完后立即**以相同加载速率加载至**试验载荷**，保持 **300⁺² s**
- 由 **5.1.1 a) b) c) d) e) g)** 材料制成的部件**不应有裂缝**
- 钢筋混凝土盖板加载后**钢筋与混凝土之间不应丧失粘着力**

### 7.5 试验方法（逐条对应设计要求的量测）

| 条 | 对象 | 方法要点 |
|---|---|---|
| 7.5.1 | 外观 | 目视检查缺陷 |
| 7.5.2 | 通风孔 | 量尺寸精确到 1 mm，面积精确到 100 mm² |
| 7.5.3 | 净孔径 | 量环形/矩形/三角形净孔径，精确到 1 mm |
| 7.5.4 | 嵌入深度 | 量 D400/E600/F900 的 A 值，精确到 1 mm |
| 7.5.5 | 总间隙 | 量间隙精确到 **0.5 mm**，计算总间隙 |
| 7.5.6 | 底座 | 检验与制造商技术规范的相容性 |
| 7.5.7 | 边缘保护 | 无涂层钢（铁）保护包边精确到 **0.1 mm**；热镀锌层精确到 **5 μm** |
| 7.5.8 | 稳固性 | 靠"单位面积质量"时质量精确到 1%、净面积精确到 100 mm²；靠锁定装置/专门设计时目视检查并按需测量 |
| 7.5.9 | 槽孔 | 目视检查分布均匀性；量尺寸精确到 1 mm；透水面积精确到 100 mm² |
| 7.5.9.1 | 直条形槽孔 | 量尺寸精确到 1 mm |
| 7.5.9.2 | 非直条形槽孔 | 用 **170×170×20 mm 量规**测量 |
| 7.5.10 | 污物盘/斗 | 用沙子填满，目视检查排水与通风能力 |
| 7.5.11 | 定位指示 | 目视检查标志或记号 |
| 7.5.12 | 表面状况 | 平面度精确到 **0.5 mm**；凸起图案高度精确到 0.5 mm；面积比按图纸或实测计算（精确到 1 mm） |
| 7.5.13 | 松动及开启 | 操作试验 |
| 7.5.14 | 密封性 | 按制造商给定密封性能制定方案：浸水法（定深度、定时间看渗漏）或充气法（测压降是否超标） |
| 7.5.15 | 座圈支承面 | 计算试验载荷下支承压力 ≤7.5 N/mm²；并判定工作条件稳固性 |
| 7.5.16 | 座圈深度 | 量整体座圈深度精确到 1 mm |
| 7.5.17 | 开启角度 | 量角度精确到 **5°**；弧形轮廓用 170×170×20 量规，插入深度精确到 1 mm |
