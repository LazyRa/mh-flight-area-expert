# 4 等级

## Core Idea

按**承载能力**分 6 级：**A15 / B125 / C250 / D400 / E600 / F900**，数字即试验载荷（kN）。等级按**安装区域**选取，有疑虑时**选高不选低**。

## Key Clauses

**4 等级**：分为 A15、B125、C250、D400、E600、F900 共 6 个等级，各等级一般适用于如下区域：

| 等级 | 试验载荷 | 适用区域 |
|---|---|---|
| **A15** | 15 kN | 只允许**行人和自行车**通行的区域 |
| **B125** | 125 kN | **人行道、行人区**及其类似区域；通用车辆停车场或停车位 |
| **C250** | 250 kN | 飞行区**车道边布置排水渠**的区域；飞行区**土面区** |
| **D400** | 400 kN | 飞行区**活动区**承载**一般轮胎载荷**飞机和作业车辆的区域 |
| **E600** | 600 kN | 飞行区**活动区**承载**较大轮胎载荷**飞机和作业车辆的区域 |
| **F900** | 900 kN | 飞行区**活动区**承载**特别大轮胎载荷**飞机的区域 |

**判定原则（原文）**：「如有疑虑，则应选择较高的等级。」

## 选型速查

- 航站楼前人行道、停车场 → **B125**（不是 C250）
- 飞行区土面区、车道边排水渠 → **C250**
- **滑行道/机坪（飞机实际通行区）** → 至少 **D400**，按机型轮载上调 E600 / F900
- 等级与试验载荷数值一一对应（表 6），**选等级即定试验载荷**

## 交叉引用

- 试验载荷见 **ch07 7.2 表 6**（净孔径 <250 mm 时按 `CO/250` 折减，最低 0.6 倍）
- 嵌入深度、底座加工、表面平整度、座圈深度等**加强要求**只对 **D400/E600/F900** 生效（6.4 / 6.6 / 6.12.1 / 6.16）
