# 2 规范性引用文件

## Core Idea

引用 9 项国家标准，覆盖铸铁、铸钢、轧制钢、铝合金、钢筋、铸件公差、热镀锌层。注日期版本仅该版本适用；不注日期按最新版（含所有修改单）。

## Key Clauses

| 标准号 | 名称 | 在本标准中的用途 |
|---|---|---|
| GB/T 700 | 碳素结构钢 | 轧制钢顶盖/座圈（5.2 c） |
| GB/T 1173 | 铸造铝合金 | 铝合金顶盖（5.2 h） |
| GB/T 1348 | 球墨铸铁件 | 球墨铸铁顶盖/箅子（5.2 b） |
| GB/T 1499 | 钢筋混凝土用钢 | 钢筋混凝土顶盖配筋（5.2 g） |
| GB/T 6414 | 铸件 尺寸公差与机械加工余量 | 铸铁件公差（5.2 f） |
| GB/T 9439 | 灰铸铁件 | 片状石墨铸铁（5.2 a） |
| GB/T 11352 | 一般工程用铸造碳钢件 | 铸钢件（5.2 d） |
| GB/T 13912 | 金属覆盖层 钢铁制件热浸镀锌层 | 热镀锌层要求与试验（5.2 e） |
| GB/T 15115 | 压铸铝合金 | 压铸铝合金件（5.2 i） |

## 注意事项

- 「凡是不注日期的引用文件，其**最新版本（包括所有的修改单）**适用于本文件」——即 GB 系列更新后自动跟随
- 本标准的标志要求还引用了 **EN 124**（欧洲井盖标准）作为参照信息，但 EN 124 未列入第 2 章
