# 第6章 道面清洁

## Core Idea
道面清洁 = **道面清扫** + **污染物清除**。清扫分定期/不定期/动态三类；设备分清扫车、吸尘器、保洁毯、油污清洗车、吸油毯（棉）五类，各有量化指标。**沥青混凝土道面禁止使用保洁毯**。

## 6.1 一般规定
- **6.1.1 道面清洁分类**：可分为**道面清扫**和**污染物清除**；道面清扫可分为**定期清扫、不定期清扫与动态清扫**：
  1. 应根据道面类型、使用频率和环境条件，明确**清扫频次与标准**。**跑道及滑行道应定期清扫，机坪道面应根据实际使用情况进行动态清扫**；
  2. 在**高峰时段或特殊天气**条件下应增强动态清扫管理，防止外来物对飞机产生影响；
  3. 针对突发事件或特殊情况，应制定**应急清扫预案**，完善应急清扫机制。
- **6.1.2 清扫方案内容**（包括但不限于）：
  1. 岗位职责和分工；
  2. 所需清扫设备、工具的种类、规格和数量；
  3. 清扫的具体时机（含定期清扫和特殊天气后的应急清扫）；
  4. 不同区域的清扫频次和作业安排；
  5. 清扫区域的划定；
  6. 清扫方法、工艺流程和安全措施；
  7. 清扫工作的统计分析。
- **6.1.3 设备与工具配置**：应根据实际情况配备，主要包括**大型清扫车、小型清扫车、吸尘器、保洁毯、油污清洗车、吸油毯（棉）、扫帚、簸箕**等。设备及工具应**定期检查和保养**。
- **6.1.4 化学剂清洗**：使用化学剂清洗污染道面应符合**国家环境保护**的有关规定。
- **6.1.5 统计分析**：应定期统计道面清扫中所收集的**外来物类型与数量**，分析外来物来源，为**外来物防范**提供依据。

## 6.2 清扫设备
- **6.2.1 清扫车**：
  1. **吸式清扫车**通过车下旋转盘刷将杂物清扫至车辆底部的吸收口，吸入车内容器，一次作业宽度 **2.0–3.5 m**；
  2. 配备**水箱及高压水龙头**；
  3. 宜配备**磁吸装置**，用于吸附铁屑、螺丝等金属杂物；
  4. **小型清扫车**一次作业宽度 **1.0–2.0 m**，配备杂物收集容器，容量**不小于 50 L**。
- **6.2.2 吸尘器**：
  1. 具备高负压吸力，吸力强度 **20–35 kPa**，能有效吸除砂石、树叶等杂物；
  2. 作业范围 **1–3 m**；
  3. **外来物回收率不低于 95%**；
  4. 垃圾箱容量 **2–10 m³**；
  5. 配备**过滤系统**，防止二次扬尘。
- **6.2.3 保洁毯**：
  1. 能快速有效回收**螺母、螺栓、垫圈、碎石、纸张**等外来物；
  2. 道面温度 **−40～+60 ℃** 范围内能正常使用，可在道面**潮湿**环境下正常工作；
  3. 可选择**单拖、双拖、三联拖**等作业方式，配备相应的拖挂杆；
  4. 配备**强磁吸设备**，能吸附道面上的金属外来物（螺母、螺栓、钢珠、钢砂等）；
  5. **外来物回收率不低于 95%**；
  6. 工作时**不得对道面造成损坏**；
  7. 非工作时，保洁毯与拖挂杆可分解存放。
- **6.2.4 油污清洗车**：
  1. 清洗压力 **10–30 MPa**；
  2. 清洗宽度 **1.5–3.0 m**；
  3. 污水箱容量 **2–5 m³**；
  4. 配备**真空吸污系统及油水分离装置**，能有效回收和分离油污与污水。
- **6.2.5 吸油毯（棉）**：
  1. **吸油层**选用高吸附性材料，具备快速吸附油污的能力；
  2. **防渗漏层**选用高分子聚合物，厚度 **0.2–4.0 mm**，具备耐油性和防渗透性；
  3. **防护层**选用合成纤维材料，具备耐磨损、耐老化及防止物理损伤的能力；
  4. **锁油层**具备在吸附饱和后短时间内不渗漏的能力。

## 6.3 清扫措施
- **6.3.1** 机坪等飞机停放区域**宜采用人工清扫方式或小型吸式道面清扫车**进行清扫。
- **6.3.2** 机械设备无法清扫的区域**宜采用人工清扫**方式（如道肩与土面区交接区、廊桥活动区等）。
- **6.3.3** **水泥混凝土道面**可使用保洁毯清扫；**沥青混凝土道面禁止使用保洁毯**。
- **6.3.4 外来物清扫**（道面含道肩）：
  1. **金属外来物**应使用**磁吸装置**清扫；
  2. **漆皮、水泥碎屑等轻质外来物**应使用**吸尘器**或具备吸式功能的清扫车清扫；
  3. 水泥混凝土**接缝缝槽或刻槽内**的外来物应使用**吹风机**吹到道面上，然后使用吸式清扫车或人工清扫；
  5. **清扫车**清扫速度应控制在 **5–15 km/h**；
  6. **保洁毯**清扫速度应控制在 **15–30 km/h**。

- **6.3.5 污染物清除**（道面含道肩的航空污水、危险废品、航空煤油）：
  1. **航空污水**可采用**高压水冲洗或稀释**；
  2. **危险废品（航空煤油、润滑油除外）**可在喷洒**去污剂或溶解剂**后采用高压水冲洗；
  3. **小面积航空煤油、润滑油污染**可使用**黄砂、麻布、吸油毯（棉）**等材料吸附，或使用**油污清洗剂**清洁，处理后采用**清水冲洗**；
  4. **大面积航空煤油、润滑油污染**应**立即停止污染区域的运行**，依据现场评估可采用**黄砂覆盖**；航油污染区域应用水清洗，并且**消防车应现场待命**；
  5. 难以去除的污染物可在使用**钢丝刷或钢丝轮打磨**后采用清水冲洗。
