# 附录 A 标志涂料技术要求

## Core Idea
规定**水性漆、溶剂型、双组份**三类标志涂料的性能指标与限值。共性限值：**VOCs <100 g/kg**、**重金属（Pb/Cd/Cr/Hg/As/Sb）≤100 mg/kg**、**不粘胎干燥时间 ≤15 min**（双组份 ≤60 min）、**遮盖率 白色 ≥95%、黄色 ≥80%**。

## A.0.1 水性漆涂料（表 A.0.1）
分**普通型 / 反光型**两类。

| 项目 | 水性漆（普通型 / 反光型） |
|---|---|
| 容器中状态 | 无结块、结皮、易于搅拌，搅拌后色泽均匀一致 |
| VOCs 含量（g/kg） | <100 |
| 重金属含量（mg/kg） | 铅 Pb、镉 Cd、铬 Cr、汞 Hg、砷 As、锑 Sb **≤100** |
| 漆划性能 | 有气或无气喷涂成型时施划性能应良好 |
| 涂层外观 | 干燥后无皱纹、斑点、起泡、裂纹、脱落、粘胎，颜色均匀一致 |
| 耐水性 | 水中浸泡 24 h 应无变色、起皱、起泡、开裂 |
| 耐碱性 | 氢氧化钙饱和溶液中浸泡 24 h 应无变色、起皱、起泡、开裂 |
| 黏度 | ≥70（KU） / 80–120（KU） |
| 密度（g/cm³） | ≥1.4 / ≥1.6 |
| 不粘胎干燥时间（min） | ≤15 |
| 遮盖率（%） | 白色 ≥95；黄色 ≥80 |
| 耐磨性（mg） | ≤60 |
| 冻融稳定性 | （−5±2）℃ 放置 18 h → 立即置于（23±2）℃ 放置 6 h 为一周期，3 周期后应无结块、结皮，易于搅匀 |
| 早期耐水性 | 温度（23±2）℃、湿度（90±3）% 下，指触干燥时间 ≤120 min |
| 附着性（划圈法） | ≤5 级 / — |

> 检测方法参照《路面标线涂料》（**JT/T 280**）。

## A.0.2 溶剂型涂料（表 A.0.2）
分**普通型 / 反光型**两类。

| 项目 | 溶剂型（普通型 / 反光型） |
|---|---|
| 容器中状态 | 无结块、结皮、易于搅拌，搅拌后色泽均匀一致 |
| VOCs 含量（g/kg） | <100（扣除不参与大气光化学反应的溶剂） |
| 重金属含量（mg/kg） | Pb、Cd、Cr、Hg、As、Sb **≤100** |
| 漆划性能 | 有气或无气喷涂成型时施划性能应良好 |
| 涂层外观 | 干燥后无皱纹、斑点、起泡、裂纹、脱落、粘胎，颜色均匀一致 |
| 耐水性 | 水中浸泡 24 h 应无变色、起皱、起泡、开裂 |
| 耐碱性 | 氢氧化钙饱和溶液中浸泡 24 h 应无变色、起皱、起泡、开裂 |
| 黏度 | 100–150（涂 4 杯，s） / 80–120（KU 值） |
| 密度（g/cm³） | ≥1.2 / ≥1.3 |
| 不粘胎干燥时间（min） | ≤15 |
| 遮盖率（%） | 白色 ≥95；黄色 ≥80 |
| 附着性（划圈法） | ≤4 级 / — |
| 柔韧性（mm） | ≤5 / — |

> 检测方法参照 **JT/T 280**；不参与大气光化学反应的溶剂检测方法参照《涂料用稀释剂》（**HG/T 3378**）。

## A.0.3 双组份涂料（表 A.0.3）
分**普通型 / 反光型 / 突起型**三类。

| 项目 | 双组份（普通型 / 反光型 / 突起型） |
|---|---|
| 容器中状态 | 无结块、结皮、易于搅拌，搅拌后色泽均匀一致 |
| 预混玻璃珠 | — / 含量 ≥30%，成圆率 ≥80% / — |
| VOCs 含量（g/kg） | <100 |
| 重金属含量（mg/kg） | Pb、Cd、Cr、Hg、As、Sb **≤100** |
| 漆划性能 | 有气或无气喷涂、刮涂、甩涂、滚涂成型时施划性能应良好 |
| 涂层外观 | 干燥后无皱纹、斑点、起泡、裂纹、脱落、粘胎，颜色均匀一致 |
| 耐水性 | 水中浸泡 24 h 应无变色、起皱、起泡、开裂 |
| 耐碱性 | 氢氧化钙饱和溶液中浸泡 24 h 应无变色、起皱、起泡、开裂 |
| 人工加速耐候性 | 试验后试板涂层不产生龟裂、剥落；允许轻微粉化和变色，色品坐标应仍在色品区域内，涂层亮度因数变化范围 ≤该颜色规定亮度因数的 20% |
| 密度（g/cm³） | 1.5–2.0 |
| 凝胶时间（min） | ≥10 |
| 不粘胎干燥时间（min） | ≤60 |
| 遮盖率（%） | 白色 ≥95；黄色 ≥80 |
| 耐磨性（mg） | ≤40 / — |
| 涂层低温抗裂性 | −10 ℃ 保持 4 h、室温放置 4 h 为一循环，连续 3 个循环后应无裂纹 |
| 附着性（划圈法） | ≤4 级 / — |
| 柔韧性（mm） | ≤5 / — |

> 检测方法参照 **JT/T 280**。

## Reference — 三类涂料对比速查

| 耐磨性（mg） | ≤60 | — | ≤40 |
