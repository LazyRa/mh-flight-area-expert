# 第7章 排水设施维护

## Core Idea
排水设施须**保持完整、畅通**。核心安排：**雨季来临前**专项检查维护（沟内淤积 >设计高度 1/5 应疏浚、裂缝 >5 mm 应修补、泵站单泵排水量 ≥额定值 85%）；**雨季每月**全功能测试强制式排水设施。

## Key Clauses
- **7.0.1 总体要求**：排水设施系统应保持**完整、畅通**。
- **7.0.2 雨季前专项检查与维护**：
  1. 检查飞行区所有**明沟、集水口、排水沟出口及连接管**；重点检查**沟体结构完整性**（裂缝、塌陷、破损）、**沟内杂物淤积情况**及**水流畅通性**、**集水井箅子的完好性和固定状态**，以及**出水口与场外排水系统的衔接有效性**；
  2. **排水沟内杂物淤积厚度超过其设计高度 1/5 时，应进行疏浚**；**集水井内沉积物应彻底清除**，井壁应无附着油污或腐蚀物；**雨水口箅子应拆卸清洗**，锈蚀、变形的应及时更换；
  3. **沟体裂缝宽度大于 5 mm 或局部塌陷时，应进行修补**，修复后强度应**不低于原设计要求**；连接管接口渗漏应使用密封胶填补或更换老化密封圈；检查井盖缺失、破损的应更换；
  4. **强制式排水泵站应启动试运行，单泵排水量应达到额定值 85% 以上**。
- **7.0.3 日常维护**：
  1. **强制式排水设施**（含排水泵站、压力管道等）在**雨季应每月进行全功能测试**，内容包括但不限于**备用电源切换和报警系统联动**等；
  2. **冰冻期间**飞行区排水沟内**不得有大量积水**；发现积水时应及时清除。
- **7.0.4 专项研究论证**：现有排水系统经疏通、日常维护后仍**无法满足飞行区排水要求**，或**技术较为复杂、维护量大且组织复杂**时，应开展**专项研究论证或设计**。

## Reference — 关键数值速查（本章）
| 项 | 值 |
|---|---|
| 排水沟淤积疏浚阈值 | >设计高度 1/5 |
| 沟体裂缝修补阈值 | >5 mm（或局部塌陷） |
| 修复后强度 | ≥原设计要求 |
| 强制式排水泵站单泵排水量 | ≥额定值 85% |
| 强制式排水设施全功能测试频次 | 雨季每月 1 次 |
