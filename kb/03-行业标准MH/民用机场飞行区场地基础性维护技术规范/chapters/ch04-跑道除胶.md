# 第4章 跑道除胶

## Core Idea
跑道除胶的目的是**恢复跑道道面表面的摩阻性能**。作业从跑道中线向两侧依次进行，方式按道面类型、运行环境、设备配套及胶层厚度选用（高压/超高压水冲洗、抛丸机打磨、机械打磨或经验证的新兴技术）。抛丸除胶须做**丸料损失率现场试验**（≤2%）。

## Key Clauses
- **4.0.1 作业方向与流程**：除胶作业应从**跑道中线向两侧**依次进行。除胶流程应根据除胶区域宽度、设备单次胶泥清除效率、每次作业覆盖宽度等参数合理确定，确保作业的**连续性和覆盖范围完整**。
- **4.0.2 除胶方式选用**：根据道面类型、运行环境、设备配套及胶层厚度选用：
  1. **高压或超高压水冲洗法**：宜使用 **30–100 MPa** 压力范围的高压水枪；特殊情况下可使用不超过 **200 MPa** 的超高压水设备；配备**旋转喷头和真空回收系统**；水流与道面保持适当角度，避免损伤道面纹理。
  2. **抛丸机打磨**：设备**必须配备高效回收装置**；**避免在沥青混凝土道面上使用**；作业时应采取措施避免损伤道面纹理。
  3. **机械打磨法**：应选用**小型铣刨机、钢丝刷或地坪研磨机**等进行**局部**除胶；合理控制打磨深度，避免过度磨损道面。
  4. 积极探索**激光、等离子体、干冰/超临界 CO₂** 等除胶新技术，经验证后逐步推广。
- **4.0.3 纹理损伤试验**：除胶设备在本场**首次使用前**，宜进行现场**道面纹理损伤试验**，确定除胶相关参数。
  > 试验选在与计划除胶区域相邻且无胶泥的道面；作业前目视检查并记录初始构造深度（铺砂法记录测点位置）；作业后再次检查，有条件时在原测点做原位表面纹理测试；损伤过大则调整工艺参数或换方法。
- **4.0.4 抛丸除胶丸料损失率试验**：抛丸除胶在本场**首次使用前**，应进行丸料回收率现场试验：
  1. 试验段区域长度**不小于 10 m**，宽度不小于抛丸机 **2 幅**作业宽度；
  2. 作业前称量丸料质量 g₀（精确到克）；
  3. 除胶时全面收集设备回收装置和磁力围挡吸附的丸料与胶泥；
  4. 除去胶泥并清洗干燥后，再次称量丸料质量 g₁（精确到克）；
  5. 按式（4.0.4）计算丸料损失率 Δg：**Δg = |g₁ − g₀| / g₀ × 100**（%）；
  6. 通过调整**抛丸速度、丸料大小、抛丸角度、磁力围挡尺寸**等参数，确保 **Δg 不大于 2%**。
- **4.0.5 除胶作业规定**：
  1. 应采用**循序渐进**方式，**单次除胶厚度宜不超过 0.5 mm**；
  2. **水泥混凝土道面**除胶期间应检查除胶区域的**接缝材料**，若失效应及时更换；
  3. 应采取有效措施**保护除胶区域内的助航灯具**；
  4. 应使用**专业集成化设备**，配备有效的**废弃物回收装置**；
  5. 作业完成后应进行**外来物（FOD）风险排查**。

## Reference — 关键数值速查（本章）
| 项 | 值 |
|---|---|
| 高压/超高压水冲洗压力 | 30–100 MPa（特殊 ≤200 MPa） |
| 抛丸除胶丸料损失率 Δg | ≤2% |
| 抛丸试验段长度 | ≥10 m（宽 ≥2 幅） |
| 单次除胶厚度 | 宜 ≤0.5 mm |
| 沥青混凝土道面 | **不得使用抛丸机** |
