# 第5章 土面区维护

## Core Idea
土面区维护分**平整和碾压**、**环境管理**两块。核心阈值：**细粒土压实度 ≥87%**、**粗粒土/巨粒土固体体积率 ≥77%**（对应 ICAO CBR 15%–20% 的最低承载力要求）。碾压质量须按测试区域划分实测（细粒土用环刀法+重型击实，粗粒土/巨粒土用固体体积率法，见附录 B）。

## 5.1 一般规定
- **5.1.1** 应根据机场航班运行情况和土面区使用特点，制定土面区**平整、碾压、植被管理**等年度维护计划。
- **5.1.2** 应使用**机械化设备**进行土面区维护，并**定期评估**维护效果。

## 5.2 土面区平整和碾压
- **5.2.1 平整碾压触发条件**：升降带和滑行带平整范围内土面区，以及跑道端安全区内土面区的**平整度、压实度**不满足《民用机场飞行区技术标准》（**MH 5001**）有关规定时应进行平整碾压：
  1. **升降带与跑道、道肩或停止道相接处**：表面应与道面**齐平**，不高于道面，且不低于道面边缘 **30 mm 及以上**；
  2. **升降带、跑道端安全区平整区内**：用**三米直尺**测量，**高差应不大于 5 cm**，并不应有**反坡**；
  3. **跑道端安全区**：纵坡降坡**不大于 5%**，横坡升降**不大于 5%**，坡度过渡应平缓；
  4. **滑行带与滑行道道肩或道面相接处**应齐平，横向降坡**不大于 5%**；飞行区指标Ⅱ为 **C、D、E、F** 的横向升坡**不大于 2.5%**，指标Ⅱ为 **A、B** 的横向升坡**不大于 3.0%**；
  5. **压实参数**：**细粒土压实度不低于 87%**，**粗粒土或巨粒土固体体积率不低于 77%**。
  > 条文说明依据：细粒土 87% 相当于标准击实法的 95%，可确保常见及洪雨饱和条件下 CBR≥15%；粗粒土/巨粒土固体体积率 77% 意味着孔隙率约 23%，浸水 CBR 一般不低于 20%。
- **5.2.2 平整作业规定**：
  1. 选用**推土机、平地机、压路机和自卸车**等机械设备；
  2. 填料**不得含有垃圾、树根和石块**，粒径**大于 10 cm 的石块应破碎处理**；
  3. 平整前**清除现有植被**，并及时运出飞行区；
  4. 初步平整用推土机，**碾压 1–2 遍**后，再用**人工作业配合平地机精细平整 2–3 遍**；
  5. 坡度应用**水准测量**复核，平整度应用**三米直尺**复核。
- **5.2.3 碾压作业规定**：
  1. 选择**土体接近最佳含水量**的季节进行碾压；
  2. 碾压按**从道面边缘向土面区、从高到低**的顺序进行；相邻两次碾压区域应**重叠 20–30 cm**；
  3. 碾压过程中应**保护区域内的目视助航设施、导航设施、驱鸟设施以及各类管线**；
  4. 碾压方式和次数根据压实度要求通过**现场试验**确定。
- **5.2.4 压实质量测试区域划分**：升降带和跑道端安全区内土面区的压实质量应在**碾压完成后**测试：
  1. **跑道端安全区**应作为**独立的测试区域**进行压实度或固体体积率测试；
  2. **升降带平整区**可沿跑道方向每 **300–800 m** 划分为一个测试区域。
- **5.2.5 现场测试规定**（同一测试区域内）：
  1. 测试点数量**不少于 3 个**，位置采用**随机抽样**确定；
  2. 升降带测试点与跑道中线的**垂直距离小于 75 m**，测试点之间的距离**不小于 50 m**；
  3. 每个测试点的测试数量**不少于 3 组**。
- **5.2.6 测试方法**：
  1. **细粒土**应按**附录 B.1 和 B.2** 的方法现场测试**压实度**；
  2. **粗粒土或巨粒土**应按**附录 B.3** 的方法现场测试**固体体积率**。
- **5.2.7 快速测试技术**：可根据本场土质类型等实际情况，积极探索应用**圆锥动力触探试验方法、无核密度仪**等其他压实质量快速测试技术。

## 5.3 土面区环境管理
- **5.3.1 植草与草的堆放**：土面区**宜植草**，草的高度**不得遮挡助航灯光和标记牌**。在跑道、滑行道的道肩及机坪外 **15 m 范围内不得存放割下的草**；临时堆放的草应**尽快清理出飞行区**。
- **5.3.2 土壤改良**：可根据本场适宜植被群落生长的土壤特性，对土面区土壤的 **pH 值**进行改良。
- **5.3.3 植被物种选择**：应选择在自然条件下具有**优势地位的少数几种单子叶草本植物**，通过人为干预强化植被群落，**降低土面区植物的多样性**：
  1. 植物**生长高度易于控制，结籽量较少**；
  2. 植物**根系应能与土壤紧密结合**，在地表下形成坚实的草土层；
  3. 植物应具备**较强的环境适应性**，后期管理要求较低。
- **5.3.4 植被控制**：
  1. 植被高度应根据**主要防范鸟类的习性**调整，结合生长周期适时采用机械或人工方式割草；
  2. 应从**灭虫时机、药剂配比及施用方式**等方面优化灭虫作业；
  3. **割草作业和喷洒农药应从道肩边缘开始，逐步向远离跑道的区域进行**；
  4. 割草作业应在不影响飞行活动的情况下进行；作业时应密切关注**虫情和鸟情**，及时采取措施防止环境临时改变产生**鸟击风险**。
- **5.3.5** 应及时清除土面区的**低洼积水**。

## Reference — 关键数值速查（本章）
| 项 | 值 |
|---|---|
| 细粒土压实度 | ≥87% |
| 粗粒土/巨粒土固体体积率 | ≥77% |
| 升降带/跑道端安全区平整区高差（3 m 直尺） | ≤5 cm，无返坡 |
| 跑道端安全区纵坡/横坡 | ≤5% |
| 滑行带横向降坡 | ≤5% |
| 滑行带横向升坡（指标Ⅱ C/D/E/F） | ≤2.5% |
| 滑行带横向升坡（指标Ⅱ A/B） | ≤3.0% |
| 相接处高差（低于道面边缘） | ≤30 mm |
| 填料石块粒径 | >10 cm 须破碎 |
| 碾压重叠宽度 | 20–30 cm |
| 升降带测试区域划分 | 沿跑道方向每 300–800 m |
| 测试点与跑道中线垂距 | <75 m |
| 测试点间距 | ≥50 m |
| 每测试点测试组数 | ≥3 |
| 道肩及机坪外草堆放禁限范围 | 15 m 内不得存放 |
