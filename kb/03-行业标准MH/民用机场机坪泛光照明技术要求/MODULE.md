# 民用机场机坪泛光照明技术要求

- **入库日期**：2026-10-22
- **源文件**：`MHT6108-2014.pdf`（16 页，10155 字符）

## 覆盖范围

民用机场**机坪泛光照明**的：

1. **基本要求**：照明设置、**照度标准值（按机场类别分档）**、眩光限制、光源、灯具、电器附件
2. **灯杆设置**（高度与位置的六类决定因素、三条硬约束）
3. **照明供配电与控制**（独立供电、载流量、三相降频闪、接地形式）
4. **照明检测**（检测条件、电参数、照度布点与计算、检测报告）
5. **照明设备维护**（70% 阈值、每年 ≥1 次）
6. **附录 A** 眩光指数计算（规范性）、**附录 B** 检测记录表（资料性）

**不覆盖**：高杆灯**杆体与升降系统**的产品要求（见 **MH/T 6013**）、机坪照明的**照度设计计算方法**（照度标准值给定，具体布灯计算另见照明设计手册）、航空障碍灯（见 MH 5001）。
