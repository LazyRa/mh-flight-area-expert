# 3 术语和定义

## Core Idea

25 条术语，分四组：**场所类**（机坪、机位、工作区等）、**照度类**（照度、水平/垂直、均匀度、维持平均照度、维护系数）、**灯具类**（灯具效率、泛光灯、显色指数、色温）、**眩光类**（眩光、不舒适眩光、眩光指数 GR、频闪效应）。

## Key Clauses

### 场所类
- **3.1 机坪 apron**：飞行区内供飞机上下旅客、装卸货物或邮件、加油、停放或维修的特定场地
- **3.2 机坪照明**：为照亮整个机坪工作区提供的**一般照明**
- **3.3 飞机机位**：机坪上停放飞机的特定场地
- **3.4 机坪工作区 operation area**：机坪上供飞机停泊、进行地面作业的区域**及其邻近区域**
- **3.5 机务维修坪** / **3.6 试车坪** / **3.7 保障车辆、设备等待区** / **3.8 飞行区楼前服务车道** / **3.9 停车区**

### 照度类
- **3.10 照度 E**：入射在面元上的光通量 ÷ 面元面积（lx）
- **3.11 水平照度 Eh** / **3.12 垂直照度 Ev**
- **3.13 照度均匀度**：规定面上**最小照度 ÷ 平均照度**
- **3.14 维持平均照度**：必须维护时在规定表面上的平均照度
- **3.15 维护系数**：使用一定周期后的平均照度 ÷ 新装时的平均照度；本标准取 **0.70**

### 灯具与光源
- **3.16 灯具效率**：灯具发出总光通量 ÷ 灯具内所有光源总光通量（光输出比）
- **3.17 泛光灯 floodlight**：光束发散角（峰值光强 1/10 两方向夹角）**>10°** 的投光灯
- **3.19/3.20 显色指数 / 一般显色指数 Ra**：CIE 第 1～8 种标准色样显色指数平均值
- **3.21 相关色温**（K）

### 眩光类
- **3.22 眩光** / **3.23 不舒适眩光**
- **3.24 眩光指数 GR**：度量室外场地照明对人不舒适感主观反应的心理物理量
- **3.25 频闪效应**：一定频率光照射下，物体运动显现不同于实际运动的现象
