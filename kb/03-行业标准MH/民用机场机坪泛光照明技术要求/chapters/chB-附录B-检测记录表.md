# 附录 B 检测记录表（资料性附录）

## Core Idea

一张现场记录表模板，分**基本情况**与**检测结果**两栏，把第 7 章要求的数据全部落到表格上。

## Key Clauses

### 表头
检验编号、检验日期、检验依据、灯具输入电压、使用单位、环境温度、机位编号、检验前/后设备状况、检验设备名称与编号；校核 / 记录 / 检验 三人签字

### 基本情况
- **场地尺寸**：长度、宽度、面积、类型、型号、布置方式
- **光源**：种类、功率、数量、生产厂
- **灯具**：安装高度、倾角、维护情况、生产厂

### 检测结果（9 项）
1. 平均水平照度（lx）
2. 水平照度均匀度
3. **水平照度梯度**
4. 平均垂直照度（lx）
5. 垂直照度均匀度
6. **现场相关色温（K）**
7. **现场显色指数 Ra**
8. **眩光指数 GR**
9. **功率密度 LPD**

## 使用提示

- 第 3 项"照度梯度"只在用 **5 m 网格**时才测（7.4.1.2）
- 第 6/7 项（色温、显色指数）现场实测，用于核对 4.3.2/4.3.3 的光源要求
