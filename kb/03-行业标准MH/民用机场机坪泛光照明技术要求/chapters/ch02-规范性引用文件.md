# 2 规范性引用文件

## Core Idea

7 项引用标准，集中在**灯具安全、电磁兼容、术语、飞行区与高杆灯**。

## Key Clauses

| 标准 | 名称 | 用途 |
|---|---|---|
| **GB 7000.1** | 灯具 第 1 部分：一般要求与试验 | 灯具安全性能（4.4.2） |
| **GB 17625.1** | 电磁兼容 限值 谐波电流发射限值（≤16 A） | 灯具谐波含量（4.4.3） |
| **GB/Z 17625.6** | 电磁兼容 限值 大于 16 A 设备的谐波电流限制 | 检测时谐波判定（7.3.2） |
| **GB 17743** | 电气照明和类似设备的无线电骚扰特性限值与测量方法 | 灯具骚扰电压（4.4.5） |
| **GB/T 18595** | 一般照明设备电磁兼容抗扰度要求 | 灯具抗扰度（4.4.4） |
| **JGJ/T 119** | 建筑照明术语标准 | 术语基础（第 3 章） |
| **MH 5001** | 民用机场飞行区技术标准 | 障碍物限制面（5.2） |
| **MH/T 6013** | 机场升降式高杆泛光灯 | 灯杆强度与刚度（5.5） |
