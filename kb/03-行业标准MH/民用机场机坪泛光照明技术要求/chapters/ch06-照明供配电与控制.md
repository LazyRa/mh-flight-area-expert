# 6 照明供配电与控制

## Core Idea

10 条：**独立供电 + 相邻不同电源**、**电流 ≤70% 载流量**、**三相供电降频闪**、**TN-S 或 TT 接地**。

## Key Clauses

- **6.1** 高杆泛光灯应采用**独立电力电缆**供电；**相邻高杆泛光灯宜采用不同电源**供电
- **6.2** 全负荷时工作电流 **≤电缆载流量额定值的 70%**
- **6.3** 电缆**中性线截面 ≥相线截面**；灯具输入电压 **≤105% 且不宜 <90%** 光源额定电压
- **6.4** 宜**分区集中控制**，并应在**控制室和杆体**设手动控制装置
- **6.5** 保证安全前提下实现**照明分级控制**，可降低照度以节能
- **6.6** 泛光灯杆的**障碍灯应自动控制**，并**与其他灯具分别供电**
- **6.7** 高杆泛光灯应设**电动和手动灯盘升降装置**
- **6.8** 采用气体放电灯时应采用**三相供电系统**降低频闪；**相邻投射方向的灯具电源应接自不同相线**
- **6.9** 配电系统接地形式应采用 **TN-S 或 TT**
- **6.10** 防雷措施符合国家相关标准

## 常被问到的数值

| 问题 | 答案 |
|---|---|
| 载流量上限 | ≤70% 额定 |
| 电压允许范围 | 90%～105% 额定 |
| 中性线截面 | ≥相线截面 |
| 接地形式 | TN-S 或 TT |
| 频闪对策 | 三相供电 + 相邻接不同相线 |
