# 第5章 沥青混合料配合比设计

## Core Idea
配合比设计走**三阶段**：目标配合比 → 生产配合比 → 生产配合比验证（试拌+试验段）。验收看**马歇尔指标 + 四项路用性能**（高温动稳定度、水稳定、低温破坏应变、抗渗）。压实厚度与粒径匹配：**AC ≥3 倍公称最大粒径、SMA ≥2.5 倍**。

## 5.1 一般规定
- **5.1.1 性能要求**：混合料应满足**密实、耐久、高温稳定性、低温抗裂性、水稳定性、抗剪切**等要求。
- **5.1.2 各层混合料类型**（表 5.1.2）：
  | 层次 | 类型 |
  |---|---|
  | 上面层 | **SMA-13、SMA-16、AC-16、AC-13、AC-10** |
  | 中面层 | **SMA-16、AC-16、AC-20、AC-25** |
  | 下面层 | **AC-20、AC-25** |
  | 基层 | **ATB-25、ATB-30** |
  | 应力吸收层（封层） | **AC-5** |
  > **AC-13 和 AC-10 仅用于道肩上面层**。
- **5.1.3** 中、下面层宜用**粗粒式或中粒式**；上面层宜用**中粒式或细粒式**。
- **5.1.4 厚度匹配**：AC 混合料沥青层**压实厚度 ≥公称最大粒径的 3 倍**；SMA **≥2.5 倍**。

## 5.2 配合比设计
- **5.2.1 级配范围**：按表 5.2.1 控制（AC-5～AC-25、SMA-13/16、ATB-25/30 的逐筛通过率，本库不逐格转录）。
- **5.2.2 三阶段设计**：
  1. **目标配合比设计**：用**实际使用材料**计算各材料用量比例，合成级配符合表 5.2.1，**马歇尔试验确定最佳沥青用量**；作为拌和设备确定冷料仓供料比例、进料速度及试拌的依据；
  2. **生产配合比设计**：间歇式拌和设备**必须从二次筛分后进入各热料仓的材料取样筛分**，确定各热料仓材料比例；反复调整**冷料仓进料比例**达到供料均衡；取**目标最佳沥青用量及 ±0.3%** 三个用量做马歇尔试验，确定生产配合比最佳沥青用量；
  3. **生产配合比验证**：按生产配合比**试拌、铺筑试验段**，用拌和料做马歇尔试验及路用性能检验，并经**试验段钻芯**检验，确定**标准配合比**——作为**施工控制依据和质量检验标准**。
- **5.2.3** 马歇尔试验方法与步骤按**附录 A**。
- **5.2.4 不得随意变更**：确定的材料品种、矿料级配、沥青用量施工中不得随意变更；**材料变化时应及时调整配合比**，必要时**重新设计**。
- **5.2.5 马歇尔技术指标**：
  - **AC**（表 5.2.5-1）：击实 **75 次**（双面）、Φ101.6×63.5 mm；**空隙率 VV 3%–5%**；**稳定度 MS ≥9.0 kN**；**流值 FL 2–4 mm**；VMA 随设计空隙率与公称最大粒径取值；**VFA 55%–70% / 65%–75% / 70%–85%**。
  - **SMA**（表 5.2.5-2）：**VV 3%–4.5%**；**MS ≥6.0 kN**；流值实测；**VMA ≥16.5%**；**VFA 75%–85%**；VCAmix ≤ VCADRC；**谢伦堡析漏 ≤0.10%**；**肯塔堡飞散损失 ≤10%**。
  - **ATB**（表 5.2.5-3）：ATB-25 击实 75 次、**MS ≥7.5 kN**；ATB-30 击实 112 次（Φ152.4×95.3）、**MS ≥15 kN**；**VV 3%–6%**；VMA 按设计空隙率 4/5/6% 取 12/13/14（ATB-25）、11.5/12.5/13.5（ATB-30）；**VFA 55%–70%**。
- **5.2.6 四项性能检验**：
  1. **高温（60℃ 轮辙动稳定度，表 5.2.6-1）**：
     | 交通 | 夏炎热 | 夏热 | 夏凉 |
     |---|---|---|---|
     | 重—抗高温增强区 / 其他区 | **10 000 / 8 000** | 8 000 / 6 000 | 6 000 / 5 000 |
     | 中—抗高温增强区 / 其他区 | 8 000 / 7 000 | 7 000 / 5 000 | 5 000 / 4 000 |
     | 轻—抗高温增强区 / 其他区 | 5 000 / 4 000 | 4 000 / 3 000 | 3 000 / 2 000 |
     > 抗高温性能增强区 = 结构 **Ⅰ区**及需高温增强的场内区域；**道肩和非承重区一般不要求**。
  2. **水稳定性（表 5.2.6-2）**：浸水马歇尔残留稳定度 **普通 ≥85%、改性 ≥90%**；冻融劈裂残留强度比 **普通 ≥80%、改性 ≥85%**；
  3. **低温抗裂（−10℃ 弯曲破坏应变，表 5.2.6-3）**：普通 **冬严寒 ≥2 800、冬寒 ≥2 500、冬冷 ≥2 000 με**；改性 **冬寒 ≥3 000、冬冷 ≥2 500 με**；
  4. **抗渗（表 5.2.6-4）**：**密级配 ≤80 ml/min**；**SMA ≤50 ml/min**。

## Reference — 关键数值速查（本章）
| 项 | 值 |
|---|---|
| 压实厚度/公称最大粒径 | AC **≥3 倍**、SMA **≥2.5 倍** |
| AC 稳定度 / 空隙率 / 流值 | ≥9.0 kN / 3%–5% / 2–4 mm |
| SMA 稳定度 / 空隙率 / VMA | ≥6.0 kN / 3%–4.5% / ≥16.5% |
| SMA 析漏 / 飞散 | ≤0.10% / ≤10% |
| 动稳定度（重·夏炎热·增强区） | **≥10 000 次/mm** |
| 残留稳定度 / 冻融劈裂（改性） | ≥90% / ≥85% |
| 低温破坏应变（冬严寒·普通） | ≥2 800 με |
| 渗水系数（密级配/SMA） | ≤80 / ≤50 ml/min |
| 生产配合比沥青用量试拌点 | 最佳 ±0.3%（三点） |
