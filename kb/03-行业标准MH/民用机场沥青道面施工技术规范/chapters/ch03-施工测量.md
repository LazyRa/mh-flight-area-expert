# 第3章 施工测量

## Core Idea
以建设单位提供的**机场统一平面/高程控制网**为唯一基准，复测合格后接管并保护。控制点要求：全机场（或跑道附近）**4～5 个永久性控制点**，埋设于**跑道端安全区边线以外 200 m**；道面**高程误差不大于 ±2 mm**。

## 3.1 一般规定
- **3.1.1** 施工测量应以建设单位提供的**机场统一平面、高程控制（网）点及其成果**作为控制基准。
- **3.1.2** 施工测量前，施工单位应对上述控制（网）点及成果**进行复测检查**。
- **3.1.3** 复测合格后**正式接管**并**妥善保护**；竣工后应将**全部测量成果资料**（含竣工测量资料、数据、图纸、计算结果）分类装册，作为竣工资料附件。

## 3.2 施工控制测量
- **3.2.1 控制点布设**：
  - 埋设位置应**通视和净空条件良好**、**无明显电磁干扰**，便于 GNSS 接收机、激光发射器、全站仪、水准仪架设观测；
  - 应**不影响飞行安全**且能永久保存；
  - 可在**跑道两端中心延长线**上、**距跑道端安全区边线以外 200 m** 处埋设；
  - 全机场（或跑道附近）应有 **4～5 个永久性测量控制点**。
- **3.2.2 标石规格**：应采用**永久性混凝土标石**；顶面**不小于 150 mm×150 mm**，底面**不小于 250 mm×250 mm**；埋深**大于 800 mm**；寒冷地区标石底部应埋设于**最大冰冻线以下 200 mm**；标石顶面**高出完工后场地标高 50～100 mm**。
- **3.2.3 平面/高程控制测量**：
  1. 平面控制可采用 **GNSS 卫星定位、导线测量、边角组合测量**；**高程控制应采用水准测量**；
  2. 布设**必须利用 2 个以上控制点**作为起算数据，并应布设成**附合或闭合网形**。
- **3.2.4 控制网损坏**：机场统一控制（网）点损坏严重、不能控制施工区域时，**由原测量单位负责恢复**并提交建设单位；建设单位组织**验收合格后**提供施工方使用。

## 3.3 测量精度
- **3.3.1 平面控制**：
  1. 施工控制网点测量应符合 **GB 50026 一级卫星定位测量**规定；导线测量按**一级导线**要求（表 3.3.1-1、3.3.1-2）；
  2. 施工放线定位测量应符合 **GB 50026 二级卫星定位测量**规定；导线按**二级导线**；
     - 表 3.3.1-1：一级 平均边长 **1 km**、固定误差 A **≤10 mm**、比例误差 B **≤20 mm/km**、最弱边相对中误差 **≤1/20000**；二级 平均边长 **0.5 km**、B **≤40 mm/km**、最弱边 **≤1/10000**；
     - 表 3.3.1-2：一级 导线长 4 km、平均边长 0.5 km、测角中误差 5″、测距中误差 15 mm、测回数（2″/6″）2/4、方位角闭合差 10√n、全长相对闭合差 **1/15000**；二级 2.4 km、0.25 km、8″、15 mm、1/3、16√n、**1/10000**；
  3. 有条件项目可用 **RTK** 布设平面控制点（符合 CH/T 2009），点位选择按 **GB/T 18314**；表 3.3.1-3：一级 相邻点平均边长 **500 m**、点位中误差 **≤±5 cm**、边长相对中误差 **≤1/20000**、与基准站距离 ≤5 km、观测次数 ≥4、起算点四等及以上；二级 300 m、±5 cm、1/10000、≤5 km、≥3、一级及以上。
- **3.3.2 高程控制**：
  1. 施工控制网点高程测量应符合 **GB 50026 二等水准**；工程点高程测量符合**三等水准**（表 3.3.2）；
  2. 表 3.3.2：二等 每千米高差全中误差 **2 mm**、DS1+铟瓦尺、往返各一次、平地闭合差 **4√L**；三等 **6 mm**、路线长 ≤50 km、DS1/DS3、平地 **12√L**、山地 **4√n**；
  3. 各施工点高程用**水准仪直接后视控制桩检测**，**不得两次转点引测**，道面工程**高程误差不大于 ±2 mm**。

## 3.4 沥青道面施工的工程测量
- **3.4.1 放线定位**：
  1. 测设道面中心线，**跑道还应加测道面边线**，宜每 **100～150 m** 布设一个满足高程精度要求的施工控制点；
  2. 结合卫星定位与摊铺机**液压控制**技术，在符合 3.3.2 前提下，可采用**无桩 3D 数字化施工**等先进技术辅助控制摊铺机高程。
- **3.4.2 灯具定位与复位**：铺筑前按 3.4.1 的施工控制点测量**各灯具中心点位置**（可按**三级导线**测设）；施工完毕后用 **GNSS、全站仪**进行**灯位复位测量**，新安装灯位应在**原有中心位置**。

## Reference — 关键数值速查（本章）
| 项 | 值 |
|---|---|
| 永久性控制点数量 | **4～5 个** |
| 控制点位置 | 跑道端安全区边线外 **200 m** |
| 标石顶面/底面 | ≥150×150 mm / ≥250×250 mm |
| 标石埋深 | **>800 mm**（寒区至冰冻线下 200 mm） |
| 标石顶面高出场地 | 50～100 mm |
| 起算控制点数量 | **≥2 个**，附合或闭合网形 |
| 道面高程误差 | **≤±2 mm** |
| 施工控制点间距（中心线/边线） | 每 **100～150 m** |
| 灯位复位 | 应在原有中心位置 |
