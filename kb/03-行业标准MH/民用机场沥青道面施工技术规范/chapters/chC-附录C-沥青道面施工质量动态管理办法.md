# 附录 C 沥青道面施工质量动态管理办法

## Core Idea
用**统计过程控制（SPC）**管施工质量：以**变异系数（或标准差）**作为施工水平的主要评价指标，绘制 **X̄–R 管理图**（均值—极差）与**直方图 + 正态分布曲线**，用**质控上下限 UCL/LCL**判定异常。超出上下限即视为**施工异常或数据异常**。

## C.0.1 评价指标
- 以试验检测质量指标的**变异系数（或标准差）**作为**施工水平的主要评价指标**。

## C.0.2 逐次/逐日曲线
- 宜绘制各技术指标的**逐次检测结果 X** 或**逐日检测结果平均值 X̄** 曲线，检查是否超出规范允许误差范围；不符合时**认真分析原因并采取措施**；
- 分阶段（一定日期或距离）计算逐日结果平均值的**平均值 X̄（期望值）、极差 R、标准差 S、变异系数 Cv**，汇总整理；
- 记录内容应包括**取样地点、时间、试验员、试验项目、试验方法、试验结果**。

## C.0.3 管理图与直方图
- 宜采用**平均值和极差管理图（X̄–R）**，将试验结果**逐次绘制管理图**（图 C.0.3-1）；
- 随施工进度绘制**施工质量直方图 + 正态分布曲线**（图 C.0.3-2）；
- 当**标准差及变异系数有增大倾向**时，应**分析原因、提出改进建议**。

## C.0.4 中心线与质控限
以平均值 X̄ 作中心线 CL，标出**质控上限 UCL** 与**质控下限 LCL** 表示允许的正常波动范围；**超出上/下限即视为施工异常或试验数据异常**。

**X̄ 图**
- **CL = X̄**（C.0.4-1）
- **UCL = X̄ + A₂·R̄**（C.0.4-2）
- **LCL = X̄ − A₂·R̄**（C.0.4-3）

**R 图**
- **CL = R̄**（C.0.4-4）
- **UCL = D₄·R̄**（C.0.4-5）
- **LCL = D₃·R̄**（C.0.4-6）

> A₂、D₃、D₄ 由**一组检测结果的试验次数 n** 决定，按**表 C.0.4** 取值。

## C.0.5–C.0.7 应用
- **C.0.5** 在 X̄–R 管理图和直方图上**可标出第 8 章规定的质量标准或允许差范围**；
- **C.0.6** 各级工程管理部门宜**随时查询或检查所有数据**；
- **C.0.7** 施工结束后宜**汇总全部数据**，计算平均值、标准差、变异系数，绘制整个工程的分布图。

## Reference — 适用指标（8.2.11）
沥青混合料**温度、油石比、级配、马歇尔稳定度、流值**，以及道面**压实度、厚度、平整度**等。
