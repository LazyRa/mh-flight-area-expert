# 第4章 材料

## Core Idea
材料进场**三关**：出厂合格证/质保书 → 现场取样检验合格 → 签发验收单登记。技术核心是**按气候分区 + 交通量选沥青标号**，以及**细集料必须用机制砂**（禁用石屑、天然砂）。共 14 类材料要求。

## 4.1 一般规定
- **4.1.1** 沥青、矿料、外掺剂等原材料**必须具有出厂（场）合格证或质保书**；进口材料应提供**海关商检合格证明**。
- **4.1.2** 进场应**按规定检验并登记**，签发**材料验收单**（含产地、品种、规格、数量、质量、日期）。
- **4.1.3** 各种材料运至现场后**必须取样检验，合格后方可使用**。
- **4.1.4** 矿料选择应遵循**就地取材**原则。
- **4.1.5** 成品改性沥青应提供**名称、代号、标号、成分、质量检验单**及运输/贮存/使用方法、健康环保安全资料。
- **4.1.6** 现场改性沥青应**针对不同原材料做配方优化设计**，检测合格后使用。

## 4.3 沥青
- **4.3.1 机场道面石油沥青**（表 4.3.1）：25℃ 针入度 A-130 **120–140**、A-110 100–120、A-90 80–100、A-70 60–80、A-50 40–60（0.1 mm）；10℃ 延度 **≥50/50/50/50/40 cm**；软化点 **≥40/43/45/46/49 ℃**；闪点 ≥230/245/260 ℃；含蜡量 **≤2.2%**；溶解度 **≥99.0%**；60℃ 动力粘度 **≥60/120/160/180/200 Pa·s**；**135℃ 运动粘度 ≤3 Pa·s**；RTFOT/TFOT 质量变化 **±0.8%**、针入度比 **≥54/55/57/61/63%**。
  > 条文说明：取消重交通道路石油沥青要求，统一以 **A** 表示机场道面石油沥青；新增 **135℃ 运动粘度**保证施工和易性。
- **4.3.2 改性沥青**（表 4.3.2）：**用于改性的基质沥青应采用机场道面石油沥青**。
  - SBS 类 Ⅰ-A～Ⅰ-D 软化点 **≥55/60/65/75 ℃**；5℃ 延度 **≥40/35/25/20 cm**；25℃ 弹性恢复 **≥60/65/70/75%**；贮存稳定性 48 h 软化点差 **≤2 ℃**；135℃ 运动粘度 ≤3 Pa·s；
  - SBR 类（Ⅱ）增加**粘韧性 ≥5.0 N·m、韧性 ≥2.5 N·m**；
  - 条文说明：改用 **5℃ 延度**评价低温性能、**25℃ 弹性恢复**代替 15℃。
- **4.3.3 抗紫外老化**：用于**太阳辐射极强烈或强烈区**上面层的沥青，应按 **MH/T 5010 附录 G.2** 评价，**紫外老化后残留延度比（15℃）≥60%**。

## 4.7 湖沥青 SBS 复合改性沥青

## 4.9 矿料
- **4.9.1 粗集料**（表 4.9.1-1）：**应采用岩石破碎加工的碎石**，有足够强度硬度、清洁干燥：
  | 指标 | 上面层 | 中、下面层 |
  |---|---|---|
  | 压碎值 | **≤20%** | ≤23% |
  | 洛杉矶磨耗损失 | ≤28% | ≤30% |
  | 表观相对密度 | **≥2.6** | ≥2.5 |
  | 吸水率 | ≤2.0% | ≤2.0% |
  | **粘附性（水煮法）** | **≥5 级** | ≥5 级 |
  | 坚固性 | ≤10% | ≤12% |
  | 针片状颗粒含量 | ≤12%（>9.5mm ≤10%、<9.5mm ≤15%） | ≤15%（≤12%、≤18%） |
  | 水洗法 <0.075 mm | ≤1% | ≤1% |
  | 软石含量 | ≤2% | ≤3% |
  | **磨光值 PSV** | **≥42** | — |
  - 颗粒形状**宜接近立方体**，表面粗糙富有棱角；粒径规格 S1–S9（表 4.9.1-2）；
  - 粘附性不符合要求时**应采取抗剥落措施**（由试验确定）；
  - 碎石供应确有困难地区经**专项论证**可用破碎砾石，4.75 mm 及以上颗粒**1 个以上破碎面 ≥90%、2 个以上 ≥80%**（表 4.9.1-3）。
- **4.9.2 细集料**（表 4.9.2-1）：**应采用机制砂**，清洁、干燥、质地坚硬、耐久、无杂质：
  - 表观相对密度 **≥2.50**；坚固性（>0.3 mm 部分）**≤12%**；塑性指数 **≤4**；砂当量 **≥60%**；**亚甲蓝值 ≤2.5 g/kg**；**棱角性（流动时间）≥30 s**；
  - 规格 S10（0–5）、S11（0–3）；
  - **与沥青粘结性能差的机制砂不得在上面层使用**。
  > 条文说明：禁用石屑（粉尘多、强度低、扁片多）与天然砂（浑圆、粘附差）；新增**亚甲蓝值**与**棱角性**指标。
- **4.9.3 矿粉**（表 4.9.3-1）：应采用**石灰石、白云石等碱性石料**磨细，干燥洁净无风化：
  - 表观相对密度 **≥2.50**；含水率 **≤1%**；级配 <0.6 mm **100%**、<0.15 mm **90–100%**、<0.075 mm **80–100%**；无团粒结块；亲水系数 **≤1**；塑性指数 **≤6**；
  - 可用**水泥、消石灰粉代替部分矿粉**，总量**不宜超过矿料总重的 2%**；
  - **搅拌设备集尘装置回收的粉尘不得用作矿粉**。

## 4.10 纤维
- **4.10.1 木质素纤维**（表 4.10.1）：纤维长度 **≤6 mm**；灰分含量 **18±5%**；pH **7.5±1.0**；**吸油率 ≥纤维质量的 5 倍**；含水率 **≤5%**；耐热性（**210 ℃、2 h**）颜色体积基本无变化。
- **4.10.2 聚丙烯腈纤维**（表 4.10.2）：密度 **≥1.18 g/cm³**；长度 **6±1.5 mm**；平均直径 **0.010–0.025 mm**；熔点 **≥220 ℃**；弹性模量 **≤17.0 GPa**；含水率 ≤5%；耐热性（210 ℃、2 h）基本无变化。
