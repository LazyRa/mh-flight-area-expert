# 附录 A 密级配沥青混合料配合比设计步骤与方法

## Core Idea
给出 **AC（密级配）混合料**的完整配合比设计步骤：**材料取样 → 矿料级配设计 → 马歇尔试验 → 最佳沥青用量确定 → 三阶段验证**。方法基础是**马歇尔试验**，试验执行 **JTG E20**，拌和必须用**小型沥青混合料拌和机**。

## A.1 一般规定
- **A.1.1** 采用**马歇尔试验配合比设计方法**，适用于**密级配**沥青混合料。
- **A.1.2** 热拌混合料配合比设计应通过**目标配合比设计、生产配合比设计、生产配合比验证**三阶段，确定**材料品种及配比、矿料级配、最佳沥青用量**。
- **A.1.3** 目标配合比设计宜按**图 A.1.3** 步骤进行。
- **A.1.4** 试验方法按 **JTG E20**；**拌和必须采用小型沥青混合料拌和机**；拌和温度与试件制作温度应符合本规范要求。
- **A.1.5** 生产配合比设计可参照本方法。

## A.2 材料选择与准备
- **A.2.1** 矿料应按 **JTG E42** 从**工程实际使用材料**中取**代表性样品**；**生产配合比设计取样至少应在干拌 5 次以后**进行。
- **A.2.2** 材料必须符合**气候和交通条件**需要，质量符合本规范**第 4 章**；单一规格级配不满足但**不同粒径组合后满足**时**允许使用**。

## A.3 矿料配合比设计
- **A.3.1** 宜借助**电子表格用试配法**进行。
- **A.3.2** 级配曲线按 **JTG E20 T0725** 绘制。
- **A.3.3 三组粗细配比**：在设计级配范围内计算 **1～3 组**粗细不同配比，设计级配曲线分别位于范围的**上方、中值、下方**；合成级配**不得有太多锯齿形交错**，且在 **0.3～0.6 mm** 范围内**不出现"驼峰"**；反复调整不满意时**宜更换材料**。
- **A.3.4** 可按当地经验选沥青用量，分别制作几组级配马歇尔试件测 **VMA**，初选满足或接近设计要求的一组作为**设计级配**。

## A.4 马歇尔试验
- **A.4.1** 技术标准符合**第 5 章**。
- **A.4.2 试件制作温度**按 6.1.2 确定并与施工实际一致；普通沥青缺粘温曲线时参照**表 A.4.2**（沥青加热 A-50 160–170 → A-130 140–150 ℃；**矿料加热比沥青高 10～30 ℃（填料不加热）**；拌和 150–170 → 130–150 ℃；**击实成型 140–160 → 120–140 ℃**）；**改性沥青在此基础上再提高 10～20 ℃**。
- **A.4.3 合成毛体积相对密度 γsb**：**γsb = 100 / (P₁/γ₁ + P₂/γ₂ + … + Pn/γn)**（A.4.3）；均用**毛体积相对密度**（无量纲），故**无须水温修正**；生产配合比时细料仓混杂无法用筛分替代法时，可**筛除 0.075 mm 部分后以统货实测值计算**。
- **A.4.4 合成表观相对密度 γsa**：按式 A.4.4 以各矿料**表观相对密度**加权计算。
- 后续：计算**有效相对密度 γse**、**最大理论相对密度**、试件毛体积相对密度，按体积参数（VV、VMA、VFA）确定**最佳沥青用量 OAC**。

## Reference — 设计链
```
取样（干拌≥5次后）
   → 三组级配（上/中/下）→ 测 VMA → 定设计级配
   → 马歇尔试件（温度见表 A.4.2）
   → 体积参数（γsb/γsa/γse → VV/VMA/VFA）
   → 最佳沥青用量 OAC
   → 性能验证（第 5 章四项）
   → 生产配合比 → 试拌试铺验证
```
