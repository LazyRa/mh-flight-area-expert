# 附录 B SMA 沥青混合料配合比设计方法

## Core Idea
SMA 用**马歇尔试件的体积设计法**——**稳定度和流值不作为接受与否的唯一指标**，核心是**粗集料骨架（VCA）**与**沥青玛蹄脂**的平衡。设计要点：粗集料骨架分界筛孔（公称最大粒径 ≤9.5 mm 用 **2.36 mm**，≥13.2 mm 用 **4.75 mm**）、三组初试级配、**VCAmix ≤ VCADRC**、纤维比例**不得忽略**。

## B.1 一般规定
- **B.1.1** 采用**马歇尔试件体积设计方法**；**马歇尔稳定度和流值不作为配合比设计接受或否决的唯一指标**。
- **B.1.2** 除另有规定外，按**附录 A** 执行。

## B.2 材料选择
- **B.2.1** 按附录 A 选择，质量必须符合**第 4 章**。
- **B.2.2** **SMA 宜采用改性沥青**。

## B.3 设计矿料级配的确定
- **B.3.1 初试级配**：
  1. 设计级配范围宜直接采用**表 5.2.1**；**粗集料骨架分界筛孔**：公称最大粒径 **≤9.5 mm 用 2.36 mm**，**≥13.2 mm 用 4.75 mm**；
  2. 在范围内调整比例设计 **3 组**不同粗细初试级配，其**分界筛孔通过率处于中值、中值 ±3% 附近**，**矿粉用量宜 10% 左右**。
- **B.3.2** 按附录 A 计算 **γsb、γsa、γse**（毛体积/表观相对密度试验方法同附录 A）。
- **B.3.3** 筛除小于分界筛孔的集料，按 **JTG E42 T0309 捣实法**测粗集料骨架**松方毛体积相对密度 γS**，按式 B.3.3 计算骨架平均毛体积相对密度 **γCA**。
- **B.3.4 松装间隙率**：**VCADRC = (1 − γS/γCA) × 100**（B.3.4）。
- **B.3.5** 按 A.4.5 预估适宜**油石比 Pa / 沥青用量 Pb**，作为**初试油石比**。
- **B.3.6** 按初试油石比与级配制作试件：**马歇尔标准击实双面 75 次**，**一组试件不得少于 4～6 个**；**毛体积相对密度由表干法测定**。
- **B.3.7 最大理论相对密度**：按式 B.3.7 计算，**纤维部分的比例不得忽略**（γt 由 γse、Pa、沥青相对密度 γa、纤维掺量 Px 与纤维相对密度 γx 共同决定）。
- 后续：计算 **VCAmix**，要求 **VCAmix ≤ VCADRC**（骨架嵌挤成立）；按 **VV 3%–4.5%、VMA ≥16.5%、VFA 75%–85%、析漏 ≤0.10%、飞散 ≤10%**（表 5.2.5-2）确定最佳沥青用量；再做四项性能验证。

## Reference — SMA 与 AC 设计差异
| 项 | AC（附录 A） | SMA（附录 B） |
|---|---|---|
| 方法 | 马歇尔试验 | **体积设计法** |
| 稳定度/流值 | 作为控制指标 | **不作为唯一接受/否决指标** |
| 骨架控制 | 无 VCA 要求 | **VCAmix ≤ VCADRC** |
| 关键筛孔 | — | 2.36 mm（≤9.5）或 4.75 mm（≥13.2） |
| 纤维 | 无 | **比例不得忽略** |
| 击实次数 | 75 | 75（一组 4～6 个试件） |
