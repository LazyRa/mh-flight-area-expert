# 第2章 术语和符号

## Core Idea
界定**沥青类材料**（石油沥青、改性沥青、乳化沥青、液体沥青、橡胶沥青、湖沥青 SBS 复合改性、高粘改性）、**矿料**（粗/细集料、矿粉、机制砂）、**结构层与功能层**（面层、加铺层、透层、粘层、封层）与**性能指标**（MS、DS、低温破坏应变、TSR）。

## 2.1 术语（2.1.1–2.1.36）

### 沥青类
- **2.1.1 机场道面石油沥青**：供机场沥青道面使用并符合其技术要求的石油沥青。
- **2.1.2 改性沥青**：掺加**橡胶、树脂、热塑性弹性聚合物**等外掺剂（改性剂）以改善性能的沥青。
- **2.1.3 乳化沥青**：沥青和水在**乳化剂**作用下制成的稳定乳状液。
- **2.1.4 改性乳化沥青**：制备乳化沥青过程中**同时加入改性剂**，或对改性沥青进行乳化加工得到的乳状液。
- **2.1.5 液体沥青**：用**汽油、煤油、柴油**等溶剂将石油沥青稀释而成（也称轻质沥青/稀释沥青）。
- **2.1.6 橡胶沥青**：沥青 + **回收轮胎橡胶粉** + 添加剂（必要时），高温下充分**反应融胀**形成的混合物。
- **2.1.7 湖沥青 SBS 复合改性沥青**：用专用设备将**湖沥青与 SBS 改性沥青**按一定比例混合均匀的特殊改性沥青。
- **2.1.8 高粘改性沥青**：将一定比例**高粘添加剂**加入基质沥青，经**剪切混融**制备的改性沥青。

### 矿料类
- **2.1.11 矿料**：**集料与矿粉**的总称。
- **2.1.12 粗集料**：碎石经加工而成、粒径 **>2.36 mm** 的集料。
- **2.1.13 细集料**：粒径 **<2.36 mm** 的**天然砂、机制砂及石屑**等总称。
- **2.1.14 矿粉**：由**石灰岩等碱性石料**磨细得到的矿物质粉末。
- **2.1.15 机制砂**：经**机械破碎**加工得到的粒径 <2.36 mm 集料。
- **2.1.16 抗剥落剂**：为增强抗水损害能力，在沥青中加入的**表面活性剂**，或在混合料中加入的**消石灰、水泥**等。
- **2.1.19 集料最大公称粒径**：集料**全部通过或少量不通过**（一般容许筛余**不超过 10%**）的最小标准筛筛孔尺寸，通常比最大粒径小一个粒级。

### 混合料类
- **2.1.17 沥青混合料**：由矿料、沥青等拌和形成的混合物。
- **2.1.18 密级配沥青混合料（AC）**：按**最大密实原则**设计、**设计空隙率不大于 6%** 的混合料。
- **2.1.20 细粒式**：最大公称粒径 **9.5 或 13.2 mm**。
- **2.1.21 中粒式**：最大公称粒径 **16 或 19 mm**。
- **2.1.22 粗粒式**：最大公称粒径 **26.5 或 31.5 mm**。
- **2.1.23 SMA**：由**粗集料形成嵌挤骨架**，沥青胶结料、细集料、矿粉填充骨架间隙的**间断级配**混合料。
- **2.1.24 ATB**：用于**道面基层**的沥青稳定碎石混合料。

### 结构层与功能层
- **2.1.25 透层**：为使面层与基层结合良好，在**基层表面**喷洒液体稀释沥青或乳化沥青，**透入基层表面一定深度**的薄层。
- **2.1.26 粘层**：为加强**沥青层之间**、**沥青层与水泥混凝土道面之间**粘结而洒布的沥青薄层。
- **2.1.27 封层**：为**封闭表面空隙、防止水分侵入**，在基层上或原有道面上铺筑的沥青或沥青混合料薄层。
- **2.1.28 沥青面层**：直接承受飞机荷载的结构层；多层时自上而下分**上面层、中面层、下面层**。
- **2.1.29 沥青加铺层**：原道面**表面状况不符合使用要求或承载能力不足**时，在原道面上加铺的沥青面层。
- **2.1.30 橡胶沥青碎石封层**：用专用设备将**橡胶沥青和单一粒径碎石**洒（撒）布在道面形成的封层。
- **2.1.31 无纺土工织物**：由短纤维或长丝随机/定向排列制成的薄絮垫，经**机械结合、热黏合或化学黏合**而成。
- **2.1.32 SBS 防水卷材**：以工程纤维机织物为**表面增强层**、工程纤维毡为**胎基**、聚合物改性沥青为**上下浸渍涂层**、聚酯膜为**底面隔离膜**，复合而成，具**自粘、防水与抗裂**作用。

### 指标类
- **2.1.9 沥青含量**：沥青质量 / 混合料总质量（%）。
- **2.1.10 油石比**：沥青质量 / **矿料总质量**（%）。
- **2.1.33 马歇尔稳定度 MS**：马歇尔试件能承受的最大荷载（kN）。
- **2.1.34 动稳定度 DS**：轮辙试验稳定期后每产生 **1 mm** 轮辙试验轮行走次数（次/mm）。
- **2.1.35 低温弯曲破坏应变**：低温弯曲试验时试件破坏的最大弯拉应变（με）。
- **2.1.36 冻融劈裂残留强度比 TSR**：冻融试件抗拉强度与未冻融试件抗拉强度之比（%）。
