# 第1章 总则

## Core Idea
规范**民用机场沥青道面施工与质量检验**的方法和标准，适用于新建、扩建、改建**运输机场**（含军民合用机场的民用部分），通用机场参照执行。两条硬要求：**施工前须制定施工组织方案**；**不停航施工必须制定确保飞行安全的施工技术方案**。

## Key Clauses
- **1.0.1 制定目的**：规范民用机场沥青道面施工，保证**施工质量、安全**，做到**技术先进、绿色环保**。
- **1.0.2 适用范围**：适用于**新建、扩建和改建民用运输机场**（**含军民合用机场的民用部分**）的沥青道面施工；**通用机场参照执行**。
- **1.0.3 内容定位**：规定民用机场沥青道面**施工与质量检验的方法和标准**。
- **1.0.4 施工组织**：施工前**应制定施工组织方案**，并做好各项准备工作。
- **1.0.5 不停航施工**：沥青道面不停航施工**必须制定确保飞行安全的施工技术方案**。
- **1.0.6 环保**：施工应符合国家**环境和生态保护**的相关规定。
- **1.0.7 符合性**：除本规范外，尚应符合国家现行相关标准的规定。

## Key Concepts
- **设计—施工分工**：本规范只管**施工与检验**；结构厚度、材料指标的设计取值见 **MH/T 5010-2025**（沥青道面设计规范）。
- **不停航施工**是本规范独立成章（第 7 章）的高风险场景，与 CCAR-139B 的不停航施工管理互为技术—管理配套。
