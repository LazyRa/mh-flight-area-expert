# 2 术语及符号

## Core Idea

10 条术语把"环氧沥青两兄弟"分清：**结合料**（拌混合料用）与**黏结料**（做黏结层用）；"固化试件 / 未固化试件"是两套不同的强度判据。

## Key Clauses

| 条 | 术语 | 要点 |
|---|---|---|
| 2.1.1 | **环氧沥青** | 由**环氧树脂、固化剂和沥青**组成的高性能铺筑材料，分**结合料**与**黏结料** |
| 2.1.2 | 环氧沥青混合料 | 环氧沥青 + 一定级配集料拌和而成 |
| 2.1.3 | 环氧沥青含量 | 结合料质量 ÷ 混合料总质量（%） |
| 2.1.4 | **环氧沥青黏结层** | 洒布/涂覆**黏结料**形成的层，功能是**防水 + 协调层间变形** |
| 2.1.5 | 环氧沥青道面 | 面层中**任一层**采用环氧沥青混合料铺筑的道面 |
| 2.1.6 | 环氧沥青加铺层 | 为改善使用功能或增强结构强度而加铺的环氧沥青混合料层 |
| 2.1.7 | **容留时间 retention time** | 规定温度下，结合料**黏度增长至规定值**（**3 Pa·s**）的时段长度 —— 即从开始拌和到铺筑碾压结束的**最大容许时间** |
| 2.1.8 | 结合料固化试件 | 规定条件（温度、时间）下固化后的结合料试件 |
| 2.1.9 | 混合料**固化试件** | 规定条件（如 **120 ℃ 下 4 h**）固化后的试件 → 代表**最终强度** |
| 2.1.10 | 混合料**未固化试件** | 成型后**冷却至室温**、未按规定条件固化的试件 → 代表**开放交通时的强度** |

## 符号

`EAC-10/13/16/20` —— 密级配环氧沥青混合料（最大公称粒径 9.5/13.2/16/19 mm）
`ESMA-10/13/16` —— 环氧沥青玛蹄脂碎石混合料（9.5/13.2/16 mm）
`CDF` —— 累积损伤因子；`EA` —— 抗压回弹模量设计值；`S` —— 标准差；`α` —— 保证率系数

## 两个易混点

1. **结合料 vs 黏结料**：结合料强度要求 ≥1.0 MPa、黏结料 ≥1.2 MPa（黏结料更高）
2. **固化试件 vs 未固化试件**：前者评"最终强度"（稳定度 ≥20/15 kN），后者评"能不能开放交通"（≥8/5 kN）
