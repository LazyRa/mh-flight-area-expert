# 5 环氧沥青加铺层设计

## Core Idea

加铺层分**结构性补强层**（要算厚度）与**功能性加铺层**（只需满足最小厚度）；最小控制厚度按**原道面类型**区分：旧沥青 **≥30 mm**、旧水泥 **≥50 mm**。

## Key Clauses

- **5.1.1** 加铺前对旧道面**检测、评价与处治**，流程符合 MH/T 5010
- **5.1.2** 分**结构性补强层**（须计算加铺厚度）与**功能性加铺层**（满足表 3.3.3 最小厚度）
- **5.1.3** 不停航条件下，设计措施符合 MH/T 5010 中不停航沥青加铺的相关规定
- **5.2.1** 加铺层可**单层或多层**；类型按表 3.3.2 选；**道肩上面层宜用 EAC-10、EAC-13**，中下面层宜用 EAC-10、EAC-13、EAC-16
- **5.2.2 最小控制厚度**
  - 原道面上面层为**沥青道面** → **≥30 mm**
  - 原道面为**水泥混凝土道面** → **≥50 mm**
- **5.2.3** 在旧沥青/旧水泥道面上加铺时，须在原道面与加铺层之间**洒布环氧沥青黏结层**（符合第 7 章）
- **5.3.1** 加铺厚度按**附录 D 典型结构**选用并计算确定
- **5.3.2** 可参照 MH/T 5010 计算；特殊工程须**专门课题研究**

## 常被问到的数值

| 问题 | 答案 |
|---|---|
| 旧沥青道面上加铺最小厚度 | 30 mm |
| 旧水泥道面上加铺最小厚度 | 50 mm |
| 是否必须洒黏结层 | 必须（5.2.3） |
