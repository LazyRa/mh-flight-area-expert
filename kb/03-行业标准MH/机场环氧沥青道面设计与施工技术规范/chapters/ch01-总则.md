# 1 总则

## Core Idea

环氧沥青道面 = 用**环氧树脂改性沥青**铺筑的高性能道面，核心优势是**抗轮辙、抗油污、抗吹蚀、长寿命**。本规范管设计 + 施工 + 质量控制。

## Key Clauses

- **1.0.1** 为规范民用机场（含军民合用机场民用部分）**环氧沥青道面工程**的设计、施工和质量控制，制定本规范
- **1.0.2 适用范围**：新建、改扩建民用机场环氧沥青道面的**设计和施工**，以及**使用环氧沥青维修材料的机场道面维护工程**
- **1.0.3** 规定设计、施工与质量控制的**方法和标准**
- **1.0.4 基本要求**
  1. 应根据**适用机型、航空交通量**，结合气候、水文、地质、材料、施工条件设计
  2. 特殊气候、地质或使用需求条件下，除符合本规范外应**专项研究**
  3. 施工前应编制**施工组织设计**；不停航施工须制定确保飞行安全的技术措施
  4. 遵循**安全、环保、节约**原则
- **1.0.5** 尚应符合国家和行业现行有关标准

## 为什么用环氧沥青（条文说明要点）

- 机场沥青道面主要病害是**轮辙变形类**和**裂缝类**；新一代大型机型投入运营后**抗轮辙**尤其关键
- 环氧树脂在固化剂作用下形成**不可逆空间网络体系**，强度高
- 环氧沥青混合料强度与模量约为改性沥青混合料的 **2～6 倍**
- 应用史：1959–1962 年美国近 20 个空军基地与洛杉矶机场跑道加铺层（抗油料侵蚀与高温尾喷）；1973 年伦敦机场环氧沥青碎石抗滑层；1980 年多哈机场抗滑表层
