# 3 结构层组合设计与计算

## Core Idea

设计年限 **30 年**；除环氧沥青层本身，其余结构层与计算方法**全部沿用 MH/T 5010**；判据是 **CDF ≤1.0**。

## Key Clauses

### 3.1 一般规定
- **3.1.1 设计年限可为 30 年**（一般改性沥青道面远低于此）
- **3.1.2** 结构组合含**面层、基层**，必要时基层下设**垫层**；面层中应含**一层或多层**环氧沥青混合料
- **3.1.3** 除环氧沥青层外的各结构层技术要求与参数符合 **MH/T 5010**
- **3.1.4 设计流程与指标**
  - 设计流程、航空交通量等级划分、气候分区符合 **MH/T 5010**
  - 针对**轮辙**与**疲劳开裂**两类损坏模式，按基层类型分别验算：

| 基层结构类型 | 控制损坏模式 | 力学设计指标 |
|---|---|---|
| 粒料类或沥青稳定类 | 沥青面层疲劳开裂 | 沥青面层**底面水平拉应变** |
| | 沥青道面轮辙 | **道基顶面竖向压应变** |
| 无机结合料稳定类 | 无机结合料稳定类基层疲劳开裂 | 基层**底面水平拉应力** |
| | 沥青道面轮辙 | 沥青面层**竖向剪应力** |

  - 采用**累积损伤因子 CDF** 作为设计指标，按 MH/T 5010 计算，**达到设计年限时 CDF ≤1.0**
  - 结构厚度分区符合 MH/T 5010

### 3.2 基层结构组合设计
- **3.2.1** 基层可用**无机结合料稳定类、沥青稳定类、粒料类**
- **3.2.2** 基层结构组合符合 MH/T 5010

### 3.3 面层结构组合设计
- **3.3.1** 环氧沥青混合料适用于**跑道、滑行道、联络道、停机坪**沥青面层各结构层；抗轮辙/抗油污/抗吹蚀/耐久性要求高的机场宜**优先选用**
- **3.3.2 各层可选类型（表 3.3.2）**

| 层次 | 可选类型 |
|---|---|
| 上面层 | EAC-10、EAC-13、EAC-16、ESMA-10、ESMA-13 |
| 中面层 | EAC-13、EAC-16、ESMA-13、ESMA-16 |
| 下面层 | EAC-16、EAC-20、ESMA-13、ESMA-16 |

- **3.3.3 最小厚度（表 3.3.3）**

| 类型 | 最小厚度 |
|---|---|
| EAC-10 / ESMA-10 | **25 mm** |
| EAC-13 / ESMA-13 | **35 mm** |
| EAC-16 / ESMA-16 | **40 mm** |
| EAC-20 | **50 mm** |

- **3.3.4** 环氧沥青混合料层**压实度 ≥98%**

### 3.4 设计参数
- **3.4.1** 抗压回弹模量、抗剪强度宜试验确定
  - 疲劳与轮辙模型中的模量取 **20 ℃ 静态抗压回弹模量**（JTG E20/T 0713）
  - **设计值 EA = 实测平均值 − α·S，α = 2.0**
  - 抗剪强度按 JTG E20/T 0718；条件受限可用**单轴贯入剪切试验**（按 MH/T 5010）
- **3.4.2** 泊松比宜 **0.25～0.30**

### 3.5 新建结构厚度
- **3.5.1** 可按**附录 A 典型结构**选用，并通过计算确定
- **3.5.2** 可参照 MH/T 5010 计算
- **3.5.3** 采用**层间连续接触**的弹性层状体系理论或**有限元**计算

## 常被问到的数值

| 问题 | 答案 |
|---|---|
| 设计年限 | 30 年 |
| CDF 判据 | ≤1.0 |
| 最小厚度（EAC-10） | 25 mm |
| 压实度 | ≥98% |
| 保证率系数 α | 2.0 |
| 泊松比 | 0.25～0.30 |
| 模量测试温度 | 20 ℃ |
