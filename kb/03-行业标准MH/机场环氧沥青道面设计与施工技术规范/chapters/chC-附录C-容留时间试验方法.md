# 附录 C 容留时间试验方法

## Core Idea

用**粘度计跟踪**环氧沥青体系黏度增长，把**黏度达到 3 Pa·s** 的时间定为容留时间。

## Key Clauses

- **C.1** 施工前应确定**最佳拌和温度**和**容留时间**
- **C.2 器具**：天平（感量 0.01 g、量程 5 kg）、水银温度计（0～300 ℃、0.5 ℃）、加热设备、烧杯、**粘度计**、环氧沥青各组分
- **C.3 步骤**
  1. 各组分分别加热至设定温度后充分混匀，**开始黏度跟踪测试**
  2. 开始阶段**每 5 min** 记录数据；黏度增长较快时**缩短记录间隔**
  3. **黏度达到 3 Pa·s 时结束测试**，该时间即为**容留时间**

## 使用提示

- 容留时间决定**拌和站到摊铺碾压**的作业窗口，施工组织设计（6.1.1）必须据此排工序
- 质量检查要求**每批做 1 次**（表 9.2.1）
