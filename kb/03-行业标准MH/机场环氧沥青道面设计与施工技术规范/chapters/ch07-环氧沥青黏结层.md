# 7 环氧沥青黏结层

## Core Idea

黏结层用**黏结料**（强度要求比结合料高：≥1.2 MPa）；洒布量按**界面类型**分四档；作业面边缘要**宽出 20～30 mm**，非作业面须覆盖保护。

## Key Clauses

### 7.1 一般规定
- **7.1.1 环氧沥青黏结料（固化试件）**：**拉伸强度 ≥1.2 MPa**、**断裂延伸率 ≥100%**
- **7.1.2 洒布量（表 7.1.2，宜通过试洒确定）**

| 黏结层位置 | 洒布量 |
|---|---|
| 新建道面**面层间** | **0.2～0.5 kg/m²** |
| 新建道面**面层与基层间** | **0.4～0.8 kg/m²** |
| 加铺层与**旧沥青**混凝土道面层间 | **0.3～0.8 kg/m²** |
| 加铺层与**旧水泥**混凝土道面层间 | **0.5～1.0 kg/m²** |

- **7.1.3** 洒布设备应能控制**各组分比例、温度及洒布量**

### 7.2 施工准备
- **7.2.1** 基层强度或道面下层满足 MH/T 5011
- **7.2.2** 作业面清扫至**无浮尘**并**保持干燥**
- **7.2.3 禁止施工条件**同 6.1.4：雨天、潮湿、气温 <10 ℃，或 <15 ℃ 且风速 >5 级

### 7.3 作业面与非作业面覆盖
- **7.3.1** 黏结层作业面边缘应比道面区边缘**宽出 20～30 mm**
- **7.3.2** 非作业面用**塑料薄膜或胶粘带**覆盖防污染
- **7.3.3** 洒布前各组分应加热到**规定温度**
- **7.3.4** 洒布车设定**混合比例**，喷洒均匀、洒布量达到设计
- **7.3.5 防粘轮**：可用碎石撒布等措施；碎石粒径宜 **5～10 mm**，**撒布覆盖率 50%～70%**；不均匀处人工补撒

## 常被问到的数值

| 问题 | 答案 |
|---|---|
| 黏结料拉伸强度 | ≥1.2 MPa |
| 面层间洒布量 | 0.2～0.5 kg/m² |
| 旧水泥道面上加铺洒布量 | 0.5～1.0 kg/m² |
| 作业面外扩 | 20～30 mm |
| 碎石粒径/覆盖率 | 5～10 mm / 50%～70% |
