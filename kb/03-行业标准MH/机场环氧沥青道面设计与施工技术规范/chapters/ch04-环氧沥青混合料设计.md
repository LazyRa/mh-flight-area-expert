# 4 环氧沥青混合料设计

## Core Idea

两类混合料（**EAC 密级配** / **ESMA 玛蹄脂碎石**）+ 六项性能门槛：稳定度、流值、空隙率、**动稳定度 ≥12000**、低温弯拉应变 ≥2000 με、水稳定性。

## Key Clauses

### 4.1 一般规定
- **4.1.1** 环氧沥青**组分比例**按道面功能、施工条件、经济性确定
- **4.1.2** 配合比设计应综合考虑气候、交通量等级、结构功能、当地材料，**通过试验**提出

### 4.2 材料规格及技术要求
- **4.2.1 环氧沥青结合料（固化试件）**：**拉伸强度 ≥1.0 MPa**、**断裂延伸率 ≥100%**（GB/T 528）
- **4.2.2** 粗集料、细集料、填料、纤维及其他添加剂符合 **MH/T 5010**

### 4.3 配合比
- **4.3.1 级配范围**：表 4.3.1-1（EAC-10/13/16/20）、表 4.3.1-2（ESMA-10/13/16，分有/无纤维）
  - EAC 级配范围较宽，便于结合工程优化
- **4.3.2 环氧沥青含量（表 4.3.2，参考范围，由马歇尔试验确定）**

| 类型 | 含量 |
|---|---|
| EAC-10 | 4.5%～7.0% |
| EAC-13 | 4.3%～6.5% |
| EAC-16 | 4.0%～6.0% |
| EAC-20 | 3.5%～5.5% |
| ESMA-10 | 5.0%～7.0% |
| ESMA-13 | 4.5%～6.5% |
| ESMA-16 | 4.0%～6.0% |

- **4.3.3 成型与技术要求（固化试件）**

| 项目 | EAC | ESMA |
|---|---|---|
| 击实次数（双面） | 75 次 | 75 次 |
| 试件尺寸 | φ101.6×63.5 mm | 同 |
| **稳定度** | **≥20 kN** | **≥15 kN** |
| 流值 | 15～50（0.1 mm） | 实测 |
| **空隙率** | **1%～5%** | **3%～5%** |

  重轮载或厚度偏薄时**可适当提高稳定度要求**。
- **4.3.4 高温性能（轮辙试验）**：**60 ℃、胎压 0.7 MPa 下动稳定度 ≥12000 次/mm**（固化试件）；不满足须调整级配或沥青用量
  - 车辙仪要求变形检测精度 ±0.0005、分辨率 0.001 mm
- **4.3.5 低温性能（小梁弯曲）**：**最大弯拉应变 ≥2000 με**（固化试件）
- **4.3.6 水稳定性（表 4.3.6）**：**浸水马歇尔残留稳定度 ≥85%**、**冻融劈裂强度比 ≥80%**
- **4.3.7 容留时间**：按附录 C 测定，须满足工程要求（黏度增长至 **3 Pa·s** 的时间）

## 常被问到的数值

| 问题 | 答案 |
|---|---|
| EAC 稳定度 | ≥20 kN（固化试件） |
| ESMA 稳定度 | ≥15 kN |
| 动稳定度 | ≥12000 次/mm（60 ℃、0.7 MPa） |
| 低温弯拉应变 | ≥2000 με |
| 残留稳定度 / 冻融劈裂比 | ≥85% / ≥80% |
| 空隙率 | EAC 1～5%、ESMA 3～5% |
| 容留时间判据 | 黏度达 3 Pa·s |
