# 3 原材料技术要求

## Core Idea

本章是本次修订改动最大的部分之一：**细集料/粗集料按 Ⅰ/Ⅱ/Ⅲ 级分级**，级别与**航空交通等级 + 环境类别**绑定；水泥成分指标按设计强度 5.0/4.5 MPa 分两档。

## Key Clauses

### 3.1 一般规定
- **3.1.1** 选用满足要求、质量可靠、供应稳定的原材料，宜因地制宜、就地取材
- **3.1.2** 水泥、矿物掺合料、外加剂、纤维、养生材料、接缝材料进场时应提供**产品合格证、出厂检验报告**

### 3.2 水泥
- **3.2.1** 应选用**旋窑**生产的**硅酸盐水泥、道路硅酸盐水泥**或经试验验证满足耐久性要求的**普通硅酸盐水泥**；**不宜选早强型水泥**；处于**二 b、三 c、四 b** 环境的道面与道肩**宜选硅酸盐水泥**
- **3.2.2 表 3.2.2-1 水泥 28 d 抗折强度**

| 面层设计强度 | 水泥 28 d 抗折强度 |
|---|---|
| 4.5 MPa | **≥7.0 MPa** |
| 5.0 MPa | **≥8.0 MPa** |

**表 3.2.2-2 水泥成分与物理指标（摘要）**

| 项目 | 5.0 MPa 档 | 4.5 MPa 档 |
|---|---|---|
| 铝酸三钙 C₃A | ≤9.0%（宜 ≤7.0%） | ≤9.0% |
| 铁铝酸四钙 C₄AF | 10.0～20.0% | 同 |
| 游离氧化钙 | ≤1.0% | ≤1.0% |
| 氧化镁 | ≤5.0% | ≤5.0% |
| 三氧化硫 | ≤3.5% | ≤3.5% |
| 碱含量 Na₂O+0.658K₂O | ≤0.6%（集料**无**潜在碱活性时 ≤1.0%） | 同 |
| 氯离子 | ≤0.06% | ≤0.06% |
| 混合材料 | 不应掺窑灰、煤矸石、火山灰质材料、烧黏土、煤渣；**有抗盐冻要求不应掺石灰岩石粉** | 同 |
| 安定性 | 沸煮法 + 压蒸法均合格 | 同 |
| 凝结时间 | 初凝 ≥120 min；终凝 210～600 min | 同 |
| 标准稠度用水量 | ≤28.0% | ≤30.0% |
| 比表面积 | 300～370 m²/kg | 同 |
| 细度（45 μm 筛余） | ≥5% | ≥5% |
| 28 d 干缩率 | ≤0.09% | ≤0.10% |
| 耐磨性 | ≤2.5 kg/m² | ≤3.0 kg/m² |

注：C₃A、C₄AF 以**熟料质量**为基准，成品水泥须先扣除混合材再折算。

### 3.3 矿物掺合料
- **3.3.1** 采用掺合料前应先明确水泥中已有混合材料的**种类和掺量**
- **3.3.2 粉煤灰**：硅酸盐/道路硅酸盐水泥可单掺或复掺低钙粉煤灰，符合 GB/T 1596 **Ⅰ级或Ⅱ级**；**铵离子 ≤80 mg/kg**；**普通硅酸盐水泥不应掺入粉煤灰**
- **3.3.3 矿渣粉**：符合 GB/T 18046；**3.3.4 硅灰**：符合 GB/T 18736

### 3.4 细集料
- **3.4.1** 采用质地坚硬、洁净的**天然砂**或**机制砂**（机制砂应符合设计文件规定）；进场宜检测**残留絮凝剂**
- **3.4.2 选用规则**：交通等级**中及以上** → Ⅰ级或Ⅱ级；**特重 + 二 b/三 c/四 b 环境** → 宜优先Ⅰ级；**轻/特轻 + 一类环境** → 可Ⅲ级；轻/特轻 + 二三四类 → 宜Ⅱ级
- **表 3.4.2 天然砂技术要求（关键项）**

| 项目 | Ⅰ级 | Ⅱ级 | Ⅲ级 |
|---|---|---|---|
| 单粒级最大压碎指标 | ≤23.0% | ≤25.0% | — |
| 坚固性 | ≤6.0% | ≤8.0% | ≤8.0% |
| 含泥量 | ≤1.7% | ≤2.0% | ≤2.5% |
| 泥块含量 | ≤0.3% | ≤0.5% | ≤0.7% |
| 饱和面干吸水率 | ≤1.5% | ≤1.5% | ≤2.0% |
| 表观密度 | ≥2550 kg/m³ | 同 | 同 |
| 松散堆积密度 | ≥1450 kg/m³ | 同 | 同 |
| 氯离子 / 硫化物硫酸盐（SO₃） | ≤0.06% / ≤0.5% | 同 | 同 |
| 云母 / 轻物质 | ≤1.0% / ≤1.0% | 同 | 同 |
| 碱活性 | 不应有碱活性或疑似碱活性 | 同 | 同 |

- **3.4.3** 天然砂细度模数 **2.6～3.2**，同一配合比变化范围 **≤0.3**；级配见 表 3.4.3（粗砂 3.1～3.7、中砂 2.3～3.0），2.36/1.18/0.30/0.15 mm 筛档允许略超，但各档超出值总和 **≤5%**
- **3.4.4 机制砂**：宜用碎（卵）石为原料；**片状颗粒 ≤10%（Ⅰ）/15%（Ⅱ）**；母岩磨光值 ≥38.0/≥35.0；石粉含量按 **MB 值**分档（MB<1.00 → <12.0%；1.00≤MB<1.40 或快速试验合格 → <7.0%；MB≥1.40 或不合格 → <3.0%（Ⅰ）/<5.0%（Ⅱ））
- **3.4.5** 机制砂级配：Ⅰ级用 **S1**；Ⅱ级用 **S1 或 S2**

### 3.5 粗集料
- **3.5.1** 用质地坚硬、耐久、洁净的碎石、破碎卵石或卵石；**破碎卵石**：16～26.5 mm 颗粒宜有 ≥1 个破碎面，>26.5 mm 宜有 ≥2 个，满足者**≥75%**
- **选用规则**同细集料（中及以上 → Ⅰ/Ⅱ级；特重 + 二 b/三 c/四 b → 宜Ⅰ级）
- **表 3.5.1 关键项**

| 项目 | Ⅰ级 | Ⅱ级 | Ⅲ级 |
|---|---|---|---|
| 碎石/破碎卵石压碎值 | ≤23.0% | ≤25.0% | ≤30.0% |
| 卵石压碎值 | ≤21.0% | ≤23.0% | ≤26.0% |
| 坚固性 | ≤5.0% | ≤8.0% | ≤8.0% |
| 针片状颗粒 | ≤8.0% | ≤10.0% | ≤12.0% |
| 软弱颗粒 | ≤3.0% | ≤4.0% | ≤5.0% |
| 含泥量（含石粉） | ≤0.5% | ≤0.8% | ≤0.8% |
| 泥块含量 | ≤0.2% | ≤0.3% | ≤0.3% |
| 饱和面干吸水率 | ≤1.0% | ≤1.5% | ≤2.0% |
| 硫化物硫酸盐 | ≤0.5% | ≤1.0% | ≤1.0% |
| 岩石抗压强度 | 岩浆岩 ≥100 / 变质岩 ≥80 / 沉积岩 ≥60 MPa | 同 | 同 |
| 表观密度 / 松散堆积密度 | ≥2500 / ≥1350 kg/m³ | 同 | 同 |
| 山皮水锈颗粒 | ≤10% | ≤12% | ≤15% |

- **3.5.2** 粗集料合成级配应由 **2～4 个单粒级**掺配，以**最小松散堆积空隙率**为目标试验确定；**不得采用不分级的统料**；合成级配 4.75～16.0 / 19.0 / 26.5 / 31.5 四档，表 3.5.2 给累计筛余范围

### 3.6 水
- **3.6.1** 符合 **GB 5749** 的饮用水可直接用于拌和、冲洗集料与养生；其他水源须符合表 3.6.1：**pH 5.0～9.5**、氯离子 **≤1000 mg/L**、硫酸根 **≤2000 mg/L**、碱含量 **≤1500 mg/L**、可溶物 **≤5000 mg/L**、不溶物 **≤2000 mg/L**、无油脂泡沫异味
- **3.6.2** 非饮用水须与饮用水做**凝结时间与胶砂强度**对比：初/终凝时间差 **≤30 min**；3 d、28 d 强度 **≥90%**

### 3.7 外加剂
- **3.7.1** 品种与掺量按施工条件、使用要求、材料特性经**配合比试验**选用；宜选高效减水剂、普通减水剂、引气减水剂、引气剂
- **3.7.2** 出厂报告须标明主要化学成分、性能指标、注意事项；**须经有资质检测机构检验合格**并提供有效报告
- **3.7.3** 现场适应性检验须用**实际使用的水泥、掺合料、集料、拌和水**试配
- **3.7.4** 引气剂应选**气泡多而微小、泡沫稳定时间长**的产品
- **3.7.5** 送检取样从**现场在用储存容器**抽取；施工配合比掺量与送检掺量偏差 **≤20%**

### 3.8 钢筋和钢材
- **3.8.1** 钢筋符合 GB 1499.1（热轧光圆）、GB 1499.2（热轧带肋）
- **3.8.2** **传力杆用钢材屈服强度 ≥235 MPa**（直径 >25 mm 时原材料归类为"钢材"）
- **3.8.3** 补强钢筋、拉杆、传力杆应顺直，无裂纹、断裂、损伤、刻痕，表面无油污、颗粒状或片状锈蚀

### 3.9 纤维
- **3.9.1 表 3.9.1 合成纤维**：断裂强度 **≥500 MPa**；初始模量 **≥5.0 GPa**；断裂伸长率 **≤30%**；含水率 **≤2.0%**；耐碱性能（极限拉力保持率）**≥95.0%**；试验值变异系数 ≤10%
- **3.9.2** 长度宜 **≤12 mm**；长度合格率/形状合格率 **>90%**；分散性相对误差 **±10%**；单丝纤维当量直径 5～100 μm，粗纤维 100～500 μm；**不得成团**
- **3.9.3** 其他纤维按设计文件与相关标准

### 3.10 隔离层材料
- **3.10.1** 沥青类隔离层符合 **MH/T 5011** 与 **MH/T 5050**
- **3.10.2 复合土工膜**：成品厚 **≥0.7 mm**、膜材厚 **≥0.3 mm**；纵横向断裂强度 **≥10 kN/m**；断裂伸长率 **≥30%**；CBR 顶破强力 **≥1.9 kN**；抗酸碱强度保持率 **≥90%**
- **3.10.3 土工布**：单位面积质量 **130～200 g/m²**；厚度 **≤0.8 mm**；断裂强度 **≥6.0 kN/m**；CBR 顶破 **≥1.0 kN**；撕破强力 **≥0.27 kN**；伸长率 5% 时拉伸力 **≥2.7 kN/m**；幅宽不小于板宽

### 3.11 养生材料
- **3.11.1** 应对混凝土无腐蚀；宜选养生剂、养生膜、养生土工布、养生复合土工膜
- **3.11.2 养生剂**分**一等品/合格品**，宜选一等品；宜为**白色乳液**，**不应含水玻璃**；**有效保水率 ≥90%（一等品）/≥80%（合格品）**；含固量 ≥15%/≥20%；干燥时间 ≤3 h；成膜后不溶、耐热不熔化不变色、密封连续无透孔；抗压/弯拉强度比 3 d、7 d 均 ≥95%（一等品）/≥90%（合格品）
- **3.11.3** 养生膜（基本型、吸水型）符合 JT/T 522
- **3.11.4** 养生土工布单位面积质量 **≥300 g/m²**
- **3.11.5 养生复合土工膜**：单位面积质量 **≥400 g/m²**；断裂强度 ≥6.0 kN/m；标准强度对应伸长率 30%～100%；CBR 顶破 ≥1.1 kN；**3 d 有效保水率 ≥90%**

## 常被问到的数值

| 问题 | 答案 |
|---|---|
| 水泥 28 d 抗折强度 | 设计 4.5 MPa → ≥7.0；设计 5.0 MPa → ≥8.0 |
| 水泥 C₃A 上限 | ≤9.0%（宜 ≤7.0%） |
| 氯离子（水泥/砂/石/水） | ≤0.06% / ≤0.06% / ≤0.06% / ≤1000 mg/L |
| 天然砂细度模数 | 2.6～3.2，同配合比波动 ≤0.3 |
| 传力杆钢材屈服强度 | ≥235 MPa |
| 合成纤维断裂强度 | ≥500 MPa |
