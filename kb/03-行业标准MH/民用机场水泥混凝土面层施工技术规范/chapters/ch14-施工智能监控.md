# 14 施工智能监控

## Core Idea

本次修订**新增**章节，全部用"宜"（非强制）：分**物料与搅拌站监控**、**铺筑监控**两段。

## Key Clauses

### 14.1 一般规定
- **14.1.1** 面层施工**宜**进行智能监控
- **14.1.2** 宜将智能监控结果与**现场试验检测数据对比分析验证**
- **14.1.3 系统宜具备的功能**
  1. 可针对不同工程规模和工况**设置监控参数与指标**
  2. 可将关键数据**实时反馈**给施工机械操作人员并指导操作
  3. 支持**精准测量、实时传输、本地缓存、断点续传**
  4. 监测**连续、数据可追溯、信息完整**

### 14.2 物料与搅拌站监控
- **14.2.1 物料监控**
  1. 自动识别记录搅拌站**出场时间**与现场**卸料时间**
  2. 实时监控运输车、上料车**轨迹**
  3. 监测胶凝材料、细集料、粗集料**进场重量与库存动态**
- **14.2.2 搅拌站监控**
  1. 实时采集、传输、存储原材料用量、拌和时间、配合比
  2. 实时管控数据，支持**日报、历史查询、统计分析**
  3. **参数超限自动预警**，可在线查看异常数据

### 14.3 铺筑监控
- **14.3.1** 实时采集分析施工参数并反馈至操作人员与现场管理人员
- **14.3.2 摊铺机铺筑**：宜含**高程、摊铺厚度、摊铺速度、振动状态、环境温度**
- **14.3.3 排式振捣器铺筑**：宜含**行进速度、振动状态**

## 使用提示

- 本章全为"宜"，属**推荐性**，但一旦写入合同/专项方案即须执行
- 智能监控数据可作为**15.1.4** 施工记录归档的补充材料
