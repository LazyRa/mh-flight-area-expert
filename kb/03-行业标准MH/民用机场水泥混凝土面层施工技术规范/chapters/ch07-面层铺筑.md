# 7 面层铺筑

## Core Idea

全书最长的一章：**模板 → 试验段 → 铺筑**。铺筑分三种工艺（摊铺机 / 自行排式高频振捣器 / 平板+插入式），各有硬参数；做面后**拉毛纹理深度**按部位分档。

## Key Clauses

### 7.1 模板制作和安装
- **7.1.1** 宜用**钢模板**；弯道、异形板可用木模板
- **7.1.2** 钢模板钢板厚度 **≥5 mm**，标准化、系列化
- **7.1.3** 木模板厚度 **20～30 mm**，无扭曲折裂，拼接严密
- **7.1.4** 企口缝模板制成**阴企口**；设拉杆的企口模板按设计位置放样钻孔；设传力杆接缝须装**传力杆定位支架**
- **7.1.6 安装要求**
  - 位置准确、支立稳固，接缝紧密平顺，**无前后错台和高低不平**
  - 模板接缝、与基层接触处、拉杆及传力杆孔洞**不应漏浆**
  - 接触面**均匀涂刷隔离剂**；钢模板之间用**螺栓连接**
  - 支撑可用角钢三角架：**面层厚 ≥280 mm → 支撑间距 ≤0.8 m；<280 mm → ≤1.0 m**
- **7.1.7** 铺筑前**复测模板平面位置与顶面高程**，检查支撑稳固性与企口对齐；铺筑中**设专人跟班检查**
- **7.1.8** 同一条企口缝的企口朝向宜一致

**表 7.1.9 模板制作精度**：高度 0/−10 mm；长度 ±5 mm；企口位置及各部尺寸 ±2 mm；两垂直边夹角偏差 ±0.5°；预留孔位置 ≤3 mm；孔径 +5/0 mm

**表 7.1.10 模板安装精度**：平面位置 **≤5 mm**；顶面高程 **±2 mm**；20 m 拉线直线性 **≤5 mm**

### 7.2 试验段铺筑
- **7.2.1** 面层施工前**应铺筑试验段**
- **7.2.2** 宜在**次要区域或场外**铺筑；宜含相邻两仓，每仓长度宜 **≥30 m**
- **7.2.3 验证内容**：① 计量/投料顺序/拌和时间/均匀性与工作性；② 运输离析、运输时间、入仓工作性；③ 模板、振实沉落量、振捣参数、整平做面、拉毛、养护、拆模及切缝时间；④ 施工配合比合理性、含气量与弯拉强度符合性；⑤ **耐磨性、盐冻剥落量**符合性；⑥ 机具、人员、管理体系适应性
- **7.2.4** 全过程记录，指标不符须分析调整
- **7.2.5** 试验段完成后编制**总结报告**；正式施工宜在工艺与弯拉强度、耐磨性、盐冻剥落量、电通量均满足要求后进行
- **7.2.6** 必要时在试验段部分板块**刻槽**，评估刻槽对抗冻、抗盐冻的影响

### 7.3 水泥混凝土铺筑
- **7.3.1** 铺筑前按气象条件做好**防雨、防晒、防风**准备
- **7.3.2 出料后严禁加水**；自铺筑至抹面完成的允许最长时间：

| 现场气温 | 最长时间 |
|---|---|
| 5～10 ℃（不含 10） | **120 min** |
| 10～20 ℃（不含 20） | **90 min** |
| 20～30 ℃（不含 30） | **75 min** |

- **7.3.3** 可优先用**摊铺机**，也可用**自行排式高频振捣器**；异形板、钢筋混凝土板、局部补强处可用**手持插入式或平板式振捣器**辅助
- **7.3.4** 摊铺厚度须预留**振实沉落量**，经现场试验确定，宜为**面层厚度的 10%～15%**；暂停施工时覆盖防失水；**未经振实且已初凝的混凝土应清除**
- **7.3.5 摊铺机施工**
  - 应具布料、振捣、挤压成型、整平功能；**振捣频率 ≥200 Hz**、单个振捣棒功率 **≥1.5 kW**、棒间距 **300～350 mm**
  - 起步前先开振捣棒振捣约 **1 min**；同一位置停留 **≤20 s**
  - 摊铺速度 **0.8～1.2 m/min**
  - 填仓施工清洁两侧道面；履带在已铺面层上行走须铺**保护垫具**
  - **双层摊铺**用两台摊铺机前后协同，**间距 ≤15 m**，上下层分别进料
- **7.3.6 自行排式高频振捣器**
  - **振动频率 ≥200 Hz**、单棒功率 **≥1.1 kW**、棒间距 **≤500 mm**
  - 摊铺整平出 **4～5 m** 工作面后启动；棒端宜插入板厚中部或钢筋网表面
  - 起步前先振约 **1 min**；正常行进速度 **0.6～1.0 m/min**
  - 异响、停振、漏振**立即停机**
  - 拉杆/传力杆部位用 **≥1.1 kW、≥50 Hz** 手持插入式振捣器辅助
- **7.3.7 平板式/手持插入式振捣器**
  - 平板式功率 **≥2.2 kW**、频率 **≥50 Hz**
  - 逐板逐行循序进行，每次移位纵横各**重叠 50～100 mm**；**不得拖振、斜振**；距模板 **50～100 mm**
  - **面层厚度 >220 mm** 时宜分上下两层湿接摊铺振捣，或用插入式辅助
  - 插入式应**快插慢提**，移动距离 **≤作用半径 1.5 倍**，距模板 **≤作用半径 0.5 倍**；分层时插入下层约 **50 mm**
  - 振捣时间以**停止下沉、无气泡逸出、表面泛浆**为准，**不应过振**
- **7.3.8 整平与做面**
  - 摊铺机施工由机械完成整平揉浆；其他工艺可用振动梁整平、钢滚筒揉浆；低洼处用混凝土填平振实，**不得用浮浆抹平**，高出部位铲平
  - **提浆厚度 1.5～3.5 mm**（量测方法见附录 B，**每工班 ≥4 次**）
  - 塑性状态用**长度超过板宽的刮尺**检查平整性；清除局部泌水和少量浮浆
  - **抹面不少于 3 遍**，将集料压入板面，消除砂眼及抹痕
  - **严禁在表面洒水或撒干水泥**
- **7.3.9 拉毛纹理深度（表 7.3.9）**

| 部位 | 表面平均纹理深度 |
|---|---|
| 刻槽的跑道、快速出口滑行道 | **≥0.50 mm**（刻槽前测） |
| 不刻槽的跑道、快滑（出口至直线段末端） | **≥0.80 mm** |
| 滑行道（不含快滑） | ≥0.40 mm |
| 机坪 | ≥0.40 mm |
| 道肩 | 无要求（二、三、四类环境**不宜拉毛**） |
| 防吹坪、服务车道、巡场路 | ≥0.40 mm |

  拉毛纹理应**垂直于纵向施工缝**；用**铺砂法**测定；需刻槽部位**不应采用纯拉槽**形成纹理。
- **7.3.10 填仓铺筑最早时间**（以两侧面层最晚铺筑时间起算）

| 现场气温 | 最早填仓时间 |
|---|---|
| 5～10 ℃ | **6 d** |
| 10～15 ℃ | **5 d** |
| 15～20 ℃ | **4 d** |
| ≥20 ℃ | **3 d** |

  铺筑填仓混凝土时应保护两侧已浇筑面层的边部与表面；做面时在新老相接处用抹刀划出整齐直线，清除板边砂浆。
- **7.3.11 钢筋网/局部补强**
  - 品种、规格、间距、加工尺寸符合设计；焊接绑扎符合国家现行标准
  - 单层钢筋网可在下层摊铺振捣整平后安设，或设架立钢筋固定后铺筑
  - 双层钢筋网宜用架立钢筋绑成整体骨架；假缝设传力杆时按「下层网→传力杆支架→传力杆→上层网」顺序安装
  - 摊铺机施工时**上层钢筋网保护层厚度宜 ≤120 mm**；**钢筋网安装后车辆机械不得碾压**
  - 安装精度：长宽 **±10 mm**、间距 **±10 mm**、保护层 **±5 mm**、边缘角隅钢筋移位 **±5 mm**（按加筋板总数 1/5 抽查）
- **7.3.12 灯坑、排水明沟、雨水口及各类井体**
  - 位置符合设计，顶面高程按图纸确定或推算
  - **灯具预埋管及深筒灯灯筒安装就位后方可浇筑**该部位面层
  - 明沟、雨水口、井体安装完毕须按设计设**面层补强钢筋**，检验合格后浇筑周围混凝土
  - 摊铺机或排式振捣器无法振捣处，用**手持插入式振捣器**

## 常被问到的数值

| 问题 | 答案 |
|---|---|
| 摊铺速度 | 0.8～1.2 m/min |
| 振实沉落量 | 面层厚度的 10%～15% |
| 抹面遍数 | ≥3 遍 |
| 提浆厚度 | 1.5～3.5 mm |
| 跑道不刻槽纹理深度 | ≥0.80 mm |
| 跑道刻槽前纹理深度 | ≥0.50 mm |
| 填仓最早时间（≥20 ℃） | 3 d |
| 出料后能否加水 | 严禁 |
