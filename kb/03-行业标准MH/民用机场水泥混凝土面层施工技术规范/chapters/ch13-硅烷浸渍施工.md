# 13 硅烷浸渍施工

## Core Idea

本次修订**新增**章节。要点：**龄期 ≥28 d**、**先做 ≥20 m² 试验段**、**总喷涂量 ≥350 ml/m² 分两遍**、**7 d 后钻芯验收**（浸渍深度 ≥3 mm、吸水率 ≤0.01、盐冻剥落量 ≤100 g/m²）。

## Key Clauses

### 13.1 一般规定
- **13.1.1** 混凝土**龄期宜 ≥28 d**；施工前**清洁表面**
- **13.1.2** 施工前做**试验段，面积宜 ≥20 m²**；检测合格后方可大面积施工
- **13.1.3** 采用其他防护剂须试验验证，指标符合设计，且**盐冻剥落量不大于本规范对硅烷浸渍的要求**

### 13.2 材料
- **13.2.1** 宜选用以**长链辛基硅烷**为活性成分的材料（正辛基三乙氧基硅烷、异辛基三乙氧基硅烷）；辛基硅烷盐冻剥落量更小、保护周期更长
- **13.2.2** **每 10 t 至少检验一次**；表 13.2.2：**硅烷含量 ≥98%**、**辛基硅烷含量 ≥90%**、**氯离子 ≤0.01%**、**密度 0.85～0.90 g/ml**
- **13.2.3** 运输防碰撞、泄漏、接触直接热源
- **13.2.4** 宜单独贮存于通风干燥阴凉处并防火；**密封贮存，开启后宜 48 h 内用完**；**贮存期宜 ≤18 个月**，超期须重新检验

### 13.3 施工
- **13.3.1** 表面应**清洁、干燥**，无疏松颗粒、积水、油污、灰尘
- **13.3.2 喷涂**：宜用**低压不间断循环泵送设备**，**压力 60～70 kPa**；小面积可辊涂或刷涂；**至少两遍**，**总喷涂量 ≥350 ml/m²**；两遍间隔按产品说明
- **13.3.3 气象条件**：宜晴朗；**大风、雾、雨停止施工**；**表面温度 5～40 ℃**，**相对湿度 30%～70%**
- **13.3.4** 宜在**填缝和标志线施工前**完成；现场及附近无明火、远离火种
- **13.3.5 过程控制**
  - **不得用溶剂或其他液体稀释**
  - 表面须达充分浸润，形成均匀连续"**湿润镜面**"效果并**保持 ≥5 s**
- **13.3.6** 施工后 **24 h 内避免雨淋**
- **13.3.7 验收（施工完成 7 d 后钻芯）**

| 项目 | 要求 |
|---|---|
| 吸水率 | **≤0.01 mm/min^1/2** |
| 硅烷浸渍深度 | **平均值 ≥3 mm，极值 ≥2 mm** |
| 盐冻剥落量 | **≤100 g/m²** |
| 检验频率 | **每 15 000 m² 钻芯一个，不少于 3 个** |

  浸渍深度用**染料指示法**；刻槽道面钻芯中间位置应避开刻槽，测点选在**表层拉毛位置**。

## 常被问到的数值

| 问题 | 答案 |
|---|---|
| 施工龄期 | ≥28 d |
| 试验段面积 | ≥20 m² |
| 喷涂压力 | 60～70 kPa |
| 总喷涂量 | ≥350 ml/m²（≥2 遍） |
| 表面温度 / 湿度 | 5～40 ℃ / 30%～70% |
| 浸渍深度 | 平均 ≥3 mm、极值 ≥2 mm |
| 验收钻芯频率 | 每 15000 m² 一个，≥3 个 |
