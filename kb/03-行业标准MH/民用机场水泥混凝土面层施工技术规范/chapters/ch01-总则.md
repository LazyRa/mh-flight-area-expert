# 1 总则

## Core Idea

适用范围 + **环境类别**（本次修订新增）是全书两个"总开关"：环境类别决定原材料等级、水胶比、含气量、耐久性指标和养生方式。

## Key Clauses

- **1.0.1** 为规范民用机场水泥混凝土面层的施工、保证施工质量，制定本规范
- **1.0.2 适用范围**：**新建、改建、扩建运输机场**（含军民合用机场的民用部分）**飞行区水泥混凝土道面和路面**的**现浇面层**施工；**通用机场**同类工程可参照执行
  - 条文说明：不仅包括跑道、滑行道、机坪、道肩、防吹坪，还包括**飞行区服务车道、巡场路**等路面
  - 机坪内**排水明沟、各类井体的外露钢筋混凝土顶板**，其抗冻、抗盐冻性能可参照相邻道面
- **1.0.3** 技术要求应依 **环境类别 + 航空交通等级 + 道（路）面所在部位** 确定
- **1.0.4** 应按设计文件要求，并考虑气候条件采取技术措施
- **1.0.5** 应保证施工安全、减少环境污染、降低能源消耗
- **1.0.6** 可采用技术可靠的**新材料、新技术、新设备、新工艺**
- **1.0.7** 尚应符合国家和行业现行有关标准

### 表 1.0.3 环境类别（本次修订新增）

| 类别 | 符号 | 条件 |
|---|---|---|
| **一般环境** | 一 | 无冻融、盐雾、除冰液、融雪剂作用 |
| **冻融环境** | 二 a | 年最冷月平均气温 **−3 ℃～2.5 ℃**；或年最冷月平均气温 >2.5 ℃ 但**出现过冻雨** |
| | 二 b | 年最冷月平均气温 **低于 −3 ℃** |
| **盐雾环境** | 三 a | 距海水涨潮线 **300～1200 m**（含 1200 m） |
| | 三 b | 距海水涨潮线 **100～300 m**（含 300 m） |
| | 三 c | 距海水涨潮线 **100 m（含）以内** |
| **除冰液、融雪剂环境** | 四 a | 年最冷月平均气温 −3 ℃～2.5 ℃ 地区的**跑道（含道肩）**；不低于 −3 ℃ 地区的**除冰坪、需除冰作业机位** |
| | 四 b | 低于 −3 ℃ 地区的跑道（含道肩）、除冰坪、需除冰作业机位，以及**冬季需喷洒融雪剂的其他部位** |

注：航空交通等级划分见 **MH/T 5004**（水泥混凝土道面设计规范）；环境类别与交通等级均由**设计文件**确定。

## 与 2015 版差异

本次修订**新增面层水泥混凝土环境类别划分**（表 1.0.3），后续各章的原材料分级、水胶比上限、含气量、耐久性指标全部与之挂钩。

- **MH/T 5086-2025** 场地基础性维护（施工完成后的维护衔接）
- **MH/T 5011-2019** 沥青道面施工（沥青隔离层施工质量）
- **MH/T 5090** 接缝材料；**MH/T 5050** 沥青隔离层技术指南
