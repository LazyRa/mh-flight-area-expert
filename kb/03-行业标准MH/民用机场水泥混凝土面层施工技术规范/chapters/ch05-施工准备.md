# 5 施工准备

## Core Idea

五块准备：**方案与试验室**、**施工测量**、**搅拌站设置**、**材料与设备检查（含检测频率表）**、**基层与隔离层检查整修**。

## Key Clauses

### 5.1 一般规定
- **5.1.1** 应编制**水泥混凝土面层施工方案**
- **5.1.2** 应建立**工地试验室**，具备原材料、配合比、施工质量检测能力
- **5.1.3** 施工前完成原材料选择与**目标配合比设计**
- **5.1.4** 完成搅拌站、钢筋加工场、材料堆场、施工便道、临时供水供电建设；夜间施工配照明
- **5.1.5** 须在**基层、隔离层及相关隐蔽工程验收合格**（或分批验收合格）后施工

### 5.2 施工测量
- **5.2.1–5.2.2** 以建设单位提供的平面、高程控制点（网）为基准，并**复测校核**
- **5.2.3** 加密控制点间距宜 **≤200 m**
- **5.2.4** 永久标石**不得影响机场运行安全**，满足通视、无明显电磁干扰
- **5.2.5 标石要求**：顶面 **≥150×150 mm**、底面 **≥250×250 mm**；一般地区埋深 **≥800 mm**，季节性冰冻地区在**最大冰冻线以下 500 mm**；顶面高出完工场地 **50～100 mm**
- **5.2.6 控制测量**：平面用 **GNSS 或导线**，高程用**水准**；布设成闭合线路/附合线路/闭合环；**每月复测一次**；软土、吹填、高填方等沉降敏感区宜 GNSS 静态 + 导线联合平差
- **5.2.7 精度**：平面控制点（网）**一级导线**；平面定位**二级导线**；高程控制点（网）**二等水准**；高程定位**三等水准**；**各施工点高程误差 ≤2 mm**，不得连续两次转点引测

### 5.3 搅拌站设置
- **5.3.1** 宜靠近施工区域，满足进度、储运、运输、环保、安全、节约用地；**改扩建工程还须考虑障碍物限制面**
- **5.3.2** 合理划分拌和作业区、材料存放区、机械停放区
- **5.3.3** 供水供电充足稳定；**设蓄水池**；用地下水时**设沉淀池**
- **5.3.4** 胶凝材料**分罐存放**并设标识牌
- **5.3.5** 集料堆场储量满足连续施工；场区道路与堆场地面**硬化**；**分仓堆放 + 隔离墙 + 标识牌**，严禁混杂；**架设顶篷**
- **5.3.6** 外加剂按产品文件存放；混合液容器宜遮盖、设机械搅拌装置、排淤底阀、排气装置；塑料容器须遮阳
- **5.3.7** 集料进料斗仓间**隔板高度 ≥0.5 m**
- **5.3.8** **严禁贴地铲装料仓底部集料**
- **5.3.9** 场区排水畅通不积水；设**分级沉淀池**处理生产废水

### 5.4 材料及设备检查
- **5.4.1–5.4.2** 原材料须检验合格；供应能力满足进度
- **5.4.3** 检测项目与频率见表 5.4.3-1（常规材料）与 5.4.3-2（机制砂）；同料源、品种、规格为**同一检验批**，分批检测、分类储存

**表 5.4.3-1 主要材料检测频率（摘要）**

| 材料 | 检测频率（关键项） |
|---|---|
| 水泥 | 抗折/抗压强度、安定性 **1500 t 一批**（压蒸法安定性由厂家每半年一次）；成分项同种水泥**不少于 3 次、首批进场前必测**；拌和前测温度 |
| 矿物掺合料 | 烧失量 **200 t 一批**；活性指数、细度 **1000 t 一批** |
| 碎石/破碎卵石/卵石 | 含泥量、泥块、针片状、软弱颗粒、级配、密度 **3000 t 一批**；压碎值、坚固性、山皮水锈、吸水率**不少于 3 次**；碱活性等**进场前每種 ≥1 次**；**含水率每工班 ≥2 次** |
| 天然砂 | 含泥量、泥块、细度模数、级配、密度 **1500 t 一批**；**含水率每工班 ≥2 次** |
| 外加剂 | 含固量、密度、减水率、含气量 **25 t 一批**；**进场取样封存留样 ≥500 ml** |
| 钢筋和钢材 | 拉伸、弯曲（传力杆除外）、重量偏差 **60 t 一批** |
| 纤维 | 进场前检测，每标段 **≥3 次** |
| 土工合成材料 | 开工前或有变化时，每种每标段 **≥3 次** |
| 养生材料 | 开工前或有变化时，每种每标段 **≥3 次** |
| 水 | 开工前和水源变化时 |

注：开工前或规格/品种/厂家/来源变化时**所有项目均应检验**；不足一批按一批检验。

- **5.4.4** 施工机械、机具、模板检查调试保养；测量仪器与试验设备**检定或校准**；易损件适量储备

### 5.5 基层、隔离层检查与整修
- **5.5.1** 基层开裂、破损应查明成因，**排除地基变形因素**后修复：破碎/隆起/松散/空鼓区域**全厚度清除**并用同材料或贫混凝土修复；沥青隔离层裂缝 **>1 mm** 宜乳化沥青灌缝 + 铺防裂贴
- **5.5.2** 复合土工膜、土工布隔离层应平整无褶皱，**搭接宽度 ≥100 mm** 并与基层固定；摊铺前不应破损
- **5.5.3** 沥青隔离层质量检查符合 **MH/T 5050**

## 常被问到的数值

| 问题 | 答案 |
|---|---|
| 控制点加密间距 | ≤200 m |
| 控制网复测周期 | 每月一次 |
| 高程误差 | ≤2 mm |
| 水泥检测批 | 1500 t |
| 粗集料检测批 | 3000 t |
| 砂检测批 | 1500 t |
| 隔离层搭接宽度 | ≥100 mm |
