# 2 术语和符号

## Core Idea

20 条术语（2.1.1–2.1.20）+ 18 个符号（2.2）。术语部分把"水胶比""饱和面干状态""体积砂率"等配合比计算的基准概念讲清，是理解第 4 章公式的前提。

## Key Clauses

### 2.1 术语

| 条 | 术语 | 要点 |
|---|---|---|
| 2.1.1 | 水泥混凝土面层 | 设于基层之上、**直接承受荷载**的结构层 |
| 2.1.2 | 飞行区 | 跑道/滑行道/机坪/升降带/跑道端安全区 + ILS、进近灯光系统所在区域 |
| 2.1.3–2.1.9 | 跑道 / 滑行道 / 机坪 / 道肩 / 防吹坪 / 服务车道 / 巡场路 | 部位定义，决定质量标准分档 |
| 2.1.10 | 水泥混凝土**设计强度** | 规定龄期的**设计弯拉强度**，一般 **28 d** |
| 2.1.11 | 合成纤维 | 以合成高分子化合物为原料制成的纤维 |
| 2.1.12 | **饱和面干状态** | 集料内部开口孔隙被水完全充满，但**颗粒表面无自由水** |
| 2.1.13 | **水胶比** | 用水量 ÷ 胶凝材料总量；用水量含拌和水、**液体外加剂中的水**、集料表面游离水，**不含**饱和面干状态所含水；胶凝材料含水泥 + 粉煤灰/矿渣粉/硅灰等 |
| 2.1.14 | 摊铺机铺筑 | 布料、摊铺、振捣密实、挤压成型、整平在行进中**连续完成** |
| 2.1.15 | 表面平均纹理深度 | 拉毛、拉槽毛等工艺形成的纹理深度**平均值** |
| 2.1.16 | 传力杆 | 板厚中部、**光圆**钢筋或钢材，传递荷载并防错台 |
| 2.1.17 | 拉杆 | 纵向接缝、板厚中部、**带肋**钢筋，防缝隙扩张 |
| 2.1.18 | 水泥混凝土加铺层 | 为提高承载力或改善表面性能而加铺的面层 |
| 2.1.19 | 不停航施工 | 机场不关闭或部分区域/时段关闭、按航班计划接收放行情况下在飞行区内施工 |
| 2.1.20 | **硅烷浸渍** | 硅烷类材料涂覆并渗入表层，降低吸水率与渗透性，提高抗冻融/抗盐雾/抗除冰液性能 |

### 2.2 符号（配合比计算用）

`Mca` 粗集料用量（饱和面干，kg/m³）｜`Mfa` 细集料用量｜`βv` 体积砂率｜`ρca`/`ρfa` 表干密度｜`ρw` 水密度｜`ρc` 水泥密度｜`Mi`/`ρi` 第 i 类掺合料用量/表观密度｜`A` 含气量体积分数｜`C` 水泥用量｜`W` 用水量｜`fc` 弯拉强度｜`fsp` 劈裂抗拉强度｜`ms`/`m1`/`m2`/`mn`/`S` 抗盐冻试验用

## 易混点

- **传力杆 = 光圆**（横缝，传递荷载、可滑动）；**拉杆 = 带肋**（纵缝，防缝隙扩张）
- **水胶比**的用水量**不含**集料饱和面干含水，但**含**外加剂带入的水
- **设计强度**指**弯拉强度**，不是抗压强度
