# 附录 B 水泥混凝土砂浆厚度量测方法

## Core Idea

本次修订**新增/完善**。用一个**27 根测试针的外环筒 + 带刻度内环筒**的量测仪，在刚整平提浆的面层上靠自重下沉，读内环刻度得**提浆（砂浆层）厚度**，三次平行取平均。

## Key Clauses

### B.1 目的及适用范围
规定水泥混凝土面层**砂浆厚度的量测方法**，适用于施工中砂浆厚度量测。

### B.2 仪器设备
砂浆厚度量测仪由两部分组成：
- **外环筒**：底部带 **27 根测试针**；外径 **80 mm**、内径 **75 mm**、壁厚 **2.5 mm**、高 **70 mm**、**刀口高度 6.5 mm**
- **内环筒**：轻质带底；外径 **74 mm**、内径 **71 mm**、壁厚 **1.5 mm**、高 **100 mm**；带标准刻度，**精度 0.5 mm**
- 两筒均**不锈钢**；**针杆直径 1 mm、针尖端部 0.3 mm**

### B.3 量测步骤
- **B.3.1 位置选定**：经振捣、整平提浆、精平抹面后，在**刚铺筑的面层中间位置**，或**距纵向施工缝 ≥100 mm** 处
- **B.3.2 仪器检查**：仪器不得粘污物；外环筒套住内环筒放在水平平板上，插紧两侧销钉，此时**测试针针尖应在同一平面**且顶部与内环筒**零刻线对齐**；否则记录初始示数
- **B.3.3 测试**：内外套筒及针用湿抹布擦净 → 外环筒针朝下套住内环筒、插紧销钉 → 轻放于提浆后的面层上 → **水平拔出两个插销**，使外环筒**靠自重下沉** → 不再下沉时读内环筒**径向一对刻度示数**
- **B.3.4** 重复 B.3.3，对**相邻位置再量测两次**（共 3 次）

### B.4 量测结果
- **B.4.1** 每次量测值 = **两对读数的差值，取较小值**，精确至 **0.5 mm**
- **B.4.2** 以 **3 次平行试验平均值**为准（精确 0.5 mm）；**单次与平均值相差 >1.5 mm 时剔除该次、重新测量并重算平均**

## 与正文的衔接

- **7.3.8** 要求**提浆厚度 1.5～3.5 mm**，**每工班量测 ≥4 次**，量测方法即本附录
