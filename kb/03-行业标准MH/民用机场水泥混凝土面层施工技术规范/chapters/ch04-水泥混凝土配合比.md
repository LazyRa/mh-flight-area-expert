# 4 水泥混凝土配合比

## Core Idea

两段式：**目标配合比**（室内试验，绝对体积法）→ **施工配合比**（试验段验证 + 现场含水率修正）。本章是全书硬指标最密集的一章：胶凝材料用量、水胶比、含气量、耐久性、耐磨性。

## Key Clauses

### 4.1 目标配合比设计
- **4.1.1** 应满足**工作性、配制强度、耐久性**，且经济合理
- **4.1.2** 通过室内试验确定**水胶比、胶凝材料用量、砂率、粗细集料用量、外加剂掺量**；集料按**饱和面干状态**折算，用**绝对体积法**计算
- **4.1.3** 弯拉强度标准龄期宜 **28 d**；目标配合比强度宜按设计强度的 **1.15 倍**配制
- **4.1.4** 拌合物**坍落度宜 ≤20 mm**；出机**维勃稠度 10～15 s**，入仓 **≤20 s**，**1 h 经时变化 ≤10 s**
- **4.1.5 耐磨性（交通等级中及以上的跑道）**

| 航空交通等级 | 每组平均磨损量 |
|---|---|
| 特重、重 | **≤2.5 kg/m²** |
| 中 | **≤3.0 kg/m²** |

- **4.1.6 耐久性（表 4.1.6）**

| 指标 | 环境类别 | 道面、道肩 | 防吹坪、路面 | 方法 |
|---|---|---|---|---|
| 抗冻耐久性指数 DF | 二 a | **≥70%** | ≥65% | GB/T 50082 快冻法 |
| | 二 b | **≥80%** | ≥75% | 同上 |
| 电通量（6 h） | 三 b | **≤1500 C** | — | 电通量法 |
| | 三 c | **≤1000 C** | ≤1500 C | 同上 |
| 盐冻剥落量 | 四 a | **≤500 g/m²** | — | 附录 A |
| | 四 b | **≤400 g/m²** | — | 附录 A |

注：DF 为 300 次快速冻融循环后动弹性模量与初始模量之比。

- **4.1.7** 宜用**备用原材料同步做配合比试验**（应对施工期材料变化）
- **4.1.8 胶凝材料用量**
  - **无掺合料**：水泥 **≥310 kg/m³**；二/三/四类环境宜 **≥330 kg/m³**
  - **有掺合料**：胶凝材料总量 **≥340 kg/m³**，其中水泥 **≥280 kg/m³**；二/三/四类环境水泥宜 **≥300 kg/m³**
  - 单掺限值：粉煤灰宜 **≤20%**、矿渣粉宜 **≤20%**、硅灰 **≤10%**
  - 复掺：各掺量不超过其单掺限值，**总掺量宜 ≤30%**
- **4.1.9 水胶比（表 4.1.9）**

| 环境类别 | 道面 | 道肩、防吹坪、路面 |
|---|---|---|
| 二、三、四 | **≤0.40** | **≤0.42** |
| 一 | ≤0.42 | ≤0.44 |

- **4.1.10** 二、四类环境**应掺引气剂**；一、三类**可掺**
- **4.1.11** 拌合物应砂浆含量适宜、黏聚性良好，无离析泌水
- **4.1.12 绝对体积法公式**（饱和面干基准，实际配料再按含水率/吸水率做湿重修正）
  - `Mca = ρca × (1 − βv) × [1 − (W/ρw + C/ρc + ΣMi/ρi + A)]`
  - `Mfa = ρfa × βv × [1 − (W/ρw + C/ρc + ΣMi/ρi + A)]`
  - **体积砂率 βv 取 0.27～0.32**（细度模数低取低值）；ρw 计算取 **1000 kg/m³**

### 4.2 施工配合比确定与调整
- **4.2.1** 目标配合比须经**工程试验段**验证调整，形成施工配合比
- **4.2.2** 按搅拌站实测集料含水率调整用水量与集料湿重；**调整不得增大水胶比、不得减少胶凝材料用量**
- **表 4.2.2 入仓含气量**

| 环境类别 | 道面、道肩 | 防吹坪、路面 |
|---|---|---|
| 二、四 | **2.5%～4.0%** | 2.0%～4.0% |
| 一、三 | 1.5%～3.0% | 1.5%～3.0% |

- **4.2.3** 胶凝材料、集料、外加剂品种/规格/产地变化时**须重新验证**
- **4.2.4** 可按温度、风速、湿度、运输时间微调；优先调**减水剂、缓凝剂**掺量使维勃稠度达标；高温低湿大风确需施工时，**增加用水量 ≤5 kg/m³**，且调整后水胶比仍须符合 4.1.9
  - 条文说明：**高温** = 连续 4 h 平均气温 >30 ℃ 或日最高 >35 ℃；**低湿** = 相对湿度 <50%；**大风** = 风力 4 级
- **4.2.5** 应定期抽检维勃稠度、含气量，复核胶凝材料用量与单位用水量，并制作弯拉强度试件；不合格**暂停施工**

## 常被问到的数值

| 问题 | 答案 |
|---|---|
| 水胶比上限 | 道面 ≤0.40；道肩/防吹坪/路面 ≤0.42（二三四类环境） |
| 最小水泥用量 | 无掺合料 ≥310（二三四类宜 ≥330）kg/m³ |
| 掺合料总量 | 复掺宜 ≤30% |
| 含气量 | 二、四类 2.5%～4.0% |
| 配制强度 | 设计强度 ×1.15 |
| 体积砂率 | 0.27～0.32 |
| 坍落度 | ≤20 mm（维勃稠度控制） |
