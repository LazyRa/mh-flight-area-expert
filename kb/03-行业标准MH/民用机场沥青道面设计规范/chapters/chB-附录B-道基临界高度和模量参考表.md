# 附录 B 道基临界高度和模量参考表

## Core Idea
提供**分土类、分自然区划**的道基临界高度（H1 干燥 / H2 中湿 / H3 潮湿）与**道基模量**参考值，用于在缺乏当地资料时判定**道基干湿类型**、估算**道基模量设计值**。查表所得模量为**静态模量**，用作设计值前**应乘以 2.0～2.5 的系数**。

## 内容构成
- **表 B-1 砂质土道基临界高度参考值**：按自然区划（如 Ⅱ3 等）给出道基顶面距**地下水**与**地表积水**的 H1/H2/H3（m）。
  - 例：自然区划 Ⅱ3 砂质土，地下水 H1 **1.9～2.2**、H2 **1.3～1.6**（其余档位见正本）。
- **黏质土、粉质土**临界高度参考值表：结构同上，按各自土类给出。
- **道基模量参考表**：按土类与干湿状态给出模量参考值（静态）。

## 使用规则
- **判定干湿类型**（对应 ch04 §4.3.3 表 4.3.3-2）：
  | 类型 | 判据 |
  |---|---|
  | 干燥 | H0 **> H1** |
  | 中湿 | **H2 < H0 ≤ H1** |
  | 潮湿 | **H3 < H0 ≤ H2** |
  | 过湿 | **H0 ≤ H3** |
  > H0 为不利季节道基相对高度；地表积水水位指不利季节**积水 20 d 以上**的水位。
- **估算道基模量**（对应 ch06 §6.2.1）：
  1. 查表所得为**静态模量**；
  2. 设计值 = 查表值 **× 2.0～2.5**；
  3. **施工阶段应通过现场测试复核**；
  4. 有条件时宜用室内试验或 FWD 实测，查表仅作初估。

## Reference — 关键数值速查
| 项 | 值 |
|---|---|
| 查表模量→设计值放大系数 | **×2.0～2.5** |
| 地表积水水位定义 | 不利季节积水 **≥20 d** |
| 干燥/中湿/潮湿/过湿边界 | H1 / H2 / H3 |

## Amendment Notes（附录 B）
- 参考表按自然区划编制，使用时应注意与当地经验核对；条文说明明确查表值为**静态模量**，不能直接作为设计值。
