# 附录 A 气候分区方法

## Core Idea
给出气候分区的**指标选择、计算步骤与修正规则**，并在缺乏气象台站数据时提供**代表性城市参考值**。高温看**最热月日最高气温平均值**，低温看**99% 可靠度的冬季极端日最低气温**，太阳辐射看**日辐射强度幅值的平均值**。

## A.1 气候分区的确定与修正
- **A.1.1 指标选择**：
  1. **高温指标**：统计年限内**最热月的日最高气温平均值**（主指标）；**99% 可靠度的极端日最高气温**（辅助指标）；
  2. **低温指标**：**99% 可靠度的冬季极端日最低气温**（主指标）；**99% 可靠度下的小时降温速率**（辅助指标）。
- **A.1.2 指标计算**：
  - **高温**：① 取当地每月逐日最高气温 → ② 算每年各月日最高气温月平均值，取最高月为当年最热月 → ③ 算统计年限内年最热月日最高气温平均值 → ④ 按日最高气温统计值算 **99% 可靠度**日最高气温作辅助指标。
  - **低温**：① 取统计年限内每年 **10 月至次年 3 月**日最低气温 → ② 算 **99% 可靠度**冬季极端日最低气温 → ③ 按逐时温度统计算降温过程小时降温速率，取 **99% 可靠度**作辅助指标。
  - **太阳辐射**：① 取日太阳辐射强度逐时数据 → ② 统计逐日辐射强度幅值 → ③ 算统计年限内幅值平均值。
- **A.1.3 修正规则**：
  1. 高温辅助指标**超过 38 ℃** 的地区，或**特重、重**交通量等级的机场 → 高温分区可**提高一级或两级**；
  2. 低温辅助指标**高于 5 ℃/h** 的地区，或**易发生寒潮、降温迅速**的地区 → 低温分区可**降低一级**。
