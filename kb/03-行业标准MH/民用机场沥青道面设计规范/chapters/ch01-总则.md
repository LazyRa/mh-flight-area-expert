# 第1章 总则

## Core Idea
规范**民用机场沥青道面设计**，适用于新建、改建、扩建**运输机场**（含军民合用机场的民用部分）的沥青道面设计；通用机场可参照执行。核心原则是**道基—道面结构—材料一体化设计**，并纳入环保、节材、减碳与新技术推广。

## Key Clauses
- **1.0.1 制定目的**：为满足我国民用机场建设和发展的需要，规范民用机场沥青道面设计。
- **1.0.2 适用范围**：
  - 适用于**新建、改建和扩建运输机场**（**含军民合用机场的民用部分**）的沥青道面设计；
  - **通用机场**沥青道面设计**可参照执行**。
- **1.0.3 设计原则**（三条）：
  1. 根据**机场用途、飞机特性及运行情况、机场所处气候条件、道基道面材料供应情况**，结合当地**地形、水文、地质、建设和养护条件及工程经验**，进行**道基、道面结构和材料一体化设计**；
  2. 遵循**保护环境、节约资源和减少碳排放**等理念；
  3. 积极推广**新材料、新工艺和新技术**。
- **1.0.4 设计内容**：应包括**道面结构组合设计、材料设计、结构厚度设计**，并通过**技术经济分析**选定设计方案。
- **1.0.5 特殊条件**：特殊气候、地质或使用需求等条件下，除符合本规范外，**宜进行专项研究**。
- **1.0.6 符合性**：除本规范外，尚应符合国家和行业现行有关标准的规定。

## Key Concepts
- **一体化设计**：结构、材料同步设计、互相验证（条文说明：有条件时宜从立项后即开展材料设计并据试验结果优化结构）。
- **功能性修复**：设计年限内针对平整度、抗滑性能或粗糙度等**功能性能衰减**进行的整体修复；**预防性养护**、因施工或材料原因引起的**局部病害修复**不属于功能性修复。
