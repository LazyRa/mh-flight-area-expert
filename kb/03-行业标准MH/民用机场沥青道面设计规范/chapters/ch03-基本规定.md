# 第3章 基本规定

## Core Idea
本章确定设计的四个前置参数与一个判据：**设计年限**（新建 ≥20 年，可论证至 30 年）、**航空交通等级**（特轻→特重五级）、**气候分区**（高温/低温/太阳辐射三套指标）、**道面结构分区**（Ⅰ–Ⅳ区，按位置确定厚度折减），最终以**累积损伤因子 CDF ≤ 1.05** 作为结构设计的统一判据。

## 3.1 设计年限
- **3.1.1 新建**：民用机场沥青道面设计年限**应不小于 20 年**；经**专项研究和论证**（含结构专项设计、材料专项设计、严格施工质量控制），可采用 **30 年**。
  - 设计年限内允许进行**功能性修复**（针对平整度、抗滑性能或粗糙度等整体修复）；预防性养护、局部病害修复**不属于**功能性修复。
- **3.1.2 加铺层**：旧道面沥青加铺层设计年限应为 **10～15 年**，**宜采用 15 年**以降低后续养护对运行的干扰；即将搬迁机场可经论证确定，但**应不小于 10 年**。

## 3.2 设计流程
- **3.2.1** 应综合考虑**航空交通需求、气候条件、飞机特性、起降频次及运行情况、道基道面材料供应、成本**等因素进行优化设计。
- **3.2.2** 参照**图 3.2.2** 流程开展设计；**宜按该流程开展道面结构材料试验**，据试验结果进行**结构与材料一体化设计**。

## 3.3 航空交通等级（表 3.3.2）
| 等级 | 运行机型 | 设计年限内年平均运行架次 |
|---|---|---|
| **特轻** | 运行 A 类机型 | — |
| **轻** | 运行 B 类及以下机型 | — |
| **中** | 主要运行 C 类及以下 | 单条跑道 C 类机型年均 **≤20 000 架次** |
| **重** | 主要运行 C 类及以上 | 单条跑道 C 类及以上年均 **20 000～100 000 架次** |
| **特重** | 运行有 E 类机型 | 单条跑道 C 类及以上年均 **>100 000 架次** |

> 注：① 运行架次含起飞与着陆；② 一组**近距平行跑道**按该组跑道**总运行架次**划分；③ **滑行道**按相关跑道运行架次划分；④ **机位滑行通道及相关机坪**可按所在部位运行架次划分。

## 3.4 气候分区
- **3.4.1** 依据机场所在地或场址周边气象台站**最近至少 10 年**气象记录，按**附录 A** 确定；不具备条件时可参考**附录 A.2 相近城市数值**。
- **3.4.2 高温分区**（表 3.4.2，按最热月日最高气温平均值 T）：
  | 分区 | 判据 |
  |---|---|
  | 夏炎热区 | T **>30 ℃** |
  | 夏热区 | **20 < T ≤ 30 ℃** |
  | 夏凉区 | T **≤20 ℃** |
- **3.4.3 低温分区**（表 3.4.3，按 **99% 可靠度**的冬季极端日最低气温）：
  | 分区 | 判据 |
  |---|---|
  | 冬严寒区 | **≤ −37 ℃** |
  | 冬寒区 | **−37 < T ≤ −21.5 ℃** |
  | 冬冷区 | **−21.5 < T ≤ −9 ℃** |
  | 冬温区 | **> −9 ℃** |
- **3.4.4 太阳辐射分区**（表 3.4.4，按平均日太阳辐射强度幅值 R）：
  | 分区 | 判据 |
  |---|---|
  | 太阳辐射极强烈区 | **R ≥ 830 W/m²** |
  | 太阳辐射强烈区 | **680 ≤ R < 830 W/m²** |
  | 太阳辐射一般区 | **R < 680 W/m²** |
  > 条文说明：以《太阳能资源等级 总辐射》（GB/T 31155）等级划分为依据，临界值由"极丰富/很丰富/丰富"边界换算。

## 3.5 设计指标
- **3.5.1** 结构设计指标是**累积损伤因子（CDF）**；应按表 3.5.1 的**控制损坏模式**逐一计算累积疲劳损伤因子。

**表 3.5.1 损坏模式与力学设计指标**
| 基层结构类型 | 控制的损坏模式 | 力学设计指标 |
|---|---|---|
| **粒料类或沥青稳定类**基层 | 沥青层疲劳开裂 | 沥青层内**最大水平拉应变** |
| | 沥青道面轮辙 | **道基顶面最大竖向压应变** |
| **无机结合料稳定类、贫混凝土、碾压混凝土或水泥混凝土**基层 | 基层疲劳开裂 | **基层底面最大水平拉应力** |
| | 沥青道面轮辙 | **沥青层竖向剪应力** |

- **3.5.2 判据**：达到设计年限时 **CDF 应不大于 1.05**。
  > 条文说明：CDF=1 表示恰在设计年限损坏；<1 尚未损坏；>1 提前损坏。考虑结构变异性允许一定偏差，故取 1.05。

## 3.6 道面结构分区及厚度（表 3.6.1）
| 分区 | 区域内容 | 结构厚度 |
|---|---|---|
| **Ⅰ** | 跑道端部，以及飞机全重通过的**滑行道、站坪、等待坪、除冰坪** | **全厚度 t** |
| **Ⅱ** | **跑道中部、快速出口滑行道** | 可减薄，**宜不低于 0.9t** |
| **Ⅲ** | **过夜机坪、维修机坪**、通过维修机坪的滑行道 | 可减薄，**宜不低于 0.8t** |
| **Ⅳ** | **防吹坪、道肩** | 防吹坪/跑道道肩 **0.35t～0.4t**；站坪/停机坪/滑行道道肩 **0.3t**，并满足防冻厚度 |

> 注：① t 为按实际飞机荷载计算的结构厚度；② **未设平行滑行道的跑道**，中部沥青道面**按Ⅰ区设计**。条文说明：跑道端部长度范围一般为跑道全长的 **1/5～1/4**。

- **3.6.2 横断面减薄限制**：
  1. **未设平行滑行道的跑道**，跑道端部横断面**两侧不应减薄**；
  2. **跑道与滑行道连接弯道及增补面范围内不应减薄**；
  3. 道面宽度 **30 m 以上**的跑道，其横断面**中间 30 m 以外**两侧可减薄；
  4. 季节性冰冻地区，减薄区域**应满足最小防冻厚度**要求。
