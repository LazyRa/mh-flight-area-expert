# 第8章 沥青加铺层设计

## Core Idea
加铺分**结构补强性**（需算厚度）与**功能改善性**（只需满足最小厚度）。流程是**先检测评价 → 再处治旧道面 → 最后算加铺厚度**：旧水泥混凝土道面用 **tj = 2.5(Fh − Cb·he)**，旧沥青道面用 **tj = h − C0·he**；不停航条件下还要做**临时接坡与过渡段**设计。

## 8.1 一般规定
- **8.1.1 分类**：
  - **结构补强性加铺层**：**应进行加铺层厚度计算**；
  - **功能改善性加铺层**：**应满足最小加铺厚度**要求。
- **8.1.2 设计内容**：应在**旧道面检测与评价**基础上进行，包括**加铺前处治方案设计、加铺结构组合设计与厚度计算、混合料目标配合比设计、不停航条件下方案设计**。
- **8.1.3** 不停航条件下**不宜采用过多的混合料类型和规格**（施工时间紧张）。
- **8.1.4** 按**图 8.1.4** 流程进行。

## 8.2 旧道面检测与评价
- **8.2.1 内容**：**损坏状况调查、材料性能测试、结构厚度测试、道基技术状况评测、承载能力测试**；按 **MH/T 5024**《民用机场道面评价管理技术规范》执行。
- **8.2.2 材料性能**：
  - **旧水泥混凝土板弯拉强度**：现场取样试验确定，**同一结构区域取样宜 ≥7 个**；试验困难时按劈裂强度换算 **fr = 1.87 fsp^0.87**（式 8.2.2）。
  - **旧沥青道面**：测**沥青含量、空隙率、矿料级配、冻融劈裂比、肯塔堡飞散率**；**钻芯宜 ≥7 个**。
- **8.2.3 结构厚度**：**钻芯或雷达**；钻芯**同一结构区域宜 ≥7 个**并计算 **95% 保证率**厚度代表值；雷达探测应**结合钻芯校核**。
- **8.2.4 承载能力**：**道基顶面反应模量或弹性模量**、**板底脱空状况**、**接缝传荷能力**。
  > 条文说明：我国机场水泥混凝土道面**脱空现象普遍**，加铺前不处治会导致**反射裂缝迅速发展**。

## 8.3 加铺前旧道面的处治
- **8.3.1** 应对**中等及严重破损**处治；分**整体处治**（旧沥青：**铣刨或整平**；旧水泥混凝土：**道面基础注浆**）与**局部处治**。
- **8.3.2 旧沥青道面整体处治判定**（表 8.3.2，**任一项满足即宜整体处治**）：
  | 指标 | 判定标准 |
  |---|---|
  | 结构状况指数 SCI | **<80** |
  | 道面状况指数 PCI | **<55** |
  | 修补面积率 | **≥30%** |
  | 轮辙 | **轮辙长度比率 ≥30% 且平均深度 ≥10 mm** |
  > 铣刨深度视病害影响深度而定；性能已无法满足使用要求时**宜进行中下面层整体处治**。
- **8.3.3 旧沥青道面局部处治**：中等/严重**裂缝灌缝**；小面积**坑槽、松散、隆起、严重泛油、喷气烧蚀**宜用**热拌沥青混合料**局部处治。
- **8.3.4 旧水泥混凝土道面注浆条件**（任一情况）：
  1. **板底存在严重脱空**；
  2. **道基顶面反应模量 <40 MN/m³**；
  3. 基层为**碎石或块石基础**，经取芯确认**土石混填严重或存在积水**。
- **8.3.5 注浆设计**：应做**试验段试注**确定注浆层位、浆液强度、配比、单孔注浆量：
  - **无机结合料稳定类基层**注浆位置宜在**基层以下**；**粒料类基层**宜在**面层以下**；
  - **平均注浆压力宜 ≤0.5 MPa，峰值宜 ≤1.5 MPa**。
- **8.3.6 注浆效果评价**：用**注浆前后弯沉值对比**，测试时间宜在**注浆完成后 14 d**，以**弯沉减少幅度**为指标。
- **8.3.7 旧水泥混凝土局部处治**：更换破碎板；修补边角与裂缝；清除失效填缝材料并重新灌缝（**嵌缝材料损坏率 >70%** 时该区域**整体更换**）；**研磨 >10 mm 的错台**。
- **8.3.8** 加铺前应**除胶、除漆或其他表面清理**。

## 8.4 加铺道面结构组合与计算
- **8.4.1 组合与最小厚度**：可单层或多层，**不停航施工宜不超过 3 层**。
  1. **上面层**宜用 **SMA-13、SMA-16、AC-16**；中、下面层宜用 **AC-16、AC-20、AC-25、SMA-16**；
  2. **道肩上面层**宜用 AC-10、AC-13；中、下面层宜用 AC-16、AC-20；
  3. **单层最小厚度**（表 8.4.1-1）：AC 型 公称 16.0→**50 mm**、19.0→**60 mm**、26.5→**75 mm**；SMA 型 13.2→**40 mm**、16.0→**50 mm**；
  4. **旧沥青道面**：加铺层最小厚度**≥50 mm**；**旧水泥道面**：加铺**宜 ≥2 层**，最小厚度按表 8.4.1-2：**特重/重 200 mm、中 150 mm、轻 120 mm**（特轻可论证）。
- **8.4.2** 结构补强性加铺应根据**旧道面评价结果、交通等级、旧道面坡度、施工条件**拟定组合并计算厚度。
- **8.4.3 层间功能层**：
  1. 沥青层之间**喷洒热沥青或乳化沥青**，洒布量由试验确定；用乳化沥青时**应充分考虑破乳时间对不停航施工的影响**；
  2. **旧水泥混凝土上加铺**可采用：改性沥青油毡/土工合成材料铺贴接缝裂缝切缝、**同步碎石封层**、**应力吸收层**；
  3. 设改性沥青油毡时，旧道面应**平整、清洁、干燥**，且与道面**良好粘结**。
- **8.4.4 厚度计算**：
  - **旧水泥混凝土道面**：**tj = 2.5 (F·h − Cb·he)**（式 8.4.4-1）
    - **F = (0.08534·ns/100 − 0.3594·k0 + 106.2946) / 100**（式 8.4.4-2）；**F > 1.0 时取 1.0**；
    - h 为按**新建水泥混凝土道面**确定的厚度（见 **MH/T 5004**）；
    - **Cb**（旧板损坏折减系数，**0.75～1.00**）：**SCI ≥85 → 1.00**；**75 ≤ SCI < 85 → 0.95**；**SCI < 75 → 0.75～0.95**。
  - **旧沥青道面**：**tj = h − C0·he**（式 8.4.4-3）
    - h 为按加铺工程设计年限与交通量算得的新建沥青道面厚度（见第 7 章）；
    - **C0**（旧沥青损坏折减系数，**0.70～1.00**）：**PCI ≥90 → 0.95～1.00**；**85 ≤ PCI < 90 → 0.85～0.95**；**55 ≤ PCI < 85 → 0.70～0.85**。
  - **旧水泥混凝土上再次加铺**：
    1) 加铺层厚度 **≥ 旧水泥混凝土板厚** 时，按**旧沥青道面**方法计算，把旧水泥混凝土道面**作为基层**，实际加铺厚度 = 计算厚度 − 旧沥青加铺层折减厚度；
    2) 加铺层厚度 **< 旧板厚** 时，按**旧水泥混凝土道面**方法计算，实际厚度 = 计算厚度 − 旧沥青层折减厚度（C0 查表 8.4.4-2，Cb 取原设计值）。
- **8.4.5 验算**：旧水泥混凝土上加铺**宜按弹性地基板理论**验算复核；旧沥青上加铺**宜按弹性层状体系**验算复核。
  > 条文说明：复合道面典型病害——加铺层过量永久变形（轮辙、加减速位置"搓板"）、旧板疲劳开裂、接缝**反射裂缝**、转弯位置**滑移裂缝**、局部松散掉粒。
- **8.4.6 复核参数**：旧道面 k0、基层模量、面层模量宜由 **FWD 测试结果反演**；加铺层模量按 6.4 节；旧板设计弯拉强度按 8.2.2。

## 8.5 不停航沥青加铺设计措施
- **8.5.1** 包括**临时加铺设计、临时接坡设计、过渡段设计**。
- **8.5.2** 铣刨原沥青面层时应结合**铣刨深度与机具能力**合理设置层数与厚度；停航时间过短且铣刨较深时，**可临时用中面层材料摊铺至上面层**，条件具备后按设计厚度**铣刨重铺**。
- **8.5.3 临时接坡**：设在**道面与道肩交接处**，应在**道肩范围内**，**横向坡度宜 ≤1:2**。
- **8.5.4 接坡过渡段**：
  1. 每次摊铺长度**末端全幅宽度**做过渡段；
  2. 过渡段**纵坡相对原道面坡度 <0.5%**；
  3. 坡脚应**铣刨成槽嵌入**已有结构，**铣刨深度 ≥40 mm**。
- **8.5.5** 道肩宽度不满足机械摊铺最小宽度时，材料与厚度**可与道面加铺层一致**，并与道面最外一幅**统一施工**。
