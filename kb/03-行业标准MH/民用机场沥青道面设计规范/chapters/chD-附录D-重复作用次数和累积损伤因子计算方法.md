# 附录 D 重复作用次数和累积损伤因子计算方法

## Core Idea
把**飞机轮迹的横向随机性**折算成道面每个条带的**实际作用次数**：假定力学响应横向分布曲线形状固定，用**等效点**把任意起落架位置的响应换算到基准位置，再按**正态分布概率**分配到 **250 mm × 80 条带**上。

## D.1 单轴起落架构型
- **D.1.1 适用范围**：**单轴单轮、单轴双轮**。
- **D.1.2 计算方法（要点）**：
  1. 全部主起落架作用下，设设计指标对应力学响应的横向分布曲线为 **f(x)**；
  2. 轮迹横向呈**正态分布**，分布曲线记为 **φ(x)**；
  3. 道面力学分析应考察横断面**每一点**：取分析点 P（距道面中心 xp），起落架横向位置不同 → P 点响应不同；
  4. **等效原理**：假定起落架在任何位置对道面产生**相同规律**的响应（曲线形状相同）。飞机中心线与道面中心线重合时，右侧起落架中心距中心 xg，响应曲线 f_{c=xg}(x)；当右侧起落架位于任意 xu 时，其对 P 点产生的响应**等价于**基准位置下坐标 (xg + xp − xu) 处 Q 点的响应：
     **f_{c=xu}(xp) = f(xg + xp − xu)**（D.1.2-1）；
  5. P 点产生该响应的次数：**nju = nj·φ(xu)**（D.1.2-2），nj 为第 j 类飞机通行次数，φ(xu) 为起落架中心位于 xu 的概率；
  6. 将道面横向划分为**宽 250 mm 的条带**，**中线两侧各 40 个**（共 80 个），近似认为**各条带上各点的作用次数与响应量相等**；
  7. **跑道端部**：飞机中心线横向位置 x（m）呈正态分布，均值 0 时概率密度
     **g(x) = 1/(√(2π)×0.775) · e^(−x²/(2×0.775²))**（D.1.2-3）；
  8. 起落架中心位于第 i 条带（i=1,2,…,80）的概率，由该条带在正态分布曲线上的区间积分得到。
- 参数与 ch07 §7.3.2 一致：**标准差 0.775 m（775 mm）**。

## D.2 多轴和复杂起落架构型
- 针对**多轴（双轴/三轴/六轮小车等）与复杂起落架**，在 D.1 等效原理基础上叠加各轴/各轮的响应，按同样条带划分与概率分配计算条带作用次数。
- 计算流程与 D.1 相同：**响应曲线 → 等效点换算 → 概率分配 → 条带累加**。

## Reference — 关键数值速查
| 项 | 值 |
|---|---|
| 条带宽度 | **250 mm** |
| 条带数 | 中线两侧各 **40**（共 80） |
| 轮迹横向分布 | 正态，**均值 0、标准差 0.775 m** |
| 等效关系 | f_{c=xu}(xp) = f(xg + xp − xu) |
| 条带作用次数 | nju = nj·φ(xu) |
