# 附录 C 道面设计用飞机参数表

## Core Idea
提供**设计机型**的关键参数——**飞机重量 G、主起落架荷载分配系数 ρ、主起落架总轮数 nc、轮胎压力 q**，用于按式 6.1.2 计算单轮轮载 Pt、按式 6.1.3 计算轮印直径 d，并按附录 D 计算荷载重复作用次数。

## 用途
1. **ch06 §6.1.2**：**Pt = ρG / nc**，ρ、G、nc 均按本附录取值；
2. **ch06 §6.1.3**：**d = 2√(1000Pt / πq)**，q 按本附录取值；
3. **ch07 §7.2.1**：统计机型参数（最大起飞重量、胎压、起落架构型与尺寸）；
4. **附录 D**：按起落架构型（单轴单轮/单轴双轮/多轴复杂构型）计算条带作用次数。

## 参数含义
| 参数 | 含义 | 单位 |
|---|---|---|
| G | 各机型飞机重量（取设计采用的重量，如最大起飞重量或实际运行重量） | kN |
| ρ | 主起落架荷载分配系数（主起落架承担的荷载比例） | — |
| nc | 主起落架总轮数（单轮/双轮/多轮构型不同） | 个 |
| q | 主起落架轮胎压力 | MPa |
| Pt | 由上式算得的单轮轮载 | kN |

> 具体机型逐项数值见**正本表 C**（本库不转录，避免误引；引用时以正本为准）。

## Reference — 计算链
```
机型参数（本附录） → Pt = ρG/nc → d = 2√(1000Pt/πq)
                            ↓
                    力学响应（弹性层状）
                            ↓
                  允许作用次数 Nj（ch07 §7.4）
                            ↓
                  CDF（ch07 §7.5）≤ 1.05
```
