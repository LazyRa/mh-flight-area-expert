# 第2章 术语、符号

## Core Idea
界定沥青道面结构层（面层/基层/道基/垫层/道床）、混合料类型（AC/SMA/ATB）、性能指标（CDF/PCI/SCI）与设计符号，是后续各章的计算与判定基础。

## 2.1 术语（2.1.1–2.1.23）

### 结构类
- **2.1.1 沥青道面**：置于道基上，由**沥青混合料面层、基层和功能层（如设置）**组成的供飞机起降、滑行和停放的铺装结构。
- **2.1.2 设计年限**：在正常设计、施工、使用和养护条件下，道面**不需要结构性维修**的预定使用年限。
- **2.1.3 沥青面层**：由沥青混合料摊铺碾压成型、**直接承受飞机荷载**的结构层；多层时自上而下分**上面层、中面层、下面层**。
- **2.1.4 基层**：承受由面层传递下来的荷载并向下传递的结构层，可分**上基层、下基层**。
- **2.1.5 道基**：基层（垫层）以下受飞机荷载作用影响的**天然、人工填筑或改良的土（岩）体**。
- **2.1.6 垫层**：位于**道基顶部**、用于改善基层和道基工作状态的填筑层或改良土层。
- **2.1.7 道床**：受飞机荷载作用**显著影响**的道基部分，分**上道床、下道床**，厚度与航空交通等级等因素有关。
- **2.1.8 沥青加铺层**：为提高旧水泥混凝土道面或沥青道面的**承载力**或改善**表面功能**而加铺的沥青混合料面层。

### 材料类
- **2.1.9 加州承载比 CBR**：标准圆形压头以规定速率分别压入试验材料与标准碎石，贯入量达 **2.5 mm** 时两者单位压力之比。
- **2.1.10 改性沥青**：掺加橡胶、树脂、热塑性弹性聚合物等外掺剂以改善性能的沥青。
- **2.1.11 砂粒式**：最大公称粒径 **4.75 mm**。
- **2.1.12 细粒式**：最大公称粒径 **9.5 mm 或 13.2 mm**。
- **2.1.13 中粒式**：最大公称粒径 **16 mm 或 19 mm**。
- **2.1.14 粗粒式**：最大公称粒径 **26.5 mm 或 31.5 mm**。
- **2.1.15 SMA（沥青玛蹄脂碎石混合料）**：沥青结合料 + 少量纤维稳定剂、细集料 + 较多填料（矿粉）组成的沥青玛蹄脂，填充于**间断级配粗集料骨架**间隙。
- **2.1.16 ATB（沥青稳定碎石混合料）**：沥青、填料与规定级配的粗/细集料拌和制成，**用于道面基层**。
- **2.1.17 沥青含量**：沥青质量与混合料总质量之比。
- **2.1.18 马歇尔稳定度**：马歇尔试验试件所能承受的最大荷载。
- **2.1.19 动稳定度**：轮辙试验中变形进入稳定期后，每产生 **1 mm 轮辙**试验轮行走的次数。

### 指标类
- **2.1.20 荷载重复作用次数**：设计年限内，考虑**起落架横向分布效应**后，道面承受的主起落架轮载累计作用次数。
- **2.1.21 累积损伤因子 CDF**：设计年限内，各机型在道面**特定位置**的实际荷载重复作用次数与容许荷载重复作用次数**比值之和**。
- **2.1.22 道面状况指数 PCI**：表征道面**表观损坏**程度的量化技术指标。
- **2.1.23 结构状况指数 SCI**：表征道面**结构性损坏**程度的量化技术指标。

## 2.2 符号（要点）
| 符号 | 含义 |
|---|---|
| Bm | 道基土平均稠度（%） |
| H0 / H1 / H2 / H3 | 不利季节道基相对高度 / 干燥、中湿、潮湿状态道基临界高度（m） |
| Ns / Ni | 设计年限内累计运行架次 / 第 i 年年运行架次 |
| Pt | 各机型主起落架单轮轮载（kN） |
| ρ / G / nc | 主起落架荷载分配系数 / 飞机重量（kN）/ 主起落架总轮数 |
| q | 主起落架轮胎压力（MPa） |
| E0 / EA / EB | 道基弹模量 / 沥青混合料模量 / 基层模量（MPa） |
| εh / εv | 沥青面层底最大水平拉应变 / 道基顶面最大竖向压应变 |
| σt / fr | 无机结合料稳定类基层层底最大水平拉应力 / 材料弯拉强度（MPa） |
| Nj | 允许荷载重复作用次数 |
| RD | 沥青面层总轮辙量（mm） |
| Ti / τi / [τ]i | 第 i 分层温度（℃）/ 最大剪应力 / 60℃ 抗剪强度（MPa） |
| t / tj | 沥青道面结构厚度 / 沥青加铺层厚度（cm） |
| MAATa / σMAAT | 年平均气温 / 年平均气温标准差（℃） |
| fsp | 劈裂强度（MPa） |
| F / Cb / he | 控制旧水泥混凝土道面开裂程度系数 / 损坏折减系数 / 旧板厚（cm） |
| k0 | 道基顶面反应模量（MN/m³） |
| ns | C 类及以上各类飞机年运行总架次 |
| C0 | 旧沥青道面损坏折减系数 |
