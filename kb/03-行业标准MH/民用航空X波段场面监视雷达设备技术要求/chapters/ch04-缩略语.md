# 4 缩略语

## Core Idea

10 个缩略语，覆盖数据格式、机内测试、信号处理、可靠性与授时。

## Key Clauses

| 缩略语 | 全称 | 中文 |
|---|---|---|
| **ASTERIX** | All Purpose Structured Eurocontrol Surveillance Information Exchange | 欧控通用结构化监视信息交换格式 |
| **BITE** | Built-in Test Equipment | 机内在线测试设备 |
| **CFAR** | Constant False Alarm Rate | 恒虚警率 |
| **LRU** | Line Replaceable Unit | 现场可更换单元 |
| **MTBF** | Mean Time Between Failures | 故障平均间隔时间 |
| **MTTR** | Mean Time To Repair | 故障维修时间 |
| **NMEA** | National Marine Electronics Association | 美国国家海洋电子协会（船舶/定位数据接口标准） |
| **NTP** | Network Time Protocol | 网络时间协议 |
| **SPD** | Surge Protective Device | 电涌保护器 |
| **STC** | Sensitivity Time Control | 灵敏度时间控制 |

## 使用提示

- **BITE / LRU** 在第 6、11 章反复出现：BITE 要求故障隔离与系统重组 ≤2 s；监控粒度要求达到 **LRU 级**
- **STC** 属接收机功能（9.2.9）；**CFAR** 属信号处理（10.1.4），两者不要混
