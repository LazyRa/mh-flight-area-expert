# 1 范围

## Core Idea

本标准规定民用航空 **X 波段场面监视雷达**设备的**功能、性能和配置要求**，适用于设备的**设计、研制、建设、检验和使用**。

## Key Clauses

- **1 范围**：规定「功能、性能和配置要求」三项内容
- **适用对象**：民用航空使用的 X 波段场面监视雷达设备
- **适用环节**：设计 / 研制 / **建设** / **检验** / **使用**（比 2015 版表述更明确）
- **代替关系**：**代替 MH/T 4043-2015**；本次为**第一次修订**（2015 年首次发布）

## 与 2015 版的主要差异（前言摘要）

| 变化 | 内容 |
|---|---|
| 范围 | 明确"功能、性能和配置要求"，明确适用设计/研制/建设/检验/使用 |
| 引用文件 | 增 **ASTERIX Cat.010 / Cat.240**；删 **GB 10436**（微波辐射卫生环境） |
| 术语 | 增「系统测量误差 / 随机测量误差 / 频率分集」；改「脉冲压缩技术」；删脉冲雷达、连续波雷达、距离/方位分辨力与精度、脉宽、上升/下降时间、检测概率、虚警概率等 10 余条 |
| 系统组成 | 重写（2015 版 4.1） |
| 一般要求 | 增脉冲压缩体制、设计结构、主备切换与模式选择、BITE/故障隔离/系统重组、在线维护、方位信号测试接口、数字/模拟视频接口、输出数据格式、运行参数管理、室内外防雷 |
| 性能要求 | 删「工作频段」；增**抗干扰能力**、**目标处理延时**；改作用距离、距离/方位参数、位置精度、目标处理能力 |
| 天馈/收发 | 删全部**连续波雷达**相关要求；增工作频率与频宽、馈线系统、天线驱动及控制、单编码器故障、天线安全保护、全固态、多频点、长短脉冲 |
| 处理系统 | 删「雷达头信号处理」「RDP 信号处理」；增**雷达信号处理组件**、**雷达数据处理组件** |
| 终端/传输 | 增**终端系统**（删"监控维护系统"旧表述）与**传输设备**（第 12 章，全新） |

## 交叉引用

- 与 **MH5001-2021** 第 11 章「监视与控制系统」、第 9 章机坪助航设备配套（场面监视雷达是 A-SMGCS 的传感器）
- 与 **AC-137-CA-2025-02**（跑道状态灯灯光子系统）、**MH/T 6127**（跑道状态灯控制处理系统）同属场面运行监视/防护类设备
- 与 **MH/T 4020**（通信导航监视设施防雷）、**GB 8702**（电磁环境控制限值）为强制引用
- 参考文献含 **ICAO Doc 9830 A-SMGCS 手册**
