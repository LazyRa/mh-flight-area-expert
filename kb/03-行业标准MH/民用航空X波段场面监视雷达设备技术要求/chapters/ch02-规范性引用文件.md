# 2 规范性引用文件

## Core Idea

引用文件由 2015 版的「GB 10436 + MH/T 4020」改为「**GB 8702 + MH/T 4020 + ASTERIX Cat.010 / Cat.240**」，即从"卫生防护"转向"**数据交换格式标准化**"。

## Key Clauses

| 文件 | 名称 | 用途 |
|---|---|---|
| **GB 8702** | 电磁环境控制限值 | 室内设备微波辐射限值（6 一般要求） |
| **MH/T 4020** | 民用航空通信导航监视设施防雷技术规范 | 系统防雷（6 一般要求） |
| **EUROCONTROL ASTERIX Category 010** | 监视数据交换 第 7 部分：**单传感器场面监视数据传输** | 目标报告输出格式（6 一般要求） |
| **EUROCONTROL ASTERIX Category 240** | 监视数据交换：**雷达视频传输** | 数字原始视频输出格式（6 一般要求） |

## 与 2015 版差异

- **新增**：ASTERIX Cat.010、Cat.240
- **删除**：GB 10436《作业场所微波辐射卫生环境》—— 改由 **GB 8702** 承担

## 注意事项

- 注日期引用仅该版本适用；不注日期按最新版（含所有修改单）
- ASTERIX 是欧控标准，国内设备须**按 Cat.010 / Cat.240 的数据项定义**输出，这是与空管自动化系统对接的关键
