# 11 终端系统

## Core Idea

两类设备：**监控维护设备**（管设备）与**目标显示设备**（管画面）。核心约束是**权限分级、操作留痕、故障告警、记录时长**。

## Key Clauses

### 11.1 监控维护设备
- **11.1.1** 采用工业标准图形工作站与操作系统，人机界面友好
- **11.1.2** 含**本地 + 远程**监控维护终端，至少具备**设备监控、设备操作、参数设置及修改**；终端故障或断连**不影响雷达正常运行**
- **11.1.3** 具备**操作控制权申请与释放**；同一时刻**只允许一台**终端拥有操作控制与参数修改权限
- **11.1.4 权限管理**：至少分**监控人员**（只能通道切换、开关辐射等常规操作，**不能**改系统参数）与**维护人员**（可常规操作 + 参数设置修改）；可自行修改登录密码
- **11.1.5** 支持主备通道「自动或手动切换」模式选择，支持手动切换操作
- **11.1.6** **自动记录所有操作**（含参数设置修改），形成设备操作记录
- **11.1.7** 彩色图形界面，不同颜色反映设备状态，点击图形模块进入子系统查看参数
- **11.1.8** 故障时给出告警信息，至少含**告警起止时间、告警模块、告警等级**
- **11.1.9** 具备告警**声音**提示，可人工关闭，具备音频外接输出接口
- **11.1.10** 对主要工作状态采集分析、正确判决并直观显示，级别达到 **LRU 级**
- **11.1.11** 具备**监控数据输出**能力与接口
- **11.1.12** 可导出运行状态记录、操作记录、故障告警记录；**记录时间 ≥1 年**；导出格式至少文本；告警记录须含时间、组件/功能模块、级别
- **11.1.13** 终端时间与雷达系统时间同步，具备自动校准
- **11.1.14 天馈系统监控**：天线转速；基座及减速箱油位/油温；驱动马达温度、变频器电流及过流/过温告警；方位信号产生单元状态；安全联动装置状态
- **11.1.15 收发系统监控**：电源供电；温度；发射功率与驻波比；接收机噪声电平；接收机本振信号
- **11.1.16 处理系统监控**：方位信号与授时设备状态；硬件功能运行状态；软件功能运行状态
- **11.1.17 传输设备监控**：各数据输入输出端口状态与告警

### 11.2 目标显示设备
- **11.2.1** 工业标准通用图形工作站与操作系统，界面良好易操作
- **11.2.2** 含**本地 + 远程**显示终端，至少具备**原始视频与目标的实时显示**
- **11.2.3** 具备原始视频与目标的**回放**功能
- **11.2.4** 可显示与导入机场**场面背景地图或基础地理图**
- **11.2.5** 可控制屏幕显示范围、显示光标坐标、控制距离环/中心点/地图背景/各类抑制区显示
- **11.2.6** 可对目标进行**距离、方位测量**与**回波强度**显示
- **11.2.7 记录时长**：本地终端**原始视频 ≥3 d**；本地与远程终端**目标报告 ≥90 d**

## 答问速查

| 项目 | 值 |
|---|---|
| 原始视频记录 | ≥3 d（本地显示终端） |
| 目标报告记录 | ≥90 d（本地 + 远程） |
| 运行/操作/告警记录 | ≥1 年 |
| 监控粒度 | LRU 级 |
| 同时可控终端 | 1 台 |
