# 5 系统组成

## Core Idea

系统由**五大分系统**构成：天馈系统、发射与接收系统、处理系统、终端系统、传输设备。2015 版只有四部分且不含传输设备。

## Key Clauses

**5 系统组成**：场面监视雷达系统应**至少**包括：

| 分系统 | 组成 |
|---|---|
| **天馈系统** | 天线系统、馈线系统、天线驱动及控制系统 |
| | · 馈线系统：**旋转关节、波导组件**等 |
| | · 天线驱动及控制系统：**天线基座、驱动马达及减速箱、天线旋转控制、天线安全保护装置、方位信号产生组件** |
| **发射与接收系统** | 发射机模块组件、接收机模块组件（射频发射与接收） |
| **处理系统** | **雷达信号处理**组件、**雷达数据处理**组件 |
| **终端系统** | **监控维护设备**、**目标显示设备** |
| **传输设备** | **网络交换机**等 |

## 与 2015 版差异

- 2015 版无独立「终端系统」「传输设备」章；本次将原"监控维护系统"拆为**监控维护设备 + 目标显示设备**，并新增**传输设备**（第 12 章）
- 处理系统从"雷达头信号处理 / RDP"改为**信号处理组件 + 数据处理组件**
