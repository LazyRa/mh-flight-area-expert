# 5 紧急抢修

## Core Idea

本章管**跑道道面突发性、威胁运行安全的严重损坏**的应急处置。逻辑主线是"**触发—措施—预案—演练**"闭环：5.1 用三条**量化门槛**界定"什么情况必须抢修"；5.2 按**作业时窗是否充足**二选一（临时性修补 / 永久性修补）；5.3 要求预案覆盖组织、流程、时效、衔接；5.4 用**可量化的演练验收**（挖坑尺寸 + 碾压遍数）证明抢修能力真实可用。核心权衡是：**开放交通的紧迫性 vs 修补的耐久性**——临时性修补允许降低耐久性，但不允许降低安全性。

## 5.1 一般规定

- **5.1.1 紧急抢修触发条件（三条，任一即触发）** 当发现道面出现以下严重损坏情况时，**应组织紧急抢修**：
  1. **跑道道面断裂**，包括整块板或者局部，并出现**错台或者局部松动**；
  2. 跑道道面出现**直径（长边）大于 120 mm（含）的掉块**；或直径（长边）**小于 120 mm 但深度大于 70 mm（含）或坡度大于 45°（含）**的破损；
  3. 跑道出现**高度大于 5 mm（含）错台**。
- **5.1.2 预案与演练** 应制定相应的跑道道面损坏紧急抢修预案并**定期开展演练**。
- **5.1.3 抢修原则** 应优先采用**成熟的快速施工技术和工艺**；抢修过程中要充分评估现场情况，**优先抢修影响飞行运行的部位**。
- **5.1.4 设备配备** 应按所用材料、维护工艺和维修量配备现场作业设备；**关键设备应按"一主一备"原则配备**。（设备包括但不限于切缝、破碎、小型压实、抹平、清扫、防水设备）
- **5.1.5 设备维保** 紧急抢修设备应**定期检查和保养**，并保持适用状态。
- **5.1.6 安全与清场** 抢修过程中应确保**人员、设备和航空器安全**；抢修完成后应**及时清理现场**。

## 5.2 紧急抢修措施

- **5.2.1 临时性 / 永久性修补的选择** 应综合损坏紧急程度、作业时段和道面使用需求：
  1. 当**永久性修补无法在限定作业时段内完成**时 → 采用**临时性修补**，并根据材料耐久性**尽早实施永久性修补**；
  2. 当**作业时段充足**时 → 应采用**永久性修补**。
- **5.2.2 裂缝伴碎块松动** 当跑道道面出现裂缝并伴有**碎块松动**时，应**清除裂缝周围松动的碎块**，并采用**填缝密封材料**进行修补。
- **5.2.3 严重掉块破损的抢修（四款）**：
  1. **临时性修补**可采用**冷拌沥青混合料、聚氨酯修补砂浆或磷酸盐水泥修补砂浆**；
  2. 采用**冷拌沥青混合料**时：
     - 按破损范围划定边界后切割，**切割深度宜与抢修深度一致**；
     - **破除深度应不小于 100 mm**，坑槽底面应基本平整；
     - 清除碎块及杂物后填入，**填料高度宜高出原道面 10 mm ~ 20 mm**；
     - **分层夯实，每层夯实厚度宜不大于 50 mm**，**边缘应额外夯实**；
     - 完成后**表面应撒适量干燥土或石灰粉**；
     - （条文说明：单次修补面积一般**不超过 1.0 m²**）
  3. 采用**聚氨酯修补砂浆或磷酸盐水泥修补砂浆**时：清除坑槽内碎块及杂物，按破损尺寸确定用量并搅拌均匀后倒入坑槽，**填料高度宜略低于原道面**，随后抹平并清除周边多余材料；
     - （条文说明：浇筑后 **15 min 内抗压强度可达 20 MPa 以上**；单次修补面积一般**不超过 0.5 m²**）
  4. **永久性修补**常用**磷酸盐水泥、改性硅酸盐早强水泥**等材料，材料性能应符合第 **4.2** 节，修补工艺应符合第 **6.2 / 6.3 / 6.4** 节。
- **5.2.4 错台** 当跑道出现**高度大于 5 mm（含）错台**时，应采用**板块拱起修复或板块研磨**方式进行修复（工艺见 6.7、6.8）。

## 5.3 紧急抢修预案

- **5.3.1 编制依据** 应充分考虑机场**航班流量、跑道构型及数量、航空器运行特点**，以及道面可能突发的**损坏类型、严重程度、损坏位置**及其对运行安全的影响，并明确不同情形下的**抢修措施、人员、材料及设备要求**，确保突发损坏后能**迅速启动、有效处置**。
- **5.3.2 预案九项内容** 应包括：**组织机构与职责分工、响应流程、人员与设备配置、材料储备、抢修措施、运行调整原则、安全防护措施、信息通报程序、开放运行标准**。
- **5.3.3 可操作性** 应涵盖**断裂、掉块、错台**等常见突发损坏的**响应策略、抢修路径及保障流程**。
- **5.3.4 时效要求** 应明确抢修作业的时效要求，针对不同事件设定相应的**响应时间、抢修完成时间及恢复通行时间**目标。
- **5.3.5 动态修订** 预案应**定期修订**，并根据**新材料、新工艺、新装备**的应用动态更新。
- **5.3.6 体系衔接** 预案应纳入**机场整体运行保障体系**，与飞行区运行安全管理、应急救援、运行调度等相关预案**相互衔接**，确保统一指挥、协调有序。

## 5.4 紧急抢修演练

- **5.4.1 演练目的** 应**定期组织**演练，检验预案的**完整性、适用性和可操作性**，并根据演练结果和实际运行情况及时修订完善。
- **5.4.2 场景覆盖** 宜涵盖**夜间作业、雨雪天气、特殊航班保障**等不同场景。
- **5.4.3 演练内容（五项）** 应包括：**抢修事件发现与响应启动、组织指挥与任务分工、人员调度与安全防护、现场作业与质量控制、运行协调与信息通报**。
- **5.4.4 演练验收（四条量化要求）**：
  1. 演练在**临时关闭的道肩、机坪或服务车道**等区域的水泥混凝土道面上进行；
  2. 演练过程中人工破除**直径不小于 150 mm、深度不小于 100 mm** 的坑槽；
  3. 修补后的道面使用**碾压设备**（压路机、货车、叉车等）碾压，**碾压遍数不少于 50 次**，碾压后**补块无开裂、松散或剥落**现象；
  4. 演练完成后**总结复盘**，必要时修改、完善预案。

## 关键指标

**表 5.1.1 紧急抢修触发门槛（跑道）**

| 损坏形态 | 量化门槛 | 是否抢修 |
|---|---|---|
| 道面断裂 | 整块板或局部 + **错台或局部松动** | 是 |
| 掉块（大） | 直径（长边）**>120 mm（含）** | 是 |
| 掉块（小但深/陡） | 直径（长边）<120 mm，且**深度 >70 mm（含）**或**坡度 >45°（含）** | 是 |
| 错台 | 高度 **>5 mm（含）** | 是 |

**抢修工艺参数**

| 项目 | 指标 | 出处 |
|---|---|---|
| 冷拌沥青混合料破除深度 | **≥100 mm** | 5.2.3-2 |
| 冷拌料填料高度 | **高出原道面 10~20 mm** | 5.2.3-2 |
| 冷拌料分层夯实厚度 | 每层 **≤50 mm** | 5.2.3-2 |
| 冷拌料单次修补面积 | 一般 **≤1.0 m²**（条文说明） | 5.2.3 条文说明 |
| 聚氨酯/磷酸盐砂浆单次修补面积 | 一般 **≤0.5 m²**（条文说明） | 5.2.3 条文说明 |
| 聚氨酯/磷酸盐砂浆 15 min 抗压强度 | **>20 MPa**（条文说明，现场测试） | 5.2.3 条文说明 |
| 关键设备配备原则 | **一主一备** | 5.1.4 |
| 演练坑槽尺寸 | **φ≥150 mm，深≥100 mm** | 5.4.4-2 |
| 演练碾压遍数 | **≥50 次** | 5.4.4-3 |

## 交叉引用

- **MH/T 5090-2025（接缝材料）** —— 5.2.2 "填缝密封材料"的品种与性能按 5090 执行；本规范未重复规定接缝材料指标。
- **MH/T 5085-2025（沥青道面维护）** —— 5.2.3 所用**冷拌沥青混合料**的技术要求按 5085 执行（本规范 4.2.8 已作转致）。
- **MH 5001-2021（飞行区技术标准）** —— 5.1.1 的掉块尺寸与错台高度门槛，须与 5001 中跑道道面"可用性/适航"判定标准对照；两者判据不同（5001 管"是否可开放"，5084 管"是否须抢修"），实际执行取严。
- **CCAR-139B（运输机场运行安全管理规定）** —— 5.3.2 的"运行调整原则、信息通报程序、开放运行标准"、5.3.6 的"纳入机场整体运行保障体系"，管理依据在 139B；本规范只管技术措施。
- **MH/T 5006-2026（水泥混凝土面层施工）** —— 5.2.3-4 永久性修补如采用普通水泥混凝土，浇筑与养护按 5006（见 6.5.11-2）。
- **MH/T 5086-2025（场地基础性维护）** —— 5.1.6 "抢修完成后及时清理现场"的**清扫作业标准**（设备、频次、FOD 防范）由 5086 第 6 章规定。
- **第 6 章（本规范）** —— 5.2.3-4 转致 6.2/6.3/6.4；5.2.4 转致 6.7/6.8。
- **附录 C（本规范）** —— 5.1.4 所列抢修设备的功能要求见附录 C。
