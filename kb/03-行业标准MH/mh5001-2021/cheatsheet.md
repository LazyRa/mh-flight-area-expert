# 速查表 Cheatsheet — MH 5001-2021

> 决策规则与阈值。所有内容以四份修订案为准；旧 PCN/ACN 体系已失效。

## 道面强度（ACR-PCR，表 3.6.3）
| 判定 | 规则 |
|---|---|
| 可用 | **ACR ≤ PCR** → 规定胎压/最大起飞质量下可用 |
| 超载运行 | **ACR > PCR** 且同时满足：①无破坏/道基未减弱；②柔性 ≤110%、刚性 ≤105%（105–110% 刚性须专门评估）；③年超载 ≤ 年总运行 **5%** |
| 轻型航空器 | 机坪质量 **≤5700kg** → 仅报告最大质量+最大胎压，不需道基类别 |

**道基强度代号（E，MPa）**：A ≥150 ｜ B 100–<150 ｜ C 60–<100 ｜ D <60
**胎压代号（MPa）**：W 无限制 ｜ X ≤1.75 ｜ Y ≤1.25 ｜ Z ≤0.50
**道面类型**：R 刚性 ｜ F 柔性　**评定**：T 技术 ｜ U 经验
报告示例：`PCR 760/R/B/W/T`、`PCR 550/F/A/Y/U`

## 飞行区指标
- **指标Ⅰ（1–4）**：基准飞行场地长度 + 翼展/主起落架外轮外边距
- **指标Ⅱ（A–F）**：翼展 + 主起落架外轮外边距（F 最大，如 A380）

## 障碍物限制面设立（按跑道类型）
| 跑道类型 | 设立限制面 |
|---|---|
| 非仪表 | 内水平、锥形、进近、过渡 |
| 非精密进近 | + 内进近、复飞 |
| 精密进近 | 全部 8 类（含内过渡） |

## 关键设置条件
| 项目 | 触发条件 |
|---|---|
| 跑道端安全区 RESA | 指标Ⅰ 3/4 **或** 指标Ⅰ 1/2 的仪表跑道（4.5.1）；宽度 ≥ 跑道 2 倍（4.5.3） |
| 跑道等待位置 | 滑行道(非单向出口)与跑道相交；仅出口滑行道仅 1 个；跑道交跑道处（4.12.2） |
| SMGCS | **必须设置**（1.0.4，第二修订案新增） |
| 跑道中线灯 | 精密进近跑道 + 起飞跑道（7.4.5） |
| 跑道接地带灯 | Ⅱ/Ⅲ类精密进近跑道（7.4.6） |
| 停止排灯 | RVR<550m 低能见度运行（7.5.5） |

## 标志 / 标记牌（第四修订案）
- **增强型滑行道中线标志**：每条滑行道与跑道交接处（仅出口滑行道除外）
- **NO ENTRY 禁止进入标志**：仅出口滑行道，白字红底，距相邻平行滑行道中心线 **0.8–1.3W**
- **滑行边线标志**与跑道等待位置标志相交处中断，净距 **0.9m**
- **跑道脱离标记牌**：设在跑道等待位置处；设 ILS/MLS 时距临界/敏感区边界或内过渡面底边 ≥ 该距离（取距跑道中线较远者）

## 供电 / 照明
- 助航灯光 = **一级负荷中特别重要负荷**；双重电源 + 应急电源（表 10.1.6）
- 机坪泛光灯：LED 色温 **≤4000K**；接地 **TN-S / TT**；独立电缆
- 机位号码标记牌字符高 **≥60**（8.5.6）；机场识别标记字体高 **≥3m**（8.7.4）

## Tells & Smells（合规检查）
- 见到资料写 **PCN/ACN** → 已失效，须重评为 **PCR/ACR**
- 跑道等待位置只有 1 个且是出口滑行道 → 正常（仅出口）
- 限制面内有固定物体无标示 → 违规（12.1.1）
- 精密进近跑道却无内过渡面 → 缺失（5.2）
