# 术语表 Glossary — MH 5001-2021 民用机场飞行区技术标准

> 术语主要取自第 2 章。[修订] = 已被修订案修改；[新增] = 修订案新增。引用格式：**术语** — 定义（Ch N）。

## A–C
- **ACN（航空器等级号）** — 旧术语，第一修订案起由 **ACR** 取代，主文与标准中均失效（Ch 2/3）
- **ACR（航空器分类等级 aircraft classification rating）** [修订] — 表示航空器对规定标准基础道基等级道面的相对影响的数字编号（2.1.41）
- **APAPI / PAPI（精密进近坡度指示系统）** — 向飞行员提供下滑坡度引导的灯光系统（2.1，7.3）
- **ARIWS（跑道侵入自主警告系统）** — 自主探测并警告跑道侵入的系统（2.1.58）
- **OFZ（无障碍物区 obstacle free zone）** — 保护起飞/着陆航迹的空间（2.1.44）

## D–F
- **道面分类等级 PCR（pavement classification rating）** [修订] — 表示道面可供不受次数限制适用的承载强度的编号；取代旧 PCN（2.1.40）
- **道面类型 R/F** — 刚性道面（R）/ 柔性道面（F），ACR-PCR 报告代号（表 3.6.3）
- **道路等待位置 road-holding position** — 道路与跑道/滑行道相交处的等待位置（2.1.39，4.12.5）
- **FOD（外来物 foreign object debris）** — 可能损伤航空器的外部物体（2.1.70）

## G–J
- **基准点 ARP（机场基准点 aerodrome reference point）** — 机场的地理参考点（2.1.4，3.2）
- **机场标高 aerodrome elevation** — 跑道中点的标高（2.1.3，3.3）
- **机场交通密度** — 划分低/中/高，影响等待坪、灯光等设置（2.1.5）
- **机坪 apron** — 供飞机停放、上下客货、加油等的场地（2.1.34，4.13）
- **机位 aircraft stand** — 机坪上供单架飞机停放的位置（2.1.33）
- **中间等待位置 intermediate holding position** — 滑行道上仅次于跑道等待的等待位置（2.1.38，4.12.4）

## K–M
- **客运机场 / 陆地民用机场** — 本标准主要适用对象（1.0.2）
- **快速出口滑行道** — 以大角度连接、便于高速脱离跑道的滑行道（4.9.10）
- **SMGCS（地面活动引导及控制系统 Surface Movement Guidance And Control Systems）** [新增] — 由目视/非目视助航设备、程序、管制等组成的组合体；第二修订案新增（2.1.83，1.0.4，2.3）

## N–Q
- **内过渡面 inner transitional surface** — 比过渡面更靠近跑道的限制面（5.1.7）
- **内进近面 inner approach surface** — 紧靠跑道入口前的进近面长方形部分（5.1.5）
- **内水平面 inner horizontal surface** — 机场周围的水平限制面（5.1.2）
- **跑道 runway** — 供飞机起飞着陆的长方形场地（2.1.7）
- **跑道端安全区 RESA** — 跑道端外用于减少冲出跑道风险的区域（2.1.27，4.5）
- **跑道等待位置 runway-holding position** — 滑行道与跑道相交处的等待位置（2.1.37，4.12.2）
- **跑道视程 RVR** — 跑道上飞机能见距离（2.1.9）

## R–T
- **RESA** 见 跑道端安全区
- **升降带 runway strip** — 包络跑道及相接停止道的地带（2.1.23，4.4）
- **胎压类型 W/X/Y/Z** — ACR-PCR 中最大允许胎压代号：W 无限制 / X≤1.75 / Y≤1.25 / Z≤0.50 MPa（表 3.6.3）
- **弹性模量 E** [修订] — 道基强度参数（MPa）；符号由第一修订案新增，分级区间由第三修订案改为 ≥/\<（表 3.6.3）
- **停机坪 / 防吹坪 / 掉头坪** — 见相应设施条款（4.3/4.16/4.3）

## U–Z
- **易折物体 frangible object** — 位移/变形不致严重损坏飞机、抗力弱的物体（2.1.71）
- **轻型航空器** [修订] — 机坪质量 ≤5700kg 的航空器；第三修订案明确定义（3.6.5 条文说明）
- **障碍物 obstacle** — 可能危及飞行的固定/移动物体（2.1.43，Ch 5/12）
- **评定方法 T/U** — ACR-PCR 中技术评定（T）/ 经验评定（U）代号（表 3.6.3）
- **道基强度 A/B/C/D** — 高强度 A(≥150) / 中强 B(100≤E<150) / 低强 C(60≤E<100) / 特低 D(<60) MPa（表 3.6.3）

## 旧术语警示
- **PCN（道面等级号）** / **ACN（航空器等级号）**：第一修订案起**全部失效**，任何合规评价须改用 **PCR / ACR**。
