# 第3章 航空数据与道面强度

## Core Idea
飞行区设计的前提是准确的航空数据（基准点、标高、温度、设施资料），以及用 **ACR-PCR 方法**评价的道面承载强度。[修订] 整节 3.6 已由第一、第三修订案重写，旧 PCN/ACN 体系失效。

## Key Clauses
- **3.1 航空数据**：应确定并提供与飞行区有关的航空数据（3.1.1）；水平基准采用 WGS-84（3.1.2）；垂直基准采用平均海平面（3.1.3）。
- **3.2 机场基准点 ARP**：机场应设一个基准点，可位于现有跑道几何中心（3.2.1）；测定地理坐标，度分秒单位（3.2.2）。
- **3.3 标高**：测定机场标高及大地水准面高差（3.3.1）；精密进近跑道应测入口标高及跑道端标高（3.3.2）；非精密进近跑道测入口标高（3.3.3）。
- **3.4 机场基准温度**：最热月（月平均温度最高月）的日最高气温月平均值（3.4.1–3.4.2）。
- **3.5 基本设施资料**：提供设施有关资料（3.5.1）；测定跑道入口中点/中心点、滑行道中心线、机位坐标（3.5.2）；测定周围重要障碍物坐标与顶端标高（3.5.3）。
- **3.6 道面强度**【ACR-PCR，见下表】。
- **3.7 公布距离**：每个跑道方向公布可用起飞/加速停止/可用起飞滑跑/可用着陆距离（3.7.1）。
- **3.8 飞行前高度表校正位置**：宜设在机坪，标高取场地平均标高（3.8.1–3.8.3）。
- **3.9 精密进近坡度指示系统（PAPI）资料**应提供（3.9.1）。

## Reference Table — 表3.6.3 ACR 和 PCR 方法报告道面强度的分类及代号
| 分类 | 代号 | 备注 |
|---|---|---|
| 1 道面类型 | **R** | 刚性道面（复合/非标准应加注解） |
| | **F** | 柔性道面 |
| 2 道基强度类型 | **A** 高强度 | 道基 E=200MPa，代表 **≥150MPa** 的 E 值 |
| | **B** 中强度 | 道基 E=120MPa，代表 **100≤E<150MPa** |
| | **C** 低强度 | 道基 E=80MPa，代表 **60≤E<100MPa** |
| | **D** 特低强度 | 道基 E=50MPa，代表 **<60MPa** |
| 3 最大允许胎压类型 | **W** 无限制 | 胎压无限制 |
| | **X** 高 | 胎压上限 1.75 MPa |
| | **Y** 中 | 胎压上限 1.25 MPa |
| | **Z** 低 | 胎压上限 0.50 MPa |
| 4 评定方法 | **T** 技术评定 | 检测评定或理论评定 |
| | **U** 经验评定 | 依据使用经验评定 |

**报告示例**：PCR 760/R/B/W/T（中强度道基刚性道面，技术评定，无胎压限制）；PCR 550/F/A/Y/U（高强度道基、类柔性复合道面，经验评定，胎压上限 1.25 MPa）。

## ACR-PCR 评价规则（3.6.2–3.6.5）
- **3.6.2**：供机坪质量 **>5700kg** 飞机使用的道面，承载强度应采用 ACR-PCR 方法，报告 PCR 值、道面类型、道基弹性模量、最大允许胎压类型、评定方法。
- **3.6.3**：采用表 3.6.3 代号报告 ACR 与 PCR。
- **3.6.4 可用性 / 超载运行**：
  - 当 **ACR ≤ PCR**：在规定胎压和最大起飞质量下可使用该道面；道面强度受季节影响明显时应确定不同 PCR。
  - 当 **ACR > PCR**（超载运行，须同时满足）：① 道面无破坏迹象、道基强度未显著减弱期间；② 柔性道面 ACR 不超过 PCR 的 **110%**，刚性或以刚性为主的复合道面 ACR 宜不超过 **105%**（超过 105% 但不到 110% 的应进行专门超载评估）；③ 年超载运行次数不超过设计年总运行次数的 **5%**。
  - 避免超载：道面呈现破损/失效迹象、冻融期间、道基强度可能因水影响而减弱时。
- **3.6.5**：供机坪质量 **≤5700kg** 的**轻型航空器**使用的道面，报告：① 最大允许航空器质量；② 最大允许胎压（例：4000kg / 0.50MPa）。轻型航空器起落架多为单轮，无需报告道基类别。
