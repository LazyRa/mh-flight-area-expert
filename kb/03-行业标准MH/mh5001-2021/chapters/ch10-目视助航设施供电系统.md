# 第10章 目视助航设施供电系统

## Core Idea
助航灯光属**一级负荷中特别重要负荷**，须双重电源 + 应急电源；机坪助航设备供电分级、泛光灯独立电缆、接地采用 TN-S/TT。本章未被四份修订案直接修改。

## Key Clauses
- **10.1 助航灯光供电系统**：
  - 10.1.1 负荷等级：一级负荷中特别重要负荷，除双重电源外增设应急电源。
  - 10.1.2–10.1.5 变电站设置（跑道附近 1–2 个）、两路稳定可靠电源（10.1.3）、站房组成（高低压间、恒流调光器间等）。
  - **10.1.6 应急电源**：精密进近跑道应满足 表 10.1.6 相应类别要求。
  - 10.1.7–10.1.10 不同跑道类型的供电要求：起飞跑道 RVR<800m 设满足表 10.1.6 的应急电源（10.1.7）；非精密进近主跑道（10.1.8）、非仪表主跑道（10.1.9）；RVR<550m 时表 10.1.6 灯光应急电源（10.1.10）。
- **10.2 机坪助航设备供电系统**：
  - 10.2.1 近机位高级 VDGS 为一级负荷，其他机坪助航设备按需要定级。
  - 10.2.2 机坪泛光灯采用独立电力电缆，相邻泛光灯宜接自不同供电回路。
  - 10.2.3 全负荷时工作电流 ≤ 电缆载流量 70%。
  - 10.2.4 中性线截面 ≥ 相线截面；灯端电压符合规定。
  - 10.2.5–10.2.6 手动 + 集中自动控制，分区/分组照明。
  - 10.2.7 气体放电灯光源采用三相供电降低频闪。
  - **10.2.8 接地方式采用 TN-S 或 TT 系统**。
  - 10.2.9 飞机地面静变电源经配电箱（亭）或电源井供电。

## Reference — 供电分级要点
| 系统 | 负荷等级 / 关键要求 |
|---|---|
| 助航灯光 | 一级负荷中特别重要；双重电源 + 应急电源（表 10.1.6） |
| 近机位高级 VDGS | 一级负荷 |
| 机坪泛光灯 | 独立电缆、TN-S/TT 接地、中性线≥相线 |
