# 3 设计参数

## Core Idea

本章把"飞机—交通—地基—材料"四类输入量全部定量化，是第 5 章厚度计算的唯一取数来源。逻辑链条是：先用**机型 + 年平均运行架次**定航空交通等级（3.0.1），由等级定**设计年限**（3.0.2）、**道床顶面反应模量下限**（3.0.8）和**混凝土弯拉强度下限**（3.0.10）；再用飞机重量换算**单主起落架荷载**（3.0.3）和**轮印尺寸**（3.0.4）；地基侧则坚持"现场实测 k0 → 公式推算 kd"的路径（3.0.6、3.0.7），不直接采用承载板测得的道床顶面值。

## Key Clauses

- **3.0.1 航空交通等级**：根据**拟运行机型**及**设计年限内年平均运行架次**按表 3.0.1 确定。
  - 注 1：跑道运行架次包括**起飞架次和着陆架次**。
  - 注 2：一组**近距平行跑道**中，单条跑道按该组近距平行跑道的**总运行架次**划分。
  - 注 3：**滑行道**按相关跑道运行架次划分。
  - 注 4：**机位滑行通道及相关机坪**可按所在部位的运行架次划分。
- **3.0.2 设计年限**：新建水泥混凝土道面及旧水泥混凝土道面上水泥混凝土加铺层的设计年限**宜为 30 年**；航空交通等级为**特重**的道面，经**专项研究论证**后可采用 **40 年或以上**。
- **3.0.3 设计荷载**：应采用所在部位**拟运行飞机的主起落架荷载**，按式（3.0.3）计算。常用飞机荷载参数见**附录 A**。
- **3.0.4 轮印简化**：计算荷载应力时飞机轮印可简化为**矩形**，单轮轮印尺寸按式（3.0.4-1）、（3.0.4-2）确定。
- **3.0.5 累计通行次数 Nsi**：按航空交通量预测数据确定。配备**完整平行滑行道**的跑道，Nsi **与预测的跑道运行次数相同**；**未配备平行滑行道**的跑道，Nsi 应按预测跑道运行次数的 **2 倍**取值。
- **3.0.6 道基顶面反应模量 k0**：宜通过**现场承载板试验**确定，测试方法可参照《民用机场道面现场测试规程》（MH/T 5110）。
- **3.0.7 道床顶面反应模量 kd**：按式（3.0.7）计算；当计算确定的 kd **大于 100 MN/m³** 时，**宜按 100 MN/m³ 取值**。
  - 【条文说明】式（3.0.7）基于 Winkler 地基上**单层弹性体**理论解、以**竖向位移**为等效指标推得；虚拟承载板半径取 **0.57 m**，垫层厚度适用范围 **0.2 m～0.8 m**；级配碎石或砾石、山皮石或土石混合填料、水泥或石灰处治土的回弹模量取值分别为 **500 MPa、200 MPa、800 MPa**。**不设垫层时，实测 k0 即为 kd**。
- **3.0.8 kd 要求**：道床顶面反应模量 kd 应符合表 3.0.8 的规定（下限值）。
- **3.0.9 基层参数**：基层弹性模量和泊松比可参照表 3.0.9 取值；**新建**道面设计时基层弹性模量**宜取高值**，**旧混凝土道面上加铺层**设计时**宜取低值**。
- **3.0.10 面层混凝土强度**：设计强度宜采用 **28 d 龄期的弯拉强度**，并应符合表 3.0.10-1；弯拉弹性模量可按表 3.0.10-2 取值，**泊松比可采用 0.15**。
  - 【条文说明】本版根据弯拉弹性模量实测结果并参考国内外标准，对取值进行了调整（2010 版为单一值）。

## 关键指标

**表 3.0.1 航空交通等级划分标准**

| 航空交通等级 | 运行机型 | 设计年限内年平均运行架次 |
|---|---|---|
| 特轻 | 运行 A 类机型 | — |
| 轻 | 运行 B 类及以下机型 | — |
| 中 | 主要运行 C 类及以下机型 | 单条跑道 C 类机型的年平均运行架次**不大于 20 000 架次** |
| 重 | 主要运行 C 类及以上机型 | 单条跑道 C 类及以上机型的年平均运行架次为 **20 000 至 100 000 架次** |
| 特重 | 主要运行 C 类及以上机型，**并运行有 E 类机型** | 单条跑道 C 类及以上机型的年平均运行架次**超过 100 000 架次** |

**计算公式**

- 单主起落架荷载：`Qc = Qa·p / nc`（3.0.3）
- 轮印长度：`L = 0.0381 × √(Qc / (q·nw))`（3.0.4-1）
- 轮印宽度：`W = 0.689 L`（3.0.4-2）
- 道床顶面反应模量：`kd = b1 + b2·k0² + b3·hu² + b4·hu·k0 + b5·k0 + b6·hu`（3.0.7）

- **附录 A** —— 3.0.3 条指定的飞机荷载参数表（52 种机型）。
- **第 5 章** —— 3.0.1、3.0.5、3.0.8、3.0.10 的取值直接进入 CDF 计算。
