# 5 试验检验方法

## Core Idea

12 项试验，对应第 4 章每条要求；两项最"硬"的试验：**防坠落制动试验**（切断主绳，落坠 ≤3 m）与**升降试验**（升降各 4 次）。

## Key Clauses

| 条 | 试验 | 关键要求 |
|---|---|---|
| **5.1 外观检查** | 查设计计算书/说明书；铭牌与接地标志；焊接与涂层质量 + 探伤报告；器材合格证、灯具检测报告、材料检验报告、**升降系统安全认证证书**；电缆进出配电箱卡紧；镀层/涂层均匀无漏镀漏涂；**距 1/4 杆长 5 处**测圆度与周长；吊线测直线度；配电箱接线与图相符；维修门灵活严密；钢丝绳与电缆检测报告 |
| **5.2 升降试验** | 升降**各四次**，其中**一次手动**；要求：平稳无卡阻无晃动、卸载装置正确动作、钢丝绳不卡不撞不转、无异常声响、紧固件无松动、无异常发热、**每次升/降中断电源或松手一次灯盘应停住不动**、钢丝绳整齐缠绕且最低点时**至少剩 4 圈** |
| **5.3 防坠落制动装置试验** | **仅对单根主绳的高杆灯做一次**：灯盘提升中**切断主钢丝绳**，制动装置及时动作，**落坠距离 ≤3 m**，**不应有零部件坠落** |
| **5.4 焊缝质量试验** | **按 50% 抽样**，超声波或射线探伤，符合 4.6.3.2、4.6.3.4 |
| **5.5 防腐蚀喷镀质量试验** | 测厚仪**抽测 20 处**镀锌层或涂层厚度 |
| **5.6 垂直度检验** | 竖立完成后用**经纬仪**检验，符合 4.6.4.6（≤0.3%） |
| **5.7 爬电距离和电气间隙测定** | 灯具与配电箱，符合 GB/T 3797、GB/T 7256 |
| **5.8 电气绝缘性能测试** | 按 GB/T 3797 |
| **5.9 灯具性能试验** | 按 GB 7000.1、GB 7000.7 |
| **5.10 外壳防护等级试验** | 按 GB/T 4208，符合 IP54 / IP65 |
| **5.11 通电试验** | 逐一开关每一路灯具；遥控则从遥控点操作；**每一操作重复 5 次**，每次均符合为合格 |
| **5.12 涂层的划格试验** | 按 GB/T 9286，达到**分级表 1 级** |

## 常被问到的数值

| 问题 | 答案 |
|---|---|
| 升降试验次数 | 各 4 次（含 1 次手动） |
| 落坠距离上限 | 3 m |
| 焊缝抽检比例 | 50% |
| 镀层抽测点数 | 20 处 |
| 通电试验重复次数 | 5 次 |
| 划格试验要求 | GB/T 9286 1 级 |
