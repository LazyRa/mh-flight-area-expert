# 3 产品分类和型号

## Core Idea

按**卷筒数量**分三类；型号编码 6 段：`GS{卷筒}-{高度}{照明方式}{功率}{光源}`。

## Key Clauses

- **3.1 产品分类**（按卷扬机构卷筒数量）
  - **单卷筒式**
  - **双卷筒式**
  - **三卷筒式**
- **3.2 产品型号命名**

```
GS 1 - 25 A 7 H
│  │    │  │ │ └─ 光源类型：H 气体放电灯 / L LED 灯
│  │    │  │ └─── 功率（kW）
│  │    │  └───── 照明方式：A 单侧 / B 双侧 / C 圆周
│  │    └──────── 标称高度（m）
│  └───────────── 卷筒数量（1/2/3）
└──────────────── 升降式高杆灯（GS）
```

**示例**：标称高度 25 m、单卷筒、气体放电灯、总功率 7 kW、单侧照明 → **`GS1-25A7H`**

## 使用提示

- 卷筒数量直接决定**主钢丝绳根数**（1 / 2 / 3 根），进而决定**安全系数**（≥8 或 ≥6）与**是否必须设防坠落制动装置**（见 ch04）
