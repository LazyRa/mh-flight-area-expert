# 2 规范性引用文件

## Core Idea

约 45 项引用标准，可归为五类：**钢材与型材**、**焊接材料与质量**、**防腐镀层**、**结构设计规范**、**电气与灯具**。

## Key Clauses

| 类别 | 主要标准 |
|---|---|
| **钢材/型材** | GB/T 700（碳素结构钢）、GB/T 1591（低合金高强度结构钢）、GB/T 3280 / GB/T 4237（不锈钢板带）、GB/T 14846（铝合金挤压型材） |
| **焊接材料** | GB/T 983（不锈钢焊条）、GB/T 5117（非合金钢焊条）、GB/T 5118（热强钢焊条）、GB/T 5293 / GB/T 12470（埋弧焊丝焊剂）、GB/T 8110（气保焊丝）、GB/T 4842（氩）、GB/T 6052（CO₂） |
| **焊接质量** | GB/T 12467.1–.5（熔焊质量要求）、GB 50661（钢结构焊接规范）、GB/T 3323（射线）、GB/T 11345（超声）、GB 50205（钢结构验收） |
| **防腐** | GB/T 13912（热浸镀锌层）、GB/T 9286（漆膜划格试验） |
| **结构设计** | GB 50009（荷载）、GB 50011（抗震）、GB 50017（钢结构）、GB 50135（高耸结构） |
| **电气/灯具** | GB/T 3797（电气控制设备）、GB/T 4208（IP 代码）、GB 7000.1（灯具通用）、GB 7000.7（投光灯具）、GB/T 7256（民用机场灯具一般要求）、GB 50168（电缆线路施工验收） |
| **钢丝绳/传动** | GB 8918（重要用途钢丝绳）、GB/T 9944（不锈钢丝绳）、GB/T 10085–10089（圆柱蜗杆传动） |
| **民航专用** | **MH 5001**（飞行区技术标准）、**MH/T 6108**（机坪泛光照明技术要求） |
