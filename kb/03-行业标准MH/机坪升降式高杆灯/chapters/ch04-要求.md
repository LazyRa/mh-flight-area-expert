# 4 要求

## Core Idea

本章是标准的实体部分：**环境 → 设计 → 制造 → 耐腐蚀 → 器材 → 技术要求**。技术要求又分 9 组：强度刚度、金属材料、焊接、灯杆、灯盘、杆顶装置、升降系统与安全保护、防腐、电器。

## Key Clauses

### 4.1 环境要求
- **4.1.1** 应能在下列环境长期运行：**−40 ℃～+55 ℃**；相对湿度 **≤95%**；盐雾；风雪冰雨；太阳辐射
- **4.1.2** 应能耐受当地可能出现的**大风和地震**
- **4.1.3** 应能耐受**航空器尾气吹袭**
- **4.1.4** 强度和刚度应能耐受**结冰、结露和雪压**

### 4.2–4.5 设计与制造
- **4.2** 设计应充分考虑**安全、可靠、经久耐用、维护方便**
- **4.3** 加工制造应符合已审批的设计图纸与工艺规范
- **4.4** 所有零部件**内外金属表面**均应防腐处理或采用耐腐蚀材料
- **4.5** 金属材料、焊接材料、紧固件、电器、灯具应符合国家标准并**有合格证**

### 4.6 技术要求

**4.6.1 强度和刚度**
- 应承受自重、风力、垂直度误差引起的弯矩，符合 GB 50009 / 50011 / 50017 / 50135
- **安全等级为一级**
- 按**承载能力极限状态**设计；按荷载效应的**基本组合和偶然组合**设计
- 须提供**结构设计计算书**；基本风压按 GB 50009 取值并考虑风荷载体形系数、风压高度变化系数、风振系数、断面形状、灯具与灯盘迎风面积
- 山区、偏僻地区、沿海海面和海岛的基本风压应乘**调整系数**

**4.6.2 金属材料**
- 碳素结构钢 GB/T 700；低合金结构钢 GB/T 1591；不锈钢 GB/T 3280 / 4237；铝合金 GB/T 14846
- **杆体不应采用沸腾钢**
- 应有质量检验报告单；提供**灯杆材料质量证明书**
- 不应有影响机械性能的裂纹、分层、重皮、夹渣；**麻点或划痕深度 ≤厚度负公差的 1/2，且 ≤0.5 mm**

**4.6.3 焊接**
- 焊条：碳素钢 → GB/T 5117；低合金高强钢 → GB/T 5118；不锈钢 → GB/T 983
- 埋弧自动焊：碳素钢 → GB/T 5293；低合金高强钢 → GB/T 12470；气保焊丝 → GB/T 8110，氩 → GB/T 4842，CO₂ → GB/T 6052
- 焊接质量符合 GB/T 12467.1–.5；焊缝外观符合 GB 50661，**均匀、圆滑过渡、无虚焊**，清理焊渣飞溅
- **焊缝及热影响区不应有裂纹、未焊满、未熔合、焊瘤、气孔、弧坑、夹渣**
- **表面咬边深度 ≤0.5 mm，咬边总长 ≤焊缝两侧长度的 10%**
- 多节杆体拼接应在**热浸镀锌前插接后焊接**
- **多边形灯杆插接处内侧应焊缝补强，补强长度 ≥较大杆口直径的 1.5 倍**
- 圆梢杆焊后**铲平磨光**；多边形灯杆插接处内插管外焊缝铲平磨光
- **探伤**：设计全焊透的一、二级焊缝应探伤，按 GB/T 3323 / 11345 / 50205，**表面探伤合格率 >95%**

**4.6.4 灯杆**
- 可为**圆形拔梢杆**或**多边形拔梢杆**
- 圆杆**截面圆度误差 ≤0.3%**，截面周长**不应有负误差**
- 多边形杆**各内角偏差 ±1.5°**，**边长误差 ≤2 mm**
- **直线度**：每 10 m 长轴线测量 **≤0.05%**；**全长 ≤0.1%**
- 壁厚符合设计；多边形杆**插接长度 ≥插接处外接圆直径的 1.5 倍**
- 下部**维修门**尺寸足以接近观察内部机件但不过大，**防风雨可加锁**，周边加强、四角圆弧
- 组装后**垂直度误差 ≤0.3%**

**4.6.5 灯盘**
- 大小与安装高度协调，容纳灯具数量符合用户要求
- 结构有足够机械强度，可拆卸小零件尽可能少，**宜分 2～3 瓣**便于运输与拼装
- 应设**防碰撞装置**，防止升降中夹杆止动；接触部位设**橡胶或塑料滚轮/衬垫**保护涂覆层

**4.6.6 杆顶装置**
- 含**雨帽、滑轮组、灯盘限位装置、导向架**等；应牢固定并设**防移位或旋转的锁定装置**
- 滑轮用耐腐蚀材料，**封闭式免维护轴承**；直径与滑槽匹配电缆/钢丝绳外径与弯曲半径
- 滑轮支架牢固焊接在底板上；**滑轮轴用不锈钢**并以挡圈固定
- 电缆/钢丝绳进出滑轮处设**导向装置**，拉紧或松弛均不脱槽、不缠绞

**4.6.7 升降系统和安全保护装置**
- **应通过特种设备检测中心或专业安全认证机构的认证**
- 钢丝绳符合 GB 8918 / GB/T 9944
- **灯杆竖立后无需放倒或高架平台即可更换/检查钢丝绳和电缆**
- 可用单/双/三卷筒卷扬系统
- **安全系数**：单根主绳 **≥8**；两根或三根主绳时单根 **≥6**
- **防坠落制动装置**：单根主绳**应设**；两根或三根**宜设**
- 应设**电气和机械限位装置**，机械限位应能承受灯盘压力
- 应具备**电动、手动**两种功能；电动**平均升降速度宜 ≤5 m/min**；**可在至少 5 m 以外操作**，按钮采用**不自保持**方式
- 单根主绳宜设**自动卸载装置**（涂红色等明显标识）；多根主绳且有防下滑锁定装置时允许钢丝绳保持负载
- 应保护钢丝绳和电缆不缠绞、不碰撞受损
- 应装**防惯性溜车装置**；应装**过扭矩保护装置**（过载自动打滑）
- 卷扬机件应能通过维修门口拆装，上方设**防尘罩**；减速器箱**整体封闭、无外露齿轮**
- 卷扬机件应**随时自动保持当前状态**（突然断电也不失效），仅人工干预才解除止动
- **钢丝绳卷筒**：钢丝绳整齐排列，不得多圈重叠/挤压边板/挤入下层；设防滑出装置；**放出最多时卷筒上至少剩 4 圈**；可在维修门口查看绳末端
- **蜗轮蜗杆减速器应自动润滑**；油箱有可开盖与放油孔；现场加油时出厂前齿轮涂防锈油脂
- 蜗杆蜗轮精度符合 GB/T 10086 / 10089（蜗杆另需 10085 / 10087 / 10088）

**4.6.8 防腐处理**
- 黑色金属部件**热浸镀锌**，必要时再涂漆或喷塑；铝材表面**钝化**
- **镀锌层平均厚度**：板厚 **<3 mm → ≥55 μm**；**3～6 mm → ≥70 μm**；**≥6 mm → ≥85 μm**
- 锌层均匀、结合牢固；浸锌后**钝化处理**；表面平滑，无滴瘤、粗糙、锌刺、起皮、漏镀、溶剂渣
- **涂漆**：环境 **5～38 ℃**、相对湿度 **≤85%**；雨天或结露不作业；涂后 **4 h 内不受雨淋**
- **底漆 ≥40 μm，涂面漆后总厚 125～175 μm**；漆膜光滑均匀，无漆泡、流挂、褶皱

**4.6.9 电器设备**
- **配电箱**：符合 GB/T 3797，**防护等级 ≥IP54**；装**漏电保护开关**；设维护照明与升降机具插座；接线图**永久固定在箱盖内面**；按规定接地；可见电气触头涂**固体薄膜保护剂**；设照明控制装置
- **接地**：所有裸露金属部件可靠接地并设**接地断接卡**，**接地电阻 <10 Ω**
- **避雷针**：灯杆应设避雷针，利用杆体或专用避雷线作引下线；避雷针宜用**直径 ≥φ25 热镀锌圆钢或热镀锌钢管**；连接用焊接或螺栓；避雷覆盖应确保灯具在保护范围内
- **电缆**：符合国家相关标准，宜用**耐高温、高湿、阻燃**电缆；配电箱至灯盘分线端子箱**分组供电**；杆内电源线/控制线用**有护套多股铜芯软电缆**；**电压损失 ≤额定电压 0.5%**；灯全亮时**电流 ≤电缆额定载流量的 70%**；线缆在保护管或杆内**不应有接头**；防与钢丝绳摩擦；支持点间距与弯曲半径符合 GB 50168
- **灯具**：符合 GB 7000.1 / 7000.7；**灯具与端子箱外壳防护等级 ≥IP65** 并有防腐涂覆层；灯具用**防腐蚀铝合金外壳**，**光学腔与电气箱分置**，配套电器置于单独电器箱；灯具效率、功率因数、色温、显色指数符合 **MH/T 6108**；防触电型式达 **Ⅰ类**；涂层符合 4.6.8.3
- **航空障碍灯**：杆顶应按 **MH 5001** 设置，并具有**有效期内的民航局通告**
- **灯杆固定与基础**：用**法兰盘 + 螺栓**固定在混凝土基础上；制造厂应提供基础材料形式、尺寸、地基承载力要求、基础设计资料及地脚螺栓规格数量分布

## 常被问到的数值

| 问题 | 答案 |
|---|---|
| 工作温度 | −40～+55 ℃，RH ≤95% |
| 安全等级 | 一级 |
| 直线度 | 每 10 m ≤0.05%、全长 ≤0.1% |
| 垂直度误差 | ≤0.3% |
| 钢丝绳安全系数 | 单根 ≥8；多根 ≥6 |
| 升降速度 | ≤5 m/min，操作距离 ≥5 m |
| 镀锌层厚度 | <3 mm ≥55 μm；3–6 mm ≥70 μm；≥6 mm ≥85 μm |
| 涂漆总厚 | 125～175 μm（底漆 ≥40 μm） |
| 配电箱 / 灯具防护等级 | IP54 / IP65 |
| 接地电阻 | <10 Ω |
| 电缆压降 / 载流量 | ≤0.5% 额定 / ≤70% 额定 |
| 卷筒最少剩绳 | 4 圈 |
