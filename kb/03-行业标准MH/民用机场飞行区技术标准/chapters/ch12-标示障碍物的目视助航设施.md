# 第12章 标示障碍物的目视助航设施

## Core Idea
位于障碍物限制面内（及特定情形下限制面外）的物体，须用标志和/或障碍灯标示，以保障航空安全。**第五修订案修改了 12.1.1 和 12.1.2**，新增了起飞爬升面/过渡面相关标示规则以及内水平面（现称"水平面"）障碍物评估面的标示要求。

## Key Clauses

### 12.1 应予标示的物体
- **12.1.1 位于障碍物限制面内物体的标志和灯光标示**（第五修订案修改）：
  - **12.1.1-4【第五修订案新增】** 距离起飞爬升面内边 3000m 以内、突出于该面之上的固定障碍物应设标志；若跑道供夜间使用还应设灯光标示。豁免条件：被另一固定障碍物遮蔽、超出周围地面高度≤150m 且设 A 型中光强障碍灯可略标志、设昼间运行高光强障碍灯可略标志、为灯塔且灯光足够可略障碍灯。
  - **12.1.1-6【第五修订案新增】** 突出于距离进近面内边 3000m 以内或突出于过渡面之上的固定障碍物应设标志及灯光标示（同 12.1.1-4 豁免条件）。
  - **12.1.1-7【第五修订案新增】** 突出于内水平面障碍物评估面（现称"水平面"）之上的固定障碍物，经航空研究认为可能对飞机构成危害时应设标志及灯光标示。豁免条件：被遮蔽、环状区域已有程序确保安全垂直净距、经研究无关重要、超地面≤150m 设 A 型中光强障碍灯可略标志、设高光强障碍灯可略标志、灯塔灯光足够可略障碍灯。
  - **12.1.1-9** 其他位于障碍物限制面以内的物体（包括目视航路附近的物体），如果航空研究认为其对航空器构成危害，则应设标志和灯光标示。
  - **12.1.1-10** 横跨河流、水道、山谷或公路的架空电线或电缆等，若经航空研究认为可能对航空器构成危害，则应设标志，并对其支撑杆塔设标志和灯光标示。
- **12.1.2 位于障碍物限制面外物体的标志和灯光标示**（第五修订案修改）：
  - **12.1.2-2** 对于其他位于障碍物限制面以外的物体（包括目视航路附近的物体），如果航空研究认为其对航空器构成危害，则应设标志和灯光标示。
  - **12.1.2-3** 横跨河流、水道、山谷或公路的架空电线或电缆等，若经航空研究认为这些电线或电缆可能对航空器构成危害，则应设标志；并对其支撑杆塔设标志和灯光标示，若杆塔设有昼间运行的高光强障碍灯，可略去标志。

### 12.2 物体的标志和（或）灯光标示
- **12.2.1 一般要求**：标志与灯光设置规则（详见附录 J 间距、图样）。
- **12.2.2 可移动物体**：如施工机械等，按运行需要标示。
- **12.2.3 固定物体**：应涂反差鲜明相间色带（按物体边长分级，如 1/7–1/21，见 12.2.3 第 3 款及表）；设置障碍灯（中光强/高光强，闪光频率 20–60 fpm 等）。
- **12.2.4 风力发电机**：边界识别、同步闪光。
- **12.2.5 架空电线、电缆及支撑塔架**：标志与灯光标示。

## Reference — 固定物体色带与障碍灯（节选）
- 色带宽度按物体最长边分级（例：≤210m → 1/7；210–270 → 1/9；…570–630 → 1/21，详见 12.2.3）。
- 障碍灯类型按物体高度与背景选（低光强/中光强 A/B/高光强 A/B/C），闪光频率与光强见 12.2.3 相关表（20–60 fpm、40–200 cd 等）。

> 具体灯光光强、颜色、间距与图样见**附录 J**；物体高度分界见 12.2.3 各表。
