# 第5章 障碍物的限制和移除

## Core Idea
【第五修订案整体重写】原第5章"障碍物限制面"（8面模型）整体删除，本章为新框架：**障碍物限制面 = 无障碍物面（OFS）+ 障碍物评估面（OES）**。OFS 严格禁止穿透，OES 允许经航空研究后有限超出。新增**飞机设计组别（ADG）**作为参数选取依据，取代原按跑道指标分级的模式。同时引入**A/B/C 区域分级管控**制度（5.12），以及 OES 参数调整 / SOES / OES→OFS 转化机制。MH/T5062-2022《民用机场净空障碍物遮蔽原则应用指南》同步废止。

## Key Clauses

### 5.1 一般规定
- **5.1.1** 障碍物限制面由 OFS（无障碍物面）和 OES（障碍物评估面）组成。
- **5.1.2** 按跑道运行类别、飞机设计组别（ADG）和飞行程序及运行最低标准设立，以最严格的要求进行限制或管控。
- **5.1.3 OFS 设立要求**：
  - 非仪表/非精密进近跑道 → 进近面、过渡面、内进近面、内过渡面
  - 精密进近跑道 → 上述 + 复飞面
  - 供起飞的跑道 → 起飞爬升面
- **5.1.4 OES 设立规定**：
  - 盘旋进近或目视航线 → 水平面
  - 直线仪表进近（除精密外）且未设立全部水平面 → 直线仪表进近面
  - 精密进近 → 精密进近面
  - 仪表离场 → 仪表离场面
- **5.1.5 参数调整/SOES**：存在特定情形（目视盘旋最低下降高过高、直线仪表进近最低下降高>150m、离场梯度>3.3%等）时，可调整 OES 参数或设立 SOES（特定的障碍物评估面），需报民航行政机关批准。
- **5.1.6 OES→OFS 转化**：可将一种或几种 OES 或其一部分转化为 OFS（适用于新物体对运行最低标准/容量产生不利影响的场景），转化后按 5.12.2/5.12.3 执行。
- **5.1.7** 论证宜在机场总体规划阶段开展。

### 5.2 进近面（OFS）
- **5.2.1** 保护最后进近至着陆接地阶段的飞机，标准下滑角 3.0°（下降梯度 5.24%）。
- **5.2.3** 进近面为跑道入口前的倾斜平面，界限包括内边（规定距离、长度、标高）、两条侧边（规定散开率）、外边。
- **5.2.4** 横向偏移/角度偏移/曲线进近的进近面侧边调整规则。
- **5.2.6** 仪表跑道进近面坡度 = 下滑角对应坡度 - 1.91%；非仪表跑道按表 5.2.7-1。
- **5.2.7 进近面参数表**（按 ADG 分类）：
  - 非仪表跑道（表 5.2.7-1）：长度 1600–2500m，坡度 3.33%–5%
  - 仪表跑道（表 5.2.7-2）：长度 4500m，坡度 3.33%

### 5.3 过渡面（OFS）
- **5.3.1** 保护飞越跑道或复飞的飞机，在进近面之外的无固定障碍物面。
- **5.3.2** 复合面（底边+顶边），顶边位于最高跑道入口标高以上 60m。
- **5.3.5 过渡面参数**：坡度 20%（所有 ADG 一致）。

### 5.4 内进近面（OFS）
- **5.4.1** 保护中断着陆或过晚复飞时下降阶段飞机，进近面的子集。
- **5.4.2** 内进近面 = 进近面中紧靠跑道入口前的长方形部分，坡度与进近面相同。
- **5.4.4 内进近面参数表**：
  - 非仪表跑道（表 5.4.4-1）：长度 900–1350m，坡度 3.33%–5%
  - 非精密进近（表 5.4.4-2）：长度 1350m，坡度 3.33%
  - 精密进近（表 5.4.4-3）：长度 1350m，坡度 3.33%
  - ADG Ⅳ/Ⅴ 在 F 指标且无数字化航空电子设备时内边长度增至 140m
- **5.4.5** 坡度减小时增加长度以保障 45m 保护高度。

### 5.5 内过渡面（OFS）
- **5.5.1** 保护中断着陆或过晚复飞时爬升阶段飞机。
- **5.5.2** 非仪表/非精密进近：垂直段 + 倾斜段复合面。
- **5.5.3** 精密进近：类似过渡面但更靠近跑道。
- **5.5.7 内过渡面参数表**：
  - 非仪表跑道（表 5.5.7-1）：垂直段高度 5–10m，倾斜段坡度 33.3%–40%
  - 非精密进近（表 5.5.7-2）：垂直段高度 5–6m
  - 精密进近（表 5.5.7-3）：坡度 33.3%–40%

### 5.6 复飞面（OFS，仅精密进近跑道）
- **5.6.1** 保护精密进近跑道中断着陆或过晚复飞时爬升阶段飞机。
- **5.6.4 复飞面参数**：距跑道入口 1800m，内边长度 90–120m，坡度 3.33%–5%。

### 5.7 起飞爬升面（OFS）
- **5.7.1** 防止障碍物对起飞飞机造成运行限制。
- **5.7.2** 多个起飞航迹应分别设立，可综合融合为一个面。
- **5.7.3** 起飞爬升面为可用起飞距离末端以外的倾斜平面。
- **5.7.6–5.7.7 起飞爬升面参数表**：
  - ≤5700kg 飞机（表 5.7.7-1）：仅 ADG Ⅰ/ⅡA、ⅡB，长度 1600–2500m
  - >5700kg 飞机（表 5.7.7-2）：所有 ADG，长度 10000m，坡度 2%–5%
  - 可结合机场标高/机型/净空环境将坡度降低到 1.6%。

### 5.8 水平面（OES）
- **5.8.1** 保护目视机动（盘旋），也可为目视起落航线和仪表飞行程序提供保护。
- **5.8.2** 以跑道两端入口中点为圆心的近似椭圆形水平面组合。
- **5.8.3 水平面参数表**：
  - ADG Ⅰ/ⅡA：半径 3350m，高度 45m
  - ADG ⅡB：半径 5350m，高度 60m
  - ADG ⅡC–Ⅴ：半径 10750m，高度 90m
- **5.8.4** 无目视盘旋且无目视起落航线时可不设立；单侧不允许时可适当缩小范围。

### 5.9 直线仪表进近面（OES）
- **5.9.1** 在水平面尚未设立时，防止物体对直线仪表进近的影响。
- **5.9.2** 下部（ADG Ⅰ 水平面）+ 上部（长方形，短边 7410m，跑道入口至短边 5350m）。
- **5.9.4 参数表**：下部高度 45m，上部高度 60m。

### 5.10 精密进近面（OES）
- **5.10.1** 保护常规直线精密进近（ILS/MLS/GBAS/ SBAS，CAT Ⅰ）。
- **5.10.2** 由四部分组成：进近部分（两段）、复飞部分（两段）、过渡部分、底部。
- **5.10.8 参数表**：
  - 进近部分：距入口 60m，内边 300m，第1段 3000m（散开率 15%，坡度 2%），第2段 9600m（散开率 15%，坡度 2.5%）
  - 复飞部分：距入口 900m，内边 300m，第1段 1800m（散开率 17.48%，坡度 2.5%），第2段 10200m（散开率 25%，坡度 2.5%）
  - 过渡部分坡度 14.30%

### 5.11 仪表离场面（OES）
- **5.11.1** 防止物体对仪表离场程序的影响。
- **5.11.2** 位于可用起飞距离末端后的倾斜平面。
- **5.11.3** 内边标高 = 跑道末端与净空道末端（如有）中点标高 + 5m。
- **5.11.5 参数表**：内边长度 300m，坡度 2.5%，第1段 3500m（散开率 26.8%），第2段 8300m（散开率 57.8%）。

### 5.12 障碍物限制要求
- **5.12.1** OFS 严格管控：除易折目视助航设备和安全运行必需物体外，所有固定物体不允许高出内进近面、内过渡面、复飞面及其复合面。
- **5.12.2** 高出进近面/起飞爬升面/过渡面的现有物体应尽可能移除，除非航空研究确认不影响飞行安全和正常运行。
- **5.12.3** 新物体或现有物体的扩展不允许高出进近面/起飞爬升面/过渡面。
- **5.12.4 经航空研究可允许高出 OES**，但在以下近似椭圆范围内有额外限制：
  - **A 区域**（跑道两端各 2000m 内、中线两侧各 1000m 内，且起飞爬升面/进近面、过渡面投影范围外）：不超过机场标高以上 75m。
  - **B 区域**（跑道中线两侧 1000–2000m，原地面高程分界 105m）：
    - 原地面 ≤105m → 不超过机场标高 +120m 或原地面 +15m（取大）
    - 原地面 >105m → 不超过原地面 +15m
  - **C 区域**（跑道中线两侧 2000m 外，原地面高程分界 120m）：
    - 原地面 ≤120m → 不超过机场标高 +150m 或原地面 +30m（取大）
    - 原地面 >120m → 不超过原地面 +30m
  - 实际最大高度取上述限制、飞行程序及运行最低标准、最低监视引导高度、无线电台场地保护等限制中的最低值。

### 5.13 障碍物限制面以外的物体
- **5.13.1** 经航空研究可能对运行构成危害的物体应视为障碍物并设标志及灯光标示。最大范围 ≤ 机场基准点半径 55km。
- 运输机场可根据净空参考高度判断；通用机场可按原地面之上 100m 判断。

### 5.14 其他物体
- **5.14.1** 未高出进近面但影响目视/非目视助航设备或无线电台使用的物体，应移除。
- **5.14.2** 位于限制面之下或之外、可能对空中航行造成影响的物体（风力发电机、烟囱、输电线路、发电站、光伏设施等），应进行航空研究；有危害的视为障碍物并尽可能移除。
