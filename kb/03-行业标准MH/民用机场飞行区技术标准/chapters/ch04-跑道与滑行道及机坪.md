# 第4章 跑道、滑行道、机坪及附属设施

## Core Idea
飞行区物理构形的核心章节（4.1–4.20）。所有几何尺寸、间距、坡度均按飞行区指标查表确定；关键安全设施（跑道端安全区、等待位置、升降带）有强制性设置条件。[修订] **4.12.2 跑道等待位置设置已由第四修订案修改**。

## Key Clauses（按小节）
- **4.1 跑道**
  - 4.1.1 方位与条数符合运行要求；4.1.2 入口宜在端头（内移须满足坡度）；4.1.3 长度满足性能；4.1.4 宽度 **≥ 表 4.1.4**（按指标Ⅱ）；4.1.5 平行跑道最小间距（按仪表/非仪表、运行方式）；4.1.6 设计坡度限制；4.1.7 强度承受拟用飞机；4.1.8 表面摩阻/平整；4.1.9 受公路/铁路/地形限制时的处理。
- **4.2 跑道道肩**：指标Ⅱ C/F 跑道应设道肩，相接处齐平，横坡 ≤2.5%。
- **4.3 跑道掉头坪**：宜设在跑道两端/较长跑道中间，强度宜同相邻跑道。
- **4.4 升降带**：包络跑道及相接停止道（4.4.1）；入口前向外延伸至少规定距离（4.4.2）；宽度 **≥ 表 4.4.3**（精密/非精密不同）（4.4.3）；带内物体限制（4.4.4）、平整（4.4.5）、坡度（4.4.6）、土面强度（4.4.7）。
- **4.5 跑道端安全区 RESA**：指标Ⅰ 3/4 或指标Ⅰ 1/2 的仪表跑道**应设**（4.5.1）；宽度 ≥ 相邻跑道 2 倍（4.5.3）；设拦阻系统且性能≥RESA 保护时可调整（4.5.4）。
- **4.6 净空道** / **4.7 停止道**（宽度同跑道、强度承载中断起飞）。
- **4.8 无线电高度表操作场地**：精密进近跑道入口前宜设，长 ≥300m。
- **4.9 滑行道**：宽度（4.9.2）、弯道半径（4.9.3）、与跑道/物体净距 **见表 4.9.5**（4.9.5）、纵横向坡度 **见表 4.9.6**（4.9.6）、视距（4.9.7）、强度 ≥ 跑道（4.9.8）、快速出口布置（4.9.10）、穿越跑道要求（4.9.11）、滑行道桥（4.9.12）、绕行滑行道（4.9.13）。
- **4.10 滑行道道肩** / **4.11 滑行带**（指标Ⅱ C/F 滑行道设道肩；滑行带内不应有危害飞机物体）。
- **4.12 等待位置**【见 Amendment Notes】。
- **4.13 机坪**：布局（4.13.1）、强度承受机型荷载（4.13.2）、机位区坡度 ≤1.0%（4.13.3）、飞机净距 **见表 4.13.5**（4.13.5）、系留/防撞（4.13.8–4.13.9）。
- **4.14 除冰设施** / **4.15 隔离航空器停放位置** / **4.16 防吹坪** / **4.17 服务车道**（单车道宽：小型车 ≥3.5m、大型车见 4.17.3；净高见表 4.17.4；停车视距见表 4.17.7；纵坡 ≤4.0%）/ **4.18 防吹篱** / **4.19 应急通道** / **4.20 机动区设备设施**（精密进近跑道特定范围内不应有特定物体）。
