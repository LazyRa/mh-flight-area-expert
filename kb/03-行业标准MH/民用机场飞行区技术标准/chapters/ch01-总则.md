# 第1章 总则

## Core Idea
本标准规定民用机场飞行区规划、设计、建设和运行的强制性技术要求；飞行区按"指标Ⅰ / 指标Ⅱ"两级划分。**第五修订案新增飞机设计组别（ADG）**作为障碍物限制面的参数选取依据。所有条款均须以现行修订案（已并入本 skill）为准。

## Key Clauses
- **1.0.1 目的**：规范民用机场飞行区的规划、设计、建设和运行，做到安全适用、技术先进、经济合理。
- **1.0.2 适用范围**：适用于陆地民用机场；在适当情况下也适用于直升机场。不适用于水上机场。
- **1.0.3 分级原则**：机场飞行区应根据拟使用该飞行区的飞机的特性，按**指标Ⅰ**（依据飞机基准飞行场地长度及翼展/主起落架外轮外边距，分 1–4）和**指标Ⅱ**（依据飞机翼展及主起落架外轮外边距，分 A–F）进行分级。
- **1.0.4 【第五修订案新增】**：飞机设计组别（ADG）分类（表 1.0.4）。一种使机场周围障碍物管理相关规范相互关联的分类方法，由飞机在跑道入口处的指示空速和翼展尺寸两个指标确定。
- **1.0.5 【原 1.0.4 顺延，第二修订案新增】**：机场应设置地面活动引导及控制系统（**SMGCS**）。
- **1.0.6 【原 1.0.5 顺延，原 1.0.4】**：机场飞行区规划、设计、建设和运行除应符合本标准外，尚应符合国家和行业现行有关标准的规定。

## ADG 飞机设计组别分类（表 1.0.4）
| ADG | 跑道入口指示空速 V_at（km/h）/（kt） | 翼展（m） |
|---|---|---|
| Ⅰ | ＜169 / 91 | ＜24 |
| ⅡA | ＜169 / 91 | 24 ~ 36（不含） |
| ⅡB | 169 ~ 224（不含）/ 91 ~ 121（不含） | ＜36 |
| ⅡC | 224 ~ 307（不含）/ 121 ~ 166（不含） | ＜36 |
| Ⅲ | ＜307 / 166 | 36 ~ 52（不含） |
| Ⅳ | ＜307 / 166 | 52 ~ 65（不含） |
| Ⅴ | ＜307 / 166 | 65 ~ 80 |

> V_at = V_s0 × 1.3，或以最大审定着陆质量在着陆形态下的失速速度 V_s1g × 1.23。如 V_s0 和 V_s1g 均可用，取较高的 V_at 值。
> 每条跑道的 ADG 根据跑道预期服务的关键飞机特性确定。典型机型对应表见**附录 A.2**。

## Key Concepts
- **飞行区指标Ⅰ（1–4）**：由飞机基准飞行场地长度及对应的翼展/主起落架外轮外边距决定。
- **飞行区指标Ⅱ（A–F）**：由飞机翼展及主起落架外轮外边距决定，F 为最大（如 A380 类）。
- **ADG（飞机设计组别）**：7 级分类（Ⅰ/ⅡA/ⅡB/ⅡC/Ⅲ/Ⅳ/Ⅴ），用于障碍物限制面参数选取（见 ch05）。
- **SMGCS**：Surface Movement Guidance And Control Systems，地面活动引导及控制系统（第二修订案新增，见 2.1.83→2.1.87、2.3）。
