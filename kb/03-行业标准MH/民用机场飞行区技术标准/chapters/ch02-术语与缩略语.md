# 第2章 术语、符号和缩略语

## Core Idea
统一飞行区标准的核心名词。本章术语（2.1.1–2.1.87）是后续所有章节的前提；其中 **PCN/ACN 已被第一修订案替换为 PCR/ACR**，SMGCS 由第二修订案新增，**OFS/OES/SOES 由第五修订案新增**。

## Key Clauses
- **2.1 术语**：2.1.1–2.1.87，共 87 条。关键术语见下。
- **2.2 符号**：几何与力学符号（含修订案新增的 **E**＝弹性模量）。
- **2.3 缩略语**：英文缩写对照表（第二修订案新增 **SMGCS**；第五修订案新增 **ADG / OFS / OES / SOES**）。

## Key Terms（高频 / 易错）
- **机场 aerodrome**（2.1.1）：供飞机起飞、降落、滑行、停放的场地及建筑物。
- **飞行区 airfield area**（2.1.6）：机场内供飞机起飞、着陆、滑行活动的部分。
- **跑道 runway**（2.1.7）／**滑行道 taxiway**（2.1.31）／**机坪 apron**（2.1.34）。
- **跑道等待位置 runway-holding position**（2.1.37）／**中间等待位置**（2.1.38）／**道路等待位置**（2.1.39）。
- **障碍物 obstacle**（2.1.43）。
- **2.1.44 无障碍物区 OFZ（第五修订案修改定义）**：内进近面、内过渡面和复飞面，以及与这些面邻接并被围合的升降带以上的空间，在此空间内除了助航所需的轻质易折的装置和为航空器安全运行所必需的物体外，不允许任何固定的障碍物物体穿透，在跑道用于飞机着陆期间，不应有移动物体高出这些限制面。新增"或净空参考高度"表述。
- [新增] **2.1.45 无障碍物面 OFS（第五修订案新增）**：为保护飞机在进近、复飞及起飞过程中的运行，确保机场的可达性和运行安全，规定的一组无障碍物的空间限制面。通常由进近面、过渡面、内进近面、内过渡面及起飞爬升面组成，精密进近跑道还包含复飞面。
- [新增] **2.1.46 障碍物评估面 OES（第五修订案新增）**：为评估障碍物对机场现有及预期飞机运行的影响，判断障碍物的可接受性，规定的一组可灵活管理障碍物的空间限制面。通常由水平面、仪表离场面、直线仪表进近面、精密进近面组成。
- [新增] **2.1.47 特定的障碍物评估面 SOES（第五修订案新增）**：结合机场飞行程序运行实际，构型、尺寸及坡度等参数需要特殊设定的空间限制面。属于 OES 的特殊形式。
- **易折物体 frangible object**（原 2.1.71 → 现 2.1.75）：位移或变形不致造成飞机严重损坏、且抗力弱的物体。
- [修订] **道面分类等级（PCR）pavement classification rating（2.1.40）【第一修订案改】**：表示道面可供不受次数限制适用的承载强度的编号。原"道面等级号（PCN）"已失效。
- [修订] **航空器分类等级（ACR）aircraft classification rating（2.1.41）【第一修订案改】**：表示航空器对规定标准基础道基等级道面的相对影响的数字编号。原"航空器等级号（ACN）"已失效。
- [新增] **地面活动引导及控制系统 SMGCS（原 2.1.83 → 现 2.1.87）【第二修订案新增】**：由目视/非目视助航设备、程序、管制、规则、管理和信息设施等组成的组合体。
- **跑道视程 RVR**（2.1.9）／**跑道侵入自主警告系统 ARIWS**（原 2.1.58 → 现 2.1.62）／**外来物 FOD**（原 2.1.70 → 现 2.1.74）。

## Symbol Notes
- **PCR / ACR**：道面与航空器的分类等级（第一修订案起）。
- **E**：道基弹性模量（MPa），用于 ACR-PCR 道基强度分级（见 ch03 表 3.6.3）。
- 旧符号 **ACN / PCN** 在主文及本标准中**全部失效**，如见到旧资料引用应按 PCR/ACR 重新评价。

## Abbreviations Notes
- **ADG**（Aeroplanes Design Group）：飞机设计组别（第五修订案新增）
- **OFS**（Obstacle Free Surfaces）：无障碍物面（第五修订案新增）
- **OES**（Obstacle Evaluation Surfaces）：障碍物评估面（第五修订案新增）
- **SOES**（Specific Obstacle Evaluation Surfaces）：特定的障碍物评估面（第五修订案新增）
- **SMGCS**：Surface Movement Guidance And Control Systems（第二修订案新增）
