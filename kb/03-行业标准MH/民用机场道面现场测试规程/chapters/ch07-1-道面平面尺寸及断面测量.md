# 7.2 道面平面尺寸及断面测量方法

## Core Idea

用全站仪/光电测距仪/GPS/水准仪测**跑道长度、跑滑宽度、纵横断面高程、排水坡度**。方法的核心不是仪器，而是**平行双测 + 相对误差 1/60 000 的门槛**：长度与宽度必须往返测两次，超限重测，以平均值通报。断面高程则规定了**测点密度**（跑道断面 ≥7 点、滑行道 ≥5 点、机坪方格网 ≤20 m）。

## Key Clauses

### 7.2.1 适用范围
- **7.2.1.1** 适用于道面**长度与宽度**、**纵横断面高程**、**跑道和滑行道中心线平面位置**、**道面上助航灯具位置**等几何尺寸的现场测量。
- **7.2.1.2** 可用于工程建设阶段的**施工过程控制**和**竣工工程质量评价**、道面改造工程的**前期勘察**，也可用于运营管理阶段**道面沉降**等技术状况评定。

### 7.2.2 仪器与材料技术要求
- **7.2.2.1** 应配备**全站仪、光电测距仪、经纬仪、GPS、水准仪、钢尺、条码尺、花杆、钢卷尺**。
- **7.2.2.2** 应配备**无线电通讯设备**、粉笔或油漆等简易现场标识材料；**夜间测量应配备照明设备**。

### 7.2.3 方法与步骤

**7.2.3.1 跑道长度测量**
- a) 根据施工/竣工平面图确定跑道起终点位置并**现场放样**；
- b) **卫星定位法**：接收机准确置于起终点，**单点定位时间宜不少于 20 min**，由平面坐标计算长度；**平行进行两次**，取平均值；两次测距**相对误差绝对值 >1/60 000 应重测**；
- c) **全站仪/光电测距仪 + 经纬仪法**：
  1) 沿跑道中心线布设距离测量辅助点，**平均间距宜 ≤300 m**；
  2) 极坐标法结合直线定线，将辅助点布设于一条直线上并现场标识；
  3) 相邻辅助点距离的**仪器测量误差绝对值 ≤3 mm**，**测距精度 1 mm**；
  4) **往返平行测量至少 1 次**，取平均值；两次测距**相对误差绝对值 >1/60 000 应重测**；
- d) 跑道长度测量**不宜采用钢尺测距法**。

**7.2.3.2 跑道、滑行道宽度测量**
- a) 确定边线及中线位置，沿中线按**间距 ≤100 m** 布设宽度测点并编号标识；
- b) 沿中线标记点架设仪器，采用**正倒镜分中法和多测回修正法**确定角度后测距，取两次平均值；**宽度值 = 中线至两侧边线水平距离之和**；
- c) 亦可在边线标志点架设全站仪/测距仪，直接测定到同断面另一边线标志点的水平距离；
- d) 断面两标志点间距离的**仪器测量误差绝对值 ≤3 mm**，**测距精度 1 mm**；
- e) 宽度测量**不宜采用钢尺测距法**；
- f) 计算各断面实测宽度与设计宽度**差值**（负值＝小于设计，正值＝大于设计），以各断面**实测结果的平均值**作为**通报结果**。

**7.2.3.3 道面高程和排水坡度测量**
- a) 水泥混凝土道面高程测点宜选在**没有错台的板角位置**；沥青道面按需平面放样；所有测点现场简易标识；
- b) 断面**沿纵向等间距**布设，**相邻断面间距宜 ≤50 m**；同一横断面测点须位于**与中心线垂直的直线**上，**直线性 ≤10 mm**；
- c) 同一断面测点数量：**跑道 ≥7 个**（参照图 1）、**滑行道 ≥5 个**（参照图 2）；
- d) 停机坪按**等间距方格网**布设，**相邻测点间距宜 ≤20 m**；
- e) 计算排水坡度时用钢尺**沿排水方向水平**量取相邻测点距离，单位 m，**精确到 0.01 m**，钢尺应保持水平；
- f) 水准测量**精度等级可参照四等**，单位 m，**精确到 0.001 m**；
- g) 计算各断面排水坡度时，**分别计算道面和道肩**的排水横坡坡度，以各断面**实测坡度的平均值**作为通报结果。

### 7.2.4 报告
- **7.2.4.1** 平面尺寸报告：测量方法；宽度测量时附图表示**断面布设位置及断面编号**；各断面实测宽度与设计宽度差值；长度/宽度通报结果；测量单位、人员、时间、天气。
- **7.2.4.2** 高程与坡度报告：附图表示**测点布设位置及编号**；附图表示**测量控制网位置及各高程控制点高程**；各高程测量结果（宜含实测与设计的差值）；排水坡度通报结果；测量单位、人员、时间、天气。

## 关键指标

**表 7.2.3 平面尺寸与高程测量精度要求**

| 项目 | 限值 |
|---|---|
| 长度/宽度测距**相对误差**（两次之差） | **≤1/60 000**（绝对值），超限重测 |
| 相邻辅助点/断面标志点距离**测量误差** | **≤3 mm**（绝对值） |
| 测距精度 | **1 mm** |
| 卫星定位**单点定位时间** | **≥20 min** |
| 长度辅助点平均间距 | **宜 ≤300 m** |
| 宽度测点间距 | **≤100 m** |
| 断面纵向间距 | **宜 ≤50 m** |
| 断面测点直线性偏差 | **≤10 mm** |
| 跑道断面测点数 | **宜 ≥7 个** |
| 滑行道断面测点数 | **宜 ≥5 个** |
| 机坪方格网测点间距 | **宜 ≤20 m** |
| 排水坡度距离量测 | 精确到 **0.01 m** |
| 水准测量精度等级 | 可参照**四等**，精确到 **0.001 m** |

## 交叉引用

- **MH 5001-2021** —— 跑道长度、跑滑宽度、纵横向坡度、道肩宽度的**设计标准值**；7.2 的实测结果用于与 MH 5001 及设计文件比对。
- **MH 5006-2026** —— 水泥混凝土面层**高程、横坡**的竣工允许偏差；7.2.3.3 的"四等水准 + 0.001 m"是其验收测量的精度底线。
- **MH/T 5011-2019** —— 沥青道面**横坡、高程**施工控制；7.2.3.3 g) 要求道面与道肩分别计算坡度，与 5011 的排水要求一致。
- **MH/T 5025** —— 永久测量控制网设置依据（7.1.3）。
- **MH/T 5086-2025** —— 运营管理阶段用本方法评定**道面沉降**，属技术状况评定的几何类指标。
