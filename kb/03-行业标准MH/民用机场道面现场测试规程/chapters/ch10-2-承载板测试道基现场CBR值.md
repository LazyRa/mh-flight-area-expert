# 10.3 承载板测试道基现场 CBR 值试验方法

## Core Idea

用**直径 50 mm 贯入杆**以 **1 mm/min** 压入道基，记录 11 个规定贯入量对应的压强，绘 **压强-贯入量曲线**，用 **2.5 mm 或 5.0 mm** 贯入量处的压强除以**标准压强（7 MPa / 10.5 MPa）**得 CBR。适用于道基、粒料基层和底基层。

## Key Clauses

### 10.3.1 适用范围
- **10.3.1** 适用于现场测定**各种道基的 CBR 值**，也适合于**粒料类基层和底基层**的 CBR 值测定。

### 10.3.2 仪器与材料技术要求
- **10.3.2.1** 荷载装置：装载铁块或集料等重物的**载重汽车，后轴重不小于 60 kN**，大梁后轴应**加装横梁作为反力架**；也可采用**堆载平台反力装置**。
- **10.3.2.2** 现场测试装置（图 9）由**千斤顶（机械或液压）、测力计（测力环或压力表）及球座**组成。千斤顶可使**贯入杆的贯入速度调节成 1 mm/min**。**测力计容量宜不小于道基强度**，**测试精度宜不小于测力计量程的 1%**。
- **10.3.2.3** **贯入杆为直径 50 mm、长约 200 mm 的金属圆柱体**。
- **10.3.2.4** **承载板每块 1.25 kg，直径 150 mm，中心孔直径 52 mm**；**不少于 4 块**，并**沿直径分成 2 个半圆块**。
- **10.3.2.5** 贯入量测定装置由平台及百分表组成：**百分表量程 20 mm，精度 0.01 mm，数量 2 个**，对称固定于贯入杆上，端部与平台接触；**平台跨度宜不小于 0.5 m**；也可由**两台贝克曼梁弯沉仪**代替。
- **10.3.2.6** 采用**洁净干燥的细干砂，粒径 0.3 mm～0.6 mm**。
- **10.3.2.7** 其它：铁铲、盘、直尺、毛刷、天平等。

### 10.3.3 方法与步骤
- **10.3.3.1 准备**
  - a) 将试验地点约**直径 300 mm** 范围内的表面找平，用毛刷刷净浮土；如表面为**粗粒土**，撒布少许洁净细砂填平，**但不能覆盖全部道基表面**，以避免形成**夹层**；
  - a)〔原文重号〕按图 9 安装测试设备，设置贯入杆及千斤顶，千斤顶顶在**汽车后轴横梁**上并调节至适中高度，**贯入杆应与道基表面紧密接触**；
  - b) 按图 9 安装贯入量测定装置（支架平台、百分表等）。
- **10.3.3.2 测试**
  - a) 在贯入杆位置安放 **4 块 1.25 kg** 的分开成半圆的承载板，**共 5 kg**；
  - b) 贯入前先施加 **45 N 荷载**，将**测力计及贯入量百分表调零**，记录初始读数；
  - c) 启动千斤顶，使贯入杆以 **1 mm/min** 压入，在贯入量为 **0.5、1.0、1.5、2.0、2.5、3.0、4.0、5.0、6.5、10.0、12.5 mm** 时分别读取测力计读数；根据情况也可在**贯入量达 7.5 mm 时结束试验**；
  - d) 连续加载，**两个贯入量百分表及测力计均应在同一时刻读数**；当两个百分表读数**差值绝对值不超过平均值的 30%** 时以其平均值为贯入量，**否则应停止试验并重新加载**；
  - e) 卸除荷载，移去测定装置；
  - f) 在试验点取土样测**含水率**：最大粒径 **≤5 mm 取约 120 g**；**≤25 mm 取约 250 g**；**≤40 mm 取约 500 g**；
  - g) 在试验点附近取样，用**灌砂法或环刀法**测**密度**。

### 10.3.4 计算和分析
- **10.3.4.1** 用**贯入试验得到的等级荷重数除以贯入断面面积（1 962.5 mm²）**得各级压强（MPa），绘制**荷载压强-贯入量曲线**（图 10）。当曲线**起点处有明显凹凸**时，应在**曲线的拐弯处作切线延长**修正，**以与坐标轴相交的点 O′ 作原点**，得修正后的曲线。
- **10.3.4.2** 从曲线上读取贯入量 **2.5 mm 及 5.0 mm** 时的荷载压强，按**公式(11)** 计算现场 CBR：

```
CBR = (pt / p0) × 100        ……………… (11)
```

  - **pt** —— 荷载压强，单位 MPa；
  - **p0** —— **标准压强**，单位 MPa。
  - 注：**贯入量为 2.5 mm 时 p0 取 7 MPa；贯入量为 5.0 mm 时 p0 取 10.5 MPa**。
- **10.3.4.2（判定规则）** CBR **一般以贯入量 2.5 mm 时的测定值为准**；当**贯入量 5.0 mm 时的 CBR 大于 2.5 mm 时的 CBR** 时，应**重新试验**；若重新试验**仍然如此**，则**以贯入量 5.0 mm 时的 CBR 为准**。

### 10.3.5 记录格式
- **10.3.5** 采用**表 6**（现场 CBR 值测定记录表），含：预定贯入量、贯入量百分表读数（1、2、平均）、测力计百分表读数、压强、CBR 计算、含水率（湿土质量/干土质量/水质量/含水率/平均含水率）、密度（试样湿重/干重/体积/干密度/平均干密度）。

### 10.3.6 报告
- a) 道基**含水率**；
- b) 测点的**干密度**；
- c) **现场 CBR 值及相应的贯入量**。

## 关键指标

| 项目 | 限值/要求 |
|---|---|
| 加载车后轴重 | **≥60 kN** |
| 贯入杆 | 直径 **50 mm**，长约 **200 mm** |
| 贯入速度 | **1 mm/min** |
| 承载板 | 每块 **1.25 kg**，直径 **150 mm**，中孔 **52 mm**，**≥4 块**（共 5 kg） |
| 贯入量百分表 | 量程 **20 mm**，精度 **0.01 mm**，**2 个** |
| 平台跨度 | **宜 ≥0.5 m** |
| 细干砂粒径 | **0.3 mm～0.6 mm** |
| 找平范围 | 约 **直径 300 mm** |
| 预加荷载 | **45 N**，测力计与百分表调零 |
| 读数贯入量序列 | 0.5 / 1.0 / 1.5 / 2.0 / **2.5** / 3.0 / 4.0 / **5.0** / 6.5 / 10.0 / 12.5 mm（可至 7.5 mm 结束） |
| 双表一致性 | 差值绝对值 **≤平均值 30%**，否则重测 |
| 贯入断面面积 | **1 962.5 mm²** |
| 标准压强 p0 | **2.5 mm → 7 MPa**；**5.0 mm → 10.5 MPa** |
| 测力计精度 | **≥量程的 1%** |
