# 11.2 制动式摩阻设备测定道面摩擦系数试验方法

## Core Idea

用**带测试轮的牵引车**在**洒水状态**下连续测摩擦系数（μ 值），是**运营期跑道适航符合性**的主要手段。核心控制量三个：**测试速度（65 或 95 km/h，偏差 ≤5 km/h）**、**滑移率固定 15%**、**水膜厚度约 1 mm**。同一测线**至少测 2 次**，两次平均值偏差 **>0.1 须重测**。

## Key Clauses

### 11.2.1 适用范围
- **11.2.1.1** 适用于评价飞机在**直线段制动状态**下的道面抗滑性能，可作为**运营管理阶段道面是否满足适航要求**的技术依据。
- **11.2.1.2** 现场测试过程中道面**直线段的距离宜不少于 500 m**。
- **11.2.1.3** 数据采集、传输、记录和处理**均由专业软件自动控制**。

### 11.2.2 仪器与材料技术要求
- **11.2.2.1** 测试仪器可由**车辆牵引**或**直接安装在车辆底盘**上；测试时的行进速度应控制在 **5 km/h～130 km/h**。
- **11.2.2.2** 摩阻测试设备包括**两个驱动轮和一个测试轮**：驱动轮为**花纹轮胎**，测试轮为**光滑轮胎**（构造见图 15），摆放方向与驱动轮**平行**。驱动轮轮轴与测试轮轮轴通过**链条系统**连接，**链条传动系统应保证测试轮胎在测试时滑移率维持在 15%**。
- **11.2.2.3** 数据采集和处理设备：
  - a) **驱动轮轴**上应装备可计算**测试距离**的传感器；
  - b) **测试轮轴**上应装备能测**水平阻力和竖向荷载**的**应变仪**，能连续采集阻力和荷载并转换成信号送至处理器，处理器计算**每一个采样点的摩擦系数**并发送至计算机存储；
  - c) 应配备**便携式兼容计算机**，装有生产商提供的**数据采集软件**。
- **11.2.2.4** 应配备**带控制阀门的水箱**，或**水泵和流量计**，以控制洒水量。

### 11.2.3 方法与步骤
- **11.2.3.1 准备**
  - a) 测试前应确保**行进路线上没有任何障碍物**；
  - b) 测试道面应**清洁，无燃油、杂物及其它污染物**。
- **11.2.3.2 测试**
  - a) 选择**机场主要机型的轮迹线**作为测线；
  - b) 测试速度应按测试车类型选定 **65 km/h 或 95 km/h**，行进过程中**不应随意变换**测试速度，**速度偏差应不大于 5 km/h**；
  - c) 道面存在**积水、积冰、霜冻**时，或道面洒水**可能结冰**时，**不应在洒水状态下测试**；
  - d) 其它情况应在**同步洒水条件**下测试，**水温应控制在 5 ℃～25 ℃**；
  - e) 检查**洒水口出水和洒水位置**是否正常：洒水位置应在**测试轮触道面中点沿行驶方向前方**，**洒水宽度应覆盖测试轮宽度**；
  - f) 宜参照**表 10** 通过控制出水洒布量控制水膜厚度，**测试状态下水膜厚度宜控制在 1 mm 左右**；
  - g) 测试前应确保设备处于稳定状态，**首次测试前应开机预热 5 min**；
  - h) **一条测线相同条件下的测试次数应不少于 2 次**；如果 **2 次测试的摩擦系数平均值偏差大于 0.1**，应**重新测试**。

**表 10 不同测试条件下理论洒布量和水膜厚度**

| 测试速度（km/h） | 理论撒布量（l/min） | 道面水膜厚度（mm） |
|---|---|---|
| **65** | **0.4** | **0.9** |
| **95** | **0.6** | **1.3** |

### 11.2.4 计算和分析
- **11.2.4** 距离传感器和应变传感器的**采样间距宜设定为 40 mm、160 mm、400 mm 或 800 mm**；各点摩擦系数的**报告长度**应参照**机场运行管理规定**或根据测试目的确定。

### 11.2.5 报告
- a) 各测点（**用距离表示**）的**摩擦系数**；
- b) 测试范围内摩擦系数的**最小值、最大值、平均值、代表值、变异系数及其位置**；
- c) 其它信息：
  1) **测试速度**；
  2) **测线的起点桩号和终点桩号**；
  3) **道面温度**；
  4) **水的洒布量或推算的理论水膜厚度**；
  5) **跑道的编号及测线的编号**；
  6) 测试人员姓名及测试时间。

## 关键指标

| 项目 | 限值/要求 |
|---|---|
| 行进速度范围 | **5 km/h～130 km/h** |
| 测试速度 | **65 km/h 或 95 km/h** |
| 速度偏差 | **≤5 km/h** |
| 滑移率 | **维持在 15%** |
| 水温 | **5 ℃～25 ℃** |
| 水膜厚度 | 宜 **约 1 mm** |
| 理论撒布量（65 km/h） | **0.4 l/min**，水膜 **0.9 mm** |
| 理论撒布量（95 km/h） | **0.6 l/min**，水膜 **1.3 mm** |
| 直线段长度 | 宜 **≥500 m** |
| 同测线测试次数 | **≥2 次** |
| 两次平均偏差判据 | **>0.1 应重测** |
| 采样间距 | **40 / 160 / 400 / 800 mm** |
| 首次测试预热 | **5 min** |

## 交叉引用

- **MH 5001-2021** —— 跑道摩擦系数的**最低维护水平/评定标准**；本方法是其**测试手段**。
- **CCAR-139B** —— 跑道摩擦系数测试与通报的**运行管理要求**（频次、测试速度、通报条件）；11.2.1.1"是否满足适航要求"即对应其运行标准。
- **MH/T 5086-2025** —— 摩擦系数低于标准时的**跑道除胶**（高压水冲洗、抛丸、机械打磨）维护作业；除胶后须复测摩擦系数。
- **11.3 摆式仪 / 11.4 铺砂法** —— 三者不可互换（11.1.3）；制动式测**摩擦系数 μ**，摆式测 **BPN**，铺砂测 **TD**。
