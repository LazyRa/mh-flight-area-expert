# 14.2 沥青道面渗水系数现场测试试验方法

## Core Idea

把**渗水仪**密封在道面上，记录量筒水面从 **100 ml 降到 500 ml** 的时间，算**渗水系数 Cw（ml/min）**。适用于**密级配及 SMA**，**不适用 OGFC**（开级配本来就透水）。核心是**密封**——密封不好或存在浅层连通孔隙时数据会虚高，需按 14.2.3.2 f) 处理。

## Key Clauses

### 14.2.1 适用范围
- **14.2.1.1** 适用于**最大公称粒径不大于 19 mm 的密级配沥青混合料或 SMA 混合料**；**不适用于 OGFC 混合料**。
- **14.2.1.2** 适用于现场检查沥青道面渗水系数，可作为**工程建设阶段沥青道面层施工质量过程控制**的技术参考，也可作为**运营管理阶段沥青道面使用性能评价**的技术依据。

### 14.2.2 仪器与材料技术要求
- **14.2.2.1 渗水仪**（图 32）：
  - 上部**盛水量筒**由**透明有机玻璃**制成，**容积 600 ml**，上有刻度，**在 100 ml 及 500 ml 处有粗标线**；
  - 下方通过**直径 10 mm 的细管**与底座相接，**中间有一开关**；
  - 量筒通过**支架**联结；
  - **底座下方开口内径 150 mm，外径 220 mm**；
  - 附**不锈钢圈压重两个**，**每个质量约 5 kg，内径 160 mm**。
- **14.2.2.2** **密封材料**可使用**防水腻子、油灰或橡皮泥**等；**不宜选用黄油**等密封材料。
- **14.2.2.3** 其它：水筒及大漏斗、**秒表**、水、粉笔、**塑料圈**、刮刀、扫帚等。

### 14.2.3 方法与步骤
- **14.2.3.1 准备**
  - a) 建设阶段以**一个沥青道面分部工程**为基本测定单位；运营阶段以**一个区域**为基本测定单位；
  - b) 可选择**沥青道面施工缝位置**进行测试，测试结果**仅作为施工缝质量控制技术参考**；
  - c) 试验前先将道面表面**清扫干净**，减少杂物影响。
- **14.2.3.2 测试**
  - a) 将**塑料圈**置于道面测点上，用**粉笔沿塑料圈内侧和外侧画圈**，**外环与内环之间**即为需密封的区域；
  - b) 用密封材料对**环状密封区域**密封，**注意不应使密封材料进入内圈**；若已进入，应用**刮刀刮走**；然后将**搓成拇指粗细的条状密封材料摞在环状密封区域中央**，摞成一圈；
  - c) 将渗水仪放在测点上，**中心尽量与圆环中心重合**，略微使劲将渗水仪压在条状密封材料表面，**再加上配重**，以防压力水从底座与道面之间流出；
  - d) **关闭开关**，向量筒注满水，然后**打开开关**使水下流**排出底部空气**；当水面下降速度变慢时用双手轻压渗水仪使**气泡全部排出**，关闭开关，**再次注满水**；
  - e) **打开开关**，待水面下降至 **100 ml 刻度**时**立即开动秒表计时**；**每间隔 60 s 读记一次**刻度，**至水面下降 500 ml 时为止**。
    - 测试过程中如**水从底座与密封材料间渗出**，说明密封不好，应**移至附近干燥路面重新操作**；
    - 当水面下降**速度较慢**，测 **3 min** 的渗水量即可停止；
    - 若水面下降**较快**，**不到 3 min 即达 500 ml**，则记录**达到 500 ml 时的时间**；
    - 若水面下降至一定程度后**基本保持不动**，说明**基本不透水或根本不透水**，应在报告中注明；
  - f) 若试验中发现**渗水量过大且对结果有疑义**：首先检查**底座与道面密封**是否良好，并观察水是否沿**沥青道面浅层连通孔隙**渗出；如怀疑由此导致结果过大，可在测试位置**钻取直径 300 mm、深度 50 mm～100 mm 的孔位**，**去除孔内沥青混合料并整平孔底**后，参照 a)～e) 重新试验，并在报告中注明。

### 14.2.4 计算和分析
- **14.2.4.1** 以**水面从 100 ml 下降到 500 ml 所需时间**为标准计算；若渗水时间过长，也可采用 **3 min 通过的水量**计算，公式：

```
Cw = (V2 − V1) / (t2 − t1) × 60        ……………… (37)
```

- **Cw** —— 道面**渗水系数**，单位 **ml/min**；
- **V2** —— 第二次计时时的水量，ml；
- **V1** —— 第一次计时时的水量，ml；
- **t2** —— 第二次计时的时间，s；
- **t1** —— 第一次计时的时间，s。
- 注：**V1 和 V2 一般为 500 ml**。
- **14.2.4.2** 作为该测定单位的试验结果，**施工缝位置的试验结果应单列统计**，并在报告中注明。

### 14.2.5 报告
- a) 各测点试验情况说明，包括**测试位置是否是施工缝、是否在道面孔位内进行试验**等；
- b) 测定单位内各测点渗水系数的**均值、最大值、最小值、均方差、变异系数**；
- c) 测试单位、测试人员、测试时间、天气状况。

## 关键指标

| 项目 | 限值/要求 |
|---|---|
| 量筒容积 | **600 ml**，粗标线在 **100 ml / 500 ml** |
| 细管直径 | **10 mm** |
| 底座开口 | 内径 **150 mm**，外径 **220 mm** |
| 配重钢圈 | **2 个，各约 5 kg，内径 160 mm** |
| 计时起止 | **100 ml → 500 ml** |
| 读数间隔 | **每 60 s** |
| 最短测试时长 | **3 min**（下降慢时） |
| 适用混合料最大公称粒径 | **≤19 mm**（密级配、SMA） |
| 不适用 | **OGFC** |
| 密封材料 | 防水腻子、油灰、橡皮泥；**不宜黄油** |
| 渗水系数单位 | **ml/min** |
| 孔位复测尺寸 | 直径 **300 mm**，深 **50 mm～100 mm** |

## 交叉引用

- **MH/T 5011-2019** —— 沥青面层**渗水系数**的施工过程控制指标；本方法是其现场检测手段（14.1.2 明确**不作竣工验收依据**）。
- **MH/T 5010-2025** —— 沥青混合料**级配设计**（密级配/SMA/OGFC 的空隙率差异）决定了本方法的适用边界（14.2.1.1）。
- **MH 5001-2021** —— 沥青道面使用性能要求。
- **MH/T 5086-2025** —— 运营期渗水严重导致的**坑槽、唧泥**类病害维护。
- **14.1.2** —— 本方法结果**不宜作为竣工质量评价依据**。
