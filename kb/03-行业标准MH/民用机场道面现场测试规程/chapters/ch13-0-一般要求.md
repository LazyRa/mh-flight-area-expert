# 第13章 13.1 一般要求

## Core Idea

压实度测试的**方法选择规则**：**沥青道面 → 钻芯法**；**基层和土面区 → 环刀法或探坑灌砂法**；**核子仪必须经有效标定**才可信。同时强调**标准密度/最大干密度的室内试验可靠性**必须分析并写进报告——因为压实度是"实测干密度 ÷ 标准干密度"，分母不可靠则结果无意义。

## Key Clauses

- **13.1.1** 应根据**测试材料**选择不同的压实度试验方法：
  - **沥青道面**压实度检测时**宜采用现场取芯法**；
  - **基层和土面区**压实度检测时**宜采用环刀法或探坑灌砂法**；
  - **核子密湿度仪**测试的结果**应经过有效的标定**。
- **13.1.2** 压实度计算时应对**标准密度（沥青混合料）**或**最大干密度（细粒土或无机结合料稳定材料）**的**室内试验成果的可靠性**进行分析，并作为**试验报告的重要内容之一**。

## 关键指标（方法选用矩阵）

| 测试对象 | 推荐方法 | 条款 |
|---|---|---|
| 沥青面层 | **钻芯法** | 13.5 |
| 基层（粒料/无机结合料） | **灌砂法**（探坑灌砂） | 13.3 |
| 土基/土面区（细粒土、无机结合料稳定细粒土） | **环刀法** | 13.2 |
| 各类土、碎石、土石混合、沥青混合料、非硬化水泥混凝土 | **核子密湿度仪**（须标定 + 对比试验） | 13.4 |

## 交叉引用

- **MH/T 5011-2019** —— 沥青道面**压实度**施工控制与验收（标准密度取值、压实度限值）；本规程 13.5 为其测试方法。
- **MH 5006-2026** —— 水泥混凝土道面**基层/底基层**压实度验收；13.2、13.3 为其测试方法。
- **MH/T 5086-2025** —— 土面区**压实度 ≥87%、固体体积率 ≥77%** 的维护指标；13.2、13.3 为其检测手段（5086 附录 B 亦给出环刀法）。
- **民航规〔2024〕3号** —— 土面区密实度的**管理要求**（第 39、40 条）。
- **MH 5001-2021** —— 各结构层压实度**设计/验收标准值**。
