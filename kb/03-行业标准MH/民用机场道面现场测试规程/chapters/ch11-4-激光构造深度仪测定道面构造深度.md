# 11.5 激光构造深度仪测定道面构造深度试验方法

## Core Idea

车载**激光传感器**连续采集路面微观剖面，算**平均构造深度**，速度快（**≥50 km/h**）、采样密（**≤10 mm**）。适用于长跑道普查，但要求道面**无严重破损、无积水积雪泥浆**，否则数据失真。

## Key Clauses

### 11.5.1 适用范围
- **11.5.1.1** 适用于各类**车载式激光构造仪连续采集道面构造深度**；道面应**无严重破损病害、无积水（积雪、泥浆）**。
- **11.5.1.2** 可作为**工程建设阶段道面工程质量验收的参考依据**，也可作为**运营管理阶段道面抗滑性能评价的参考依据**。

### 11.5.2 仪器与材料技术要求
- **11.5.2.1** 测试系统由**承载车辆、距离传感器、激光传感器和主控制系统**组成。
- **11.5.2.2** 技术要求和参数：
  - a) **最大测试速度：≥50 km/h**；
  - b) **采样间隔：≤10 mm**；
  - c) **传感器测试精度：0.1 mm**；
  - d) **距离标定误差绝对值：＜0.1%**；
  - e) **系统工作环境温度：0 ℃～60 ℃**。

### 11.5.3 方法与步骤
- **11.5.3.1 准备**
  - a) 测试前应确保**行进路线上没有任何障碍物**；
  - b) 测试道面应**清洁，无燃油、杂物及其它污染物**；
  - c) 按设备操作手册要求对**各传感器进行校准**；
  - d) 若需现场安装距离测量装置，应按手册说明安装，确保**机械紧固装置安装牢固**；
  - e) 系统各部分应符合测试要求，**不应有明显的可视性破损**。
- **11.5.3.2 测试**
  - a) 按规定**预热时间**预热；
  - b) 测试车停在**测试起点前 50 m～100 m** 处，启动程序，按手册和现场技术要求设置测试状态；
  - c) 驾驶员按手册要求的**测试速度**驾驶，**避免急加速和急减速**，尽可能**沿直线行驶**；
  - d) 进入测试区域后启动**采集和记录**程序；测试中及时准确将**起终点**和需特殊标记位置输入记录；
  - e) 驶出测试区域后**停止采集**并恢复仪器至初始状态；
  - f) 检查**数据文件是否完整、内容是否正常**，若发现问题应**重新测试**；
  - g) 关闭电源，结束测试。

### 11.5.4 报告
- a) 各测点（**用距离表示**）的**构造深度**；
- b) 测试范围内构造深度的**最小值及其位置**；
- c) 测试范围内的**平均构造深度和标准差**；
- d) 测试单位、测试人员、测试时间、天气状况。

## 关键指标

| 项目 | 限值/要求 |
|---|---|
| 最大测试速度 | **≥50 km/h** |
| 采样间隔 | **≤10 mm** |
| 传感器测试精度 | **0.1 mm** |
| 距离标定误差 | **＜0.1%（绝对值）** |
| 系统工作环境温度 | **0 ℃～60 ℃** |
| 起点停车距离 | **50 m～100 m** |
| 道面状态要求 | 无**严重破损**、无**积水/积雪/泥浆** |

## 交叉引用

- **MH 5001-2021** —— 道面**构造深度**指标；本方法用于长距离连续评价。
- **MH/T 5011-2019** —— 沥青道面**构造深度**竣工检测；激光法效率高，宜与铺砂法（11.4）**抽样比对**。
- **MH 5006-2026** —— 水泥混凝土道面表面构造验收；**刻槽道面**（11.4 不适用）可用本方法。
- **11.4 手工铺砂法** —— 铺砂法为**基准方法**，激光法需与之建立相关性；11.5.1.2 明确本方法仅作**参考依据**（非裁定依据）。
- **MH/T 5086-2025** —— 构造深度不足时的**表面处治**维护。
