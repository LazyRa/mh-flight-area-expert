# 12.4 水泥混凝土道面邻板高差测试方法

## Core Idea

用 3 m 直尺横跨**接缝**，量接缝处的**最大间隙**即为**邻板高差**（错台量）。核心是**抽样覆盖规则**：横缝按**不少于 30%** 随机抽断面；**所有纵缝**都要测；每个断面**连续五块板**；每块板**至少测 3 次**取最大。读数**精确到 1 mm**。

## Key Clauses

### 12.4.1 适用范围
- **12.4.1** 可作为**工程建设阶段水泥混凝土道面竣工质量验收**的参考依据。

### 12.4.2 仪器与材料技术要求
- **12.4.2.1** **三米直尺**：测量基准面长度 **3 m**，基准面应平直，用**铝合金或硬木**等材料制成。
- **12.4.2.2** 最大间隙测量器具可选**楔形塞尺**或**深度尺**：
  - a) **楔形塞尺**：硬木或金属制**三角形**塞尺，有手柄，**长高比不小于 10**，**宽度不大于 15 mm**，边部有高度标记，**刻度读数分辨率不大于 0.5 mm**；
  - b) **深度尺**：金属制，有手柄，**测量杆端头直径不小于 10 mm**，**刻度读数分辨率不大于 0.2 mm**。
- **12.4.2.3** 其它：皮尺或钢尺、粉笔等。

### 12.4.3 方法与步骤
- **12.4.3.1 准备**
  - a) **跑道、滑行道、联络道沿中心线方向**，采用**随机抽样**确定需测邻板高差的**横断面**，横断面宽度为**全幅宽度**，**抽样不宜少于横缝数量的 30%**；
  - b) **跑道、滑行道、联络道垂直中心线方向**，**所有纵缝均应进行**邻板高差测定，测定时应**选择连续五块板**；
  - c) **停机坪等面状区域**，应在**每 2 000 m²** 区域内选择**一个断面**进行测定，测定时**选择连续五块板**；
  - d) 测试前应将道面**接缝位置清扫干净**。
- **12.4.3.2 测试**
  - a) 选定测试断面的一侧，将三米直尺**放置在邻板两侧**（见图 22），**在板块接缝位置**，采用**楔形塞尺或深度尺**量取三米直尺基准面距道面表面的**最大间隙**作为测试结果，**精确到 1 mm**；
  - b) **各板块测试次数不小于 3 次**，以该板块上**量测的最大间隙**作为该接缝的**邻板高差**，单位 **mm**；
  - c) 沿断面方向**逐板测量**各板块的邻板高差，直至结束。

### 12.4.4 计算和分析
- **12.4.4** 应分别记录每块板的测定结果，以该断面上**最大的邻板高差**作为测试结果，单位 **mm**；并根据技术标准计算**各条接缝的合格率**。

### 12.4.5 报告
- a) 各个断面的**邻板高差最大值**；
- b) 各个断面邻板高差的**合格率**；
- c) 测试单位、测试人员、测试时间、天气状况。

## 关键指标

| 项目 | 限值/要求 |
|---|---|
| 直尺长度 | **3 m** |
| 塞尺长高比 | **≥10**，宽度 **≤15 mm** |
| 塞尺/深度尺分辨率 | **≤0.5 mm** / **≤0.2 mm** |
| 邻板高差读数精度 | **1 mm** |
| 横缝断面抽样率 | **≥横缝数量的 30%** |
| 纵缝测定范围 | **全部纵缝** |
| 每个断面板块数 | **连续 5 块板** |
| 每块板测试次数 | **≥3 次**，取最大间隙 |
| 面状区域断面密度 | 每 **2 000 m²** 一个断面 |
| 断面测试结果 | 该断面**最大邻板高差** |

## 交叉引用

- **MH 5006-2026** —— 水泥混凝土面层**相邻板高差（错台）**的竣工允许偏差与合格率判定；12.4 为其测试方法。
- **MH/T 5024** —— 错台是水泥混凝土道面**竖向变形类**损坏之一（8.3.2 c) 2)），影响 PCI 与行驶品质。
- **MH 5001-2021** —— 道面平整度与错台的设计要求。
- **MH/T 5086-2025** —— 运营期错台超限后的**打磨/加铺**处治。
- **12.1.2** —— 邻板高差**不宜作为平整度综合状况的评定依据**，仅作专项指标。
- **12.3 三米直尺** —— 工具相同，但 12.3 测板内平整度、12.4 测接缝错台，测点位置与判定标准不同。
