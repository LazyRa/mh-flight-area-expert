# 7.4 高程测量检验道面结构层厚度试验方法

## Core Idea

**不开孔测厚度**：靠方格网测点在**每层施工前后各测一次高程**，两次高程之差即该层厚度，逐层累加得总厚度。适合工程建设阶段的**全过程控制**，精度取决于水准测量等级（**三等**，0.001 m）和测点位置的**前后一致**。

## Key Clauses

### 7.4.1 适用范围
- **7.4.1** 适用于工程建设阶段道面结构层**总厚度**以及**各层厚度**的检验，可作为**施工过程控制**与**竣工工程质量评价**的技术依据。

### 7.4.2 仪器与材料技术要求
- **7.4.2.1** 应配备水准仪、全站仪、光电测距仪、经纬仪、GPS、钢尺、条码尺、花杆、钢卷尺。
- **7.4.2.2** 应准备**施工图中的方格网高程图**和**水准测量记录手簿**。
- **7.4.2.3** 应配备无线电通讯设备、粉笔或油漆等标识材料；**夜间测量应配备照明设备**。

### 7.4.3 方法与步骤
- **7.4.3.1** 结合方格网高程图和飞行区**测量控制网**资料现场勘查，根据**工程进度计划**编制道面高程测量计划。
- **7.4.3.2** 步骤：
  - a) 结构层施工前按方格网高程图**现场放样**并简易标识；高程测点按**方格网设计位置**布设并**统一编号**；
  - b) 施工前顶面所有测点用**水准仪**测量，**精度等级可参照三等**，单位 m，**精确到 0.001 m**；
  - c) 根据设计图纸（方格网高程图）绘制各测点**初始高程**；
  - d) 该结构层施工完成后**重新放样**，测点位置**与施工前保持一致**，统一编号；
  - e) 施工后所有测点用**水准仪**测量，**可参照三等**，精确到 **0.001 m**；
  - f) 绘制各测点**施工后高程**；
  - g) **重复 d)～f)**，直至道面**全部结构层施工完毕**。

### 7.4.4 计算和分析
- **7.4.4.1** 按**公式(2)** 计算各结构层实际厚度：

```
Δhij = hij − h(i−1)j        ……………… (2)
```

  - **Δhij** —— 第 i 层 j 测点的结构层厚度，单位 mm；
  - **hij** —— 第 i 层 j 测点结构层**施工后**的高程，单位 mm；
  - **h(i−1)j** —— 第 i 层 j 测点结构层**施工前**的高程，单位 mm。

- **7.4.4.2** 按**公式(3)** 计算结构层实际总厚度：

```
Δhj = Σ(i=1→n) Δhij        ……………… (3)
```

  - **Δhj** —— j 测点的结构层总厚度，单位 mm；
  - **n** —— 道面结构层层数；
  - **Δhij** —— 第 i 层 j 测点结构层施工厚度，单位 mm。

- **7.4.4.3** 按**公式(4)** 计算道面结构层总厚度与设计总厚度的差值：

```
Δj = Δhj − Δh′j        ……………… (4)
```

  - **Δj** —— j 测点结构层**摊铺厚度差**，单位 mm；
  - **Δhj** —— j 测点结构层**实际**摊铺总厚度，单位 mm；
  - **Δh′j** —— j 测点结构层**设计**摊铺总厚度，单位 mm。
  - 注：**Δh′j 可由方格网高程图查询**。

### 7.4.5 报告
- a) 各测点施工厚度的**均值、最大值、最小值、标准差、变异系数**；
- b) 各测点施工厚度**与设计厚度差值**的均值、最大值、最小值、标准差、变异系数；
- c) **标识各测点实际高程的道面方格网高程图**。

## 关键指标

| 项目 | 要求 |
|---|---|
| 高程测量精度等级 | 可参照**三等** |
| 高程读数精度 | **0.001 m** |
| 测点布设 | 按**方格网设计位置**，**统一编号** |
| 前后测点位置 | 必须**保持一致** |
| 厚度计算精度 | 单位 **mm** |

## 交叉引用

- **MH 5006-2026** —— 水泥混凝土道面**各结构层厚度**的施工控制与验收允许偏差；本方法因"逐层可测、不破损"，最适合 5006 的过程控制。
- **MH/T 5011-2019** —— 沥青面层**摊铺厚度**的过程控制（松铺系数、压实后厚度）；本方法的 Δhij 可作为摊铺厚度的独立校核。
- **MH 5001-2021** —— 设计总厚度 Δh′j 的来源。
- **MH/T 5025** —— 测量控制网（7.4.3.1 前置条件）。
- **7.3 / 7.5** —— 本方法为**非破损**厚度法，与探坑/钻芯（破损、直接）和短脉冲雷达（无损、连续）构成三类互补手段；验收争议时以 7.3 钻芯法为准。
