# 第4章 缩略语

## Core Idea

本章集中定义 17 个英文缩略语，其中大部分在条文里直接作为**指标名**使用（PCI、IRI、BPN、CBR、FWD）。记住这批缩略语等于拿到了全规程的"索引键"。

## Key Clauses

- **4** 下列缩略语适用于本文件：

| 缩略语 | 英文 | 中文 |
|---|---|---|
| **BPN** | British Pendulum Number | 摆值 |
| **CBR** | California Bearing Ratio | 加州承载比 |
| **CDV** | Corrected Deduct Value | 损坏折减修正值 |
| **DV** | Deduct Value | 损坏折减扣分值 |
| **FWD** | Falling Weight Deflectometer | 落锤式弯沉仪 |
| **GPS** | Global Positioning System | 全球定位系统 |
| **HDV** | Highest individual Deduct Value | 最大损坏折减扣分值 |
| **IRI** | International Roughness Index | 国际平整度指数 |
| **ISM** | Impulse Stiffness Modulus | 冲击劲度模量 |
| **OGFC** | Open-Graded Friction Course | 开级配沥青磨耗层 |
| **PCI** | Pavement Condition Index | 道面状况指数 |
| **PCN** | Pavement Classification Number | 道面等级号 |
| **PDOP** | Position Dilution of Precision | 空间位置精度因子 |
| **SCI** | Structure Condition Index | 道面结构状况指数 |
| **SMA** | Stone Matrix Asphalt | 沥青玛蹄脂碎石 |
| **TD** | Texture Depth | 道面构造深度 |

> ⚠️ 原文缩略语清单实为 16 条（BPN、CBR、CDV、DV、FWD、GPS、HDV、IRI、ISM、OGFC、PCI、PCN、PDOP、SCI、SMA、TD）。CDV/DV/HDV/SCI 仅在第 8 章 PCI 计算中被间接引用（实际算法见 MH/T 5024），本规程正文未再展开。

## 交叉引用

- **MH/T 5024** —— DV、CDV、HDV、SCI 是 5024 的 PCI/SCI 评价体系用语，本规程第 8 章只做调查、不做扣分计算。
- **MH/T 5011-2019** —— OGFC、SMA 两种沥青混合料类型在本规程 13.5（压实度）、14.2（渗水系数）中被区别对待（OGFC **不适用**渗水系数法）。
- **MH 5001-2021** —— PCN 的通报与 ACN-PCN 比对由 MH 5001 规定，本规程第 9 章 FWD 为其提供计算数据。
