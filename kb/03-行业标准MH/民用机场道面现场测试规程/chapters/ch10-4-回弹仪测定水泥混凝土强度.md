# 10.5 回弹仪测定水泥混凝土强度试验方法

## Core Idea

用**回弹仪**打混凝土板面取**回弹值**，扣除 **3 个最大值和 3 个最小值**后取平均，再结合**碳化深度**查表推算抗压强度。本方法**只能"快速评定"，不能替代试件加载**，也**不能作为竣工验收的法定依据**——这是本章最重要的定性限制。

## Key Clauses

### 10.5.1 适用范围
- **10.5.1.1** 适用于现场对**普通水泥混凝土道面抗压强度**进行**快速评定**；通过评定结果可推测道面水泥混凝土**浇筑质量的均匀性**和**薄弱区域的位置**。
- **10.5.1.2** 本方法测定的抗压强度**不应替代**通过**试件加载**测定的抗压强度，**不应作为工程竣工验收时质量评定的法定依据**。
- **10.5.1.3** **钢筋水泥混凝土板**以及**混凝土板厚度小于 100 mm** 的道面**不宜使用**本方法。

### 10.5.2 仪器与材料技术要求
- a) **回弹仪**：指针直读式（结构见图 14），或数字显示式、自动记录式；均须满足：
  1) 水平弹击状态下，弹击锤脱钩瞬间**标称动能应为 2.207 J**；
  2) 弹击锤与弹击杆碰撞瞬间**弹击压簧处于自由状态**，弹击锤起点应位于刻度尺**零点**；
  3) 在**洛氏硬度 HRC60±2 的钢砧**上，回弹仪**率定值应为 80±2**。
- b) 其它：**浓度 1% 的酚酞酒精溶液**、**洛氏硬度 HRC60±2 的钢砧**、手提式砂轮、卷尺、游标卡尺、凿子、锤、吸耳球等。

### 10.5.3 方法与步骤
- **10.5.3.1 准备**
  - a) 回弹仪出现以下情况应**送检定单位**：
    1) **累计弹击次数超过 6 000 次**；
    2) **弹击拉簧座、弹击杆、缓冲压簧、中心导杆、导向法兰、弹击锤、指针轴、指针片、指针块、挂钩、调零螺丝**等主要零件**更换后**；
    3) 弹击拉簧前端**不在拉簧座原孔位**或**调零螺丝松动**；
    4) 仪器遭受**严重撞击**或其它损害。
  - b) 回弹仪出现以下情况应在**钢砧上标定**；若结果不在 **80±2** 内，应**常规保养后再标定**，再次不合格应**送检**：
    1) 进行构件测试**前后**；如连续数天测试，可**每天测试完毕后标定一次**；
    2) 现场测定过程中**对回弹值测试结果有疑义**；
    3) 标定宜在**室温 20 ℃±5 ℃** 条件下进行；标定时先将钢砧稳固置于**刚度较大**的水泥混凝土地坪上，回弹仪向下弹击时弹击杆**分 4 次旋转、每次约 90°**，**弹击 3～5 次**，取**最后连续 3 次读数稳定**的回弹值平均值作为标定值。
  - c) **环境温度低于 10 ℃** 条件下**不宜**进行本试验。
- **10.5.3.2 测试**
  - a) **选择测区、布置测点**：
    1) 以建设阶段的**分部工程**为基本单位，以**单块水泥混凝土板块作为一个测区**；一个基本单位宜按**板块总数量的 30% 随机抽样**；
    2) 宜选板块内**矩形区域**测试，**测点数量不小于 16（4×4）处**，**相邻测点间距不小于 30 mm**，**测区边界距板边或助航灯具等结构物不小于 100 mm**；
    3) 测区表面应**清洁、干燥、平整**，不应有浮浆、油垢、麻面；
  - b) **回弹值测定**：回弹仪**轴线应始终垂直于**混凝土表面：
    1) 弹击杆顶住表面，轻压仪器，松开按钮，弹击杆徐徐伸出，将**弹击锤挂在挂钩上**；
    2) 缓慢均匀施压，待弹击锤脱钩冲击弹击杆后，指针向后移动到一定位置，该点回弹值即为指针刻度线示值；
    3) 依次读数记录；若条件不利于读数，可**按下按钮锁住机芯**移至他处读数，**精确到 1 个单位**；
    4) 测试完毕后应将弹击杆压入仪器内，经弹击后按下按钮锁住机芯；
  - c) **碳化深度测定**：
    1) **龄期少于 3 个月**的水泥混凝土道面**不需测定**碳化深度；
    2) **龄期超过 3 个月**的，若道面龄期相近，可**选择 1 块板块**测定；**不宜选择位于飞机轮迹处**的板块；
    3) 用钻机钻取**直径约 15 mm** 的孔洞，用吸耳球吹去粉末碎屑后，**立即**将 **1% 酚酞酒精溶液**洒在孔洞内壁边缘；当已碳化与未碳化部分出现**清晰界限**（未碳化部分变**紫红色**）时，用**游标卡尺**量测交界面至混凝土表面的垂直距离，即为碳化深度值，**精确到 0.5 mm**；
    4) **测点碳化深度 ≤0.5 mm 记为 0**；**≥6.0 mm 记为 6.0 mm**；
    5) 若对碳化深度有疑义，可**增加板块数量**测定，以各次测定值的**平均值**作为结果。

### 10.5.4 计算和分析
- **10.5.4.1** 对 1 个测区所有测点的回弹值，**剔除 3 个最大值和 3 个最小值**后，取其余回弹值的**平均值**作为该测区（板块）的**通报回弹值**。
- **10.5.4.2** 推算抗压强度，可选以下方法：
  - a) 根据**通报回弹值和测定的碳化深度**，按**表 9** 查得抗压强度；
  - b) 若**缺乏现场测定的碳化深度**，可按**公式(19)** 推算：

```
R = 0.025 N²        ……………… (19)
```

  - **R** —— 道面抗压强度，单位 **MPa**；
  - **N** —— 测区（板块）**通报回弹值**。

  - c) 有试验条件时，宜通过试验建立**回弹值-抗压强度经验关系式**：
    1) 采用 **1.50、1.75、2.00、2.25、2.50** 五个**水灰比**，按 **150 mm×150 mm×150 mm** 尺寸制备标准试件；
    2) 试件**养生条件尽量与现场一致**；
    3) 达到现场测定龄期后，**先用回弹仪测回弹值**，再通过**室内试验测抗压强度**；
    4) 用**回归分析**建立经验关系式，**相关系数应不低于 0.90**。

### 10.5.5 报告
- a) 现场测定**通报回弹值**的均值、均方差、变异系数；
- b) **推算抗压强度的方法**；若采用经验关系式，应给出关系式及**相关系数**；
- c) 由通报回弹值推算的**板块抗压强度**的均值、均方差、变异系数；
- d) 测试单位、测试人员、测试时间、天气状况。

## 关键指标

| 项目 | 限值/要求 |
|---|---|
| 标称动能（水平弹击） | **2.207 J** |
| 钢砧率定值 | **80±2**（钢砧 **HRC60±2**） |
| 送检阈值（累计弹击） | **>6 000 次** |
| 标定环境温度 | **20 ℃±5 ℃** |
| 试验环境温度 | **低于 10 ℃ 不宜进行** |
| 抽样比例（建设阶段） | **板块总数量的 30%** |
| 单测区测点数 | **≥16（4×4）处** |
| 相邻测点间距 | **≥30 mm** |
| 测区边界距板边/灯具 | **≥100 mm** |
| 数据取舍 | 剔除 **3 个最大值 + 3 个最小值** |
| 回弹值读数精度 | **1 个单位** |
| 碳化深度测孔直径 | 约 **15 mm** |
| 碳化深度读数精度 | **0.5 mm** |
| 碳化深度上下限 | **≤0.5 mm 记 0**；**≥6.0 mm 记 6.0 mm** |
| 免测碳化深度的龄期 | **<3 个月** |
| 无碳化深度时的强度公式 | **R = 0.025 N²**（MPa） |
| 经验关系式相关系数 | **≥0.90** |
| 不适用情形 | **钢筋混凝土板**；**板厚 <100 mm** |

## 交叉引用

- **MH 5006-2026**（水泥混凝土面层施工）—— 10.5.1.2 明确本方法**不能作为竣工验收的法定依据**；竣工验收的强度判定仍以 5006 规定的**试件抗压强度**为准。本方法用于**质量均匀性普查**和**薄弱区定位**。
- **MH/T 5024** —— 混凝土强度不足是道面结构状况评价的输入之一；回弹法可作**快速筛查**。
- **MH/T 5086-2025** —— 运营期发现混凝土强度可疑区域后的处治纳入维护体系。
- **7.3 钻芯法** —— 若需**法定强度**数据，应在回弹法定位的薄弱区**钻芯取样**做室内试验。
