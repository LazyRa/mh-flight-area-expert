# 第6章 现场取样

## Core Idea

现场取样是所有"取回实验室再测"类试验的**共同前置工序**，也是本规程唯一直接管到**钻孔后如何修补道面**的章节。两条主线：**取样数量由试验目的定、抽样位置随机定**；**取完必须立即修补且高差 ≤3 mm**，因为机场道面开孔即构成运行风险。

## Key Clauses

### 6.1 一般要求
- **6.1.1** 现场取样前应根据**取样用途**进行**区域划分**。
- **6.1.2** 取样**数量**应根据**试验目的**确定；本规程**仅根据平行试验要求**对**最少取样数量**作出规定。

### 6.2 道面现场取样
- **6.2.1.1** 适用于对道面的**面层**或**稳定类基层**进行取样。
- **6.2.1.2** 适用于采用**取芯钻机**或**切割机**现场钻取或切割道面的**代表性试样**。
- **6.2.1.3** 采用取芯钻机时，**芯样直径宜不小于最大集料粒径的 3 倍**。
- **6.2.2.1** 取芯钻机可采用**牵引式或车载式**，由发动机或小型发电机驱动；钻头直径一般 **100 mm 或 150 mm**，应配备**冷却装置**。
- **6.2.2.2** 道面切割机可采用手推式或牵引式，配**金刚石盘锯**及冷却装置；盘锯半径应满足切割试样尺寸要求。
- **6.2.2.3** 其它器具：台秤、盛样器（袋）或铁盘、试样标签、钩钎、镐、铁锹、量尺（绳）、毛刷、硬纸、棉纱。
- **6.2.3.1** 准备工作：
  - a) 工程建设阶段以**分部工程**作为基本单位；运营管理阶段根据实际情况确定范围，数量应满足试验要求；
  - b) 取样位置采用**随机抽样**方法确定；
  - c) 取样位置**清扫干净**并作**现场简易标识**，宜标识在平面图上。
- **6.2.3.2** 取样步骤（a～i）：
  - a) 标记钻孔位置或画出切割面积；
  - b) 移机、固定支座、**垂直**放下钻头；
  - c) 开冷却装置→启动电机→**徐徐压下**钻杆，下压过程尽可能平稳；
  - d) 钻至指定深度后**平缓拔出**、停转，用钩钎取出芯样；
  - e) 切割时锯片对准位置→开冷却→缓慢压下至要求深度→平稳推进→抬起锯片；**四面全部切割完成后**用镐或铁锹取出，**尽可能保证试样边角完整**；
  - f) 试样放于盛样器，必要时封装；
  - g) 填写**样品标签一式两份**（一份贴试样、一份备查），标签含：试件编号、分部工程/取样区域名称、取样位置、试件用途、取样日期、取样人员；**宜现场清洗干净后拍照备案**；
  - h) 破损区域**立即修补**（材料见下表）；
  - i) 修补区与周边道面**高差绝对值不大于 3 mm**，修补后**及时清扫并检查**，确保无碎粒或工具遗留。

## 关键指标

**取样与修补要求**

| 项目 | 要求 |
|---|---|
| 芯样直径 | 宜 **≥ 最大集料粒径 × 3** |
| 钻头直径（常规） | **100 mm / 150 mm** |
| 样品标签 | **一式两份** |
| 修补高差 | **≤ 3 mm（绝对值）** |
| 取样位置确定 | **随机抽样** |
| 基本单位（建设阶段） | **1 个分部工程** |

**破损区域修补材料（6.2.3.2 h）**

| 部位 | 修补材料 |
|---|---|
| 基层类材料 | 水泥混凝土 或 水泥碎石 |
| 水泥混凝土道面（建设阶段） | 水泥混凝土 |
| 水泥混凝土道面（**运营管理阶段**） | **快凝水泥混凝土**（龄期以满足**适航时间**为准） |
| 沥青道面 | 热拌沥青混合料 或 高性能冷拌修补材料 |

## 交叉引用

- **MH 5006-2026**（水泥混凝土面层施工）—— 6.2.1.3 的"芯样直径 ≥3 倍最大集料粒径"与 5006 的取芯验收要求一致；本章的芯样是 5006 抗压/厚度验收的取样来源。
- **MH/T 5011-2019**（沥青道面施工）—— 13.5 钻芯法压实度的芯样按本章 6.2 钻取；沥青道面修补材料（热拌/冷拌）选用与 5011 的修补条款对接。
- **MH/T 5086-2025**（场地基础性维护）—— 运营管理阶段钻孔后必须用**快凝**材料并在**适航时间**内恢复，属于维护作业范畴，与 5086 的道面修补要求互为补充。
- **CCAR-139B** —— 道面开孔属"施工影响运行"事件，须履行通报与恢复适航程序。
- **MH/T 5025** —— 取样位置标识宜纳入测量控制网/平面图体系。
