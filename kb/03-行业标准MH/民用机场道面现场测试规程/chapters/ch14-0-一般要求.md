# 第14章 14.1 一般要求

## Core Idea

沥青道面"相关指标"（渗水系数、施工温度）定位明确：**只作施工过程控制，不作竣工质量评价依据**。同时要求试验数量除满足规程外**应尽可能增加**——因为沥青施工是连续过程，样本太少看不出波动。

## Key Clauses

- **14.1.1** 沥青道面**施工过程控制**中的各项试验应作为**施工过程质量控制**的技术依据；试验数量**除满足本规程有关规定外，应根据实际情况尽可能增加**。
- **14.1.2** 沥青道面施工过程控制各项试验结果**不宜作为工程竣工质量评价**的技术依据。

## 交叉引用

- **MH/T 5011-2019** —— 沥青道面**施工过程控制**的指标体系与频次；本章的渗水系数、温度是其中的现场检测项。
- **MH/T 5010-2025** —— 配合比设计与**施工温度区间**（拌和、摊铺、碾压温度）的设计依据。
- **MH 5001-2021** —— 沥青道面使用性能要求。
- **14.2 / 14.3** —— 两方法的共同定性限制：**仅过程控制，不作竣工验收依据**（14.1.2）。
