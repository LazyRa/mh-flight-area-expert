# 11.4 手工铺砂法测定道面构造深度试验方法

## Core Idea

把**已知体积的标准砂（25 000 mm³）**摊成圆、量直径、算平均深度，得**构造深度 TD**。最原始也最通用，但**不适用于刻槽道面**（刻槽的构造是定向的，铺砂会"漏"）。控制点：量砂筒容积 **25 ml±0.15 ml**、砂粒径 **0.15～0.3 mm**、**不重复使用**、同一测点 **3 个单点**取平均。

## Key Clauses

### 11.4.1 适用范围
- **11.4.1.1** 适用于测定道面表面的**宏观构造**，可作为**运营管理阶段道面抗滑性能评价**的技术参考。
- **11.4.1.2** 可作为**工程建设阶段道面竣工工程质量评价**的技术依据。
- **11.4.1.3** 本方法**不适用于刻槽道面**。

### 11.4.2 仪器与材料技术要求
- **11.4.2.1** 人工铺砂仪由**圆筒和推平板**组成：
  - a) **量砂筒**（图 17）：一端封闭，可通过**称量砂筒中水的质量确定容积 V**，并调整其高度以控制**容积在 25 ml±0.15 ml** 范围内；附有**专门的刮尺（300 mm 钢板尺）**刮平筒口量砂；
  - b) **推平板**（图 18）：木制或铝制，**直径 50 mm**，底面粘一层**厚约 1.5 mm 的橡胶片**，上面有一圆柱把手。
- **11.4.2.2** **量砂为干燥洁净的标准砂，粒径 0.15 mm～0.3 mm**。
- **11.4.2.3** 量尺为**钢板尺或钢卷尺**，也可采用**构造深度尺**。
- **11.4.2.4** 其它：装砂容器（小铲）、扫帚或毛刷、**挡风板**等。

### 11.4.3 方法与步骤
- **11.4.3.1 准备**
  - a) 准备足量洁净标准砂，**晾干过筛**，取 **0.15 mm～0.3 mm** 的砂置于干燥洁净容器备用；
  - b) **量砂不应重复使用**；
  - c) 测点应选在**主要机型主起落架轮迹带**，沿**两条轮迹带交错布置**，**测点间距不大于 100 m**，**每 4 000 m² 不少于 1 点**。
- **11.4.3.2 测试**
  - a) 用扫帚或毛刷将测点附近道面**清扫干净**，面积**宜不小于 0.3 m×0.3 m**；
  - b) **不应直接用量砂筒装砂**，应用**小铲**沿筒壁向圆筒中注满砂；手提圆筒上方，**轻轻叩打 3 次**，砂密实后用**钢尺一次刮平**砂面；
  - c) 将砂倒在道面上，用**底面粘有橡胶片的推平板**，**由里向外重复作旋转摊铺运动**，稍稍用力将砂尽可能向外推开，使砂填入道面凹凸空隙，尽可能摊成**圆形**，**不可在表面留有浮动余砂**；
  - d) 用**钢板尺**测量所构成圆的**两个垂直方向的直径**，取**平均值**，**精确到 5 mm**；
  - e) 同一测点**平行测定不少于 3 个点**，**同一位置 3 个单点间距应不大于 3 m**；**同一测点不同位置应由同一试验员测定**；以 3 次测定结果的**平均值**作为该测点**代表值（精确到 0.01 mm）**；
  - f) 测定后用扫帚或毛刷将道面上的细砂**清扫干净**。

### 11.4.4 构造深度计算
- **11.4.4** 按**公式(21)** 计算：

```
TD = 4V / (π·D²) = 31 831 / D²        ……………… (21)
```

- **TD** —— 道面表面构造深度，单位 **mm**；
- **V** —— 砂的体积，单位 **mm³**；
- **D** —— 摊平砂的**圆形面积的平均直径**，单位 **mm**。
- 注：**砂的体积取 25 000 mm³**。

### 11.4.5 报告
- a) 各测试单点的表面构造深度及 **3 次测定的平均值**；当平均值**小于 0.2 mm** 时，试验结果以 **"＜0.2 mm"** 表示；
- b) 评定段构造深度的**平均值、标准差、变异系数**；
- c) 测试单位、测试人员、测试时间、天气状况。

## 关键指标

| 项目 | 限值/要求 |
|---|---|
| 量砂筒容积 | **25 ml±0.15 ml** |
| 量砂粒径 | **0.15 mm～0.3 mm** |
| 砂体积（计算取值） | **25 000 mm³** |
| 推平板直径 | **50 mm**，橡胶片厚约 **1.5 mm** |
| 刮尺 | **300 mm 钢板尺** |
| 清扫面积 | 宜 **≥0.3 m×0.3 m** |
| 装砂方式 | **小铲装砂**，叩打 **3 次**，**一次刮平** |
| 直径量测 | **两个垂直方向**取平均，精确到 **5 mm** |
| 单点重复 | **≥3 个点**，间距 **≤3 m**，**同一试验员** |
| 测点密度 | 间距 **≤100 m**，**每 4 000 m² ≥1 点** |
| 结果精度 | **0.01 mm** |
| 低于 0.2 mm 的表述 | **"＜0.2 mm"** |
| 不适用 | **刻槽道面** |

- **MH 5001-2021** —— 道面**构造深度**的设计/验收指标；本方法为其测试手段之一。
- **MH/T 5011-2019** —— 沥青道面**构造深度**的施工控制（摊铺、碾压工艺对宏观构造的影响）与竣工检测。
- **MH 5006-2026** —— 水泥混凝土道面**表面构造**（拉毛/拉槽）的验收；注意**刻槽道面不适用本方法**（11.4.1.3），刻槽道面应改用 11.5 激光法或铺砂法的替代方法。
- **11.5 激光构造深度仪** —— 连续、快速，适合长距离普查；铺砂法适合**标定/抽检**与**争议复核**。
- **11.3 摆式仪** —— BPN 反映微观构造，TD 反映宏观构造，两者共同决定湿态抗滑。
