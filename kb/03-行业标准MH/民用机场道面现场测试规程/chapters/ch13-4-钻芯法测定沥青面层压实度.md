# 13.5 钻芯法测定沥青面层压实度试验方法

## Core Idea

钻取沥青芯样 → 室内测**毛体积密度 ρs** → 除以**标准密度 ρ0** 得压实度。两个关键点：**取样时机**（普通沥青摊铺后**第二天**、改性沥青及 SMA **第三天**）与**标准密度的取值方式**（马歇尔试件密度 或 最大理论密度，逐日测定）。**钻头不宜用淋水冷却**，避免芯样吸水影响密度。

## Key Clauses

### 13.5.1 适用范围
- **13.5.1** 适用于测定**摊铺沥青的密度**，并根据**标准密度**计算沥青道面摊铺压实后的**压实度**，可作为**工程建设阶段机场沥青道面压实质量评定**的技术依据。

### 13.5.2 仪器与材料技术要求
- **13.5.2.1** 主要仪器和材料：**道面取芯钻机、天平（感量不大于 0.1 g）、水槽、吊篮、石蜡、卡尺、毛刷、小勺、取样袋**等。
- **13.5.2.2** 取芯钻机可采用**牵引式（车辆或手推式）或车载式**，由发动机或小型发电机驱动；**钻头直径宜不小于 100 mm**，**不宜使用淋水冷却装置**。

### 13.5.3 方法与步骤
- **13.5.3.1 准备**
  - a) 建设阶段以**一个沥青道面分部工程**为基本测定单位；以沥青面层**每 8 000 m² 作为一个测试区域**；**同一个测试区域测点数量不小于 3 个**；**一个测定单位的测点数量不小于 10 点**；
  - b) 按第 6 章道面工程现场取样方法钻取芯样；**若芯样包括不同层位的沥青混合料**，应用**切割机沿各层结合面锯开**；
  - c) 钻孔取样应在**道面完全冷却后**进行：**普通沥青道面宜在摊铺后的第二天**取样；**改性沥青及 SMA 道面宜在摊铺后的第三天**取样。
- **13.5.3.2 试验**
  - a) 现场取出芯样，**在水中轻轻刷净**黏附的粉尘；若芯样边角有**浮松颗粒应清除**；
  - b) 将芯样**晾干或用电风扇吹干不少于 24 h，直至恒重**；
  - c) 室内测定芯样密度 **ρs**，方法按吸水率选：
    1) 一般用**表干法**测**毛体积相对密度**；
    2) **吸水率大于 2%** 的芯样，宜用**蜡封法**测毛体积相对密度；
    3) **吸水率小于 0.5%** 的特别致密沥青混合料，可用**水中重法**测**表观相对密度**；
  - d) 应采用**配合比设计时的标准密度**，逐日测定沥青混合料的标准密度 **ρ0**：
    1) **以每天实验室实测马歇尔击实试件密度作为标准密度**：沥青拌和厂每天取样 **1～2 份**，实测马歇尔试件密度取平均值；制备马歇尔试件时，**试件成型温度与道面复压温度应尽可能一致**；
    2) **以每天实测的最大理论密度作为标准密度**：对**普通沥青混合料**，拌和厂在取样做马歇尔试验的同时以**真空法**实测最大理论密度，**平行试验试样数宜不少于 2 组**取平均值；对**改性沥青混合料、SMA 混合料**，应以**该批次总量检验的平均筛分结果及油石比平均值计算的最大理论密度**为准，也可采用**抽提筛分的配合比及油石比**计算最大理论密度。

### 13.5.4 计算和分析
- **13.5.4** 沥青混合料面层的**施工压实度**为**毛体积密度与标准密度之比**，以百分率表示，按**公式(36)**：

```
K = (ρs / ρ0) × 100        ……………… (36)
```

- **K** —— 沥青面层某测定部位的**压实度（%）**；
- **ρs** —— 沥青混合料现场取芯试件的**实际密度**，kg/m³；
- **ρ0** —— 沥青混合料的**标准密度**，kg/m³。

### 13.5.5 报告
- a) 用于计算压实度的**沥青混合料标准密度及其测定方法**；
- b) 现场**取芯位置及芯样编号**；
- c) **取芯日期**；
- d) 各芯样**室内实验实际测定的密度及其测定方法**；
- e) 测定单位内压实度的**平均值、最小值、方差、变异系数**；
- f) 测试单位、测试人员、测试时间、天气状况。

## 关键指标

| 项目 | 限值/要求 |
|---|---|
| 钻头直径 | 宜 **≥100 mm** |
| 冷却方式 | **不宜使用淋水冷却装置** |
| 天平感量 | **≤0.1 g** |
| 测试区域划分 | 每 **8 000 m²** 一个 |
| 每测试区域测点数 | **≥3 个** |
| 每测定单位测点数 | **≥10 点** |
| 取芯时机（普通沥青） | 摊铺后**第二天** |
| 取芯时机（改性沥青、SMA） | 摊铺后**第三天** |
| 芯样干燥 | **≥24 h** 至恒重 |
| 表干法适用 | 一般沥青混合料 |
| 蜡封法适用 | 吸水率 **>2%** |
| 水中重法适用 | 吸水率 **<0.5%**（特别致密） |
| 马歇尔标准密度取样 | 每天 **1～2 份** |
| 最大理论密度平行试验 | **≥2 组** |

## 交叉引用

- **MH/T 5011-2019** —— 沥青道面**压实度**的施工控制与验收限值；本方法是其**标准检测方法**（13.1.1"沥青道面宜采用现场取芯法"）。
- **MH/T 5010-2025** —— **配合比设计**确定的标准密度、最大理论密度；13.5.3.2 d) 的 ρ0 取值与 5010 的配合比设计成果直接对应。
- **MH/T 5041-2019**（环氧沥青）—— 环氧沥青混合料的密度测定同样用表干法/蜡封法，但**固化后不宜水中重法**，需注意适用性。
- **MH 5001-2021** —— 压实度设计/验收标准。
- **6 现场取样** —— 芯样钻取按 6.2，钻孔后须按 6.2.3.2 h/i 修补（高差 ≤3 mm）。
- **13.4 核子仪** —— 沥青面层可用散射法快速测密度，但须与本章钻芯法比对（≥15 点，R ≥0.95）。
