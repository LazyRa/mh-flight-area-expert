# 12.2 激光平整度测试系统测定道面平整度试验方法

## Core Idea

车载**激光纵断面高程 + 距离传感器**连续采集，按 **100 m 计算区间**用 IRI 标准程序算**国际平整度指数**（m/km）。参数三件套：**采样间隔 ≤500 mm**、**传感器精度 0.5 mm**、**距离标定误差 ≤0.1%**；测线布在**飞机主轮迹区**，跑道上**不少于 2 条**。

## Key Clauses

### 12.2.1 适用范围
- **12.2.1** 适用于**连续采集道面的国际平整度指数（IRI）**，可作为**工程建设阶段道面平整度质量验收的参考**，也可作为**运营管理阶段道面平整度状况技术评定**的技术依据。

### 12.2.2 仪器与材料技术要求
- **12.2.2.1** 系统由**承载车辆、距离传感器、纵断面高程传感器和主控制系统**组成；主控制系统完成**数据采集、传输、存储与计算**。
- **12.2.2.2** 技术要求和参数：
  - a) **测试速度：30 km/h～100 km/h**；
  - b) **采样间隔：≤500 mm**；
  - c) **传感器测试精度：0.5 mm**；
  - d) **距离标定误差绝对值：≤0.1%**；
  - e) **系统工作环境温度：0 ℃～60 ℃**。

### 12.2.3 方法与步骤
- **12.2.3.1 准备**
  - a) 选择**飞机主轮迹区域**布置测线；**在跑道上测试时测线数量应不少于 2 条**；
  - b) 确保行进路线上**没有任何障碍物**；
  - c) 测试道面**清洁，无燃油、杂物及其它污染物**；
  - d) 按手册对**距离传感器和高程传感器**进行校准；
  - e) 检查**轮胎气压**应达标准气压，**车胎清洁、不应粘附杂物**；
  - f) 检查系统各部分，**不应有明显的可视性破损**；
  - g) 打开电源，启动控制程序，检查各部分工作状态；
  - h) 距离传感器和相对高程传感器应**定期精度校准和标定**。
- **12.2.3.2 测试**
  - a) 按规定**预热时间**预热；
  - b) 测试车停在**起点前 50 m～100 m** 处，启动程序并设置测试状态；
  - c) 驾驶员按手册要求速度（**50 km/h～80 km/h**）驾驶，**避免急加速急减速**，尽可能**保持直线**；
  - d) 进入区段后启动**采集和记录**，及时准确输入**起终点**及特殊标记位置；
  - e) 驶出区段后停止采集，恢复设备至初始状态；
  - f) 检查**数据文件完整性**，若发现问题**重新测试**；
  - g) 关闭电源，结束测试。

### 12.2.4 计算和分析
- **12.2.4** 采集数据应以 **100 m 为计算区间长度**，用 **IRI 的标准计算程序**计算 IRI 值，单位 **m/km**。

### 12.2.5 报告
- a) 各测段（**用距离表示**）的 **IRI**；
- b) 测试范围内 IRI 的**最小值及其位置**；
- c) 测试范围内的**平均 IRI 和标准差**；
- d) 测试单位、测试人员、测试时间、天气状况。

## 关键指标

| 项目 | 限值/要求 |
|---|---|
| 测试速度（系统能力） | **30 km/h～100 km/h** |
| 实际驾驶速度 | **50 km/h～80 km/h** |
| 采样间隔 | **≤500 mm** |
| 传感器测试精度 | **0.5 mm** |
| 距离标定误差 | **≤0.1%（绝对值）** |
| 系统工作环境温度 | **0 ℃～60 ℃** |
| 计算区间长度 | **100 m** |
| IRI 单位 | **m/km** |
| 跑道测线数 | **≥2 条**（布于主轮迹区） |
| 起点停车距离 | **50 m～100 m** |

## 交叉引用

- **MH 5001-2021** —— 道面**IRI 限值**；12.2 提供实测值。
- **MH/T 5011-2019** —— 沥青道面**平整度**施工控制与竣工检测；IRI 是其主要验收指标之一。
- **MH 5006-2026** —— 水泥混凝土道面平整度验收；12.1.1 规定建设阶段宜用三米直尺（12.3），本方法在建设阶段仅作**参考**（12.2.1）。
- **MH/T 5086-2025** —— 平整度劣化（沉陷、错台、轮辙）后的维护处治。
- **12.3 三米直尺** —— 建设阶段的**裁定方法**；两者数据不可直接互换。
