# 第10章 10.1 一般要求

## Core Idea

强度与模量的现场原位测试有三条共同纪律：**结果只作参考、异常必须追因、数据必须归档**。特别是与实验室结果不一致时，不是简单取其一，而是**分析差异来源**。

## Key Clauses

- **10.1.1** 强度和模量现场原位测试结果可作为**工程建设阶段前期勘察与质量评定**的技术依据；**如测试结果和实验室测试结果存在差异，应分析差异的来源**。
- **10.1.2** 如现场测试结果**变异性过大**，应在**增加测点**的基础上，对现场测试位置的**代表性**进行分析，并对现场原位测试结果的**可靠性**进行评估。
- **10.1.3** 强度和模量现场测试结果应作为**工程验收资料**或者**机场管理的基础资料**存档。

## 交叉引用

- **MH/T 5025**《民用机场勘察规范》—— 10.1.1 的"前期勘察"阶段原位测试与勘察报告的衔接依据。
- **MH 5001-2021** —— 道面结构设计所需的**土基反应模量 K、综合回弹模量 E0、CBR** 等设计参数由本规程 10.2～10.4 提供。
- **MH/T 5010-2025**（沥青道面设计）—— 设计参数取值与本规程实测值的关系；实测与室内试验差异（10.1.1）在设计中应如何取舍须在设计文件中说明。
- **MH 5006-2026** —— 水泥混凝土面层施工前的**道基/基层验收**，10.2～10.4 的结果是验收资料之一（10.1.3）。
