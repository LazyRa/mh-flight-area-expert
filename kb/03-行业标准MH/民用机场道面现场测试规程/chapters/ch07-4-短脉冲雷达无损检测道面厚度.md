# 7.5 短脉冲雷达无损检测道面厚度试验方法

## Core Idea

用**探地雷达**连续、无损测面层厚度，同时能发现**裂缝、脱空**等内部损伤。核心控制点是**精度随探测深度衰减**（≤100 mm 时 ±3 mm，≥250 mm 时 ±10 mm），且**必须先用钻芯法校验**——雷达不是绝对量测，而是需要标定的间接量测。

## Key Clauses

### 7.5.1 适用范围
- **7.5.1.1** 适用于测定**面层厚度**；可用于**新建、改建道面工程质量验收**和**道面加铺工程的厚度调查**。
- **7.5.1.2** 适用于探测**道面及基础内部的损伤**（裂缝、脱空等），可作为**道面损坏调查**的方法。
- **7.5.1.3** 数据采集、传输、记录和处理均应由**专业软件自动控制**。
- **7.5.1.4** 雷达电磁波在道面介质中传播会**逐渐衰减**；探测精度和最大探测深度决定于**雷达系统参数**及**道面材料的电磁属性**。

### 7.5.2 仪器与材料技术要求
- **7.5.2.1** 测试系统由**天线、发射机、接收机、信号处理机、终端设备、承载车**组成（示意图见图 3）。
- **7.5.2.2** 技术要求与参数：
  - a) **探测精度**应满足**表 1**；
  - b) **距离标定误差绝对值 ≤0.1%**；
  - c) 设备工作温度 **0 ℃～40 ℃**；
  - d) **最小分辨层厚 ≤40 mm**；
  - e) 天线：带宽能适应所选天线频率；
  - f) 收发器：时间信号处理能力可适应所需测试深度。

**表 1 系统测量精度技术要求**（单位为毫米）

| 探测深度 | 测量误差 |
|---|---|
| **≤100** | **±3** |
| **100～250** | **±5** |
| **≥250** | **±10** |

### 7.5.3 方法与步骤
- **7.5.3.1 准备**
  - a) **距离标定**：承载车行驶**超过 20 000 km** 应更换轮胎并重新标定；**使用超过 1 年**也应标定；方法按厂商说明；
  - b) 安装雷达天线：按检测精度要求选**合理的天线频率**，按厂商方法安装并连好连接线；
  - c) **开机预热**：预热时间**不应少于厂商规定时间**；
  - d) 启动软件：将**金属板置于天线正下方**，启动控制软件标定程序获取参数；
  - e) 设置参数：设置**天线频率、采样率、时窗**；
  - f) **检测前校验**：应通过**钻芯法**对厚度检测结果进行**校验**。
- **7.5.3.2 测试**
  - a) 承载车停在测试起点前 **50 m～100 m**，开启**安全警示灯**，启动软件，缓慢加速至正常检测速度；
  - b) 进入测试区域后**维持正常检测速度**并开始测试；操作人员应及时记录道面下部**地梁、下穿管线或其它结构物**的具体位置；
  - c) 到达终点后停止采集；
  - d) 关闭电源，结束测试。
- **7.5.3.3 信号处理和图像识别**：选取合适软件处理信号生成地下结构图像，由**具有工程经验的技术人员**识别判断。

### 7.5.4 报告
- a) 厚度报告：检测区域的**厚度变化情况**和**厚度均值**；
- b) 内部损伤报告：**裂缝、脱空**等病害的具体位置及损坏程度；
- c) 注浆效果检测报告：原病害位置、**病害处治前后图像特征对比**；
- d) 必要时可包括专业软件的**原始测试数据**；
- e) 测试区域名称、设备型号、测试单位、人员、气候条件。

## 关键指标

| 项目 | 限值 |
|---|---|
| 探测深度 ≤100 mm | 误差 **±3 mm** |
| 探测深度 100～250 mm | 误差 **±5 mm** |
| 探测深度 ≥250 mm | 误差 **±10 mm** |
| 距离标定误差 | **≤0.1%（绝对值）** |
| 最小分辨层厚 | **≤40 mm** |
| 设备工作温度 | **0 ℃～40 ℃** |
| 距离标定周期 | 行驶 **>20 000 km** 或使用 **>1 年** |
| 起点停车距离 | **50 m～100 m** |
| 厚度结果校验 | **必须钻芯法校验** |

## 交叉引用

- **MH 5006-2026** —— 水泥混凝土面层**厚度验收**；雷达法可作为 5006 验收的**大面积普查**手段，但**争议部位须钻芯复核**（7.5.3.1 f）。
- **MH/T 5011-2019** —— 沥青面层厚度检测与加铺层厚度调查；7.5.1.1 的"加铺工程厚度调查"即对应 5011 的加铺设计前调查。
- **MH/T 5024** —— 脱空、裂缝等内部损伤是 SCI/PCI 评价的输入；雷达是 8.3 损坏调查的**辅助手段**（7.5.1.2）。
- **MH/T 5041-2019**（环氧沥青）—— 加铺层厚度与层间状态检测可借助雷达；环氧沥青层介电特性差异需另行标定。
- **7.3 探坑及钻芯法** —— 雷达的**校验基准**（7.5.3.1 f）。
