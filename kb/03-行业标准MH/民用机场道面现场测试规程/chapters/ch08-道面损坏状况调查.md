# 第8章 道面损坏状况调查

## Core Idea

本章解决"**看多少、看什么、怎么记**"。核心是**抽样统计**：以"单元"为基本单位，按 95% 置信度用公式算最小样本数，跑道最低抽样率 **40%**、滑行道和机坪 **15%**，抽样后还要用实测 PCI 标准差**回代校验**。损坏类型按水泥混凝土/沥青两套分类记录，PCI 的算法不在本章，而是交给 **MH/T 5024**。

## Key Clauses

### 8.1 适用范围
- **8.1.1** 适用于**机场运营管理阶段**对道面进行**损坏等级评定**；飞行区**服务车道和巡场道路**的损坏等级评定可参照执行。
- **8.1.2** 评定结果可作为机场管理机构制订**道面年度维护计划**的技术依据，也可作为**是否实施道面大中修工程**的决策依据。
- **8.1.3** 道面**日常巡查**（包括**每日的道面巡视检查**和**每季度的道面徒步检查**）和**道面详细调查**宜按本方法实施。

### 8.2 仪器和材料技术要求
- a) 长度量具：**钢卷尺、皮尺、钢尺**；
- b) 错台或轮辙量具：**三米直尺、塞尺**；
- c) **规范格式的纸质记录表格、数码相机**；
- d) 记录板、粉笔等；**夜间调查应配备照明设备**。

### 8.3 方法和步骤

**8.3.1 准备（抽样）**
- a) 调查应在运营管理阶段**飞行区场地划分方法**基础上实施，以**单元**为基本单位，分析和评价"**区域**"及"**部位**"的损坏状况；
- b) 可采用**抽样调查**确定"单元"，必要时**全面调查**；抽样方法：
  1) 随机抽样以各"区域"内所有单元为总体，**最小单元数目应满足 95% 置信度要求**；**跑道最低抽样率不宜小于 40%**，**滑行道和停机坪不宜小于 15%**；
  2) 可指定**附加样本单元**——具有特殊损坏类型（如开挖补块）、不反映道面状况均一性但对损坏状况有重大影响的单元；
  3) 按**公式(5)** 计算初定样本容量，**含小数时取大于该数的最小整数**：

```
n = N·s² / [ e²·N/4 + s² ]        ……………… (5)
```

  - **n** —— 抽样的最小单元数目；**N** —— 区域内单元总数；**s** —— PCI 统计的标准差；**e** —— PCI 计算时的允许误差，**允许误差值在 ±5 范围内**。
  - 注：**沥青道面 s 值可初定为 10，水泥混凝土道面 s 值可初定为 15**；获得实际 PCI 数据后应以实际标准差代入。

  4) 按**公式(6)** 计算抽样间隔，**不能整除时取较小的整数**：

```
i = N / n        ……………… (6)
```

  - **i** —— 抽样单元间隔；**N** —— 区域内单元总数；**n** —— 抽样最小单元数。
  - 即在第 1～i 个单元中随机抽取第 **x** 个单元，随后**每间隔 i 个单元**抽取一个，随机样本序号为 **x，x+i，x+2i，……**；若随机抽样中遇到**附加样本单元**，应**替换为等数量的普通单元**。

  5) 对抽取样本单元进行损坏调查并计算 PCI，按**公式(7)** 计算 PCI 标准差：

```
s = √[ Σ(i=1→n)(PCIi − PCIj)² / (n − 1) ]        ……………… (7)
```

  - **s** —— 调查单元 PCI 的标准差；**PCIi** —— 区域内第 i 个调查单元的 PCI 值；**PCIj** —— 被调查单元 PCI 的**平均值**；**n** —— 调查单元数目。

  6) 将实际标准差 s 代入**公式(5)** 得实际应抽样单元数 **n1**：若 **n > n1**，抽样率满足要求；若 **n < n1**，需在整个区域内**再随机抽样 (n1−n) 个单元**调查，重复步骤直至满足条件。

**8.3.2 调查步骤**
- a) 现场确认**调查单元**及其**现场位置标识**；
- b) 徒步巡视单元内各种损坏现象：**水泥混凝土道面调查选定单元内的所有板块**，**沥青道面调查选定单元内的所有道面**；
- c) **水泥混凝土道面及上面层为水泥混凝土的复合道面**，损坏分 5 类：
  1) **面层断裂类**：纵向、横向、斜向裂缝，角隅断裂，破碎板或交叉裂缝；
  2) **竖向变形类**：沉陷或错台；
  3) **接缝类**：胀裂，嵌缝料损坏，接缝破碎，唧泥和板底脱空；
  4) **表层类**：耐久性裂缝，收缩裂缝，坑洞，起皮、网裂和龟裂，板角剥落；
  5) **修补类**：小补丁（修补面积 **<0.5 m²**）、大补丁（**>0.5 m²**）和开挖补块；
- d) **沥青道面及上面层为沥青混凝土的复合道面**，损坏分 4 类：
  1) **裂缝类**：龟裂，不规则裂缝，纵向、横向裂缝，反射裂缝，滑移裂缝；
  2) **表面损坏类**：松散和老化，泛油，集料磨光；
  3) **变形类**：沉陷，隆起，车辙，搓板，道面推挤；
  4) **其它类**：喷气烧蚀，油料腐蚀，补丁和开挖补块；
- e) 记录**损坏的相对位置**：水泥混凝土道面以**相对于现场标识位置的板块行列编号**记录；沥青道面记录**损坏中心点距单元起始点的纵、横向距离**；
- f) 记录**损坏类型、损坏程度、损坏量**；记录要求分别**参照 MH/T 5024**；
- g) 现场巡视记录完成后**确认下一个调查单元**，直至完成计划中所有单元；
- h) 各单元调查结果**按区域汇总**，宜**拍摄照片备查**；
- i) 应按 **MH/T 5024** 中的道面 **PCI 计算方法**计算各道面单元 PCI。

### 8.4 报告
- a) 调查区域**编号、道面结构、使用年限、航空交通量**等信息；
- b) 道面损坏状况**调查表**及**损坏统计结果**；
- c) 道面**单元、区域、部位**的 PCI 计算结果；
- d) 道面**损坏状况等级评价结果**；
- e) **损坏原因分析**以及**处理建议**；
- f) 测试单位、测试人员、测试时间、天气状况。

## 关键指标

**表 8.3 抽样与调查控制参数**

| 项目 | 限值/要求 |
|---|---|
| 置信度 | **95%** |
| 跑道最低抽样率 | **≥40%** |
| 滑行道、停机坪最低抽样率 | **≥15%** |
| PCI 允许误差 e | **±5 范围内** |
| s 初定值（沥青道面） | **10** |
| s 初定值（水泥混凝土道面） | **15** |
| 小补丁 / 大补丁分界 | **0.5 m²** |
| 日常巡查频次 | **每日巡视 + 每季度徒步检查** |
| PCI 算法依据 | **MH/T 5024** |

## 交叉引用

- **MH/T 5024**《民用机场道面评价管理技术规范》—— 本章的**方法出口**：损坏类型/程度/量的记录要求（8.3.2 f）与 **PCI 计算**（8.3.2 i）均按 5024 执行；DV/CDV/HDV/SCI 等术语也来自 5024。
- **MH/T 5086-2025** —— 调查结果直接支撑**维护计划**与**大中修决策**（8.1.2），5086 规定维护等级与作业频次，两者构成"评—修"闭环。
- **CCAR-139B** —— 8.1.3 的**每日巡视检查**与**每季度徒步检查**是 CCAR-139B 对机场管理机构的最低要求，本章规定其技术方法。
- **民航规〔2024〕3号**《运输机场飞行区场地管理办法》—— 巡查频次与记录归档的管理依据。
- **MH 5001-2021** —— 道面"区域/部位"划分与单元尺寸的几何基础。
- **7.5 短脉冲雷达** —— 板底脱空、裂缝等**内部损伤**可用雷达辅助确认（7.5.1.2）。
