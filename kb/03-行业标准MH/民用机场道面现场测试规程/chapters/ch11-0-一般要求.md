# 第11章 11.1 一般要求

## Core Idea

抗滑性能测试分**定点式**与**连续式**两类。规程给出明确的**方法优选顺序**：评价道面抗滑性能**优先用连续式摩擦系数法**（制动式摩阻设备），且**不同方法的测试结果不能互相换算**，必须按各自的评定标准判定。

## Key Clauses

- **11.1.1** 跑道抗滑性能测试可采用**定点式**抗滑性能测试方法和**连续式**抗滑性能测试方法。
- **11.1.2** **宜优先采用连续式摩擦系数测试方法**评价道面抗滑性能；**宜采用制动式摩阻测试设备**测试跑道摩擦系数。
- **11.1.3** **不同抗滑性能测试方法的测试结果应符合相应的评定标准**。

## 交叉引用

- **MH 5001-2021** —— 跑道摩擦系数、构造深度的**评定标准值**来源；11.1.3 即"各方法对各自的标准"。
- **CCAR-139B** —— 跑道摩擦系数测试的**频次与最低值通报**要求（运行管理层面）。
- **MH/T 5086-2025** —— 摩擦系数不足时的**除胶、打磨**等恢复性维护作业。
- **MH/T 5011-2019 / MH 5006-2026** —— 沥青/水泥混凝土面层**构造深度**的施工控制指标（11.4、11.5 为其检测方法）。
