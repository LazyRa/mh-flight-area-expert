# 13.4 核子密湿度仪测定压实度试验方法

## Core Idea

用**γ 射线（密度）+ 中子（含水率）**无损快速测密度与含水率。两条路线：**散射法**（贴近表面，适沥青等难成孔材料）、**直接透射法**（打孔插杆，适土基基层，测厚 **≤0.3 m**）。可信前提是**每年标定 + 每日标准计数 + 与钻芯/环刀/灌砂法对比（≥15 点，R ≥0.95）**。同时是**辐射安全**作业，测时人员须退至 **2 m 以外**、周围 **10 m** 内不得有其它辐射源。

## Key Clauses

### 13.4.1 适用范围
- **13.4.1.1** 适用于现场用核子密湿度仪以**散射法或直接透射法**测定**土基、基层或道面材料**的**密度和含水率**，并计算施工压实度。适用材料包括**各类土、碎石、土石混合物、沥青混合料和非硬化水泥混凝土**等。
- **13.4.1.2** 仪器按规定方法**标定**，并经**质检部门核定认可**后，检测结果可作为**工程建设阶段工程质量评定和竣工验收**的技术依据。
- **13.4.1.3** 测定**沥青混合料等难以成孔材料**宜用**散射法**（可测层厚取决于仪器性能）；测定**土基、基层等容易成孔材料**宜用**直接透射法**（**可测层厚宜不大于 0.3 m**）。
- **13.4.1.4** 属**无损测试**，通过对同一位置**重复检测**，可作为判定**现场压实次数或压实方法是否合理**的技术依据。
- **13.4.1.5** 现场使用时应**加强测试人员的保护**，减少仪器使用时对周边人员的**辐射影响**。

### 13.4.2 仪器与材料技术要求
- **13.4.2.1 干扰因素**：
  - a) 仪器对**靠近表层材料**的密度最为敏感；当测试材料表面与仪器底部之间存在**空隙**时，散射法结果可能存在**表面偏差**，此时**宜改用直接透射法**；
  - b) 材料的**粒度、级配、均匀性及组成成分**对密度影响较小；**结晶水或有机物**对**含水率**影响明显（如**高岭土、云母、石膏、石灰**），这类材料的含水率宜与其它方法比较并**必要修正**；
  - c) **沥青道面刚摊铺完成后**测定时，**仪器放置时间应尽可能短**，以减少高温影响；
  - d) 测试过程中，**周围 10 m 范围内不应存在其它任何辐射源**。
- **13.4.2.2 标定**：
  - e) **每年**应对核子密湿度仪进行标定，由**仪器生产厂家或有资质的独立服务机构**进行；
  - f) **仪器维修后应标定**才能使用；测定过程中对结果有疑义，宜**首先重新标定**；
  - g) 标定后，**所有标定块上的每一测试深度上的标定响应应在 ±16 kg/m³ 范围内**。
- **13.4.2.3** 应定期检查是否符合国家**健康保护和安全使用**标准：
  - **密度测定范围 1 120 kg/m³～2 730 kg/m³**，**测定误差宜不超过 ±30 kg/m³**；
  - **含水率测量范围 0～640 kg/m³**，**测量误差宜不超过 ±15 kg/m³**。
  - 主要部件：a) **γ 射线源**（双层密封同位素源，如**铯-137、钴-60、镭-226**）；b) **中子源**（如**镅-241-铍**）；c) **探测器**（γ 探测器如 **G-M 计数管**，或热中子探测器如**氦-3 管**）；d) **读数显示设备**（液晶显示器、脉冲计数器、数率表或直接读数表）；e) **标准计数块**（密度和含氢量均匀不变，用于测定仪器运行状况并提供射线计数参考标准）；f) **钻杆**（打测试孔，插探测杆）；g) **安全防护设备**（符合国家规定）；h) **刮平板**、钻杆和接线等。
- **13.4.2.4** 其它：**0.15 mm～0.30 mm 细砂**、天平或台秤、毛刷等。

### 13.4.3 方法与步骤
- **13.4.3.1 准备**
  - a) **安全事项**：
    1) 启动仪器开始工作时，**测试人员应退至距离仪器 2 m 以外**；
    2) 使用完毕后**手柄置于安全位置**，装入专用仪器箱，放置在符合**核辐射安全规定**的地方；
    3) 仪器应由**相关部门审查合格的专人保管**，保管及使用人员应符合国家关于**核辐射检测**的规定；
  - b) **每天使用前用标准计数块测标准值**：
    1) 接通电源，按说明书要求**预热**；
    2) 将仪器平稳置于标准计数块上，按要求**标准化计数**；若计数**超过规定限值**，应检查方法和环境，符合要求后**再测一次**；若第二次仍超限，则**仪器应修理并标定**；
  - c) **与破坏性方法比对**：
    1) 选测试点，**构造纹理较大的表面应用细砂填平**，然后将仪器放置、**转动几下**或用**刮平板平刮几下**，确保达到测试条件后测定密度并记录；
    2) 在该位置用**钻孔法（或环刀法、探坑灌砂法）**测定材料密度并记录；
    3) **密度测试数量不小于 15 点**，回归分析不同方法测定密度之间的相关关系，**相关系数不小于 0.95** 时，可采信核子密湿度仪结果；
    4) 核子仪测定结果的**精度应通过比较试验结果确定**；
  - d) 建设阶段以**一个分部工程**作为基本测定单位；
  - e) **散射法**测定时，测点距道面边缘或其它物体的**最小距离不小于 0.3 m**；测点表面尽可能平整，参考**图 28** 用**细砂填平**凹凸空隙，确保仪器底部与测试表面**紧密接触**；
  - f) **标准密度取值**：**沥青混合料以施工当天的实测沥青混合料最大理论密度**作为标准密度；**土基和基层材料采用重型标准击实法测定的最大干密度**作为标准密度，并测最佳含水率；
  - g) **直接透射法**测定时，参考**图 29** 用**导板和钻杆**在测试位置打孔：打一个**垂直**测试孔（垂直度以**插入探测杆后仪器在测定表面上不倾斜**为准），**孔深应大于探测杆达到的测试深度**；成孔后将探测杆插入，仪器安放稳固。
- **13.4.3.2 试验**
  - a) 按说明书要求时间**预热**；**散射法**测沥青混合料面层密度时，参考**图 30** 将仪器平稳置于测试点，启动后**人员须退至 2 m 以外**，按选定测定时间测量，到时**读取数值并迅速关机**；**一个测点测试次数不小于 13 次**，取各次结果**平均值**；
  - b) **直接透射法**测定时，参考**图 31** 将放射源棒插入预先打好的孔内，启动后**人员退至 2 m 以外**，按选定时间测量，到时读数并迅速关机；**一个测点测试次数不小于 13 次**，取平均值；
  - c) **不同型号仪器操作步骤可能不同**，可参照仪器使用说明书操作。

### 13.4.4 计算和分析
- **13.4.4** 按**公式(34)** 或**公式(35)** 计算干密度和压实度：

```
ρd = ρw / (1 + ω)        ……………… (34)
```

- **ρd** —— 由核子密湿度仪测定的材料**密度**，kg/m³；
- **ρw** —— 试样的**湿密度**，kg/m³；
- **ω** —— **含水率，以小数表示**。

```
K = (ρd / ρc) × 100        ……………… (35)
```

- **ρd** —— 由核子密湿度仪测定的材料密度，kg/m³；
- **K** —— 测试点的**施工压实度（%）**；
- **ρc** —— 测试材料的**标准密度**，kg/m³。

### 13.4.5 报告
- a) **核子密湿度仪的型号**；b) 试验地点；c) **现场测试温度**；d) **测定材料类型**；e) **道面结构层厚度**；f) **测试深度**；g) **测定材料干密度**；h) **压实度**；i) 测试单位、测试人员、测试时间、天气状况。

## 关键指标

| 项目 | 限值/要求 |
|---|---|
| 密度测定范围 | **1 120 kg/m³～2 730 kg/m³** |
| 密度测定误差 | 宜 **≤±30 kg/m³** |
| 含水率测量范围 | **0～640 kg/m³** |
| 含水率测量误差 | 宜 **≤±15 kg/m³** |
| 标定周期 | **每年**（厂家或有资质机构） |
| 标定响应偏差 | **±16 kg/m³**（各标定块各深度） |
| 直接透射法可测层厚 | 宜 **≤0.3 m** |
| 散射法测点距边缘 | **≥0.3 m** |
| 辐射源安全距离 | 人员退至 **2 m 以外** |
| 周边辐射源限制 | **10 m 范围内不得有其它辐射源** |
| 对比试验点数 | **≥15 点** |
| 对比相关系数 | **≥0.95** |
| 单点测试次数 | **≥13 次**取平均 |
| 填缝细砂粒径 | **0.15 mm～0.30 mm** |
| 标准密度（沥青） | 施工当天**实测最大理论密度** |
| 标准密度（土基/基层） | **重型击实法最大干密度** |
