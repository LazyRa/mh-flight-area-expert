## 覆盖范围

民用机场**新建、改建、扩建和维护工程**中水泥混凝土道面**接缝材料**的设计、施工与维护：

1. **技术要求**：填缝密封材料（硅酮/聚氨酯/聚硫/改性硅烷）、预塑嵌缝条、背衬条、胀缝板、界面剂
2. **施工和维护**：新建道面接缝材料施工（填缝料/嵌缝条/胀缝板）与既有道面接缝材料维护（六类失效 + 四级判定）
3. **质量检验**：材料进场检验（3 份样品）+ 施工/维护实测项目
4. **附录 A** 室内试验方法（A.1–A.15）、**附录 B** 现场试验方法（B.1–B.2）、**附录 C** 施工常用设备

**不覆盖**：道面接缝的**构造设计与缝槽尺寸**（见 MH/T 5004）、接缝的**切缝施工工艺**（见 MH 5006）、道面整体维护管理（见 MH/T 5084）。

## 本规范的定位（条文说明）

把此前分散在 **MH/T 5004（设计）**、**MH 5006（施工）**、**MH/T 5084（维护）** 三本规范中涉及接缝材料的条款**统一纳入**，形成"材料—施工—维护—检验"一条线。

| **3.1.1** | 填缝密封材料**必须配背衬条**；预塑嵌缝条可单独用（配界面剂）；胀缝板专用于胀缝 |
| **3.1.2** | 六项性能：防水、**抗异物嵌入（FOD）**、弹性伸长、粘结、耐老化、高温不溢出低温不脆裂 |
| **3.1.3** | 跑道/快滑选耐候更好；站坪选**耐油**；强紫外区选**抗紫外老化** |
| **3.1.4** | 每批每品种须**出厂合格证 + 有资质机构检验报告**；进口材料须**报关单 + 中文资料** |
| **表 3.2.2** | 表干时间 **≤5 h（新建）/≤2 h（运行）**；锥入度 **≤60**；低温拉伸量 **≥20 / ≥10 mm**；耐油质量变化 **≤30%**；加热质量变化 **≤3%**；低温抗裂 −30 ℃ 弯 90° 不开裂 |
| **3.3.1** | 预塑嵌缝条 **≥5 孔**多孔结构；典型缝槽宽 6/8/10/12/25 mm 对应外形宽 11/15/18/21/41 mm |
| **3.3.2** | 压缩应力（25%）标准条件 **≥0.08 MPa**；老化/浸油后 **≥0.05 MPa** |

| **表 3.3.4** | 界面剂粘度 **≥1500 Pa·s**；不挥发物 **≥30%**；橡胶-混凝土剪切 **≥0.27 MPa** |
| **3.4.2** | 背衬条宽度比缝槽**大 2～5 mm** |
| **3.5.3** | 胀缝板厚 = 胀缝宽 **±2 mm**；泡沫类压缩应力 0.2–0.6 MPa、弹性恢复 **≥90%**；沥青纤维板 2.0–10.0 MPa、**≥65%** |

| **4.2.4** | 胀缝板：整块、**贯通全板厚**、直立挤压、底面平齐无空隙 |
