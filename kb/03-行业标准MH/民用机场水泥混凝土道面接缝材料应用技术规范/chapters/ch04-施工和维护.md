# 4 施工和维护

## Core Idea

分**新建**与**既有**两条线；核心是**缝槽清理 → 材料施工 → 成品保护**，以及既有道面的**六类失效 + 四级判定（好/中/次/差）**。

## Key Clauses

### 4.1 一般规定
- **4.1.1** 应按**材料进场检验、储存运输、设备人员配备、现场条件确认、施工工序实施、成品保护、检验评定**七环节编方案
- **4.1.2** 缝槽清理应采用**清缝机**，并检查缝槽是否**坚实、干净、干燥**
- **4.1.3** **降雨天气或环境气温低于 5 ℃** 时不宜施工或维护

### 4.2 新建道面接缝材料施工
- **4.2.1** 应在**缝槽清理后**按材料类型实施
- **4.2.2 填缝密封材料**
  1. 背衬条安装**深度**符合设计；安装**防水背衬条**后，灌注前须做**接缝位置渗水性能试验**
  2. 灌注应采用**机械灌缝机具**，宜**连续灌注**
  3. 双组分材料应**按规定比例配比并搅拌均匀**
  4. 灌注应**饱满、密实、与缝壁粘结牢固**
  5. 施工表面应**低于面层表面**
  6. 及时清除洒溢材料
  7. **表干前应封闭交通**
- **4.2.3 预塑嵌缝条**
  1. 试验段须按附录 B.1 做**压入拉伸性能现场试验**（符合 3.3.3）
  2. 缝槽两侧**均匀涂刷界面剂**
  3. 采用**压条机**压入；**先纵缝后横缝**，交叉位置涂界面剂
  4. 表面应**低于面层表面**
  5. 及时清除洒溢界面剂
- **4.2.4 胀缝板**
  1. 同一板块胀缝应采用**整块**胀缝板
  2. 非连续浇筑时，胀缝板应**粘结在先浇板缝一侧**，粘结牢固严密，**验收合格后**浇另一侧
  3. 底面与板底**平齐无空隙**；缝中应**直立且处于挤压状态**
  4. 道肩切缝形成胀缝时，**清理间隙后**放置胀缝板
  5. 胀缝板应**完整贯通整个板厚**，两侧混凝土**完全分隔**

### 4.3 既有道面接缝材料维护
- **4.3.1** 应定期检查与评定；宜建立**维护信息化台账**
- **4.3.2 六类失效**
  1. **封水失效**（封水性能失效）
  2. **刺入破坏**（碎石或杂物嵌入缝槽）
  3. **黏聚性破坏**（材料内部开裂、黏聚性丧失）
  4. **粘附性失效**（与缝槽侧壁分离）
  5. **挤出**（从缝槽挤出）
  6. **其他**（缝槽长草、油污等化学侵蚀）
- **4.3.3** 采用**人工目视调查 + 接缝位置渗水性能试验**（附录 B.2）检查评定
- **4.3.4 表 4.3.4 性能分级（按失效接缝长度占比）**

| 失效占比 | 等级 | 维护建议 |
|---|---|---|
| **≤5%** | **好** | 无需维护 |
| **5%～15%** | **中** | 重点关注、经常检查 |
| **15%～30%** | **次** | **安排更换计划** |
| **>30%** | **差** | **尽快实施更换** |

  注：占比 = 出现 6 类失效的接缝长度 ÷ 总检查区域接缝长度
- **4.3.5** 维护应在**缝槽清理后**按材料类型实施
- **4.3.6** 填缝密封材料维护时，应**彻底清除**缝槽内已有材料与背衬条
- **4.3.7** 预塑嵌缝条维护时，应**现场量测缝槽宽度**并按表 3.3.1 选型；彻底清除原有材料

## 常被问到的数值

| 问题 | 答案 |
|---|---|
| 施工气温下限 | 5 ℃（雨天不宜） |
| 填缝料表面 | 低于面层表面 |
| 嵌缝条压入顺序 | 先纵缝后横缝 |
| 性能分级阈值 | 5% / 15% / 30% |
| 达到"次"怎么办 | 安排更换计划（"差"则尽快更换） |
