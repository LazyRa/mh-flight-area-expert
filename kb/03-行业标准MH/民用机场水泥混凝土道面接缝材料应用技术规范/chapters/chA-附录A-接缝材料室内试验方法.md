# 附录 A 接缝材料室内试验方法（规范性）

## Core Idea

15 个试验方法（A.1–A.15），覆盖**填缝密封材料、预塑嵌缝条、背衬条**的全部性能指标；A.1 是**所有试验的基材制备**前提。

## Key Clauses

| 条 | 试验项目 | 对应指标 |
|---|---|---|
| **A.1** | **试验基材制备** | 所有填缝密封材料/防水背衬条试验的前置条件（3.2.2 注 a、3.4.3 注） |
| A.2 | **表干时间** | 新建 ≤5 h；运行机场 ≤2 h |
| A.3 | **25 ℃ 锥入度** | ≤60（0.1 mm） |
| A.4 | **低温拉伸量** | <−3 ℃ 地区 ≥20 mm；−3～2.5 ℃ ≥10 mm；防水背衬条 ≥30 mm |
| A.5 | **冷拉-热压条件定伸粘结性**（拉伸强度损失率） | 填缝料 ≤35%；防水背衬条 ≤20% |
| A.6 | **人工光源-水-热暴露下定伸粘结性** | 无粘附性失效或粘聚性破坏 |
| A.7 | **浸油条件下质量变化率** | 填缝料 ≤30%；防水背衬条 ≤±30% |
| A.8 | **浸油后拉伸强度损失率** | 填缝料 ≤20%；防水背衬条 ≤20% |
| A.9 | **加热条件下质量变化率** | 填缝料 ≤3%；防水背衬条 ≤±3% |
| A.10 | **高温拉伸强度损失率** | ≤35% |
| A.11 | **低温抗裂性** | −30±2 ℃ 沿 φ25 mm 圆棒弯曲 90°，不开裂、不分层、与铝片粘附不失效 |
| A.12 | **标准条件下压缩应力**（25% 变形） | 预塑嵌缝条 **≥0.08 MPa** |
| A.13 | **冷热循环-人工光源-浸水条件下压缩应力** | **≥0.05 MPa** |
| A.14 | **浸油条件下压缩应力** | **≥0.05 MPa** |
| A.15 | **预塑嵌缝条低温抗裂性** | −30±2 ℃ 弯曲 90° 不开裂 |

## 使用提示

- 附录 A 是**规范性附录**，试验结果直接决定材料是否合格
- **具体试验步骤、试件尺寸、养护条件以正本为准**（本模块只做指标与方法的对应索引，不复制操作细节，避免因文本提取失真造成误用）
- 需要做哪些项由 3.2.2 / 3.3.2 / 3.4.3 的注决定：**低温项**看年平均月最低气温是否 <0 ℃，**耐油项**看是否为易受油料腐蚀区域
