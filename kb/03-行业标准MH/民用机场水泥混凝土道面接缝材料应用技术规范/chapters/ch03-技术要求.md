# 3 技术要求

## Core Idea

四类材料的指标表：**填缝密封材料（表 3.2.2）**、**预塑嵌缝条（表 3.3.1 尺寸 + 3.3.2 性能 + 3.3.4 界面剂）**、**背衬条（3.4.2 尺寸 + 3.4.3 防水型）**、**胀缝板（表 3.5.3）**。

## Key Clauses

### 3.1 一般规定
- **3.1.1 选材规则**：应选**填缝密封材料、预塑嵌缝条、胀缝板和背衬条**；填缝密封材料须与背衬条配合；预塑嵌缝条可单独使用；胀缝板专用于胀缝
- **3.1.2 性能六项要求**：① 良好**防水**性能；② **抗异物嵌入**（防硬质杂物嵌入，降低 **FOD** 风险）；③ 良好**弹性与伸长率**；④ 良好**粘结**性能；⑤ 优异**耐老化**（紫外线、雨水、温度、航空燃油、除冰液）；⑥ **高温不溢出、低温不脆裂**
- **3.1.3 按气候与环境选材**：① 跑道/快滑等选**耐候性更好**的材料；② 易受油料腐蚀的**站坪**区域选**耐油**材料；③ 强紫外线地区选**抗紫外老化**材料
- **3.1.4 证明文件**：每批次每品种提供**出厂合格证 + 检验报告**（由有资质机构出具，含主要性能指标检测结果）；**进口材料**还须提供**海关报关单**及**中文版**合格证、检验报告与技术资料
- **3.1.5 运输贮存**：远离热源火源、避免雨淋热晒、不得接触可致溶解或破坏的化学品；干燥通风贮存；**不得超过产品有效期**

### 3.2 填缝密封材料
- **3.2.1** 宜选**硅酮类、聚氨酯类、聚硫类、改性硅烷类**
- **3.2.2 表 3.2.2 性能要求**

| 项目 | 指标 |
|---|---|
| **表干时间** | 新建道面 **≤5 h**；运行机场 **≤2 h** |
| **25 ℃ 锥入度** | **≤60（0.1 mm）** |
| **低温拉伸量** | 年最冷月均气温 **<−3 ℃ → ≥20 mm**；**−3～2.5 ℃ → ≥10 mm** |
| 定伸粘结性 | 冷拉-热压拉伸强度损失率 **≤35%**；人工光源-水-热暴露下**无粘附性失效或粘聚性破坏** |
| 耐油性 | 浸油质量变化率 **≤30%**；浸油后拉伸强度损失率 **≤20%** |
| 耐候性 | 加热质量变化率 **≤3%**；高温拉伸强度损失率 **≤35%**；**低温抗裂：−30±2 ℃ 沿 φ25 mm 圆棒弯曲 90°，不开裂、不分层、与铝片粘附不失效** |

注：a 试验基材制备见附录 A.1；b 年平均月最低气温 <0 ℃ 时做低温项；c 易受油料腐蚀区域做耐油项。

### 3.3 预塑嵌缝条
- **3.3.1** 应为**不少于 5 孔的多孔结构**；尺寸按表 3.3.1 选（典型缝槽宽 6/8/10/12/25 mm 对应外形宽 11/15/18/21/41 mm，最小深度 20/30/35/38/60 mm）
- **3.3.2 性能**：宽度偏差 **≤±0.5 mm**、高度偏差 **≤±2.0 mm**；标准条件压缩应力（25% 变形）**≥0.08 MPa**；冷热循环-人工光源-浸水条件下 **≥0.05 MPa**；浸油条件下 **≥0.05 MPa**；低温抗裂 −30±2 ℃ 弯曲 90° 不开裂
- **3.3.3 现场压入拉伸性能**（附录 B.1）：压入缝槽后**即时拉伸率与 24 h 拉伸率 ≤1%**；两次压入后**长度变化 ≤±5 mm**
- **3.3.4 界面剂（表 3.3.4）**：粘度 **≥1500 Pa·s**；不挥发物 **≥30%**；橡胶-混凝土粘结面剪切强度 **≥0.27 MPa**；橡胶-橡胶粘结面 **≥0.3 MPa**

### 3.4 背衬条
- **3.4.1** 良好弹性与柔韧性、**不吸水**、耐酸碱、高温变形小；形状宜**圆柱体**
- **3.4.2** 宽度应比缝槽**大 2～5 mm**；宽/厚/直径偏差 **≤±0.5 mm**，长度偏差 **≤±10 mm**
- **3.4.3 防水背衬条**外表面宜包覆长期防水材料，其防水材料应满足：低温拉伸量 **≥30 mm**；冷拉-热压拉伸强度损失率 **≤20%**；耐油质量变化率 **≤±30%**、浸油后拉伸强度损失 **≤20%**；加热质量变化率 **≤±3%**、高温拉伸强度损失 **≤35%**；低温抗裂同 3.2.2

### 3.5 胀缝板
- **3.5.1** 应适应胀缝体积变化，具有**较高弹性和良好耐久性**
- **3.5.2** 材料应采用**聚乙烯泡沫塑料板、泡沫橡胶板或沥青纤维板**等
- **3.5.3** 厚度应为**胀缝宽度 ±2 mm**；表 3.5.3：

| 指标 | 聚乙烯泡沫塑料板/泡沫橡胶板 | 沥青纤维板 |
|---|---|---|
| 压缩应力 | **0.2～0.6 MPa** | **2.0～10.0 MPa** |
| 弹性恢复率 | **≥90%** | **≥65%** |
| 挤出量 | **<5.0 mm** | **<3.0 mm** |
| 弯曲荷载 | 5～50 N | 5～40 N |

## 常被问到的数值

| 问题 | 答案 |
|---|---|
| 填缝料表干时间 | 新建 ≤5 h、运行机场 ≤2 h |
| 锥入度 | ≤60（0.1 mm） |
| 低温拉伸量 | <−3 ℃ 地区 ≥20 mm；−3～2.5 ℃ ≥10 mm |
| 预塑嵌缝条孔数 | ≥5 孔 |
| 嵌缝条压缩应力（25%） | ≥0.08 MPa（标准）、≥0.05 MPa（老化/浸油后） |
| 背衬条宽度 | 比缝槽宽 2～5 mm |
| 胀缝板厚度 | 胀缝宽 ±2 mm |
| 胀缝板弹性恢复率 | 泡沫类 ≥90%、沥青纤维板 ≥65% |
