# 附录 C 接缝材料施工常用设备（资料性）

## Core Idea

列出接缝施工与维护的常用机具清单，便于配置设备与编制方案。

## Key Clauses

本附录为**资料性附录**，按第 4 章施工工序梳理常用设备，主要包括：

| 工序 | 对应设备（正文提及） |
|---|---|
| **缝槽清理** | **清缝机**（4.1.2 明确要求采用） |
| **填缝密封材料灌注** | **机械灌缝机具**（4.2.2-2 要求机械灌注、宜连续灌注） |
| **预塑嵌缝条压入** | **压条机**（4.2.3-3 明确要求） |
| **界面剂涂刷** | 涂刷工具（4.2.3-2 要求均匀涂刷） |
| **胀缝板安装** | 粘结与固定工具（4.2.4） |
| **维护作业** | 清除旧材料、量测缝宽等配套工具（4.3.6 / 4.3.7） |

## 使用提示

- 附录 C 只给**设备类别**，不给型号与参数；具体选型按工程量、缝槽尺寸与材料类型确定
- 正文强制要求的三件设备是：**清缝机、机械灌缝机具、压条机**
