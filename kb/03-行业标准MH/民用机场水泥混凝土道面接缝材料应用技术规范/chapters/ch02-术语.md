# 2 术语

## Core Idea

9 条术语，把**三类填缝密封材料 + 预塑嵌缝条 + 背衬条 + 胀缝板 + 界面剂**分清。

## Key Clauses

| 条 | 术语 | 要点 |
|---|---|---|
| 2.0.1 | **填缝密封材料** | 填充缝槽、防止**地表水、除冰化学品、不可压缩物质**（砂粒石子）进入；具施工流动性或可塑性的弹性材料；含**硅酮类、聚氨酯类、聚硫类、改性硅烷类** |
| 2.0.2 | 硅酮类 | 以**聚硅氧烷**为主要成分 |
| 2.0.3 | 聚氨酯类 | 以**聚氨基甲酸酯**为主要成分 |
| 2.0.4 | 聚硫类 | 以**液态聚硫橡胶**为主要成分，配固化剂等 |
| 2.0.5 | 改性硅烷类 | 以**改性硅烷聚合物**为主要成分 |
| 2.0.6 | **预塑嵌缝条** | **多腔体或波纹状**的预成型弹性密封材料，常由**氯丁橡胶**或其他合成橡胶制成 |
| 2.0.7 | **背衬条** | 橡胶条、发泡聚氨酯或微孔泡沫塑料等**可压缩弹性材料**；分**普通背衬条**与**防水背衬条** |
| 2.0.8 | **胀缝板** | 预制**可压缩材料**，装于胀缝中吸收膨胀，避免隆起、开裂及对相邻结构损害 |
| 2.0.9 | **界面剂** | 增强**预塑嵌缝条与缝槽壁**粘结性能的辅助材料 |

## 使用关系（3.1.1 的组合规则）

- **填缝密封材料**：必须与**背衬条**配合使用
- **预塑嵌缝条**：可**单独**使用（需配**界面剂**）
- **胀缝板**：**专用于胀缝**
