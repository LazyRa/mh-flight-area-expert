# 5 质量检验

## Core Idea

两条：**材料进场检验**（3 份样品、抽检项目精简）+ **施工/维护质量实测**（下凹值、有效深度、粘结、外观、胀缝板、渗水系数）。

## Key Clauses

### 5.1 接缝材料检验
- **5.1.1** 应无**裂纹、气泡、杂质**；包装标识完整清晰（厂家、生产日期、批号），提供**出厂质量证明文件**
- **5.1.2 组批与取样**
  - 以**同一标段、同一生产厂家、同一品种、同一规格**为一个检验批；每批**随机抽取 3 份样品**
  - 填缝密封材料**拌和均匀后取样，每份 ≥1 kg**
  - 预塑嵌缝条**随机截取，每份长度 ≥1 m**
  - 防水背衬条应提供**防水裹覆材料样品，每份 ≥1 kg**
- **5.1.3 送检项目（精简，聚焦与运行安全关联密切且周期短的指标）**
  1. 填缝密封材料：**表干时间、锥入度、低温拉伸量**
  2. 预塑嵌缝条：**尺寸测量、压入拉伸性能现场试验、标准条件下压缩应力**
  3. 防水背衬条：对所采用防水材料做**低温拉伸量**与**冷拉-热压循环下定伸粘结性**

### 5.2 施工和维护质量检验
- **5.2.1** 材料内部应**密实**，表面**低于道面表面**，接缝表面**齐整、连续**，周边**不得有溢料**
- **5.2.2** 预塑嵌缝条在**交叉位置**表面应**连续、齐平**
- **5.2.3 表 5.2.3 实测项目**

| 材料 | 检查项目 | 规定值 |
|---|---|---|
| **填缝密封材料** | **下凹值** | **夏季 1～3 mm；冬季 3～4 mm** |
| | **有效深度** | **聚硫类/聚氨酯类 12～15 mm；硅酮类/改性硅烷类 8～10 mm** |
| | 粘结度 | 与缝壁粘结良好，**无脱开、开裂** |
| | 外观 | 不起泡、不溢油、颜色均匀、饱满密实、缝面整齐、两侧板面干净 |
| **预塑嵌缝条** | **下凹值** | 跑道/快滑：**夏季 3～4 mm、冬季 4～5 mm**；其他区域：**夏季 2～3 mm、冬季 3～4 mm** |
| **胀缝板** | 倾斜 | **≤20 mm** |
| | 弯曲和位移 | **≤10 mm** |
| | 连浆 | **不允许** |
| **防水背衬条** | **渗水系数** | **≤30 ml/min** |

**检查频率**：下凹值、渗水系数均**每 5000 延米抽检 ≥1 处**，每处量一块板的 **3 点**取平均（不足 5000 延米抽检 1 处）

注 a：无倒角时下凹值按低于道面表面计；有倒角时按**低于倒角下沿**计；跑道与快滑设置倒角的，下凹值可**减少 1 mm**

## 常被问到的数值

| 问题 | 答案 |
|---|---|
| 取样份数 / 每份量 | 3 份；填缝料 ≥1 kg、嵌缝条 ≥1 m |
| 填缝料夏季/冬季下凹值 | 1～3 mm / 3～4 mm |
| 有效深度（聚硫、聚氨酯） | 12～15 mm |
| 有效深度（硅酮、改性硅烷） | 8～10 mm |
| 胀缝板倾斜 / 弯曲位移 | ≤20 mm / ≤10 mm |
| 防水背衬条渗水系数 | ≤30 ml/min |
| 抽检频率 | 每 5000 延米 ≥1 处 |
