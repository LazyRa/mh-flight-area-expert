# 第三章 地面车辆和人员跑道侵入防范管理

## Core Idea
针对**跑道侵入**这一最高风险事件，规定组织（跑道安全小组）、制度（防范方案）与运行许可（管制员许可制）三层防范。

## Key Clauses

### 第一节 基本要求（第三十二~三十六条）
- **第三十二条** 机场运营人统一协调管理；对进入（含穿越）**地面保护区**或**机动区**的车辆和人员实施严格管控。
- **第三十三条** 成立**跑道安全小组**（运营人+航司+空管+地服等）；建立例会制度；**跑道运行模式变更、基础设施重大变化或发生跑道侵入事件后**，应及时开展危险源识别与风险评估。
- **第三十四条** 制定**地面车辆和人员跑道侵入防范方案**。
- **第三十五条** 地面保护区/机动区作业人员须**培训考核合格**方可进入；其他人员进入应由符合条件人员**引领和监督**。
- **第三十六条** 定期开展跑道侵入防范宣传教育活动。

### 第二节 运行要求（第三十七~三十九条）
- **第三十七条** 会同空管建立进出制度（协议）与协调机制，确定通信方式、**标准用语**和**车辆呼号**。
- **第三十八条** **跑道开放运行期间**，任何车辆/人员进入地面保护区或机动区作业，**应当向管制员提出申请、经许可后方可进入**，并严格按许可区域和时段作业。
- **第三十九条** 应在管制员限定时间内**及时撤离**；按指定路线撤离至指定位置；撤离后通报管制员；**再次进入须重新申请许可**。

## Thresholds / 关键词
| 项 | 要求 |
|---|---|
| 进入前提 | 培训考核合格（作业人员）/ 引领监督（其他人员） |
| 许可 | 跑道开放期间必须经管制员许可 |
| 风险复评触发 | 运行模式变更 / 基础设施重大变化 / 发生跑道侵入事件 |
