# 第五章 外来物防范管理

## Core Idea
围绕**FOD（外来物）**建立"组织—预防发现移除—事件报告—信息利用"闭环，核心是**道面清扫频次**与**危险源溯源管控**。

## Key Clauses

### 第一节 基本要求（第六十七~六十八条）
- **第六十七条** 成立**外来物防范管理委员会**（运营人+航司+空管+地服等），建立例会制度。
- **第六十八条** 制定**外来物防范管理方案**。

### 第二节 预防、发现和移除（第六十九~七十四条）
- **第六十九条** 系统识别各保障环节可能产生外来物的**危险源**，制定风险防控/缓解措施。
- **第七十条** 保障作业基本要求（禁止项）：① 不得随地丢弃垃圾/废弃物；② 运输或临时存放垃圾须遮盖、不得泄漏逸出；③ 不得在道面直接排放油料/污水/有毒有害物；④ 不得在机坪内进行垃圾分拣。
- **第七十一条 清扫频次**：跑道、滑行道**每半月 ≥1 次全面清扫**；机坪**每日动态清扫、每周 ≥1 次全面清扫**；出现泥浆/砂子/油料等污物**立即清除**。
- **第七十二条** 划定**外来物控制区域**，明确各方巡查职责/程序/方法。
- **第七十三条** 所有飞行区从业人员**主动移除**外来物；配备足够移除设备和收集容器。
- **第七十四条** 人工巡查发现立即移除；自动探测设备发现的按中国民航局规定**分类分级处置**。

### 第三节 事件确认和报告（第七十五~七十六条）
- **第七十五条** 航司/维修单位发现（疑似）外来物损伤 → 及时通报机场运营人。
- **第七十六条** 运营人与航司/维修单位**及时确认**，符合报告标准的按规定报告民航行政机关；三方应就确认和报告工作**签订协议**（明确现场确认部门、人员到达时限、确认内容）。

### 第四节 信息收集、分析与利用（第七十七~七十九条）
- **第七十七条** 对外来物分类，对**中、高危险等级**外来物**溯源**并制定源头管控措施。
- **第七十八条** 制定外来物信息报告程序，建立**外来物数据库**，**至少每季度**分析并编制分析报告。
- **第七十九条** 及时通报委员会成员单位，据此完善防范方案。

## Thresholds
| 项 | 值 |
|---|---|
| 跑道/滑行道全面清扫 | 每半月 ≥1 次 |
| 机坪清扫 | 每日动态 + 每周 ≥1 次全面 |
| 外来物信息分析 | 至少每季度 |
| 溯源范围 | 中、高危险等级外来物 |
