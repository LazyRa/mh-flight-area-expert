# 第六章 目视助航设施运维管理

## Core Idea
目视助航设施（标志/灯光/标记牌/配电/监控等）的**设置须符合 MH5001**，运行期间须**清晰有效**，并规定巡查频次、飞行校验、光学检测与综合评估。

## Key Clauses

### 第一节 基本要求（第八十~八十三条）
- **第八十条** 目视助航设施设置应符合 **MH5001**。**设施范围**：风向标、活动区道面标志、标志物、标记牌、助航灯光、机坪助航设备（含泛光照明、目视停靠引导系统）、助航灯光配电系统（10 kV 以下受电变配电系统+自备应急电源）、助航灯光监视及控制系统。
- **第八十一条** 设立/指定部门负责；**助航灯光机务员须取得应急管理部门颁发的特种作业操作证（电工作业）**。
- **第八十二条** 制定运维管理制度。
- **第八十三条** 与空管在工作制度（协议）中明确助航灯光**开启/关闭/光级变更程序**及通报程序。

### 第二节 运行要求（第八十四~八十九条）
- **第八十四条** 开放运行期间要求：① 标志/标志物清晰有效、位置正确；② 灯光完好率与允许失效时间符合标准、无遮挡物；③ 标记牌清晰可辨、引导无歧义、无遮挡物；④ 风向标/机坪助航设备/配电/监控安全可靠运行；⑤ **备用电源转换时间符合在用跑道运行类别**要求。
- **第八十五条** 对 **PAPI、进近灯光系统、跑道灯光系统**等进行**飞行校验**。
- **第八十六条** 对助航灯光、标记牌、机坪泛光照明的主要**光学性能指标定期检测**。
- **第八十七条** 低能见度运行时加强供配电监控；**停止供配电设施附近的所有施工/维护**，并通知上级供电单位停止影响机场供电的施工维护。
- **第八十八条** 保护飞行区外目视助航设施：① 进近灯光系统场地保护范围内（除 ILS/MLS 天线外）无突出灯具光中心平面的物体；② 危及安全的**非航空地面灯**应熄灭/遮蔽/改装。
- **第八十九条** **至少每 3 年综合评估一次**；**及时评估**情形：新机场/新跑道投用前及运行 3 个月内、发生误滑/刮碰/误入事件、交通密度或跑道运行类别或最大机型变化、运行有关人员反映指示不清。

### 第三节 巡查和维护（第九十~九十五条）
- **第九十条** 制定巡查方案。
- **第九十一条** 巡查 = **每日全面巡查（首次/夜航/中间动态）** + **定期全面步行检查**；**至少 2 人**（含至少 1 名助航灯光机务员）。
- **第九十二条 每日巡查细则**：首次巡查 → 全天开放机场早高峰前；按航班开放的机场首个航班计划时刻前 **30 分钟**；实行**夜航巡查**（跑道进近灯光检查在夜航前完成，其余在灯光开启后 **1 小时内**完成）；精密进近跑道日架次 **≥15** 时对机动区灯光/标记牌**不少于 1 次**中间动态巡查。
- **第九十三条** 定期全面步行检查：**每季度 ≥1 次，间隔 ≤4 个月**。
- **第九十四条** 应急巡查（同第四十三条情形）；**每周 ≥1 次**飞行区周边巡查（发现危及安全的非航空地面灯及时处置）。
- **第九十五条** 制定维护方案；**差异化维护**（紧急抢修/日常维护/预防性维护）。

## Thresholds
| 项 | 值 |
|---|---|
| 首次巡查时限 | 首个航班计划时刻前 30 分钟 |
| 夜航巡查 | 灯光开启后 1 小时内完成 |
| 定期步行检查 | 每季度 ≥1 次，间隔 ≤4 个月 |
| 综合评估周期 | 至少每 3 年 |
| 新设施评估 | 投用前 + 运行 3 个月内 |
| 飞行区周边巡查 | 每周 ≥1 次 |
