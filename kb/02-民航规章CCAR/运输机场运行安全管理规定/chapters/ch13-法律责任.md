# 第十三章 法律责任

## Core Idea
**罚则汇总章**——按违规条款逐条列出处罚主体、处罚方式与罚款幅度。核心是"**哪一条违规 → 多少钱**"的速查。

## 罚款幅度速览
- **最重**：擅自不停航施工 **10–50 万**（第204条）；高管未考核/未培训 **10–20 万**（第188条）
- **常见档**：1–5 万 / 5–10 万
- **轻档**：1 万以下、2 万以下、5 万以下
