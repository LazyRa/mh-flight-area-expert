# 第7章 助航灯光

## Core Idea
目视助航灯光系统按功能分区：进近灯光、PAPI、跑道灯光、滑行道灯光、其他灯光（含跑道状态灯）。灯具须易折、光强受控，非航空灯光不得引起混淆。本章未被四份修订案直接修改。

## Key Clauses
- **7.1 一般规定**：非航空地面灯危及安全时应熄灭/遮蔽/改装（7.1.1）；建立激光飞行保护区域（7.1.2）；混淆灯光处理（7.1.3）；灯具与隔离变压器箱要求（7.1.4）；光强与控制（7.1.5）。
- **7.2 进近灯光系统**：简易进近灯光（7.2.1，A 型单灯/B 型短排灯）；场地范围（7.2.4）。Ⅰ/Ⅱ/Ⅲ类精密进近灯光见 附录 G。
- **7.3 精密进近坡度指示系统 PAPI**：提供坡度引导（7.3.1）；含 APAPI/PAPI，高于坡度见 2 白、低于见 2 红（详见条文）。
- **7.4 跑道灯光系统**：
  - 7.4.1 跑道边灯（恒定发光、可变白光）；7.4.2 跑道入口灯；7.4.3 入口翼排灯；7.4.4 跑道末端灯；7.4.5 跑道中线灯（精密进近/起飞跑道设）；7.4.6 跑道接地带灯（Ⅱ/Ⅲ类设）；7.4.7 简易接地带灯；7.4.8 跑道入口识别灯。
- **7.5 滑行道灯光系统**：中线灯（7.5.1）、边灯（7.5.2，蓝色）、跑道警戒灯（7.5.3，A/B 型）、中间等待位置灯（7.5.4）、停止排灯（7.5.5）、禁止进入排灯（7.5.6）、快速出口指示灯（7.5.7）、除冰坪出口灯（7.5.8）、跑道掉头坪灯（7.5.9）、机位操作引导灯（7.5.10）、逆向反光标志物（7.5.11–7.5.13）。
- **7.6 其他灯光系统**：不适用地区灯（7.6.1）、风向标（7.6.2，夜间照明、轻质量易折）、着陆方向标（7.6.3）、停止道灯（7.6.4）、航空灯标（7.6.5）、盘旋引导灯（7.6.6）、跑道引入灯光（7.6.7）、应急灯光（7.6.8）、**跑道状态灯（7.6.9）**、道路等待位置灯（7.6.10）。

## Reference — 关键灯光设置条件
| 灯光 | 设置条件（节选） |
|---|---|
| 跑道中线灯 | 精密进近跑道及起飞跑道（7.4.5） |
| 跑道接地带灯 | Ⅱ类或Ⅲ类精密进近跑道（7.4.6） |
| 停止排灯 | 跑道视程 <550m 等低能见度运行（7.5.5） |
| 跑道状态灯 | 按运行需要（7.6.9） |

> 灯具光强值、颜色、间距等见 附录 E（接地带灯等）、附录 G（进近灯光）。
