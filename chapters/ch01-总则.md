# 第1章 总则

## Core Idea
本标准规定民用机场飞行区规划、设计、建设和运行的强制性技术要求；飞行区按"指标Ⅰ / 指标Ⅱ"两级划分，所有条款均须以现行修订案（已并入本 skill）为准。

## Key Clauses
- **1.0.1 目的**：规范民用机场飞行区的规划、设计、建设和运行，做到安全适用、技术先进、经济合理。
- **1.0.2 适用范围**：适用于陆地民用机场；在适当情况下也适用于直升机场。不适用于水上机场。
- **1.0.3 分级原则**：机场飞行区应根据拟使用该飞行区的飞机的特性，按**指标Ⅰ**（依据飞机基准飞行场地长度及翼展/主起落架外轮外边距，分 1–4）和**指标Ⅱ**（依据飞机翼展及主起落架外轮外边距，分 A–F）进行分级。
- **1.0.4 【第二修订案新增】**：机场应设置地面活动引导及控制系统（**SMGCS**）。[修订] 此为修订案新增条款，原 1.0.4 顺延为 1.0.5。
- **1.0.5 【原 1.0.4 顺延】**：机场飞行区规划、设计、建设和运行除应符合本标准外，尚应符合国家和行业现行有关标准的规定。

## Key Concepts
- **飞行区指标Ⅰ（1–4）**：由飞机基准飞行场地长度及对应的翼展/主起落架外轮外边距决定，数值越大代表可保障的飞机性能越强。
- **飞行区指标Ⅱ（A–F）**：由飞机翼展及主起落架外轮外边距决定，F 为最大（如 A380 类）。
- **SMGCS**：Surface Movement Guidance And Control Systems，地面活动引导及控制系统（第二修订案新增，见 2.1.83、2.3）。
