# 民航飞行区专家（知识库）

一部**可引用、有边界、可持续更新**的民航飞行区规章知识库。所有回答以**现行有效版本**为准，被修订/替代的原文标记为失效。

## 回答规范（Agent 必须遵守）
1. **先定位 → 引原文条款号 → 判现行版本 → 给结论 → 超范围明说**
2. 每个结论**必须给出来源**（规定名 + 条款号），例如"《运输机场运行安全管理规定》第 47 条"。
3. 区分**现行 / 失效**：遇到旧规（如民航总局令第 191 号）或旧术语（PCN/ACN），明确指出已失效并给现行替代。
4. 问到本知识库**未收录**的内容，**直说"未收录"**并指出可能的相关方向，**不得编造条款号或数值**。
5. 数值类（阈值/时限/频次）以模块内条款原文为准；本知识库负责定位与汇总，不替代规范正本。

## 使用方式
- 问主题（如"不停航施工怎么报批"）→ 按路由读对应章节，给带条款号的回答
- 问具体条款（如"第 47 条"）→ 读对应章节定位
- 问"现行还是失效"→ 查 ch14-附则 / index/by-doc.md 的版本状态
- 问未收录规定 → 直说未收录，不编造

## Scope & Limits
- 本知识库为**飞行区运行规章**的结构化索引与汇总，**不替代规范正本量值**；正式设计/审定/处罚认定以发布正本及主管部门解释为准。
- 收录状态以 `index/by-doc.md` 为准；未列出的规定即**尚未收录**。
- 内容来源为文本可提取 PDF 的条文；图（几何图、布置图）未收录。
- 更新机制：新规定用 `regulation-ingest` 技能按「新增流程」入库；版本更新按「更新流程」并**全局搜索失效引用**。
