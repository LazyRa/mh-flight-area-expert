# 第12章 标示障碍物的目视助航设施

## Core Idea
位于障碍物限制面内（及特定情形下限制面外）的物体，须用标志和/或障碍灯标示，以保障航空安全。本章未被四份修订案直接修改（但适用对象依 ch05 限制面定义）。

## Key Clauses
- **12.1 应予标示的物体**：
  - 12.1.1 位于障碍物限制面内的物体，其标志和灯光标示应符合要求。
  - 12.1.2 位于障碍物限制面外、但对飞行运行造成限制或影响的物体，亦应标示。
- **12.2 物体的标志和（或）灯光标示**：
  - **12.2.1 一般要求**：标志与灯光设置规则（详见 附录 J 间距、图样）。
  - **12.2.2 可移动物体**：如施工机械等，按运行需要标示。
  - **12.2.3 固定物体**：应涂反差鲜明相间色带（按物体边长分级，如 1/7–1/21，见 12.2.3 第 3 款及表）；设置障碍灯（中光强/高光强，闪光频率 20–60 fpm 等，见相关表）。
  - **12.2.4 风力发电机**：边界识别、同步闪光（12.2.4）。
  - **12.2.5 架空电线、电缆及支撑塔架**：标志与灯光标示（12.2.5）。

## Reference — 固定物体色带与障碍灯（节选）
- 色带宽度按物体最长边分级（例：≤210m → 1/7；210–270 → 1/9；…570–630 → 1/21，详见 12.2.3）。
- 障碍灯类型按物体高度与背景选（低光强/中光强 A/B/高光强 A/B/C），闪光频率与光强见 12.2.3 相关表（20–60 fpm、40–200 cd 等）。

> 具体灯光光强、颜色、间距与图样见 **附录 J**；物体高度分界见 12.2.3 各表。
