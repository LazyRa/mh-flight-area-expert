# 第二章 机场运行安全保障

## Core Idea
规定机场运行安全的**组织架构、人员资质与基本保障要求**——从上到下搭班子（委员会、部门、指挥中心），从人到物明确资质与底线保障。

## Key Clauses

### 第一节 基本管理要求（第九~十七条）
- **第九条** 成立**机场运行安全管理委员会**（运营人主要负责人任主任；成员含航司/空管/地服等），6 项职责；**每半年至少召开一次**。
- **第十条** 成立**安全生产委员会**，**至少每月召开一次**安全生产会议。
- **第十一条** 设立**机场飞行区运行安全管理部门**，承担委员会办公室职责，具体负责九大运行安全业务。
- **第十二条** 设立**机场运行指挥中心**；**年起降架次 ≥1.5 万**的机场应当设立。
- **第十三条** 取得机场运营许可证的运输机场应建立并实施**安全管理体系（SMS）**，纳入机场使用手册。
- **第十四条** 定期评估 SMS 符合性/有效性；定期开展 SMS 审核。
- **第十五条** 定期评估机场运行安全状况（管理工作实施情况 + 设施设备状况）；评估可自行或委托，结束后形成评估报告。
- **第十六条** 建立**机场资料库**（法律法规规章标准、ICAO 附件、设计图纸、制度手册程序、设施设备技术资料与运维记录）。
- **第十七条** 建立运行安全工作记录，确保真实/完整/准确，**至少保存 5 年**。

### 第二节 人员资质及培训（第十八~二十四条）
- **第十八条** 主要负责人/安全生产分管负责人/运行安全分管负责人**岗位空缺不得超过 3 个月**，且主要负责人与安全生产分管负责人**不得同时空缺**。
- **第十九条** 建立**飞行区从业人员资质和培训管理制度**；培训档案**保存不少于 3 年**。
- **第二十条** 高管参加培训考核并合格；经历要求：主要负责人中至少一名**≥5 年民航经历**；安全生产/运行安全分管负责人**≥3 年**相关经历；飞行区运行安全管理部门主要负责人**≥2 年**。
- **第二十一条** **持证上岗**岗位：运行指挥员、场务员、助航灯光机务员、旅客登机桥操作员、民航专用车辆操作员等。
- **第二十二条** 驻场单位人员培训；**复训周期不得超过 13 个月**。
- **第二十三条** 建立**飞行区从业人员违章记分管理制度**（重新培训考核、暂停作业等）。
- **第二十四条** 佩带**控制区通行证**、穿工作服并配**反光标识**；配备防护用品与工间休息场所。

### 第三节 基本保障要求（第二十五~三十一条）
- **第二十五条** 会同空管等评估、改进、优化**地面活动引导与控制体系**（SMGCS 对应）。
- **第二十六条** 低能见度运行机场应制定**低能见度运行保障程序**；运行期间**停止**活动区可能影响秩序的常规巡查/维护/施工。
- **第二十七条** 制定雷雨、大风、降雪等**特殊天气保障预案**。
- **第二十八条** 航班备降：完善基础设施、预留足够备降机位、**不得无故拒绝航班备降**。
- **第二十九条** **未经民航行政机关批准，不得擅自新增或改变活动区场地、目视助航设施的功能及特性**。
- **第三十条** 制定跑道/滑行道/机坪**临时关闭管理规定**；临时关闭应按 **MH5001** 设置标志（灯）；**不得擅自关闭**。
- **第三十一条** 新建/改扩建跑道、平行滑行道未投用前，应设**关闭标志、不适用地区标志物和灯**，并提供航空情报原始资料。

## Thresholds
| 项 | 值 |
|---|---|
| 运行安全管理委员会会议 | 每半年 ≥1 次 |
| 安全生产委员会会议 | 每月 ≥1 次 |
| 设立运行指挥中心门槛 | 年起降架次 ≥1.5 万 |
| 关键负责人空缺 | ≤3 个月；主/安负责人不得同时空缺 |
| 工作记录保存 | ≥5 年 |
| 培训档案保存 | ≥3 年 |
| 复训周期 | ≤13 个月 |
| 主要负责人民航经历 | ≥5 年（至少一名） |
