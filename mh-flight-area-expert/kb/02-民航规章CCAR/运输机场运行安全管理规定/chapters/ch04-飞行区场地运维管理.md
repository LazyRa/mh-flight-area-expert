# 第四章 飞行区场地运维管理

## Core Idea
本规定**技术含量最高**的一章：明确飞行区场地的物理特性须符合 **MH5001**，并规定**巡查频次、损坏处置阈值、跑道表面状况评估与通报**等运行尺度。

## Key Clauses

### 第一节 基本要求（第四十~四十四条）
- **第四十条** 跑道/滑行道/机坪的几何构型、平面尺寸、道面状况等物理特性及其**有限超载使用应符合 MH5001**；超载使用须**征得机场运营人同意**。
- **第四十一条** 确保道面（含道肩）、升降带、跑道端安全区（RESA）和排水设施**持续处于适用状态**。
- **第四十二条** 设立/指定部门负责，配备与运行量相适应的场务员及设施设备。
- **第四十三条** 制定飞行区场地运维管理制度。
- **第四十四条** 定期对道面、飞机荷载桥梁、下穿通道**综合评价**；破损加剧/大面积沉降/突发沉陷时**专项评价**；特殊地质与高填方边坡持续监测。

### 第二节 巡查和维护（第四十五~五十九条）
- **第四十六条** 巡查 = **每日全面巡查（首次 + 中间动态）** + **定期全面步行检查**。
- **第四十七条 每日全面巡查细则**：
  - 跑道首次巡查 → 全天开放机场**早高峰前**完成；按航班开放的机场 **首个航班计划时刻前 30 分钟**完成。
  - 跑道中间动态巡查：日着陆/起飞架次 **≥15 → 不少于 3 次**；**<15 → 不少于 1 次**。
  - 驾车人工巡查：**至少 2 人**（含至少 1 名场务员），**车速 ≤45 km/h**；完成后通报管制员并记录日志。
- **第四十八条** 定期全面步行检查：**每季度 ≥1 次，最大间隔 ≤4 个月**。
- **第四十九条** 升降带、RESA、滑行带内土面区（含防吹坪）**每日 1 次**全面巡查。
- **第五十条** 雨季前至少 1 次排水设施全面检查；暴雨期间随时巡查；雨后检查。
- **第五十一条** 高温/大风等增加巡查；影响运行安全及时通报管制员。
- **第五十二条** 不停航施工/维护作业结束后检查相关区域。
- **第五十三条** **应急巡查**情形：① 机组/管制员通报事件或异常；② 应急救援响应结束或残损航空器搬移结束；③ 地震等地质灾害后。
- **第五十四条 立即通报塔台暂停起降的跑道损坏情形**：
  1. 水泥混凝土道面断裂（错台或局部松动）；
  2. 未断裂但**错台 ≥5 mm**；
  3. 掉块**直径（长边）≥12 cm**；
  4. 掉块 <12 cm 但**深度 ≥7 cm** 或**坡度 ≥45°**；
  5. 沉陷或导致平整度不符的突发性沉降。
- **第五十五条** 需处理但暂不影响安全的轻微情形 → 报告并**增加检查频次**。
- **第五十七条** 活动区道面**全生命周期管理**；**差异化维护** = 紧急抢修 + 日常维护 + 预防性维护。
- **第五十八条** 严重损坏（第54条）→ **立即抢修**；轻微损坏（第55条）→ **24 小时内维护**；**每年至少 1 次**跑道道面损坏紧急抢修演练。

### 第三节 跑道表面状况评估和通报（第六十~六十六条）
- **第六十条** 定期评估干跑道橡胶沉积/磨光对摩阻特性的影响；配备**自湿装置**的连续摩擦系数测试设备。
- **第六十一条** 摩擦系数测试：某段（累计长度 **>100 m**）低于最低摩阻力水平时 → 立即通报塔台，并报航空情报。
- **第六十二条** 清除橡胶的情形：① 摩擦系数（任意连续 100 m）低于维护目标值；② 多处（累计 >100 m）低于最小摩阻值；③ 接地带中线两侧被橡胶覆盖约 **80%** 且呈光泽。
- **第六十三条** 持续监测/评估/通报**湿和污染跑道**表面状况（跑道状况代码 + 污染物种类/深度/覆盖范围）。
- **第六十四条** 以**跑道每 1/3 段**污染物为基础，结合摩擦系数、机组报告的刹车效应、车辆控制/减速、气温/道温/露点/风速风向等综合判断。
- **第六十五条** 湿和污染跑道运行期间，保障**跑道标志和助航灯光清晰可见**。
- **第六十六条 暂停起降情形**：① 积水或雪浆 **>13 mm**；② 跑道标志/助航灯光被冰雪覆盖且除冰雪后仍不能提供目视参考；③ **跑道状况代码 ≤1**；④ 飞行机组报告刹车效应**"差"或"极差"**；⑤ 航空器偏出/冲出跑道。

## Thresholds（关键数值）
| 项 | 值 |
|---|---|
| 跑道中间动态巡查 | 日架次 ≥15 → ≥3 次；<15 → ≥1 次 |
| 驾车巡查 | ≥2 人（含 1 场务员），车速 ≤45 km/h |
| 定期步行检查 | 每季度 ≥1 次，间隔 ≤4 个月 |
| 立即暂停起降（错台） | ≥5 mm |
| 立即暂停起降（掉块） | 长边 ≥12 cm；或 <12cm 但深 ≥7cm / 坡 ≥45° |
| 轻微损坏维护时限 | 24 小时内 |
| 紧急抢修演练 | 每年 ≥1 次 |
| 摩阻预警区段 | 累计 >100 m |
| 暂停起降（积水/雪浆） | >13 mm |
| 暂停起降（跑道状况代码） | ≤1 |
