# 第八章 机场净空保护管理

## Core Idea
净空保护以 **MH5001 的障碍物限制面**为技术基础，规定净空图管理、障碍物限制、巡查频次与疑似障碍物/空飘物处置。

## Key Clauses

### 第一节 基本要求（第一百二十~一百二十三条）
- **第一百二十条** 设立/指定部门负责净空管理，配备净空管理巡查人员与设备。
- **第一百二十一条** 制定净空管理制度。
- **第一百二十二条** 依照 **MH5001** 和本场远期总体规划，制作**机场净空保护区域图、机场障碍物限制面图**，及时报送县级以上地方政府有关部门备案；总体规划调整或跑道基础数据变化时相应调整。
- **第一百二十三条** 协调配合地方政府制定发布净空保护具体管理规定。

### 第二节 障碍物的限制（第一百二十四~一百二十五条）
- **第一百二十四条** 评估净空保护区域内活动对飞行安全的影响，协助地方政府划定**禁止/限制活动的区域、高度和要求**并公布。
- **第一百二十五条** 会同驻场单位确保**升降带、跑道端安全区、精密进近跑道无障碍物区（OFZ）、滑行带、净空道**等区域内设施设备的设置位置、易折性和高度**持续符合 MH5001**。

### 第三节 净空巡查和情况处置（第一百二十六~一百三十一条）
- **第一百二十六条** 制定净空巡查方案。
- **第一百二十七条 巡查频次**：全区域**每月 ≥1 次**；重点区域**每周 ≥1 次**；**无障碍区域及距跑道端 1.5 km 进近面以内区域每日 ≥2 次**。
- **第一百二十八条** 发现/接报疑似障碍物 → 立即测量评估；确属障碍物：① 立即制止并消除影响；② 不能立即消除且影响飞行程序/运行最低标准的，采取临时调整等管控措施、通报空管、报航空情报、报地方政府处置。
- **第一百二十九条** 空飘物 → 会同空管、机组评估后**分类分级处置**。
- **第一百三十条** 加强**障碍物图-A 型区域**巡查：新增/扩展物体超过起飞航径区障碍物鉴别面坡度 **1.2%** 且低于起飞爬升面坡度的，及时报航空情报。
- **第一百三十一条** 建立**净空管理档案**（图纸、巡查记录、障碍物测量与处置资料、审核核查资料等）。

## Thresholds
| 项 | 值 |
|---|---|
| 净空全覆盖巡查 | 每月 ≥1 次 |
| 重点区域巡查 | 每周 ≥1 次 |
| 无障碍区域及跑道端 1.5 km 进近面内 | 每日 ≥2 次 |
| 障碍物鉴别面坡度 | 1.2% |
