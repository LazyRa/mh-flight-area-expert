# 第十章 场道除冰雪管理

## Core Idea
冰雪天气下的场道保障：**组织（除冰雪管理委员会）+ 预案 + 设备配备**按机场年起降架次分级，并规定作业中对航空器与助航设施的保护距离。

## Key Clauses

### 第一节 基本要求（第一百五十二~一百五十六条）
- **第一百五十二条** 有降雪/道面结冰情况的机场应成立**机场除冰雪管理委员会**（运营人+航司+空管+地服等）。
- **第一百五十三条** 制定**场道除冰雪预案**，内容包括：① 委员会人员组成；② 责任单位/责任人及职责；③ 启动程序；④ 信息传递与通信方式；⑤ 不同雪情优先清除的跑道/滑行道/机坪区域及顺序；⑥ 针对干雪/湿雪/雪浆/冰及不同气温的作业程序与车辆设备人员组合；⑦ 设备故障应急处置程序；⑧ 车辆设备及物资储备清单。应定期演练评估、总结复盘、动态修订。
- **第一百五十四条** 明确优先清除的跑道/滑行道/机坪，保障能力与计划航班量相适应。
- **第一百五十五条** 根据场地面积、气候条件并参照过去 5 年冰雪情况配备设备、物资和人员。
- **第一百五十六条 降雪期间**：当日最后一个计划航班结束前应**不间断除雪**。**除冰雪设备配备（单次可清除跑道宽度）**：
  - 年起降架次 **≥4 万** → **40 米**（保障机场持续开放）；
  - 年起降架次 **1 万（含）~4 万** → **20 米**（保证大雪及以下按航班计划持续开放）；
  - 年起降架次 **<1 万** → **10 米**（保证中雪及以下按航班计划持续开放）。

### 第二节 作业要求（第一百五十七~一百六十二条）
- **第一百五十七条** 入冬前准备：协调会议、人员培训、车辆设备维护保养、**模拟演练（一般每年入冬前 ≥3 次）**、除冰液物资检查、确定堆雪场地。
- **第一百五十八条** 及时清除跑道/滑行道/机坪/道肩积雪；机坪堆放冰雪不得影响运行且不得被气流吹起；雪停后及时全部清除。
- **第一百五十九条** 及时清除运行跑道/滑行道/机坪上**目视助航设施的冰雪**；滑行道/机坪积雪厚度 **<5 cm** 时优先清除标志及遮挡标记牌/灯光的积雪。
- **第一百六十条** 作业中保护跑道/滑行道边灯等助航设施；**航空器周边 5 米范围内不得使用大中型除雪设备**；雪冰临时堆放高度与**发动机底端/螺旋桨 ≥40 cm**、与**机翼 ≥1 m**。
- **第一百六十一条** 利用航班间隙除冰雪应指定**现场指挥员**并与空管保持联络；所有除冰雪车辆与其建立通信；常降雪多跑道机场应配置**除冰雪指挥调度系统**。
- **第一百六十二条** 关闭/暂停使用区域除冰雪完毕经检查合格后，及时将开放区域通报管制员。

## Thresholds
| 项 | 值 |
|---|---|
| 设备单次清雪宽度 | ≥4万架次→40m；1万~4万→20m；<1万→10m |
| 入冬前演练 | 一般每年 ≥3 次 |
| 优先清雪条件 | 滑行道/机坪积雪厚度 <5 cm |
| 大中型除雪设备限制 | 航空器周边 5 米内禁用 |
| 堆雪高度 | 与发动机/螺旋桨 ≥40 cm；与机翼 ≥1 m |
