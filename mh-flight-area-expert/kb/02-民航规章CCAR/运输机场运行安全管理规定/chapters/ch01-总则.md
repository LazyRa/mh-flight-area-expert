# 第一章 总则

## Core Idea
确立《运输机场运行安全管理规定》的立法依据、适用范围、管理体制与责任分工，核心原则是**机场运营人对机场运行安全负统一协调管理责任**，各驻场单位按职责共担。

## Key Clauses
- **第一条** 立法依据：《中华人民共和国民用航空法》《中华人民共和国安全生产法》《民用机场管理条例》等法律、行政法规。
- **第二条** 适用范围：运输机场（含军民合用机场民用部分）的运行安全管理。**"机场运行安全"涵盖**：地面车辆和人员跑道侵入防范、飞行区场地运维、外来物防范、目视助航设施运维、机坪运行、净空保护、鸟击及动物侵入防范、场道除冰雪、不停航施工等。航空安保另按相关法规执行。
- **第三条** 管理体制：中国民航局 → 全国统一监督管理；民航地区管理局 → 辖区监督管理；两者统称**民航行政机关**。
- **第四条** 机场运营人 → 对运行安全统一协调、管理，维护正常秩序，承担相应责任。
- **第五条** 机场运营人应与航司、空管、地服等驻场单位签订**安全生产管理协议**，明确职责/风险管控/隐患治理措施，并指定**专职安全生产管理人员**。
- **第六条** 全员安全生产责任制；推动**安全管理体系（SMS）与安全风险分级管控、隐患排查治理双重预防机制有机融合**；鼓励应用新技术。
- **第七条** 飞行区内任何单位和个人应遵守法律法规规章、经批准的**机场使用手册**、以及各专业管理委员会审定通过的制度；机场运营人应组织制定委员会章程和议事规则。
- **第八条** 机场集团（公司）及其全资/控股/参股机场公司共同保障运行安全；承担运营人职责的集团应与所属分公司签安全生产管理协议；受委托/授权管理的机场应明确安全投入与责任。

## Thresholds / 关键词
| 项 | 值 |
|---|---|
| 责任主体 | 机场运营人（统一协调管理） |
| 监管主体 | 中国民航局 / 民航地区管理局（民航行政机关） |
