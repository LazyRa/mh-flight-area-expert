# 第5章 障碍物限制面

## Core Idea
为起降安全，机场周围划设一组想象的"限制面"，其内的物体受控。限制面分 8 类（内水平面、锥形面、进近面、内进近面、过渡面、内过渡面、复飞面、起飞爬升面），按跑道类型决定设立哪些。

## Key Clauses
- **5.1 障碍物限制面**（几何定义，详见 图 5.1.x、尺寸/坡度见 表 5.2.7）：
  - **5.1.2 内水平面**：机场及其周围以上的水平面。
  - **5.1.3 锥形面**：从内水平面周边起向上、向外倾斜的面。
  - **5.1.4 进近面**：跑道入口前的一个倾斜平面或几个平面的组合。
  - **5.1.5 内进近面**：进近面中紧靠跑道入口前的一块长方形部分。
  - **5.1.6 过渡面**：沿升降带边缘和部分进近面边缘，坡度向上、向外倾斜到内水平面的面。
  - **5.1.7 内过渡面**：类似过渡面但更靠近跑道。
  - **5.1.8 复飞面**：位于跑道入口后规定距离、在两侧内过渡面之间延伸的面。
  - **5.1.9 起飞爬升面**：跑道端或净空道端外的一个倾斜平面或其他规定的面。
- **5.2 障碍物限制要求**：
  - **5.2.1** 对障碍物的限制应符合下列要求。
  - **5.2.2** 非仪表跑道应设立：内水平面、锥形面、进近面、过渡面。
  - **5.2.3** 非精密进近跑道应增设：内进近面、复飞面（即较非仪表跑道更严）。
  - **5.2.8 / 5.2.9** 在限制范围内超过起飞爬升面/进近面/过渡面/锥形面等的物体，以及新物体扩建，按更严格要求控制。
  - **5.2.10** 除功能需要设在升降带上的易折物体外，固定物体不应穿透内水平面/锥形面等。
  - **5.2.12** 高压输电线及塔架应按障碍物限制面评估控制（5.2.14）。
- **5.3 限制面以外物体**：仍可能对运行造成限制/影响，须评估。
- **5.4 其他物体**：未高出进近面但对目视/非目视助航设备有不良影响的，宜予处理。

## Reference — 限制面设立规则（按跑道类型）
| 跑道类型 | 应设立的障碍物限制面 |
|---|---|
| 非仪表跑道 | 内水平面、锥形面、进近面、过渡面 |
| 非精密进近跑道 | 上述 + 内进近面、复飞面 |
| 精密进近跑道（仪表） | 全部 8 类（含内过渡面） |
